# 수강 기간과 학습 현황 보기

> **검토용 가이드** · 실제 서비스 화면·동작 확인과 이미지 보완이 남아 있습니다. 본문의 실행 보류·주의사항을 먼저 확인하세요.

<figure><img src="../.gitbook/assets/branding/page-headers/learning/access-period-and-progress-v2.png" alt="수강 기간과 학습 현황 확인하기 대표 이미지"><figcaption></figcaption></figure>

**마이페이지 → 내 학습 → 수강중 강좌**에서 강좌별 기간과 진도율을 확인합니다. 수업별 완료 여부는 강의실의 PC **커리큘럼**, 모바일 **목차**에서 확인합니다.

**확인 순서:** 강좌 찾기 → 수강 종료일 → 완료 수업 수와 목차. 진도율 100%나 완료 표시는 무제한 이용·기간 연장·환불 가능 여부를 뜻하지 않습니다. 목록 필터, 현재 이용 가능 여부, 재생 위치와 학습 완료를 읽는 방법은 아래에서 따로 안내합니다.

## 시작 전 확인 <a href="#before-you-start" id="before-you-start"></a>

| 확인할 것 | 내용 |
| --- | --- |
| 학원 사이트·계정 | 강좌를 구매하거나 수강권을 받은 사이트와 계정이 맞는지 확인합니다 |
| 강좌·수업 제목 | 같은 이름의 강좌가 있으면 학원 안내와 대조합니다. 묶음 상품 전체와 개별 강좌의 현황을 혼동하지 않습니다 |
| 구매 전/후 기간 | 상품 소개의 수강기한과 내 강좌의 실제 종료일은 구분합니다. [상품 확인 안내](../purchase/product-and-access-period.md)를 참고합니다 |
| 영상 종류 | 일반 업로드 영상과 YouTube/Vimeo 외부 영상은 기록 방식이 다릅니다 |
| 확인 목적 | 기간·학습 현황을 읽는 절차입니다. 기간 연장·권리 복구·완료 수정이나 환불 신청을 실행하지 않습니다 |

## 1. 내 강좌 목록 열기 <a href="#step-1" id="step-1"></a>

1. 학원 사이트의 **마이페이지 → 내 학습 → 수강중 강좌**를 엽니다.
2. 먼저 **전체**를 선택해 강좌 제목을 찾습니다. 목록 아래 다른 페이지가 있으면 함께 확인합니다.
3. 필요한 경우 **수강중·완료·만료** 필터로 범위를 좁힙니다. 필터를 바꾸면 첫 페이지부터 표시됩니다.
4. 강좌 카드의 **진도율·N일·~YYYY.MM.DD**를 확인합니다. 기간 항목이 없는 경우도 따로 구분합니다.

강좌가 안 보이거나 구매/직접 지급 여부부터 확인해야 한다면 [내 강의 찾고 수강 시작하기](find-course-and-start.md)를 먼저 참고합니다. 이 목록에 모든 취소·삭제 이력이 남는 것은 아닙니다.

> **화면 예시 준비 중** · 기간과 학습 현황은 내 강좌 목록에서 확인합니다.

> **동작 예시 준비 중** · 목록 필터로 강좌를 찾아봅니다.

## 2. 수강 기간과 종료일 읽기 <a href="#step-2" id="step-2"></a>

<figure><img src="../.gitbook/assets/branding/learning-period-progress-illustration-v1.png" alt="수강 일정 달력과 학습 체크리스트"><figcaption></figcaption></figure>

| 목록에서 보이는 것 | 읽는 방법 | 같은 뜻이 아닌 것 |
| --- | --- | --- |
| N일 | 현재 수강 등록 시점부터 종료 시점까지의 기간을 일수로 표시 | 오늘부터 남은 일수, 반드시 첫 재생일부터 시작하는 기간 |
| ~YYYY.MM.DD | 해당 강좌의 종료일 표시 | 그날 23:59까지 재생된다는 보장, 정확한 종료 시각 |
| 기간/종료일 항목 없음 | 현재 목록에 표시할 종료일이 없는 상태 | 모든 강좌·자료의 평생/무제한 이용 보장 |
| 만료된 카드의 흐린 표시 | 기간/접근 상태와 함께 확인할 표시 | 학습 기록 삭제, 모든 권리와 자료가 동시에 같은 상태라는 증명 |

예를 들어 **30일**은 매일 줄어드는 남은 날짜 표시가 아닙니다. 남은 기간을 확인할 때는 종료일을 먼저 보고, 정확한 마감 시각이 필요하면 학원 안내를 확인합니다. 날짜만으로 시간대나 자정 마감을 임의로 계산하지 않습니다.

상품의 수강기한, 수강권 지급 시점, 첫 재생 시점이 모두 같다고 가정하지 않습니다. 연장·재지급 안내를 받았는데 종료일이 다르면 강좌명과 현재 표시를 학원에 전달합니다. 학생 화면에서 기간을 직접 수정하거나 **다시 구매하기**로 연장을 시험하지 않습니다.

> **화면 예시 준비 중** · N일은 남은 날짜 수가 아니며 종료일을 함께 확인합니다.

## 3. 목록 필터와 실제 이용 권한 구분하기 <a href="#step-3" id="step-3"></a>

**수강중·완료·만료는 목록을 찾기 위한 필터**입니다. 필터 결과만으로 현재 재생·자료 다운로드·질문 작성이 모두 가능한 것으로 판단하지 않습니다.

| 상황 | 확인할 것·다음 행동 |
| --- | --- |
| 수강중 필터인데 만료처럼 보여요 | 카드의 종료일·현재 안내를 함께 확인합니다. 저장된 목록 상태와 시각 기준 접근 판정이 다를 수 있으므로 전체에서도 찾습니다 |
| 완료에 있는 강좌를 다시 보고 싶어요 | 완료와 기간은 별도입니다. 기간·실제 진입 가능 여부를 확인하고, 수강 진입은 [내 강의 찾고 수강 시작하기](find-course-and-start.md)를 참고합니다 |
| 만료된 강좌의 진도가 남아 있어요 | 남아 있는 학습 현황과 재생 권한은 별도입니다. 기록이 보인다고 일반 수업을 다시 볼 수 있는 것은 아닙니다 |
| 취소/사용 중지 안내 뒤 강좌가 없어졌어요 | 전체 목록에도 모든 취소·삭제 이력이 표시되는 것은 아닙니다. 학원이 안내한 수강권 상태를 문의합니다 |
| 같은 강좌에 수강권이 여러 개예요 | 목록 표시만으로 권리별 기간 합산·자동 연장·기록 통합을 단정하지 않습니다. 대상 계정/강좌를 학원에 확인합니다 |

만료 뒤에도 일부 목차/기록이 남거나 미리보기만 허용될 수 있지만, 목록에서 만료 강의실에 항상 들어갈 수 있다는 뜻은 아닙니다. 이용 보류(동결)·취소 상태나 수강권이 여러 개일 때의 실제 제한과 화면은 아직 확인이 필요합니다. 직접 주소를 입력해 제한을 우회하지 않습니다.

## 4. 강좌 전체 진도율 읽기 <a href="#step-4" id="step-4"></a>

목록의 `진도율 : 3강/10강 (30%)`는 전체 10개 수업 중 완료로 기록된 수업이 3개라는 뜻입니다. **전체 영상 시간의 30%를 시청했다는 의미가 아닙니다.**

| 표시 | 의미 |
| --- | --- |
| 앞의 수업 수 | 완료로 기록된 수업 수 |
| 뒤의 수업 수 | 해당 강좌의 전체 수업 수 |
| 퍼센트·진도 막대 | 완료 수업 수 ÷ 전체 수업 수를 기준으로 한 반올림 값 |

수업마다 길이가 달라도 강좌 진도율은 시간 가중 평균이 아닙니다. 일부를 시청했지만 아직 완료되지 않은 수업은 완료 수업 수에 포함되지 않을 수 있습니다. 수업이 추가/변경되면 전체 수업 수와 비율이 달라질 수 있으므로 퍼센트만 비교하지 않습니다.

퍼센트는 반올림된 값입니다. **100%만으로 모든 수업 완료를 단정하지 말고 완료 수업 수와 목차 표시를 함께 확인**합니다. 진도율이 100%라고 해서 곧바로 완료 필터로 이동하거나 수료증이 발급되는 것은 아닙니다.

> **화면 예시 준비 중** · 강좌 진도율은 완료한 수업 수 기준입니다.

## 5. 목차에서 수업별 완료 여부 확인하기 <a href="#step-5" id="step-5"></a>

1. 수강 가능한 강좌를 열어 강좌·수업 제목이 맞는지 확인합니다. 진입 방법은 [내 강의 찾고 수강 시작하기](find-course-and-start.md), 패널 조작은 [PC·모바일에서 영상 보기](watch-on-desktop-and-mobile.md)를 참고합니다.
2. PC에서는 **커리큘럼**, 모바일에서는 **목차**를 엽니다.
3. 상단의 **진도율 완료 수업 수/전체 수업 수·퍼센트**를 확인합니다. 묶음 전체가 아니라 현재 표시된 강좌명을 기준으로 읽습니다.
4. 섹션을 펼쳐 수업 제목 옆 **완료 체크 표시**를 확인합니다. 현재 선택된 수업의 강조색은 완료 여부와 다릅니다.
5. 확인을 마쳤으면 **패널 닫기**로 돌아갑니다. 현황을 확인하기 위해 **자료**를 누르거나 다른 수업을 반복 재생할 필요는 없습니다.

수업별 시청 퍼센트의 별도 숫자 표시 여부는 아직 확인이 필요합니다. 완료 체크가 없다고 한 번도 시청하지 않았다는 뜻은 아닙니다. 화면 아래 **수강완료**도 직접 누르는 버튼이 아니라 해당 수업의 상태 표시입니다.

> **화면 예시 준비 중** · 완료 체크와 현재 선택된 수업을 구분합니다.

## 6. 재생 위치·학습 완료·외부 영상 구분하기 <a href="#step-6" id="step-6"></a>

| 확인하는 정보 | 의미·주의할 점 |
| --- | --- |
| 일반 영상 재생 막대의 현재 위치 | 지금 보고 있는 지점입니다. 끝으로 이동했다고 앞 구간까지 시청한 것은 아닙니다 |
| 일반 영상 이어보기 위치 | 저장된 위치가 있는 미완료 수업에서 복원을 시도합니다. 정확한 기기 간 복원·저장 성공을 보장하지 않습니다 |
| 일반 영상의 완료 체크/수강완료 | 누적 시청 기록과 완료 판정에 따른 상태입니다. 직접 누르는 완료 버튼·재생 막대 100%와 다릅니다 |
| 외부 영상의 시청 전·시청 시작·시청 완료 | 표시되는 경우 재생 시작/종료 이벤트에 따른 재생 여부입니다. 전 구간 시청이나 일반 영상 수강완료와 같지 않습니다 |
| 외부 영상의 진도율·이어보기 | YouTube/Vimeo 영상은 클킷에서 일반 영상과 같은 진도율/이어보기를 저장·제공하지 않습니다 |

외부 영상에 **시청 완료**가 보여도 일반 영상의 완료 수업 수나 강좌 진도율이 같은 방식으로 올라간다고 기대하지 않습니다. 외부 서비스 자체의 재생 기록도 클킷 기록과 구분합니다.

학습 진도는 구매 상품의 **환불용 이용률·이용 근거**와 별도입니다. 진도 0%/체크 없음이 미이용·전액 환불 가능을, 100%가 환불 불가를 자동 확정하지 않습니다. 환불은 학원의 확인된 정책과 해당 주문의 판정을 따릅니다.

> **화면 예시 준비 중** · 재생 위치·학습 완료·외부 시청 상태는 다른 정보입니다.

## 7. 현황이 예상과 다를 때 <a href="#step-7" id="step-7"></a>

| 상황 | 확인할 것·다음 행동 |
| --- | --- |
| 방금 봤는데 진도/체크가 그대로예요 | 현재 수업·영상 종류와 확인한 시각을 기록합니다. 기록 전송/저장과 목록·목차 반영 시점이 같지 않을 수 있습니다 |
| 목록과 강의실 수치가 달라요 | 같은 강좌인지, 완료/전체 수업 수가 같은지, 각각 언제 확인했는지 비교합니다. 즉시 일치하거나 특정 초 안에 갱신된다고 보장하지 않습니다 |
| 끝까지 이동했는데 완료가 아니에요 | 재생 위치 이동과 실제 시청 기록은 다릅니다. 끝 구간 반복 이동·중복 재생·재진입으로 완료를 만들지 않습니다 |
| 외부 영상 완료인데 강좌 진도는 안 올라요 | 외부 재생 여부와 일반 진도 계산 차이를 먼저 확인합니다. 외부 상태만으로 진도 오류를 확정하지 않습니다 |
| 새 수업이 생긴 뒤 진도율이 달라졌어요 | 전체 수업 수·목차와 변경 안내를 확인합니다. 비율 변화만으로 기존 학습 기록이 삭제됐다고 단정하지 않습니다 |
| 해당 상태의 강좌가 없습니다. | 전체·다른 페이지와 현재 계정을 확인합니다. 필터 결과 없음과 수강권 없음은 별도입니다 |
| 수강 중인 강좌를 불러오지 못했습니다. | 조회 오류입니다. 빈 목록으로 해석하거나 재구매하지 말고 시각·문구를 학원에 전달합니다 |
| 만료·권한/시청 한도 안내가 보여요 | 학습 현황과 별개인 이용 제한입니다. 새로고침·재생 반복·다른 계정/주소로 우회하지 않습니다 |

반영 차이가 계속되면 아래 정보를 모아 학원에 확인합니다. 진도를 복구하려고 브라우저 저장정보를 삭제하거나 계정 재가입·수강권 재구매를 시도하지 않습니다. 화면 이동·일시정지·강의실 재진입도 기록 전송/저장에 영향을 줄 수 있으므로, 현황을 확인하려고 재생 상태를 반복해서 바꾸지 않습니다.

> **화면 예시 준비 중** · 수업 수와 확인 시각을 함께 학원에 전달합니다.

학원 사이트 주소, 계정 식별에 필요한 최소 정보, 강좌·수업 제목, 일반/YouTube/Vimeo 구분, 확인 시각, 표시된 종료일·완료/전체 수업 수·퍼센트, 선택한 필터, PC/모바일·기기/브라우저와 화면 문구를 전달합니다. 목록과 목차가 다르면 두 화면을 구분하고 개인정보를 가립니다.

**비밀번호·인증번호·세션/토큰·영상/자료 URL·Vimeo 접근키는 보내지 않습니다.** 로그인할 수 없을 때는 로그인 후에만 이용할 수 있는 1:1 문의 대신 학원이 별도로 안내한 연락처로 문의합니다.

## 완료 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 본인 계정의 강좌를 전체·상태 필터와 페이지에서 찾아 기간·종료일을 확인했습니다. N일은 남은 일수가 아니며 정확한 만료 시각은 별도 확인이 필요합니다.
- [ ] 완료 수업 수·전체 수업 수·반올림한 진도율과 목차의 완료 체크를 확인했습니다. 선택색·재생 위치는 완료 여부와 다릅니다.
- [ ] 기간이 없거나 학습이 완료됐더라도 무제한 이용·자동 연장을 뜻하지 않습니다. 목록 필터와 실제 재생·자료·질문 이용 가능 여부도 따로 확인합니다.
- [ ] 외부 영상의 시청 상태·일반 영상 진도·환불용 이용 근거는 서로 다릅니다. 차이가 계속되면 반복 재생·재구매 없이 필요한 정보만 문의합니다.
