# 내 강의 찾고 수강 시작하기

> **검토용 가이드** · 실제 서비스 화면·동작 확인과 이미지 보완이 남아 있습니다. 본문의 실행 보류·주의사항을 먼저 확인하세요.

<figure><img src="../.gitbook/assets/branding/page-headers/learning/find-course-and-start-v2.png" alt="내 강의 찾고 수강 시작하기 대표 이미지"><figcaption></figcaption></figure>

구매하거나 학원에서 지급받은 강좌를 찾는 참고 경로는 **마이페이지 → 내 학습 → 수강중 강좌**입니다. 기기·사이트별 실제 메뉴 위치는 확인이 필요하므로 메뉴가 다르면 학원에 수강 경로를 문의하세요. 강좌와 이용 기간을 확인한 뒤 강의실에서 수업을 선택합니다. 이 가이드에서 **강좌**는 수업을 모은 단위이고, **수업(강의)**은 목차에서 선택해 듣는 개별 영상입니다.

**수강 순서:** 강좌 찾기 → 강의실 열기 → 수업 제목 확인 → 영상 재생. 목록에 보이는 것만으로 재생 가능한 상태인지 알 수는 없습니다. 강좌가 없거나 제한 안내가 나오면 재구매하지 말고 기존 주문이나 학원의 지급 안내를 확인합니다.

## 시작 전 준비 <a href="#before-you-start" id="before-you-start"></a>

| 준비할 것 | 확인할 내용 |
| --- | --- |
| 학원 사이트와 계정 | 수강권을 구매하거나 지급받은 사이트·계정이 맞는지 확인합니다. 다른 학원이나 다른 계정의 강좌가 자동으로 합쳐지지 않습니다 |
| 대상 강좌명 | 구매한 상품에 포함된 강좌명 또는 학원이 안내한 지급 강좌명을 준비합니다. 상품명과 강좌명이 다를 수 있습니다 |
| 구매 또는 지급 정보 | 구매자는 기존 주문, 직접 지급받은 학생은 학원의 지급 안내를 확인합니다. 직접 지급은 구매 내역이 없어도 강좌를 확인할 수 있습니다 |
| 이용 기간 | 목록의 기간·종료일과 학원 안내를 확인합니다. 기간이 표시되지 않는다고 무제한이라고 판단하지 않습니다 |

계정은 [내 계정과 로그인 방식 확인하기](../account/check-account-and-login-method.md), 구매 구성은 [상품 구성·가격·이용 기간 확인하기](../purchase/product-and-access-period.md), 원 주문(해당 상품을 구매한 주문)은 [결제하고 무료 상품 신청하기](../purchase/payment-and-free-order.md)를 참고합니다.

## 먼저 내 상황 고르기 <a href="#choose-your-situation" id="choose-your-situation"></a>

| 상황 | 시작할 곳 | 구분할 것 |
| --- | --- | --- |
| 학원에서 수강권을 받았어요 | 내 학습 → 수강중 강좌 | 결제부터 다시 하지 않습니다 |
| 유료 결제 또는 무료 신청을 했어요 | 원 주문 확인 → 수강중 강좌 | 결제/신청 완료와 실제 강좌 지급은 별도입니다 |
| 예전에 듣던 강좌를 찾고 싶어요 | 전체 필터·다른 페이지 확인 | 수강중 화면 이름이 모든 강좌의 이용 가능을 뜻하지 않습니다 |
| 자료나 교재만 구매했어요 | 상품 구성·내 자료 또는 원 주문 확인 | 강좌가 포함되지 않았다면 강좌 목록이 비어 있을 수 있습니다 |
| 강좌는 있는데 들어갈 수 없어요 | 기간·제한 안내 확인 → 필요하면 문의 | 목록에 남아 있는 것과 영상/자료 이용 권한은 다릅니다 |

## 1. 수강중 강좌 목록 열기 <a href="#step-1" id="step-1"></a>

**메뉴 위치 확인 필요:** 아래는 참고 경로입니다. 기기·사이트별 실제 메뉴 위치는 아직 확인이 필요합니다. 메뉴가 다르거나 보이지 않으면 학원에 수강 경로를 확인하고, 새 계정이나 새 결제로 해결하지 않습니다.

1. 학원 사이트에서 수강권을 받은 계정으로 로그인합니다. 계정이 확실하지 않으면 새로 가입하거나 다른 계정으로 결제하지 않습니다.
2. PC에서는 **마이페이지 → 내 학습**으로 이동합니다. 모바일에서는 사이트의 **메뉴 열기** 아이콘을 누르고 **내 학습**으로 이동합니다.
3. **수강중 강좌** 탭을 확인합니다. **내 자료·내 노트·학습 Q&A**는 다른 탭입니다.
4. 목록을 불러오는 동안 기다립니다. 조회 실패 안내가 나오면 빈 목록과 구분하고, 목록의 다시 불러오기 동작으로 확인합니다.

로그인이 풀려 로그인 화면으로 이동했다면 로그인 후 다시 **내 학습 → 수강중 강좌**를 엽니다. 로그인 후에도 이전에 선택한 수업으로 자동으로 돌아가지 않을 수 있습니다.

> **화면 예시 준비 중** · 내 학습의 수강중 강좌를 엽니다.

## 2. 필터와 페이지로 강좌 찾기 <a href="#step-2" id="step-2"></a>

1. 먼저 **전체**를 선택해 대상 강좌가 있는지 확인합니다.
2. 필요하면 **수강중·완료·만료** 필터를 바꿉니다. 필터를 바꾸면 첫 페이지부터 다시 확인합니다.
3. 페이지 이동이 표시되면 다른 페이지도 확인합니다. 현재 페이지에 없다는 이유만으로 지급이 누락되었다고 판단하지 않습니다.
4. 찾은 강좌의 제목을 학원 안내나 구매 상품의 포함 강좌와 대조합니다. 검색창이나 정렬 메뉴가 보이지 않으면 필터와 페이지 이동으로 찾습니다.

필터는 강좌를 찾는 수단입니다. **완료가 무제한 이용을 뜻하지 않고, 수강중 필터에 보이는 것만으로 현재 재생 권한이 확정되지 않습니다.** 취소/회수된 강좌가 전체에 반드시 남는 것도 아닙니다. 실제 진입 결과와 제한 안내를 함께 확인합니다.

| 표시되는 내용 | 먼저 확인할 것 |
| --- | --- |
| 수강 중인 강좌가 없습니다. | 전체 필터·현재 계정·강좌 포함/지급 여부 |
| 해당 상태의 강좌가 없습니다. | 선택한 필터를 전체로 바꾸고 다른 페이지 확인 |
| 수강 중인 강좌를 불러오지 못했습니다. | 조회 오류입니다. 다시 불러오기를 확인하고 계속 실패하면 문의 |
| 강좌명은 맞는데 기간/상태가 예상과 달라요 | 학원의 지급 안내·기존 주문과 대조. 재구매로 확인하지 않음 |

> **동작 예시 준비 중** · 필터와 페이지를 바꾸며 대상 강좌를 찾습니다.

> **화면 예시 준비 중** · 빈 목록과 조회 실패를 구분합니다.

## 3. 강좌 카드 확인하고 강의실 열기 <a href="#step-3" id="step-3"></a>

1. 강좌 카드의 **강좌명·이용 기간/종료일·학습 현황** 중 표시된 항목을 읽습니다.
2. 강좌 소개를 확인하려면 **강좌 제목**을 누릅니다. 이 동작은 강의실 진입과 다릅니다.
3. 수강을 시작하려면 이용 가능한 강좌의 **썸네일 이미지**를 누릅니다. 현재 목록에는 별도 **수강하기** 버튼이 없으므로 해당 버튼을 찾지 않습니다.
4. 강의실이 열리면 상단 강좌명과 수업 제목을 확인합니다. 다른 강좌/수업이 보이거나 제한 안내가 나오면 재생하지 않고 아래 문제 확인으로 이동합니다.

| 카드의 항목 | 읽는 방법 |
| --- | --- |
| N일 | 시작일과 종료일 사이의 기간 표시이며 남은 날짜 수가 아닙니다 |
| ~YYYY.MM.DD | 표시된 종료 날짜입니다. 해당 날짜의 정확한 종료 시각까지 보장하는 표시가 아닙니다 |
| 완료한 강의 수/전체 강의 수 | 학습 현황입니다. 결제 상태·환불용 이용률·모든 영상의 재생 가능을 뜻하지 않습니다 |
| 기간 표시 없음 | 무제한을 뜻한다고 판단하지 말고 학원 안내를 확인합니다 |
| 만료·비활성 썸네일 | 현재 목록에서 강의실로 들어갈 수 없는 상태입니다. 제목의 소개 화면과 구분합니다 |
| 다시 구매하기 | 표시·활성화된 경우의 구매 경로입니다. 기존 기간의 자동 연장·같은 가격/구성이나 누락된 권리의 복구를 보장하지 않습니다 |

**묶음 상품**은 구매한 구성의 강좌를 각각 확인합니다. 묶음 상품에서 각 강좌로 이동하는 실제 동작은 아직 확인이 필요합니다. 선택한 강좌와 다른 강좌/수업이 열리거나 일부 강좌가 보이지 않으면 임의로 주소를 바꾸거나 재구매하지 않고 학원에 알립니다.

> **화면 예시 준비 중** · 제목은 소개로, 이용 가능한 썸네일은 강의실로 연결됩니다.

## 4. 들을 수업 선택하기 <a href="#step-4" id="step-4"></a>

1. 강의실이 처음 열리면 자동 선택된 수업의 제목을 확인합니다. 이전에 듣던 수업이 기대와 다르면 직접 목차에서 선택합니다.
2. PC에서는 화면의 측면 도구 **커리큘럼**, 모바일에서는 하단 **목차**를 엽니다. PC 도구가 보이지 않으면 강의실 화면 위로 포인터를 옮겨 확인합니다.
3. 들을 수업이 있는 섹션을 펼칩니다. 수업 목록에서 **수업 제목**을 누릅니다.
4. 상단 수업 제목과 현재 선택 표시가 맞는지 확인합니다. 체크 표시가 있더라도 이용 기간이 자동 연장된 것은 아닙니다.

현재 자동 선택은 **목차 순서상 재생 위치가 남아 있는 미완료 수업 중 마지막 항목**, 없으면 첫 수업을 기준으로 합니다. 실제로 가장 최근에 시청한 수업이라고 단정할 수 없습니다. 정확히 이어서 들으려면 수업 제목부터 확인합니다.

목차의 **자료**는 수업 선택 버튼이 아닙니다. 다운로드 동작으로 이어질 수 있으므로 강의실 이동 확인용으로 누르지 않습니다. 목차가 비어 있거나 화면이 계속 준비 중이면 수업이 없다고 단정하지 말고 학원에 확인합니다.

> **화면 예시 준비 중** · 강좌명과 자동 선택된 수업 제목을 확인합니다.

> **화면 예시 준비 중** · 목차에서 들을 수업을 선택합니다.

## 5. 재생 시작하고 다음 수업으로 이동하기 <a href="#step-5" id="step-5"></a>

1. 선택한 수업의 영상 영역이 준비되면 **재생**을 누릅니다. 강의실이 열렸다고 영상이 자동으로 시작되는 것은 아닙니다.
2. 영상의 화면과 소리가 정상인지 확인합니다. 다른 수업 영상·제한 안내·오류가 보이면 계속 시청하지 않습니다.
3. 다른 수업을 들으려면 목차에서 직접 선택하거나 화면의 **이전·다음**을 누릅니다. 해당 방향에 수업이 없으면 버튼이 비활성화될 수 있습니다.
4. 강좌 소개로 돌아가려면 상단의 뒤로 화살표를 이용합니다. **내 강좌 목록**을 다시 보려면 사이트의 **마이페이지 → 내 학습 → 수강중 강좌**로 이동합니다.

일반 영상과 YouTube/Vimeo 같은 외부 영상은 재생 화면·기록 방식이 다릅니다. 모든 영상의 자동 재생·동일 위치 이어보기·진도 저장을 보장하지 않습니다. 기기별 재생 조작은 [PC·모바일에서 영상 보기](watch-on-desktop-and-mobile.md)를 참고합니다. 수강 기간·학습 현황은 [수강 기간과 학습 현황 확인하기](access-period-and-progress.md)를 참고합니다.

> **화면 예시 준비 중** · 화면과 소리를 확인하고 다음 수업으로 이동합니다.

## 강좌가 없거나 수강을 시작할 수 없을 때 <a href="#section-8" id="section-8"></a>

| 상황 | 확인할 내용·다음 행동 |
| --- | --- |
| 결제했는데 목록에 없어요 | 사이트·계정→원 주문→강좌 포함 여부→전체/페이지/조회 오류 순서로 확인합니다. 재결제하지 않습니다 |
| 직접 지급받았는데 없어요 | 학원이 지급한 계정·강좌명·기간을 확인합니다. 구매 내역이 없는 것을 지급 실패로 단정하지 않습니다 |
| 로그인 화면으로 이동해요 | 로그인 후 내 학습에서 다시 강좌를 찾습니다. 다른 계정 가입이나 세션 정보 공유로 해결하지 않습니다 |
| 수강 등록/상태/권한 안내 뒤 목록으로 돌아와요 | 안내 문구를 기록하고 계정·기간·지급 상태를 학원에 확인합니다. 주소창 수정으로 우회하지 않습니다 |
| 만료 또는 미리보기만 가능하다고 나와요 | 일반 수강·미리보기·목록 열람은 권한이 다릅니다. 전체 수업 이용이나 자료/질문 가능으로 확대하지 않습니다 |
| 월 영상 시청시간 한도 안내가 나와요 | 학원에 제한 안내를 전달합니다. 학생이 클킷 플랜/추가 팩을 구매하는 절차가 아닙니다 |
| 영상 준비 중입니다. / 강좌 정보 오류가 나와요 | 준비 중 문구만으로 영상 변환이 진행 중이라고 확정하지 않습니다. 강좌·수업명과 안내를 전달합니다 |
| 묶음의 다른 강좌/수업이 열리거나 목차가 계속 준비 중이에요 | 선택한 대상과 실제 제목을 기록하고 문의합니다. 다른 수업 재생·반복 진입·재구매로 확인하지 않습니다 |

접근 제한은 기간 만료 외에도 지급·취소 여부와 수강 권한 상태에 따라 달라질 수 있습니다. 수강 권한을 직접 복구·이전하거나 제한을 우회하려 하지 않습니다. 기간·조회 문제가 불명확하면 **다시 구매하기**부터 누르지 않습니다.

> **화면 예시 준비 중** · 제한 안내를 확인하고 재구매보다 학원 문의를 우선합니다.

## 학원에 문의할 때 <a href="#contact-academy" id="contact-academy"></a>

학원 사이트 주소, 계정 식별에 필요한 최소 정보, 강좌명·선택한 수업 제목, 구매/직접 지급 구분, 구매자라면 원 주문번호, 시도한 시각, 선택한 필터·표시 기간·안내 문구, PC/모바일과 브라우저 종류를 전달합니다. 선택한 강좌와 열린 제목이 다르면 둘 다 적습니다.

**비밀번호·인증번호·세션/토큰·재생/자료 URL은 보내지 않습니다.** 캡처의 개인정보와 주소창은 가립니다. 로그인할 수 없을 때는 로그인 후에만 이용할 수 있는 1:1 문의 대신 학원이 별도로 안내한 연락처로 문의합니다.

## 완료 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 구매하거나 지급받은 학원 사이트의 본인 계정으로 강좌를 찾았습니다. 빈 목록과 조회 오류는 구분합니다.
- [ ] 필터·다른 페이지에서 강좌명과 기간을 확인하고, 썸네일로 강의실을 열었습니다. 강좌 제목은 소개 화면으로 이동합니다.
- [ ] 열린 수업 제목을 확인하고 목차에서 들을 수업을 선택해 화면·소리를 확인했습니다. 자동 선택이 최근 시청순 복귀를 보장하지는 않습니다.
- [ ] 이전·다음 수업 이동과 소개 화면·내 강좌 목록으로 돌아가는 방법을 확인했습니다.
- [ ] 강좌가 없거나 제한·오류가 계속되면 재구매하지 않고 기존 주문이나 지급 안내와 필요한 정보만 학원에 전달합니다.
