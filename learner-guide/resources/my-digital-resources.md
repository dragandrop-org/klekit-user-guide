# 구매하거나 지급받은 디지털 자료 이용하기

> **검토용 가이드** · 실제 서비스 화면·동작 확인과 이미지 보완이 남아 있습니다. 본문의 실행 보류·주의사항을 먼저 확인하세요.

<figure><img src="../.gitbook/assets/branding/page-headers/resources/my-digital-resources-v2.png" alt="구매하거나 지급받은 디지털 자료 이용하기 대표 이미지"><figcaption></figcaption></figure>

구매하거나 지급받은 디지털 자료는 **마이페이지 → 내 학습 → 내 자료**에서 확인합니다. 자료명·파일명·지급일을 대조하고 다운로드 안내를 확인한 뒤, 실제 기기에 저장된 파일을 열어 봅니다.

**자료 받기:** 필요한 자료를 찾아 다운로드 안내를 읽고, 저장된 파일을 열어 내용을 확인합니다. 화면의 **받음** 표시나 새 창 열림만으로 기기에 저장된 것은 아닙니다.

## 시작 전 확인 <a href="#before-you-start" id="before-you-start"></a>

| 확인할 것 | 내용 |
| --- | --- |
| 사이트와 계정 | 자료를 구매하거나 지급받은 학원 사이트·계정인지 확인합니다. [내 계정 확인](../account/check-account-and-login-method.md)을 참고합니다 |
| 제공 대상 | 상품 구성이나 학원 안내에 해당 디지털 자료가 포함됐는지 확인합니다. 결제 완료 안내만으로 모든 자료 지급을 확정하지 않습니다 |
| 자료 종류 | 강의실의 수업 첨부는 [강의 첨부 자료 받기](lecture-materials.md), 별도 디지털 자료는 내 자료에서 확인합니다. 공지 첨부·배송 교재와도 구분합니다 |
| 다운로드 필요 여부 | 실제 사용할 자료만 받습니다. 다운로드 주소 발급 이력이 남을 수 있으므로 취소 가능 여부를 시험하려고 누르지 않습니다 |

## 1. 내 자료에서 원하는 항목 찾기 <a href="#step-1" id="step-1"></a>

1. 학원 사이트에 로그인한 뒤 **마이페이지 → 내 학습 → 내 자료**로 이동합니다.
2. 처음에는 **전체**에서 자료 목록을 확인합니다. 자료명·파일명과 형식·**지급일**을 학원 안내와 대조합니다.
3. 필요하면 **받음**, **미받음** 필터를 선택합니다. 필터 옆 숫자는 해당 목록 항목 수이며 실제 저장 파일 수가 아닙니다.
4. 목록이 여러 페이지이면 다음 페이지도 확인합니다. 자료가 없으면 먼저 **전체**로 돌아와 사이트·계정을 다시 확인합니다.
5. 원하는 항목의 **상세 보기**를 누릅니다. 목록의 **다운로드**로도 받을 수 있지만 파일 정보를 먼저 확인하는 흐름을 권장합니다.

같은 자료명이 여러 번 보일 수 있습니다. 각 항목의 파일명·지급일·이용 상태를 따로 확인하며 중복 구매나 오류로 단정하지 않습니다. 자료명 검색창이나 구매/무료/직접 지급 구분 필터가 보이지 않으면 전체 목록과 받음/미받음 필터·페이지 이동으로 확인합니다.

> **화면 예시 준비 중** · 내 자료에서 대상 파일과 지급일을 확인합니다.

> **동작 예시 준비 중** · 필터와 상세 정보를 확인한 뒤 목록으로 돌아옵니다.

## 2. 상세에서 파일 정보 확인하기 <a href="#step-2" id="step-2"></a>

상세에는 **자료명·파일명·상태**, **파일 형식·지급일·최초 다운로드**와 **자료 다운로드**가 표시됩니다. 목록으로 돌아가려면 **내 자료 목록**을 이용합니다.

| 표시 | 읽는 방법 |
| --- | --- |
| 자료명·파일명 | 학원이 안내한 대상인지 대조합니다. 자료명이 같아도 연결된 파일이 다를 수 있습니다 |
| 파일 형식 | 파일명 확장자를 기준으로 표시합니다. 형식 표시만으로 파일이 정상이며 기기에서 열 수 있다고 보장하지 않습니다 |
| 지급일 | 해당 항목의 권한이 지급된 날짜입니다. 구매일·수강 종료일·다운로드 주소 만료 시각과 다릅니다 |
| 최초 다운로드 | **최초 다운로드 주소 발급 시각**입니다. 기기에 저장하거나 파일을 처음 연 시각이 아닙니다. 발급 이력이 없으면 `-`로 표시됩니다 |

파일 용량·버전 번호/선택 메뉴·다운로드 횟수/남은 횟수·이용 종료일·주소 만료 카운트다운이 모두 표시되는 화면은 아닙니다. 기간이나 제공 버전이 궁금하면 학원 안내와 함께 확인합니다. 날짜가 없다는 이유로 영구 이용을 약속하지 않습니다.

> **화면 예시 준비 중** · 최초 다운로드는 파일 저장이 아닌 주소 발급 시각입니다.

## 3. 받음과 이용불가 구분하기 <a href="#step-3" id="step-3"></a>

| 보이는 상태 | 의미와 다음 행동 |
| --- | --- |
| 미받음 | 조회된 항목에 다운로드 주소 발급 이력이 없습니다. 파일이 기기에 없는지 또는 취소가 가능한지는 이 표시만으로 확정하지 않습니다 |
| 받음 | 다운로드 주소 발급 이력이 있습니다. 저장 위치와 실제 파일을 확인합니다. 저장 실패·창 닫기도 별도로 확인해야 합니다 |
| 이용불가 | 현재 항목의 다운로드 버튼을 사용할 수 없는 상태입니다. 상세 정보를 확인하고 학원에 문의합니다 |
| 받음/미받음인데 요청에 실패함 | 화면 표시와 요청 시점의 권한 검사는 다릅니다. 취소 처리 중 이용 제한·파일 상태·통신 문제 등을 학원에 확인합니다 |

**받음·미받음 필터와 현재 다운로드 가능 여부는 별개입니다.** 이용불가 항목도 과거 발급 이력에 따라 받음/미받음 필터에 남을 수 있습니다. 활성 버튼이나 미받음 표시만으로 현재 권한·취소 가능 여부를 판단하지 않습니다.

취소 처리 중에는 새 다운로드 주소 발급이 제한될 수 있습니다. 이용 보류 표시가 항상 보이는 것은 아니므로, 학생이 직접 해제하려 하거나 다른 계정·직접 주소·재구매로 제한을 우회하지 않습니다.

> **화면 예시 준비 중** · 발급 이력과 현재 이용 가능 여부를 구분합니다.

## 4. 다운로드 안내를 읽고 요청하기 <a href="#step-4" id="step-4"></a>

<figure><img src="../.gitbook/assets/branding/digital-files-download-illustration-v1.png" alt="디지털 문서와 다운로드"><figcaption></figcaption></figure>

1. 상세의 **자료 다운로드** 또는 목록의 **다운로드** 중 한 곳을 누릅니다. 이 단계에서는 확인창이 열립니다.
2. **자료를 다운로드하시겠어요?** 창에서 취소 제한과 주소 유효 시간 안내를 읽습니다.
3. 지금 받을 필요가 없으면 **취소** 또는 **닫기**로 돌아갑니다. 이 버튼은 확인창을 닫는 것이며 주문 취소 신청이 아닙니다.
4. 받을 자료가 맞으면 확인창의 **다운로드**를 한 번 누릅니다. `처리중...`이면 기다리고 반복 클릭하지 않습니다.
5. 새 창/탭 또는 현재 화면에서 파일이 열리거나 다운로드되는지 확인합니다. 이후 아래 절차 중 지금 사용하는 기기의 저장 확인만 진행합니다.

> **다운로드 전에 확인하세요**
> 다운로드 주소가 발급되면 단순 취소가 제한될 수 있습니다. 파일을 저장하지 못하거나 창을 닫아도 발급 이력이 자동 취소되는 것은 아닙니다. 실제 취소·환불 가능 여부는 주문과 학원의 확인된 안내에 따르며 이 화면만으로 가능/불가를 확정하지 않습니다.
>
> 확인창은 발급된 주소가 **10분 동안 유효**하다고 안내합니다. 이는 임시 주소의 유효 시간이며 자료 이용 기간이나 10분 안에 파일 저장을 끝내야 한다는 뜻이 아닙니다. 만료된 주소를 수정·공유하거나 유효 시간을 연장하려 하지 않습니다.

새 창을 열 수 없으면 현재 화면에서 파일로 이동할 수 있습니다. 새 창이 보이지 않는다고 즉시 다시 누르지 말고 현재 화면·다운로드 내역부터 확인합니다. 확인창이 닫히거나 받음으로 바뀌는 것은 실제 파일 저장 완료 알림이 아닙니다.

> **화면 예시 준비 중** · 다운로드 전에 취소 제한과 임시 주소 안내를 확인합니다.

## 5. PC 또는 모바일에서 저장 확인하기 <a href="#step-5" id="step-5"></a>

이미 요청했다면 아래에서 **현재 기기의 절차만** 확인합니다. 저장 방법을 확인하려고 목록과 상세 양쪽에서 다시 다운로드할 필요는 없습니다.

### PC에서 확인 <a href="#desktop-check" id="desktop-check"></a>

1. 새 창/현재 탭에 파일이 열렸다면 파일명과 내용을 확인합니다. 미리보기와 기기 저장은 별개입니다.
2. 자동 다운로드됐다면 브라우저 다운로드 내역에서 완료/실패 상태를 확인합니다. 미리보기라면 실제 제공되는 저장/다운로드 기능으로 저장합니다.
3. 다운로드 폴더 또는 선택한 저장 위치에서 파일을 찾고 엽니다. 내용이 학원 안내와 맞는지 확인합니다.
4. 기존 학원 사이트 탭으로 돌아올 수 있는지 확인합니다. 탭을 닫거나 뒤로 갔다고 발급 기록이 취소되지는 않습니다.

> **화면 예시 준비 중** · 주소 발급 후 기기에 저장된 파일을 확인합니다.

### 모바일에서 확인 <a href="#mobile-check" id="mobile-check"></a>

1. 다운로드 요청 후 새 탭이나 현재 화면의 파일 미리보기·다운로드 안내를 확인합니다. 이미 요청했다면 버튼을 다시 누르지 않습니다.
2. 기기/브라우저에서 실제 제공하는 저장 기능을 확인합니다. 모든 파일이 사진 앱/갤러리에 저장되는 것은 아닙니다.
3. 다운로드 내역과 파일 보관 위치를 확인한 뒤 저장된 파일을 엽니다. 미리보기만 됐거나 파일명만 보이는 상태를 완료로 판단하지 않습니다.
4. 학원 사이트로 돌아오면 계정과 자료명이 맞는지 확인합니다. 다른 브라우저로 임시 주소를 복사해 제한을 우회하지 않습니다.

iPhone·Android·앱 내 브라우저가 같은 메뉴·저장 위치를 제공한다고 가정하지 않습니다. PDF/문서/압축파일 등에 따라 열기 방법이 다르며 임의의 프로그램 설치·확장자 변경·보안 설정 해제를 요구하지 않습니다.

> **화면 예시 준비 중** · 사용하는 기기의 파일 위치에서 저장 결과를 확인합니다.

## 6. 제공 파일과 사용 범위 확인하기 <a href="#step-6" id="step-6"></a>

내 자료는 **해당 지급 항목에 연결된 파일**을 제공합니다. 학원이 새 파일을 등록해도 기존 항목과 기기에 저장한 파일이 모두 최신판으로 자동 교체되는 것은 아닙니다. 파일명이나 내용이 안내와 다르면 학원에 필요한 버전을 확인합니다.

학생 화면에서 버전 번호를 고르거나 최신 파일로 교체·재지급하는 기능의 제공 여부는 아직 확인이 필요합니다. 같은 제목의 여러 항목도 각각의 파일명·지급일을 대조하고, 원하는 버전을 찾으려고 모두 다운로드하지 않습니다.

자료와 임시 다운로드 주소는 다른 사람에게 공유하지 않습니다. 구매·지급받았다고 재배포·공개 업로드가 허용되는 것은 아니며 학원이 안내한 사용 범위를 따릅니다.

## 자료를 받지 못했을 때 <a href="#section-10" id="section-10"></a>

| 상황 | 확인할 것·다음 행동 |
| --- | --- |
| 지급된 자료가 없습니다. | 전체 필터·사이트·계정과 상품 구성/지급 안내를 확인합니다. 구매 여부가 불명확하면 [원 주문(해당 상품을 구매한 주문) 확인 안내](../purchase/payment-and-free-order.md)를 참고하고 재구매로 시험하지 않습니다 |
| 해당 상태의 자료가 없습니다. | 선택한 필터의 빈 결과입니다. 전체로 돌아가 확인합니다 |
| 내 자료를 불러오지 못했습니다. / 자료 상세를 불러오지 못했습니다. | 지급 없음과 조회 실패는 다릅니다. 화면의 재시도를 이용하고 계속 실패하면 문의합니다. 조회 재시도를 다운로드 재발급과 혼동하지 않습니다 |
| 이용불가·다운로드 비활성 | 현재 상태와 취소/지급 안내를 확인하고 문의합니다. 권한을 직접 복구하거나 제한을 우회하려 하지 않습니다 |
| 다운로드 URL을 발급하지 못했습니다. 다시 시도해주세요. | 오류 문구만으로 원인이나 다운로드 주소 발급 이력의 유무를 알 수는 없습니다. 이미 열린 화면·다운로드 내역·받음/최초 다운로드를 먼저 확인합니다. 결과가 불명확하면 반복 발급보다 문의를 우선합니다 |
| 파일 안전 경고나 이용 제한 안내가 나와요 | 파일 열기·반복 발급을 멈추고 문구를 학원에 전달합니다. 보안 설정 해제·직접 주소 우회로 해결하지 않습니다 |
| 받음인데 파일을 못 찾겠어요 | 받음은 발급 이력입니다. 다운로드 내역·저장 위치·미리보기 여부를 확인합니다 |
| 새 창이 비거나 현재 화면이 바뀌었어요 | 새 창/현재 탭과 브라우저 차단·다운로드 내역을 확인합니다. 보안 설정을 일괄 해제하지 않습니다 |
| 접근 거절·주소 만료가 나와요 | 임시 주소와 현재 자료 권한을 구분합니다. 오래된 주소를 수정/재사용하지 않으며 다시 받아야 하면 현재 권한과 필요를 확인한 뒤 정상 화면에서 진행합니다 |
| 파일이 안 열리거나 버전/내용이 달라요 | 자료명·파일명·지급일·기기·오류 문구를 전달합니다. 반복 다운로드·임의 변환·추가 구매로 해결하려 하지 않습니다 |

> **화면 예시 준비 중** · 조회·권한/발급·기기 저장 문제를 구분합니다.

## 학원에 문의할 때 <a href="#contact-academy" id="contact-academy"></a>

학원 사이트, 계정 식별에 필요한 최소 정보, 자료명·파일명·지급일, 현재 필터/상태·최초 다운로드 표시, 발생 시각·PC/모바일·기기/브라우저, 화면 문구, 다운로드 내역·실제 저장/열기 여부를 전달합니다. 구매 건이면 주문번호, 지급 건이면 학원의 지급 안내를 함께 확인합니다.

**비밀번호·인증번호·토큰/세션·서명 다운로드 URL은 보내지 않습니다.** 캡처의 주소창·다른 자료/개인 파일·결제 개인정보를 가립니다. 로그인할 수 없을 때는 로그인 후에만 이용할 수 있는 1:1 문의 대신 학원이 별도로 안내한 연락처로 문의합니다.

## 완료 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 자료를 구매하거나 지급받은 사이트·계정을 확인했다.
- [ ] 강의 첨부·별도 내 자료·공지 첨부·배송 교재를 구분했다.
- [ ] 전체/받음/미받음과 페이지를 확인해 필요한 항목을 찾았다.
- [ ] 자료명·파일명·형식·지급일과 제공 파일을 대조했다.
- [ ] 받음/최초 다운로드를 실제 저장·열기 완료와 구분했다.
- [ ] 취소 제한·10분 주소 안내를 읽고 필요한 경우에만 요청했다.
- [ ] 현재 기기의 저장 위치에서 파일을 찾아 내용을 확인했다.
- [ ] 이용불가/실패·버전 차이를 반복 발급·재구매·권한 우회로 시험하지 않았다.
- [ ] 자료·임시 주소를 공유하지 않고 필요한 최소 정보만 문의했다.

지급 내역 복구 등으로 자료 이용이 보류된 경우에도 목록 표시나 일반적인 발급 오류만으로 원인을 확정하지 않습니다. 원 주문·자료 이용 권한·지급 파일 버전은 학원 담당자의 확인이 필요합니다. 학생이 직접 복원할 수 있거나, 자동 재지급·모든 기존 파일 이용이 보장되는 것은 아닙니다. 확인을 위해 주소를 반복 발급하거나 오래된 주소로 우회하지 않습니다.
