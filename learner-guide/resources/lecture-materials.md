# 강의 첨부 자료 받기

> **이용 전 확인** · 사용할 수 있는 기능과 화면이 아직 확인되지 않은 항목이 있습니다. 화면이나 안내가 다르면 학원에 확인하고, 문서에서 멈추도록 안내한 작업은 진행하지 마세요.

<figure><img src="../.gitbook/assets/branding/page-headers/resources/lecture-materials-v2.png" alt="강의 첨부 자료 받기 대표 이미지"><figcaption></figcaption></figure>

강의 첨부 자료는 강의실의 PC **커리큘럼**, 모바일 **목차**에서 해당 수업 옆 **자료** 버튼으로 받습니다. 다운로드할 수업을 먼저 확인한 뒤, 파일이 실제 기기에 저장됐는지 확인합니다.

**자료 받기:** 수업의 첨부 자료를 선택하고, 저장된 파일을 열어 확인합니다. 버튼 클릭·새 창 열림·로딩 종료만으로 파일이 저장된 것은 아닙니다.

## 시작 전 확인 <a href="#before-you-start" id="before-you-start"></a>

| 확인할 것 | 내용 |
| --- | --- |
| 사이트·계정·강좌 | 수강권을 받은 학원 사이트와 계정이 맞는지 확인합니다. 강좌를 못 찾았다면 [수강 시작 안내](../learning/find-course-and-start.md)를 참고합니다 |
| 대상 수업 | 학원이 안내한 강좌·섹션·수업 제목과 대조합니다. 현재 재생 중인 수업과 자료를 받을 수업은 다를 수 있습니다 |
| 기간·권한 | 수강 기간·현재 제한 안내를 확인합니다. 목차가 보이거나 수업을 완료했다고 자료를 항상 받을 수 있는 것은 아닙니다 |
| 자료 종류 | 강의 첨부 자료인지, 별도 구매/지급 디지털 자료인지, 공지 첨부인지 구분합니다 |
| 받을 필요가 있는지 | 실제 사용할 때만 자료를 누릅니다. URL 발급 단계에서 이용 이력이 기록될 수 있으므로 환불 가능 여부 확인용으로 실행하지 않습니다 |

| 찾는 자료 | 확인할 곳 |
| --- | --- |
| 특정 수업에 붙은 강의 자료 | 강의실 → PC 커리큘럼 / 모바일 목차 → 해당 수업의 자료 |
| 별도로 구매하거나 지급받은 디지털 자료 | 마이페이지 → 내 학습 → 내 자료. [디지털 자료 이용 안내](my-digital-resources.md) 참고 |
| 공지사항 첨부파일 | [공지사항 확인 안내](../communication/read-notices.md)의 해당 공지 상세. 강의실 자료 버튼과 별도 |
| 배송되는 교재 | 주문·배송 안내. 자료 다운로드를 교재 배송으로 보지 않음 |

## 1. 강의실에서 목차 열기 <a href="#step-1" id="step-1"></a>

1. **마이페이지 → 내 학습 → 수강중 강좌**에서 이용할 강좌를 찾고 강의실을 엽니다. 제목과 기간은 [수강 기간·학습 현황 안내](../learning/access-period-and-progress.md)를 참고합니다.
2. PC에서는 오른쪽 **커리큘럼**, 모바일에서는 하단 **목차**를 엽니다. 영상 전체화면이면 먼저 강의실 화면으로 돌아옵니다.
3. 강좌명을 확인하고 해당 섹션을 펼칩니다. 원하는 **수업 제목** 옆에 **자료** 버튼이 있는지 확인합니다.
4. 수업 제목은 수업 이동, 자료 버튼은 다운로드 동작입니다. 자료 위치를 확인하려고 제목이나 재생 버튼을 반복 누르지 않습니다.

목차 패널을 열었다고 영상이 자동 일시정지되는 것은 아닙니다. 재생 중이라면 필요에 따라 재생기에서 먼저 일시정지합니다. 패널 닫기는 [PC·모바일 영상 보기](../learning/watch-on-desktop-and-mobile.md)를 참고합니다.

> **화면 예시 준비 중** · 강의 첨부 자료는 목차의 해당 수업에서 받습니다.

> **동작 예시 준비 중** · 목차에서 수업과 자료 버튼의 위치를 확인합니다.

## 2. 자료 버튼과 이용 가능 여부 확인하기 <a href="#step-2" id="step-2"></a>

| 보이는 상태 | 확인할 것·다음 행동 |
| --- | --- |
| 자료 버튼이 있어요 | 해당 수업의 첨부를 받는 위치입니다. 수업 제목을 먼저 대조합니다 |
| 자료 버튼이 없어요 | 첨부가 없거나 목록을 아직 불러오지 못한 경우 등을 구분해야 합니다. 버튼 없음만으로 자료 미제공을 확정하지 않습니다 |
| 자료 버튼이 비활성화돼 있어요 | 처리 중인지 기간/권한 제한 안내가 있는지 확인합니다. 강제로 활성화하거나 다른 계정/직접 주소로 우회하지 않습니다 |
| 목차는 보이는데 받을 수 없어요 | 목차 열람과 다운로드 권한은 별도입니다. 만료·취소 심사 중 이용 제한 등의 상황은 학원에 확인합니다 |

현재 목차의 자료 버튼은 **파일 선택창이 아닙니다.** 파일명·용량·형식 목록이나 파일별 선택 메뉴, 전체 강좌 압축 다운로드의 제공 여부는 아직 확인이 필요합니다. 어떤 파일을 주는지 먼저 알아야 한다면 클릭 전에 학원 안내를 확인합니다.

완료 체크는 수업 학습 상태이며 자료를 이미 받았다는 표시가 아닙니다. 무료 수업·미리보기·외부 영상이라는 이유만으로 첨부 다운로드 권한이 모두 같다고 판단하지 않습니다.

> **화면 예시 준비 중** · 자료 버튼과 학습 완료 표시를 구분합니다.

## 3. 필요한 자료 요청하기 <a href="#step-3" id="step-3"></a>

1. 받을 수업 제목을 확인한 뒤 해당 행의 **자료**를 한 번 누릅니다.
2. 버튼에 처리 중 표시가 나타나면 기다립니다. 연속으로 누르거나 다른 수업의 자료를 함께 눌러 결과를 시험하지 않습니다.
3. 새 창/탭에 파일이 열리거나 브라우저에서 다운로드가 진행되는지 확인합니다. 파일 형식·기기·브라우저에 따라 결과가 다를 수 있습니다.
4. 다음 단계에서 실제 파일 저장 여부를 확인합니다. 버튼이 다시 활성화되거나 오류 안내가 없다는 것만으로 성공을 확정하지 않습니다.

아래 PC·모바일 안내 중 **지금 사용하는 기기의 절차만** 확인합니다. 이미 요청했다면 저장 여부를 먼저 확인하고, 다른 기기에서 같은 버튼을 다시 누를 필요는 없습니다.

**자료를 누르면 다운로드 주소 발급 단계에서 이용 이력이 기록될 수 있습니다.** 파일을 저장하지 못했거나 창을 닫았다고 기록이 자동 취소되는 것은 아닙니다. 다운로드 이력의 처리와 환불 가능 여부는 해당 주문·학원의 확인된 안내를 따르며 학생이 직접 기록을 초기화하지 않습니다.

같은 수업에서 여러 파일/창이 열리거나 일부만 받아졌다면 이미 저장된 파일부터 확인합니다. 자료 버튼은 원하는 파일 하나를 선택하는 메뉴가 아니므로, 부족한 파일을 받으려고 반복 누르기 전에 학원에 대상 파일을 확인합니다.

> **화면 예시 준비 중** · 필요한 자료만 요청하고 처리 중에는 기다립니다.

## 4. PC에서 파일 저장 확인하기 <a href="#step-4" id="step-4"></a>

1. 파일이 새 창/탭에서 열렸다면 내용과 수업이 맞는지 확인합니다. **브라우저에서 열린 상태와 기기에 저장된 상태는 다릅니다.**
2. 열린 뷰어에 저장/다운로드 기능이 있으면 실제 제공되는 조작으로 저장합니다. 자동 다운로드됐다면 브라우저의 다운로드 내역에서 완료/실패 상태를 확인합니다.
3. 저장한 위치에서 파일을 찾습니다. 기본 다운로드 폴더나 사용자가 선택한 폴더 등 실제 브라우저 설정에 따릅니다.
4. 저장된 파일을 열어 수업 내용과 페이지/본문을 확인합니다. 파일명만 같거나 다운로드 내역에 항목이 있다는 것만으로 정상 파일로 판단하지 않습니다.

모든 파일이 PDF로 열리거나 원래 파일명 그대로 저장된다고 보장하지 않습니다. 저장 위치·버튼 이름은 브라우저/운영체제에 따라 다를 수 있습니다. 파일을 열려고 임의의 프로그램을 설치하거나 보안 설정을 해제하지 않습니다.

> **화면 예시 준비 중** · 새 탭 열림과 실제 파일 저장을 구분합니다.

## 5. 모바일에서 파일 저장 확인하기 <a href="#step-5" id="step-5"></a>

1. 하단 **목차**에서 자료를 요청한 뒤 새 화면/탭이나 브라우저 다운로드 안내가 나타나는지 확인합니다. 이미 요청했다면 자료를 다시 누르지 않습니다.
2. 파일 미리보기가 열리면 기기/브라우저에서 실제 제공하는 저장 동작을 확인합니다. 미리보기만 된 경우 저장 완료로 보지 않습니다.
3. 다운로드 내역과 기기의 파일 보관 위치를 확인하고 저장된 파일을 엽니다. 사진 앱/갤러리로 모든 문서가 저장되는 것은 아닙니다.
4. 자료 확인 후 기존 강의실 탭으로 돌아와 강좌·수업 제목을 확인합니다. 패널이 열려 있으면 **패널 닫기**로 영상 화면에 돌아옵니다.

iPhone·Android와 앱 내 브라우저가 같은 메뉴/폴더를 제공한다고 가정하지 않습니다. 결과가 불명확하면 현재 브라우저·기기와 표시 문구를 기록해 문의합니다. 다른 브라우저로 자료 다운로드 주소를 복사하거나 파일을 전달받아 권한 제한을 우회하지 않습니다.

> **화면 예시 준비 중** · 기기에서 저장된 파일을 찾아 확인합니다.

## 6. 파일 내용과 사용 범위 확인하기 <a href="#step-6" id="step-6"></a>

파일을 열어 **대상 수업·내용·열림 오류 여부**를 확인합니다. 저장된 파일을 열 수 없거나 빈 파일/예상과 다른 내용이면 반복 다운로드로 확인하지 말고 학원에 문의합니다. 필요한 프로그램이나 파일 형식 안내는 학원의 확인된 정보를 따릅니다.

강의 자료와 다운로드 주소는 다른 사람에게 공유하지 않습니다. 자료를 받았다고 재배포·공개 업로드가 허용되는 것은 아니며 학원이 안내한 사용 범위를 따릅니다. 받은 파일이 이후 교체/수정될 때 기기에 자동 갱신되는 것으로 보지 않습니다.

> **화면 예시 준비 중** · 저장한 파일을 열어 해당 수업 자료인지 확인합니다.

## 자료를 받지 못했을 때 <a href="#section-8" id="section-8"></a>

| 상황 | 확인할 것·다음 행동 |
| --- | --- |
| 다른 수업 자료가 열렸어요 | 자료를 누른 행의 수업 제목과 열린 내용을 대조합니다. 현재 재생 수업의 자료라고 가정하지 않습니다 |
| 자료 버튼이 없거나 계속 비활성화돼요 | 강좌·섹션·수업, 현재 기간/제한 안내를 확인하고 문의합니다. 목록 오류를 첨부 없음으로 단정하지 않습니다 |
| 자료 다운로드에 실패했습니다. 잠시 후 다시 시도해 주세요. | 발급/요청 단계의 안내입니다. 이미 열린 탭·다운로드 내역·저장 파일을 먼저 확인하고 반복되면 문의합니다 |
| 새 창/탭이나 저장 파일이 없어요 | 브라우저에 표시된 새 창/다운로드 차단·실패 안내가 있는지 확인합니다. 보안 설정을 일괄 해제하거나 반복 발급하지 않습니다 |
| 창은 열렸는데 접근 거절·시간 경과 안내가 나와요 | 임시 다운로드 주소의 접근 문제일 수 있습니다. 수강 기간과 같은 것으로 단정하거나 주소를 수정/공유하지 않습니다. 현재 화면 문구를 학원에 전달합니다 |
| 일부 파일만 받았어요 | 이미 받은 파일과 누른 수업을 확인합니다. 모두 실패한 것으로 보고 버튼을 반복 누르지 말고 필요한 파일을 학원에 확인합니다 |
| 파일이 안 열리거나 내용이 달라요 | 파일명·기기·오류 문구·대상 수업을 전달합니다. 확장자 변경/보안 해제·추가 구매로 해결하려 하지 않습니다 |
| 만료·취소 심사/이용 제한이 있어요 | 파일 저장 문제가 아닌 권한 문제와 구분합니다. 다른 계정·직접 주소나 재구매로 복구를 시험하지 않습니다 |

화면의 실패 안내가 모든 브라우저 저장 실패를 감지하는 것은 아닙니다. 반대로 파일을 못 찾았다는 사실만으로 이용 이력이 없다고 판단하지 않습니다. 다시 받을 필요가 있다면 학원 확인 후 현재 권한이 허용된 정상 화면에서 진행하며, 오래된 다운로드 주소는 재사용하지 않습니다.

> **화면 예시 준비 중** · 요청 실패와 기기 저장/열기 문제를 구분해 전달합니다.

## 학원에 문의할 때 <a href="#contact-academy" id="contact-academy"></a>

학원 사이트 주소, 계정 식별에 필요한 최소 정보, 강좌·섹션·수업 제목, 클릭한 시각, PC/모바일·기기/브라우저, 표시 문구, 새 창/탭 열림 여부, 다운로드 내역·저장 파일 여부와 파일명을 전달합니다. 일부만 받은 경우 받은 파일과 부족한 파일을 구분합니다.

**비밀번호·인증번호·세션/토큰·자료 다운로드 주소·영상 URL·Vimeo 접근키는 보내지 않습니다.** 개인정보·주소창·다른 파일을 가린 캡처만 전달합니다. 로그인할 수 없을 때는 로그인 후에만 이용할 수 있는 1:1 문의 대신 학원이 별도로 안내한 연락처로 문의합니다.

## 완료 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 현재 학원 사이트·계정과 강좌/수업 제목을 확인했다.
- [ ] 강의 첨부·별도 내 자료·공지 첨부·교재 배송을 구분했다.
- [ ] PC 커리큘럼·모바일 목차에서 해당 수업의 자료를 찾았다.
- [ ] 수업 제목 이동·완료 체크와 자료 버튼의 동작을 구분했다.
- [ ] 기간/권한과 다운로드 이용 이력 안내를 확인하고 필요할 때만 요청했다.
- [ ] 버튼 처리 종료·새 창 열림과 실제 파일 저장을 구분했다.
- [ ] 저장 위치에서 파일을 찾아 열고 대상 수업의 내용을 확인했다.
- [ ] 자료/주소를 공유하거나 기록 없음·환불 가능을 임의로 판단하지 않았다.
- [ ] 실패/일부 저장 시 반복 발급·권한 우회 없이 필요한 정보만 학원에 전달했다.
