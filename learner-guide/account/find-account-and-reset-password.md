# 계정 찾기·비밀번호 재설정

<figure><img src="../.gitbook/assets/branding/page-headers/account/find-account-and-reset-password-v2.png" alt="아이디 찾고 비밀번호 재설정하기 대표 이미지"><figcaption></figcaption></figure>

**아이디가 기억나지 않으면 휴대폰 인증으로 가입 이메일을 확인**하고, **비밀번호가 기억나지 않으면 가입 이메일을 인증해 새 비밀번호를 설정**합니다. 구매하거나 수강권을 받은 학원 사이트에서 진행합니다.

**필요한 기능부터 선택하세요:** 아이디를 잊었다면 아이디 찾기, 학원 사이트의 이메일 로그인에 쓰는 비밀번호를 잊었다면 비밀번호 재설정을 이용합니다. 재설정 후에는 **새 비밀번호로 다시 로그인**합니다. 아이디 조회·이메일 인증·비밀번호 저장만으로 로그인되거나 강좌 지급·계정 통합이 이루어지는 것은 아닙니다.

## 시작 전 준비 <a href="#before-you-start" id="before-you-start"></a>

| 준비할 것 | 확인할 내용 |
| --- | --- |
| 학원 사이트 주소 | 구매하거나 수강권을 받은 사이트의 이름·주소가 맞는지 확인합니다. 클킷 관리자 주소나 다른 학원 사이트에서 찾지 않습니다 |
| 가입 때 사용한 휴대폰 | 아이디 찾기는 해당 사이트 계정에 등록한 번호와 문자 수신이 필요합니다. 현재 쓰는 번호와 가입 당시 번호가 같은지 확인합니다 |
| 가입 이메일 | 비밀번호 재설정은 해당 사이트에 가입한 이메일의 수신함을 확인할 수 있어야 합니다. 아이디 결과의 가려진 문자는 직접 입력할 이메일이 아닙니다 |
| 로그인 방식 | 이메일·비밀번호 또는 카카오/구글 중 사용한 방식을 확인합니다. 카카오·구글로 가입했어도 비밀번호를 재설정할 수 있는 계정이 있습니다. |
| 개인 기기와 비공개 문의 경로 | 비밀번호·인증번호·인증 주소는 공유하지 않습니다. 로그인할 수 없다면 학원에서 안내한 외부 연락처와 문의 방법을 확인합니다 |

이미 로그인한 상태라면 복구 화면 대신 사이트 홈으로 이동할 수 있습니다. 먼저 현재 계정을 확인합니다. 로그인 중 계정 설정에서 비밀번호를 변경하는 것과 로그인하지 않은 상태에서 비밀번호를 재설정하는 것은 다른 절차입니다.

## 먼저 내 상황 고르기 <a href="#choose-your-situation" id="choose-your-situation"></a>

| 상황 | 사용할 기능 | 다음 행동 |
| --- | --- | --- |
| 가입 이메일을 모름 | 로그인 → 아이디 찾기 → 등록 휴대폰 인증 | 일부 가려진 이메일·가입일시를 참고해 본인 계정 확인 |
| 가입 이메일은 알지만 비밀번호를 모름 | 로그인 → 비밀번호 재설정 → 이메일 인증 | 새 비밀번호 저장 뒤 로그인 |
| 이메일과 비밀번호를 모두 모름 | 아이디 찾기부터 진행 | 전체 이메일을 확인한 뒤 해당 가입 방식으로 로그인 또는 재설정 |
| 소셜 로그인 전용 계정 안내가 나옴 | 가입했던 카카오/구글 간편 로그인 | 같은 제공자·같은 소셜 계정으로 로그인. 새 가입으로 우회하지 않음 |
| 예전 번호·이메일을 사용할 수 없거나 계정을 구분할 수 없음 | 학원에서 안내한 비공개 문의 | 본인 확인과 가능한 복구 방법 문의. 연락처 변경·계정 통합·권리 이전을 임의로 진행하지 않음 |

## 1. 로그인 화면에서 필요한 기능 열기 <a href="#step-1" id="step-1"></a>

1. 학원에서 안내한 사이트를 열고 **로그인**으로 이동합니다. 모바일에서 보이지 않으면 메뉴를 엽니다.
2. 이메일이 기억나지 않으면 **아이디 찾기**, 비밀번호를 바꾸려면 **비밀번호 재설정**을 선택합니다.
3. 두 기능을 모두 사용해야 한다면 아이디 찾기로 이메일부터 확인합니다. 이때 찾는 아이디는 학생 이름이나 휴대폰 번호가 아니라 **이메일 주소**입니다.

> **화면 예시 준비 중** · 이메일이 기억나지 않으면 아이디 찾기, 비밀번호를 잊었다면 재설정을 선택합니다.

> **동작 예시 준비 중** · 필요한 복구 기능으로 이동합니다.

## 2. 등록한 휴대폰으로 아이디 찾기 <a href="#step-2" id="step-2"></a>

1. **아이디(이메일) 찾기** 화면에서 **휴대폰 번호**의 국가를 확인합니다. 국내 번호라면 **대한민국 +82**를 선택합니다.
2. 해당 계정에 등록한 본인 휴대폰 번호를 입력합니다. 국내 번호는 입력란 안내에 따라 하이픈 없이 입력합니다.
3. **인증**을 눌러 문자 발송을 요청합니다.
4. 문자로 받은 **6자리 인증 번호**를 입력합니다. 화면의 남은 시간과 오류 안내를 확인합니다.
5. **확인**을 누르고, 인증과 아이디 결과 조회가 끝날 때까지 기다립니다. 문자를 받았거나 번호를 입력한 상태만으로 계정을 찾았다고 판단하지 않습니다.

문자가 오지 않으면 국가·번호 오타와 차단 메시지를 먼저 확인합니다. 번호를 잘못 입력했는데 수정할 수 없으면 시작 화면으로 돌아가 올바른 번호로 다시 시작합니다. 번호를 바꾸기 위해 재발송을 누르거나 다른 사람의 번호를 사용하지 않습니다.

인증번호가 틀렸거나 만료되었다는 안내가 나오면 새 발송이 필요한지 확인합니다. **재발송이 성공한 뒤 새로 받은 번호**를 사용하며 연속 요청하지 않습니다. 남은 시간이 표시되더라도 서버에서 만료 안내가 나오면 기존 번호로 반복 확인하지 않습니다.

> **화면 예시 준비 중** · 등록한 휴대폰으로 인증하고 아이디 결과를 확인합니다.

## 3. 아이디 결과에서 본인 계정 확인하기 <a href="#step-3" id="step-3"></a>

1. 결과 화면의 **일부 가려진 이메일**과 **가입일시**를 확인합니다. 같은 번호로 등록한 계정이 여러 개면 결과가 여러 개 나올 수 있습니다.
2. 가려진 이메일과 가입일을 가입 당시 정보와 비교합니다. `*`처럼 가려진 부분을 나타내는 문자를 그대로 로그인 칸에 입력하지 않습니다.
3. 사용할 **전체 이메일 주소**를 확인했다면 **확인**으로 로그인 화면에 돌아갑니다. 이메일·비밀번호로 이용하는 계정의 비밀번호가 기억나지 않으면 **비밀번호 재설정**을 선택합니다.
4. 결과만으로 전체 이메일이나 가입 방식을 알 수 없다면 학원에 문의합니다. 가입일이 같거나 휴대폰이 같다는 이유로 구매·수강 계정이 동일하다고 단정하지 않습니다.

**가입된 아이디가 없습니다**가 나오면 사이트·등록 번호·기존 가입 방식을 다시 확인합니다. 예전 번호나 탈퇴 관련 상태일 수도 있으므로 이 안내만으로 미가입을 확정하거나 새 계정을 만들지 않습니다. 구매·지급 이력이 있다면 기존 계정 확인을 먼저 요청합니다.

결과 화면을 새로고침하거나 저장한 주소로 다시 열었을 때 인증 만료·잘못된 접근 안내가 나올 수 있습니다. 안내에 따라 아이디 찾기부터 다시 진행합니다. **결과 주소는 복구용 공유 링크가 아니며 다른 사람에게 전달하지 않습니다.**

> **화면 예시 준비 중** · 가려진 이메일과 가입일시를 참고해 기존 계정을 확인합니다.

## 4. 가입 이메일 인증하기 <a href="#step-4" id="step-4"></a>

1. 로그인 화면 또는 아이디 결과의 **비밀번호 재설정**을 엽니다.
2. **이메일**에 해당 사이트의 **전체 가입 이메일**을 입력하고 오타를 확인합니다. 아이디 찾기 결과에 나온 일부 가려진 이메일을 그대로 입력하지 않습니다.
3. **인증**을 눌러 이메일 발송을 요청합니다.
4. 해당 수신함에서 받은 **6자리 인증번호**를 입력하고 인증번호 옆의 **확인**을 누릅니다.
5. **이메일 인증이 완료되었습니다** 표시를 확인합니다. 이 표시는 이메일 인증 완료이며 아직 비밀번호 변경 완료가 아닙니다.

메일이 보이지 않으면 입력 주소·스팸함·차단 설정과 발송 오류를 확인합니다. 재발송은 화면 안내에 따라 요청하고, 성공 후 새로 받은 번호를 사용합니다. **가입되지 않은 이메일** 안내가 나오면 사이트·주소·기존 소셜 가입 방식을 확인합니다. 화면에 회원가입 링크가 있어도 기존 구매·지급 계정 확인을 먼저 합니다.

이메일을 잘못 입력했는데 수정할 수 없다면 재설정 시작 화면에서 올바른 주소로 다시 시작합니다. 인증 후 오래 머물렀거나 만료 안내가 나오면 화면 안내에 따라 이메일 인증부터 다시 진행합니다. 정확한 유효 시간을 추측하거나 발송을 반복해 해결하지 않습니다.

> **화면 예시 준비 중** · 이메일 인증 완료와 비밀번호 변경 완료는 다릅니다.

## 5. 새 비밀번호를 입력하고 저장하기 <a href="#step-5" id="step-5"></a>

1. 이메일 인증을 완료한 뒤 **새 비밀번호**를 입력합니다.
2. 현재 화면에서 요구하는 **8자 이상 30자 이하**, **소문자·대문자·숫자·특수문자 모두 포함** 조건을 확인합니다. 이전 비밀번호와 다른 값을 정합니다.
3. **새 비밀번호 확인**에 동일한 값을 입력합니다. 조건 표시와 일치 여부의 오류가 없는지 확인합니다.
4. **재설정 완료**를 한 번 누르고 결과를 기다립니다. 버튼이 비활성화되어 있으면 인증 완료·입력 조건·일치 여부부터 확인합니다.
5. **비밀번호 재설정 완료** 안내가 나타나는지 확인합니다. 조건 표시가 충족되거나 버튼을 누른 것만으로 저장 성공이라고 판단하지 않습니다.

비밀번호를 보려면 입력란의 보기 아이콘을 사용할 수 있지만 공용 화면·화면 공유·촬영 중에는 노출하지 않습니다. 인증 완료 후에도 재설정 요청에서 인증 만료 안내가 나오면 이메일 인증부터 다시 진행합니다.

저장 중 연결이 끊기거나 결과가 불분명하면 **같은 재설정 요청을 연속 실행하지 않습니다**. 로그인 화면에서 해당 계정과 새 비밀번호로 로그인되는지 먼저 확인합니다. 로그인도 되지 않으면 오류와 발생 단계를 정리해 학원에 문의합니다. 실패 안내만으로 비밀번호가 그대로라고 단정하지 않습니다.

> **화면 예시 준비 중** · 조건을 충족하고 이전과 다른 비밀번호를 입력합니다.

## 6. 새 비밀번호로 다시 로그인하기 <a href="#step-6" id="step-6"></a>

1. **비밀번호 재설정 완료** 안내에서 **로그인**을 선택합니다. **메인 페이지**로 이동했다면 사이트에서 로그인을 다시 엽니다.
2. **아이디**에 전체 가입 이메일, **비밀번호**에 새로 설정한 값을 입력합니다. 브라우저 자동 완성이 이전 비밀번호를 넣지 않았는지 확인합니다.
3. **로그인**을 누르고 본인 계정으로 접속되었는지 확인합니다. PC는 사용자 메뉴의 **마이페이지 → 계정 설정 → 내 프로필**, 모바일은 메뉴의 **계정 설정** 등 로그인 후 항목에서 이름·이메일을 확인합니다.
4. 구매·지급받은 강좌가 있다면 같은 계정인지 확인합니다. 강좌가 보이지 않는다고 다시 가입·결제하지 않습니다. 로그인에 성공했더라도 해당 강좌를 이용할 수 있는지는 따로 확인해야 합니다.

비밀번호 재설정은 **카카오·구글 계정 자체의 비밀번호 변경이 아닙니다**. 또한 재설정 완료가 모든 기기의 즉시 로그아웃이나 탈퇴 취소·수강권 복구를 보장하지 않습니다. 공용 기기 이용 후 로그아웃과 계정 보안 확인은 별도로 합니다.

> **화면 예시 준비 중** · 완료 안내 뒤 새 비밀번호로 로그인해 본인 계정을 확인합니다.

## 7. 소셜 로그인 전용 안내가 나오는 경우 <a href="#step-7" id="step-7"></a>

‘**소셜 로그인 전용 계정입니다**’라는 안내가 나오면 이 화면에서 비밀번호 재설정을 계속하지 않습니다.

1. 안내의 **소셜 로그인하기**를 눌러 로그인 화면으로 이동합니다.
2. 가입 때 사용한 카카오 또는 구글 아이콘을 선택하고 **같은 소셜 계정**으로 진행합니다.
3. 본인 계정으로 돌아왔는지 확인합니다. 추가 회원가입 화면이 나오거나 소셜 계정도 찾을 수 없다면 새 가입을 계속하기 전에 학원에 문의합니다.

카카오·구글 계정 자체에 접속할 수 없다면 해당 서비스의 복구 안내를 확인합니다. 학원 사이트의 비밀번호 재설정으로 외부 계정이 복구되거나 다른 소셜 계정이 자동 연결되는 것은 아닙니다. 카카오·구글로 가입했더라도 비밀번호를 재설정할 수 있는지는 본인 계정 화면의 안내를 확인하세요. **소셜 로그인 전용 계정입니다**라는 안내가 표시되면 가입 때 사용한 카카오·구글 계정으로 로그인합니다.

> **화면 예시 준비 중** · 소셜 전용 안내가 나오면 기존 소셜 계정으로 로그인합니다.

## 잘되지 않을 때 <a href="#troubleshooting" id="troubleshooting"></a>

| 증상 | 먼저 확인 | 다음 행동 |
| --- | --- | --- |
| 복구 화면 대신 홈이 열려요 | 현재 로그인 상태·계정 | 이미 로그인했다면 현재 프로필을 먼저 확인합니다. 로그인 중 비밀번호 변경과 로그인 전 비밀번호 재설정을 구분합니다 |
| 문자나 이메일이 오지 않아요 | 국가·등록 번호/주소·스팸/차단·발송 오류 | 안내에 따라 재발송하되 연속 요청하지 않습니다. 기존 연락처를 못 쓰면 학원에 문의합니다 |
| 인증번호가 틀리거나 시간이 남았는데 만료돼요 | 인증 대상·최근 성공한 발송의 번호·표시된 오류 | 만료 안내를 우선 확인하고 새 발송이 성공하면 새 번호로 인증합니다. 인증번호를 문의에 넣지 않습니다 |
| 요청이 많거나 입력 가능 횟수를 넘었다고 나와요 | 발송과 확인 중 어느 단계인지·화면 안내 | 반복 요청을 멈추고 안내에 따릅니다. 다른 번호·계정으로 제한을 우회하지 않습니다 |
| 전화번호나 이메일 입력을 수정할 수 없어요 | 발송/인증 후인지·입력 대상 오타 | 해당 복구 시작 화면으로 돌아가 올바른 대상부터 다시 확인합니다. 다른 계정으로 넘어가지 않습니다 |
| 가입된 아이디/계정이 없다고 나와요 | 학원 사이트·예전 연락처·가입 방식·탈퇴 안내 | 기존 구매/지급 이력이 있다면 재가입보다 학원 확인을 우선합니다 |
| 이메일 일부가 가려지거나 결과가 여러 개예요 | 가입일시·기존 가입 기록·구매 계정 | 가려진 이메일을 그대로 입력하거나 가려진 부분을 추측하지 말고, 전체 이메일 주소와 본인 계정을 확인합니다 |
| 결과 페이지를 다시 열면 오류가 나요 | 새로고침·뒤로가기·저장된 결과 주소 사용 여부 | 결과 주소를 재사용/공유하지 않고 안내에 따라 아이디 찾기부터 진행합니다 |
| 재설정 완료 버튼을 누를 수 없어요 | 이메일 인증·비밀번호 길이/문자 조건·일치 여부 | 오류가 있는 입력부터 수정합니다. 인증 완료와 비밀번호 저장을 구분합니다 |
| 이전 비밀번호와 같거나 저장 오류가 나요 | 이전과 다른 값·화면 오류·인증 만료 | 다른 비밀번호를 사용하고 만료 안내가 있으면 이메일 인증부터 다시 진행합니다. 정확한 오류 문구는 화면 기준입니다 |
| 소셜 로그인 전용 안내가 나와요 | 가입 제공자·실제 선택한 소셜 계정 | 같은 방식으로 로그인합니다. 새 이메일 가입·연결 해제·계정 통합으로 우회하지 않습니다 |
| 저장 뒤 로그인되지 않거나 강좌가 없어요 | 결과 안내·전체 이메일·자동 완성·현재 계정·구매/지급 여부 | 불명확하면 반복 재설정/재가입/재결제하지 말고 학원에 문의합니다. 로그인과 강좌 지급을 따로 확인합니다 |

먼저 **학원 이름, 아이디 찾기/비밀번호 재설정 중 막힌 단계, 오류 문구와 발생 시각**을 알려 주세요. 추가 요청을 받으면 기기·브라우저와 학원 첫 화면 주소를 전달하되 주소창 전체나 인증 링크는 보내지 않습니다. 계정을 확인하는 데 필요한 정보는 학원의 비공개 경로로 필요한 범위만 전달합니다. **비밀번호·인증번호·인증 메일·계정 찾기나 비밀번호 재설정 과정의 결과 페이지 주소·카카오·구글 같은 소셜 로그인 후 학원 사이트로 돌아온 페이지의 주소·토큰·다른 사람의 계정 정보는 공유하지 않습니다.** 로그인할 수 없다면 로그인 후에만 이용할 수 있는 1:1 문의 외에 학원에서 별도로 안내한 연락처를 확인합니다. 실제 문의 연락처·본인 확인 방법·운영 시간은 아직 확인이 필요합니다.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 구매하거나 수강권을 받은 학원 사이트에서 복구를 시작했습니다.
- [ ] 아이디 찾기의 휴대폰 인증과 재설정의 이메일 인증을 구분했습니다.
- [ ] 아이디 결과를 이용했다면 가려진 이메일·가입일시를 확인하고 실제 사용할 전체 이메일을 확인했습니다.
- [ ] 계정 없음·복수 결과·예전 연락처 문제에서 재가입보다 기존 계정 확인을 우선했습니다.
- [ ] 재설정했다면 이메일 인증 후 조건에 맞는 새 비밀번호와 확인 값을 입력했습니다.
- [ ] 비밀번호 입력 조건이나 인증 완료가 아니라 재설정 완료 결과를 확인했습니다.
- [ ] 새 비밀번호 또는 소셜 전용 안내에 맞는 기존 방식으로 다시 로그인해 본인 계정을 확인했습니다.
- [ ] 비밀번호 변경과 강좌 지급·외부 소셜 계정 복구·전체 기기 로그아웃을 같은 결과로 해석하지 않았습니다.
- [ ] 비밀번호·인증번호·결과 주소를 공유하지 않고, 공용 기기 이용 후 로그아웃했습니다.
