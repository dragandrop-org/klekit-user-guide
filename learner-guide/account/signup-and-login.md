# 회원가입·로그인하기

> **검토용 가이드** · 실제 서비스 화면·동작 확인과 이미지 보완이 남아 있습니다. 본문의 실행 보류·주의사항을 먼저 확인하세요.

**학원에서 안내한 사이트**에 가입하거나, 이미 가입한 계정으로 로그인합니다. 강사·운영자가 클킷을 관리하는 주소가 아니라 수강할 학원 사이트에서 시작합니다.

**완료 기준:** 해당 사이트에서 본인 계정으로 로그인하고, 계정 설정의 이름·이메일을 확인합니다. **로그인 성공과 강좌·자료 지급은 별개**입니다. 구매하거나 지급받은 강좌가 없다면 내 학습 목록이 비어 있어도 로그인 실패가 아닙니다.

## 시작 전 준비 <a href="#before-you-start" id="before-you-start"></a>

| 준비할 것 | 확인할 내용 |
| --- | --- |
| 학원 사이트 주소 | 학원에서 안내한 주소·사이트 이름이 맞는지 확인합니다. 다른 학원이나 관리자 사이트의 계정으로 자동 이용된다고 생각하지 않습니다 |
| 기존 가입 여부 | 이미 가입했다면 새 계정을 만들기 전에 기존 이메일·카카오/구글 가입 방식을 확인합니다. 구매하거나 수강권을 지급받은 계정을 사용합니다 |
| 이메일과 휴대폰 | 신규 가입 화면에서 인증을 진행할 수 있도록 사용할 이메일과 문자를 확인할 수 있는 휴대폰을 준비합니다 |
| 가입 유형 | 학생은 학생 계정으로 진행합니다. 학부모 가입은 사이트에서 허용하고 학원에서 해당 유형을 안내한 경우에만 선택합니다 |
| 개인 기기 | 공용 PC에서는 자동 로그인을 선택하지 않고, 이용 후 로그아웃합니다. 비밀번호·인증번호는 다른 사람에게 전달하지 않습니다 |

## 먼저 내 상황 고르기 <a href="#choose-your-situation" id="choose-your-situation"></a>

| 상황 | 시작할 곳 | 확인할 결과 |
| --- | --- | --- |
| 처음 이메일로 가입 | 회원가입 → 이메일 간편회원가입 → 이메일 인증 → 추가 정보·필수 동의 | 가입 요청 결과를 확인하고 본인 계정으로 로그인 |
| 처음 카카오/구글로 가입 | 회원가입 → 해당 간편회원가입 → 외부 인증 → 필요한 이메일 인증·추가 정보·필수 동의 | 소셜 인증만이 아니라 사이트 가입과 로그인까지 확인 |
| 이메일로 가입한 적 있음 | 로그인 → 아이디에 가입 이메일·비밀번호 입력 | 계정 설정에서 본인 정보 확인 |
| 카카오/구글로 가입한 적 있음 | 로그인 → 간편 로그인에서 같은 제공자·같은 계정 선택 | 다른 소셜 계정이 아닌 기존 가입 계정인지 확인 |
| 가입 방식이나 비밀번호를 모름 | 로그인 화면의 아이디 찾기·비밀번호 재설정 또는 학원 문의 | 재가입·재결제 전에 기존 계정 확인. 복구 상세는 [아이디 찾고 비밀번호 재설정하기](find-account-and-reset-password.md)에서 확인 |

## 1. 학원 사이트에서 가입 화면 열기 <a href="#step-1" id="step-1"></a>

1. 학원에서 안내한 사이트를 엽니다. 사이트 이름과 주소가 맞는지 확인합니다.
2. PC에서는 상단의 **로그인** 또는 **회원가입**을 누릅니다. 모바일에서 보이지 않으면 메뉴를 열어 같은 항목을 찾습니다.
3. 로그인 화면에서도 **회원가입**으로 이동할 수 있습니다. 이미 가입한 계정이 있다면 가입 대신 로그인을 선택합니다.
4. 가입 화면에서 **이메일 간편회원가입**, **카카오 간편회원가입**, **구글 간편회원가입** 중 사용할 방식을 선택합니다. 실제 화면에 제공된 방식을 기준으로 합니다.

> **화면 예시 준비 중** · 학원 사이트에서 가입하거나 기존 계정으로 로그인합니다.

> **동작 예시 준비 중** · 가입 방식을 선택하고 이메일 가입 화면을 확인합니다.

## 2. 이메일 인증하기 <a href="#step-2" id="step-2"></a>

이메일로 처음 가입할 때 진행합니다. 소셜 가입 후 이메일 인증 화면이 나온 경우에도 같은 방식으로 확인합니다.

1. **이메일**에 사용할 주소를 입력하고 오타가 없는지 확인합니다.
2. **인증**을 눌러 인증번호 발송을 요청합니다.
3. 해당 이메일에서 받은 **6자리 인증번호**를 입력하고 **확인**을 누릅니다. 화면에 표시되는 남은 시간을 확인합니다.
4. 이메일 인증이 완료되면 추가 정보 입력 화면으로 이동합니다. 인증번호만 받은 상태는 가입 완료가 아닙니다.

메일이 보이지 않으면 입력 주소와 스팸함부터 확인합니다. 만료 안내가 나오면 화면 안내에 따라 **재발송**을 요청하고 새로 받은 번호로 확인합니다. 발송 중이거나 오류가 반복될 때는 연속해서 요청하지 말고 안내 문구를 확인합니다.

**이미 가입된 이메일입니다**가 나오면 새 이메일로 우회 가입하기 전에 기존 가입 방식을 확인합니다. 소셜로 가입한 계정도 같은 이메일을 사용할 수 있습니다. 같은 이메일을 입력했다고 계정이 자동 통합되거나 구매 권리가 옮겨지는 것은 아닙니다.

> **화면 예시 준비 중** · 이메일 인증을 완료하면 추가 정보 입력으로 이동합니다.

## 3. 추가 정보와 휴대폰 인증 완료하기 <a href="#step-3" id="step-3"></a>

1. 인증한 **이메일**이 맞는지 확인하고 **이름**을 입력합니다. 이 단계의 이메일은 읽기 전용입니다.
2. **가입 유형**이 표시되면 학원 안내에 맞는 유형을 선택합니다. 학생은 **학생**, 허용된 학부모 가입은 **학부모**를 선택합니다.
3. **휴대폰 인증**에 사용할 번호를 입력하고 **인증**을 누릅니다. 국내 번호는 입력란 안내에 따라 하이픈 없이 입력합니다.
4. 문자로 받은 **6자리 인증번호**를 입력하고 **확인**을 누릅니다. **휴대폰 인증이 완료되었습니다** 표시를 확인합니다.
5. **비밀번호**와 **비밀번호 확인**을 입력합니다. 현재 가입 화면은 **8자 이상 30자 이하**, **소문자·대문자·숫자·특수문자 모두 포함**을 요구합니다. 두 칸을 동일하게 입력합니다.
6. 아래 필수 동의 항목을 확인하고 다음 절의 최종 가입을 진행합니다.

이 가입 화면에서는 휴대폰 인증까지 완료해야 회원가입 버튼을 사용할 수 있습니다. 인증한 뒤 번호를 수정했다면 다시 인증합니다. 인증번호를 입력하거나 확인 버튼을 누른 것만으로 성공을 판단하지 말고 완료 표시를 확인합니다.

> **화면 예시 준비 중** · 추가 정보와 휴대폰 인증을 확인하고 비밀번호 조건을 맞춥니다.

### 학부모로 가입하는 경우 <a href="#parent-signup" id="parent-signup"></a>

학부모 유형은 사이트가 허용한 경우에만 표시됩니다. **학부모**를 선택하면 **자녀 이름**을 입력합니다. 이 정보는 학원 확인용이며 **별도 학생 계정 생성·구매 권리 이전·자녀 계정 자동 연결을 뜻하지 않습니다**.

학부모 항목이 없거나 자녀 이름 입력 오류가 해결되지 않으면 학원에 가입 유형을 문의합니다. 임의로 다른 유형을 선택하거나 학생·학부모 계정을 여러 개 만들지 않습니다.

> **화면 예시 준비 중** · 학부모 가입은 허용된 사이트에서만 선택합니다.

## 4. 필수 동의를 확인하고 가입하기 <a href="#step-4" id="step-4"></a>

1. 이용약관과 개인정보 처리방침의 내용을 열어 읽습니다.
2. 화면의 필수 항목인 **클킷 이용약관**, **개인정보 처리방침**, **만 14세 이상입니다**를 확인합니다.
3. **다양한 혜택 및 이용소식**은 선택 항목입니다. 필수 항목과 구분해 수신 여부를 정합니다. **아래 약관에 모두 동의합니다**는 선택 항목도 함께 체크하므로 원하지 않는 수신 동의가 포함되지 않았는지 확인합니다.
4. 입력 오류·휴대폰 인증·필수 동의를 확인한 뒤 **회원가입**을 누릅니다.
5. 가입 요청 결과와 이후 로그인 상태를 확인합니다. 로그인 화면으로 돌아왔다면 가입한 계정으로 로그인하고, 오류가 있다면 아래 문제 해결을 확인합니다.

만 14세 미만이라면 사실과 다르게 동의해 진행하지 말고 학원에 이용·가입 안내를 문의합니다. 학부모 가입을 연령 확인의 우회 방법으로 설명하지 않습니다.

> **화면 예시 준비 중** · 필수 동의와 선택 수신 동의를 구분해 확인합니다.

## 5. 카카오·구글로 처음 가입하기 <a href="#step-5" id="step-5"></a>

1. 회원가입 화면에서 **카카오 간편회원가입** 또는 **구글 간편회원가입**을 선택합니다.
2. 외부 인증 화면에서 앞으로 사용할 **본인 소셜 계정**을 확인하고 안내에 따라 진행합니다. 공유 기기에 로그인된 다른 사람의 계정을 선택하지 않습니다.
3. 학원 사이트로 돌아오면 표시되는 화면을 확인합니다. 처음 가입하는 경우 추가 정보 입력이 필요합니다. 이메일 인증 화면이 나오면 2절부터 진행합니다.
4. 이메일·이름·휴대폰 인증·비밀번호/확인·필수 동의를 확인하고 **회원가입**을 완료합니다. 소셜 신규 가입도 현재 화면에서는 이 추가 정보를 입력합니다.
5. 기존 가입 계정이라 바로 로그인된 경우에는 새 가입을 반복하지 말고 7절에서 현재 계정을 확인합니다.

소셜에서 이메일이 전달되면 이메일 인증 단계가 생략될 수 있습니다. **이메일 인증 생략과 추가 정보·휴대폰 인증·가입 완료는 다릅니다.** 표시된 이메일을 바꿀 수 없거나 예상한 계정이 아니면 가입을 진행하지 말고 선택한 소셜 계정부터 확인합니다.

외부 인증 취소·오류·복귀 지연이 있으면 가입·로그인이 완료됐다고 판단하지 않습니다. 외부 인증 주소나 복귀 주소 전체에는 인증정보가 포함될 수 있으므로 복사해 공유하지 않습니다.

> **화면 예시 준비 중** · 소셜 신규 가입도 필요한 추가 정보를 입력합니다.

## 6. 기존 계정으로 로그인하기 <a href="#step-6" id="step-6"></a>

### 이메일과 비밀번호로 로그인 <a href="#email-login" id="email-login"></a>

1. 학원 사이트에서 **로그인**을 엽니다.
2. **아이디**에 가입한 **이메일 주소**를 입력합니다. 학생 이름이나 휴대폰 번호를 입력하는 칸이 아닙니다.
3. **비밀번호**를 입력합니다. 공용 PC에서는 **자동 로그인**을 선택하지 않습니다.
4. **로그인**을 누르고 결과를 확인합니다. 가입 때 사용한 이메일과 학원 사이트가 맞는지 다시 확인합니다.

아이디가 기억나지 않으면 **아이디 찾기**, 비밀번호가 기억나지 않으면 **비밀번호 재설정**을 사용합니다. 두 기능의 상세 절차는 [아이디 찾고 비밀번호 재설정하기](find-account-and-reset-password.md)에서 확인합니다. 기존 계정을 확인하지 않고 다시 가입하거나 같은 상품을 재결제하지 않습니다.

### 카카오 또는 구글로 로그인 <a href="#social-login" id="social-login"></a>

로그인 화면의 **간편 로그인**에서 가입 때 사용한 카카오/구글 아이콘을 선택합니다. 같은 제공자라도 소셜 계정이 다르면 기존 수강 계정과 다를 수 있습니다. 추가 가입 화면이 새로 나타나면 입력을 계속하기 전에 사이트·제공자·선택한 계정을 확인합니다.

탈퇴 대기·재동의 등 별도 안내가 나오면 일반 로그인 완료와 구분합니다. 이 안내는 탈퇴 취소·복구·약관 재동의의 실행 절차를 다루지 않습니다. 안내가 해결되지 않으면 학원에 문의합니다.

## 7. 로그인된 계정과 다음 행동 확인하기 <a href="#step-7" id="step-7"></a>

1. 로그인 뒤 PC에서는 사용자 메뉴의 **마이페이지**를 엽니다. 모바일에서는 메뉴의 **계정 설정** 등 로그인 후 항목으로 이동합니다.
2. **계정 설정 → 내 프로필**에서 본인의 이름·이메일을 확인합니다. 프로필을 불러오지 못했다면 다른 계정이라고 단정하지 말고 오류를 먼저 확인합니다.
3. 이미 구매하거나 수강권을 받은 경우에는 **내 학습 → 수강중 강좌**에서 대상 강좌를 확인합니다. 상세한 이동은 [내 강의 찾고 수강 시작하기](../learning/find-course-and-start.md)를 참고합니다.
4. 아직 구매·지급 이력이 없다면 강좌 목록이 비어 있을 수 있습니다. 로그인 성공을 확인하기 위해 상품을 구매하거나 영상을 재생할 필요는 없습니다.
5. 공용 기기 이용을 마쳤다면 사용자 메뉴 또는 모바일 메뉴에서 **로그아웃**합니다. 로그아웃 뒤 본인 정보가 그대로 노출되지 않는지 확인합니다.

다른 사람 계정이라면 그 상태로 구매·질문·개인정보 변경을 하지 않습니다. 로그아웃 후 본인 가입 방식으로 다시 로그인합니다. 보호자가 결제한 내역이 자녀의 다른 계정에 자동으로 나타난다고 보장하지 않습니다.

> **화면 예시 준비 중** · 본인 계정 확인과 강좌 지급 여부는 별도로 확인합니다.

## 막혔을 때 확인하기 <a href="#troubleshooting" id="troubleshooting"></a>

| 상황 | 먼저 확인할 것 | 다음 행동 |
| --- | --- | --- |
| 이메일이나 문자가 오지 않아요 | 주소/번호 오타, 스팸함·차단 메시지, 발송 오류·진행 상태 | 화면 안내에 따라 재발송하되 반복 요청하지 않습니다. 계속되지 않으면 학원에 오류 문구를 전달합니다 |
| 인증번호가 틀리거나 만료됐어요 | 입력한 대상과 새로 받은 번호, 남은 시간·만료 안내 | 만료됐다면 새 번호로 다시 확인합니다. 인증번호를 문의 메시지에 넣지 않습니다 |
| 이미 가입된 이메일이라고 나와요 | 기존 이메일·소셜 가입 방식과 학원 사이트 | 기존 로그인 또는 아이디 찾기/비밀번호 재설정을 먼저 확인합니다. 새 계정으로 우회하지 않습니다 |
| 회원가입 버튼을 누를 수 없어요 | 이메일 단계 완료, 이름, 비밀번호 조건/일치, 휴대폰 인증, 필수 동의·학부모 선택 시 자녀 이름 | 오류가 표시된 입력부터 확인합니다. 선택 수신 동의를 가입 필수로 보지 않습니다 |
| 약관 내용이 열리지 않거나 가입 오류가 계속돼요 | 필수 동의 내용과 화면 오류 | 내용을 확인하지 않고 전체 동의를 눌러 넘기거나 선택 동의를 필수로 바꾸지 않습니다. 학원에 오류를 문의합니다 |
| 가입을 눌렀는데 완료인지 모르겠어요 | 알림/오류와 현재 로그인 상태, 기존 계정 로그인 가능 여부 | 연속 가입보다 기존 계정 확인을 우선합니다. 가입과 이후 자동 로그인이 별도 처리될 수 있습니다 |
| 소셜 로그인 후 가입 화면이 다시 나와요 | 학원 주소·카카오/구글 제공자·실제 선택한 계정 | 새 가입을 계속하기 전에 기존 계정을 확인합니다. 계정 연결 해제나 통합을 해결책으로 실행하지 않습니다 |
| 학부모 선택이 없거나 자녀 이름 오류가 나요 | 학원이 안내한 가입 유형과 화면 오류 | 다른 유형·새 계정으로 우회하지 말고 학원에 확인합니다. 자녀 계정/수강권 자동 생성을 기대하지 않습니다 |
| 로그인 오류·탈퇴/재동의 안내가 나와요 | 입력한 이메일과 가입 방식, 안내 문구 | 로그인 오류만으로 미가입/탈퇴 완료를 단정하지 않습니다. 해결되지 않으면 학원에 문의합니다 |
| 로그인했는데 강좌가 없어요 | 현재 계정, 구매/지급 여부, 내 학습 목록의 조회 오류·필터 | 미구매 빈 목록과 권리 누락을 구분합니다. 로그인 확인을 위한 재구매·재생은 하지 않습니다 |

문의할 때는 **학원 사이트 이름·민감한 경로를 뺀 주소, 가입 방식, 막힌 단계, 오류 문구, 기기/브라우저**를 정리합니다. 계정 식별 정보는 학원이 안내한 비공개 문의 경로로 필요한 범위만 전달합니다. **비밀번호·인증번호·인증 메일 링크·소셜 복귀 주소·토큰·다른 학생 정보는 공유하지 않습니다.** 로그인하지 못하는 상황에서 로그인 후 1:1 문의만을 유일한 창구로 안내하지 않으며, 실제 학원 연락처·운영 시간은 공개 전 확정합니다.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 수강할 학원 사이트와 가입 주소가 맞습니다.
- [ ] 기존 계정이 있는지 확인하고 사용할 가입/로그인 방식을 구분했습니다.
- [ ] 신규 가입했다면 필요한 이메일·휴대폰 인증의 완료 표시를 확인했습니다.
- [ ] 학부모 유형은 허용된 경우에만 선택했고 자녀 이름을 권리 자동 연결로 해석하지 않았습니다.
- [ ] 필수 동의와 선택 수신 동의를 구분했고 실제 조건과 다르게 체크하지 않았습니다.
- [ ] 가입 요청과 이후 로그인 결과를 구분해 확인했습니다.
- [ ] 계정 설정에서 본인의 이름·이메일을 확인했습니다.
- [ ] 빈 강좌 목록을 로그인 실패로 단정하거나 확인용 구매/재생을 하지 않았습니다.
- [ ] 공용 기기에서는 자동 로그인을 선택하지 않고 이용 후 로그아웃했습니다.
