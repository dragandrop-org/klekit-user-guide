# 내 계정과 로그인 방식 보기

<figure><img src="../.gitbook/assets/branding/page-headers/account/check-account-and-login-method-v2.png" alt="내 계정과 로그인 방식 확인하기 대표 이미지"><figcaption></figcaption></figure>

**계정 설정 → 내 프로필**에서 현재 계정의 이름·이메일·휴대폰과 **간편로그인 연결 상태**를 확인합니다. 강좌나 결제 내역이 예상과 다르면 정보를 바꾸기 전에 구매하거나 수강권을 받은 계정인지 먼저 확인합니다.

**확인 순서:** 내 프로필 → 이름·이메일 → 카카오·구글 연결 상태 → 기존 로그인 방식. 구매 내역·강좌 목록도 같은 계정의 정보인지 확인합니다. 계정을 확인하는 동안 개인정보나 연결 상태를 바꾸지 않습니다.

## 시작 전 준비 <a href="#before-you-start" id="before-you-start"></a>

| 준비할 것 | 확인할 내용 |
| --- | --- |
| 학원 사이트 주소 | 구매하거나 수강권을 받은 사이트의 이름·주소가 맞는지 확인합니다. 다른 학원 사이트나 클킷 관리자 주소와 구분합니다 |
| 기존 로그인 정보 | 가입 이메일 또는 사용했던 카카오/구글 계정을 확인합니다. 같은 카카오·구글 로그인 방식을 사용해도 선택한 계정이 다르면 같은 학원 사이트 계정이라고 단정하지 않습니다 |
| 구매·지급 정보 | 구매 당시 안내·주문 정보 또는 학원에서 수강권을 지급한 계정을 참고합니다. 다른 사람의 계정에 접속해 비교하지 않습니다 |
| 개인 기기 | 프로필·연락처·주문 정보가 화면 공유나 공용 기기에 남지 않도록 합니다. 비밀번호·인증번호는 문의에 넣지 않습니다 |

아직 로그인하지 않았다면 [회원가입·로그인하기](signup-and-login.md)를 먼저 확인합니다. 기존 계정이 기억나지 않으면 [아이디 찾고 비밀번호 재설정하기](find-account-and-reset-password.md)를 참고합니다. 계정 확인을 위해 새로 가입하거나 다시 결제하지 않습니다.

## 먼저 내 상황 고르기 <a href="#choose-your-situation" id="choose-your-situation"></a>

| 상황 | 먼저 볼 곳 | 다음 행동 |
| --- | --- | --- |
| 지금 누구의 계정인지 모르겠어요 | 계정 설정 → 내 프로필 | 이름만 보지 말고 이메일·등록 휴대폰과 기존 가입 정보를 비교 |
| 카카오/구글을 연결했는지 궁금해요 | 내 프로필 → 간편로그인 설정 | 연동/미연동 표시만 읽기. 확인 목적으로 스위치를 누르지 않음 |
| 어떤 방식으로 다시 로그인할지 모르겠어요 | 기존 로그인 기록·가입 안내와 연결 상태 | 연결 상태만으로 현재 로그인 방식·비밀번호 유무를 확정하지 않음 |
| 결제했는데 강좌가 없어요 | 내 프로필을 확인한 뒤, 구매 내역과 내 학습 메뉴를 각각 확인 | 현재 계정·원 주문(해당 상품을 구매한 주문)·강좌 목록을 따로 확인. 재결제하지 않음 |
| 다른 사람의 계정이 열려 있어요 | 사이트 주소·현재 프로필 | 수정·구매·수강을 중단하고 로그아웃 후 본인의 기존 방식으로 로그인 |

## 1. 내 프로필 열기 <a href="#step-1" id="step-1"></a>

1. 학원 사이트의 이름과 주소를 확인합니다.
2. PC에서는 상단 **사용자 메뉴 → 마이페이지 → 계정 설정 → 내 프로필**로 이동합니다.
3. 모바일에서는 상단 메뉴를 열고 **계정 설정**으로 이동해 **내 프로필**을 확인합니다. 메뉴의 프로필 영역에서도 계정 설정으로 이동할 수 있습니다.
4. 프로필 로딩이 끝난 뒤 정보를 읽습니다. **프로필 정보를 불러오지 못했습니다**가 나오면 정보가 없는 계정이라고 판단하지 않습니다.

상단의 이름·사진·이니셜이나 **회원** 표시만으로 구매 계정을 확정하지 않습니다. 로그인 화면으로 이동했다면 기존 계정으로 로그인한 뒤 다시 확인합니다.

> **화면 예시 준비 중** · 계정 설정의 내 프로필에서 현재 계정을 확인합니다.

> **동작 예시 준비 중** · 정보를 바꾸지 않고 내 프로필로 이동합니다.

## 2. 이름·이메일·휴대폰 확인하기 <a href="#step-2" id="step-2"></a>

1. **이름**과 **이메일**을 기존 가입 정보와 비교합니다. 이름이 같다는 이유만으로 같은 계정이라고 단정하지 않습니다.
2. **휴대폰번호**가 본인이 등록한 번호인지 확인합니다. 국가번호·하이픈 등 표시 형식 차이와 실제 번호 차이를 구분합니다.
3. 이메일의 `-`나 휴대폰의 **등록 필요**는 현재 화면에 해당 값이 표시되지 않는 상태입니다. 해당 표시만으로 강좌 미지급·회원 탈퇴·로그인 실패를 판단하지 않습니다.
4. 본인 정보가 아니거나 오래된 정보라면 먼저 기존 계정 여부를 확인합니다. 확인을 위해 **이메일 변경·휴대폰 변경·휴대폰 인증**을 누르지 않습니다.

연락처 옆 표시만으로 현재 이메일·휴대폰의 본인 인증이 모두 완료되었다고 판단하지 않습니다. 이 페이지에서는 표시된 등록 정보만 확인하며 연락처 변경·인증은 진행하지 않습니다.

> **화면 예시 준비 중** · 등록 정보를 비교하되 값 없음과 조회 오류를 구분합니다.

### 학부모 계정인 경우 <a href="#parent-account" id="parent-account"></a>

학부모 계정에는 **자녀 이름**이 추가로 표시될 수 있습니다. 표시된 이름은 학원 확인용 정보이며 **별도 학생 계정 생성·학생 계정 연결·구매나 수강권 이전 완료 표시가 아닙니다**. 학생의 강좌를 가져오기 위해 자녀 이름을 바꾸지 않습니다.

> **화면 예시 준비 중** · 자녀 이름 표시는 학생 계정 연결이나 수강권 이전이 아닙니다.

## 3. 카카오·구글 연결 상태 읽기 <a href="#step-3" id="step-3"></a>

1. 내 프로필의 **간편로그인 설정**으로 이동합니다.
2. **구글 간편로그인**, **카카오 간편로그인** 옆의 **연동 / 미연동**을 확인합니다.
3. **연동**은 해당 제공자가 현재 사이트 계정에 연결되어 있다는 표시입니다. **미연동**은 연결되지 않았다는 표시이며, 누르면 확인 화면만 열린다는 뜻이 아닙니다.
4. 상태만 확인할 때는 스위치를 누르지 않습니다. 켜면 외부 계정 연결을 시작할 수 있고, 끄면 연동 해제 확인으로 이어질 수 있습니다.

**연동 표시는 이번에 어떤 방식으로 로그인했는지, 처음 가입한 방식이 무엇인지, 어느 카카오/구글 이메일 계정인지까지 보여주지 않습니다.** 두 제공자가 모두 연결되어 있어도 현재 로그인 방식을 하나로 추측하지 않습니다. 외부 계정의 식별 정보가 필요하면 기존 가입 기록을 확인하거나 학원에 문의합니다.

> **화면 예시 준비 중** · 연동은 연결 상태이며 현재 로그인 방식이나 외부 계정 이메일 표시가 아닙니다.

## 4. 다시 로그인할 방식 확인하기 <a href="#step-4" id="step-4"></a>

| 이미 알고 있는 정보 | 사용할 안내 | 여기서 단정하지 않을 것 |
| --- | --- | --- |
| 해당 사이트에서 이메일·비밀번호로 로그인한 적이 있음 | [회원가입·로그인하기](signup-and-login.md)의 기존 계정 로그인. 비밀번호를 잊었다면 [아이디 찾고 비밀번호 재설정하기](find-account-and-reset-password.md) | 이메일이 표시된다는 이유만으로 비밀번호 등록·로그인 가능을 확정하지 않음 |
| 카카오/구글의 특정 계정으로 로그인한 적이 있음 | [회원가입·로그인하기](signup-and-login.md)의 같은 제공자·같은 소셜 계정 로그인 | 제공자 이름만 같으면 자동으로 같은 학생 계정이 된다고 보지 않음 |
| 간편로그인 연결 상태만 알고 기존 방식은 모름 | 가입 당시 기록과 현재 프로필을 확인하고 필요하면 학원 문의 | 연결 스위치·비밀번호 변경을 시험해 로그인 방식을 알아내지 않음 |

내 프로필의 **비밀번호**는 가려진 문자로 표시되며 **비밀번호 변경** 버튼이 있습니다. **가려진 문자가 보인다고 실제 비밀번호가 등록되어 있거나 이메일 로그인이 가능하다는 뜻은 아닙니다.** 이 화면에서 현재 비밀번호를 볼 수 있는 것은 아닙니다.

로그인 중 **비밀번호 변경**과 로그인 전 **비밀번호 재설정**은 다른 절차입니다. 카카오·구글로 가입했더라도 이메일·비밀번호로 로그인할 수 있는지는 본인 계정에 따라 다를 수 있습니다. [아이디 찾고 비밀번호 재설정하기](find-account-and-reset-password.md)에서 본인 계정에 맞는 안내를 확인합니다. 계정 확인만을 위해 로그아웃 후 여러 방식을 차례로 시험하거나 새 비밀번호를 저장하지 않습니다.

> **화면 예시 준비 중** · 비밀번호 숨김 표시만으로 등록 여부를 알 수는 없습니다.

## 5. 구매하거나 지급받은 계정과 비교하기 <a href="#step-5" id="step-5"></a>

1. 내 프로필의 이메일·등록 정보를 구매 또는 학원 지급 당시 계정 정보와 비교합니다.
2. **마이페이지 → 구매 내역 → 결제**에서 주문명·상태·금액 등 이미 알고 있는 주문 정보와 비교합니다. 목록에 표시된 날짜만으로 결제 성공이나 강좌 지급 완료를 판정하지 않습니다.
3. **결제 내역이 없습니다**와 **결제 내역을 불러오지 못했습니다**를 구분합니다. 페이지 이동·모바일 추가 목록도 확인하며 첫 화면에 없다는 이유로 모든 주문이 없다고 단정하지 않습니다.
4. 강좌 지급 여부는 **내 학습 → 수강중 강좌** 목록에서 따로 확인합니다. **전체 / 수강중 / 완료 / 만료** 필터와 오류 안내를 구분합니다.
5. 내역이 예상과 다르면 재가입·재결제·연락처 변경을 하지 말고 학원에 계정과 지급 여부 확인을 요청합니다.

**학원이 직접 수강권을 지급한 계정은 결제 내역이 없어도 강좌가 있을 수 있습니다.** 반대로 결제 내역이 있다고 모든 강좌의 이용 권한이 현재 유효한 것은 아닙니다. 구매한 상품의 구성·지급·기간은 별도로 확인합니다. 계정을 확인하려고 강의실에 들어가 재생하거나 자료를 내려받을 필요는 없습니다.

보호자 명의 결제·같은 휴대폰·같은 자녀 이름만으로 다른 학생 계정에 강좌·자료 이용 권한이 자동으로 연결되지는 않습니다. 구매 내역 목록에 구매자 이메일이나 계정 통합 버튼이 제공된다고 가정하지 않습니다. 주문 상세는 [주문·결제 내역 확인하기](../orders/order-and-payment-history.md), 수강 시작 방법은 [내 강의 찾고 수강 시작하기](../learning/find-course-and-start.md)에서 확인합니다.

> **화면 예시 준비 중** · 결제 내역과 강좌 지급 여부는 따로 확인합니다.

## 6. 다른 계정이라면 변경 전에 멈추기 <a href="#step-6" id="step-6"></a>

1. 사이트 주소와 프로필을 다시 확인합니다. 다른 사람의 계정이라면 수정·구매·수강을 중단합니다.
2. 본인 계정으로 바꾸려면 사이트의 **로그아웃**을 이용합니다. PC는 사용자 메뉴, 모바일은 메뉴에서 찾습니다.
3. [회원가입·로그인하기](signup-and-login.md)의 기존 계정 안내에 따라 본인이 사용한 방식으로 로그인합니다. 소셜 로그인에서는 제공자와 선택한 외부 계정을 모두 확인합니다.
4. 돌아온 내 프로필이 본인 계정인지 확인합니다. 계속 다른 계정이 열리거나 기존 계정을 구분할 수 없다면 학원에 문의합니다.

로그아웃 오류가 났는데 화면에서 로그인 메뉴가 보이는 경우에도 **이 사이트에서 실제로 로그아웃됐는지, 다른 기기에서도 로그아웃됐는지는 이 화면만으로 확인할 수 없습니다**. 공용 기기·타인 계정 문제가 있으면 개인정보를 남기지 말고 학원에 상황을 알립니다. 연결 해제·이메일 변경·재가입을 계정 전환이나 통합의 대체 방법으로 사용하지 않습니다.

## 확인과 변경 구분하기 <a href="#reading-vs-changing" id="reading-vs-changing"></a>

| 화면 요소 | 단순 확인 범위 | 계정 확인 중 하지 않을 일 |
| --- | --- | --- |
| 이름·학부모 계정에 표시되는 자녀 이름 | 표시된 값 읽기 | 수정·저장·자녀 이름 삭제 |
| 프로필 사진 | 현재 표시 읽기 | 사진 변경·파일 업로드 |
| 이메일·휴대폰 | 등록 값·등록 필요 표시 읽기 | 변경·인증 발송/확인 |
| 비밀번호 | 숨김 표시·변경 기능의 위치 구분 | 숨김 표시를 실제 비밀번호 조회나 등록 여부의 증거로 해석하기·비밀번호 변경 또는 재설정 실행 |
| 간편로그인 설정 | 연동/미연동 읽기 | 스위치 조작·외부 연결·해제 |
| 마케팅 정보 수신 동의 | 선택 항목 위치만 구분 | 체크박스 조작. 변경이 바로 반영될 수 있으므로 확인용으로 누르지 않음 |
| 회원탈퇴 | 별도 절차임을 구분 | 진입·비밀번호 입력·탈퇴 요청 |

## 잘되지 않을 때 <a href="#troubleshooting" id="troubleshooting"></a>

| 증상 | 먼저 확인 | 다음 행동 |
| --- | --- | --- |
| 내 프로필 대신 로그인 화면이 열려요 | 사이트 주소·로그인 유지 여부 | 본인의 기존 방식으로 로그인합니다. 계정이 기억나지 않으면 [아이디 찾고 비밀번호 재설정하기](find-account-and-reset-password.md)를 확인합니다 |
| 프로필 로딩이 길거나 오류가 나요 | 로딩/조회 오류·통신 상태 | 정보 없음으로 해석하지 않습니다. 오류가 계속되면 발생 시각·기기/브라우저를 정리해 문의합니다 |
| 이름은 같지만 이메일이 달라요 | 가입 당시 이메일·현재 사이트 | 변경 전에 기존 구매/지급 계정을 확인합니다. 이름만으로 계정을 통합하지 않습니다 |
| 휴대폰 항목에 **등록 필요**가 표시되거나 이메일이 비어 있어요 | 현재 표시와 알고 있는 가입 정보 | 미가입·탈퇴·권리 없음으로 단정하지 말고 학원에 확인합니다. 확인을 위해 인증을 실행하지 않습니다 |
| 간편로그인이 연동인데 어느 계정인지 모르겠어요 | 기존 소셜 계정·가입 기록 | 화면이 외부 계정 이메일이나 현재 로그인 이력을 보여준다고 가정하지 않습니다 |
| 미연동이거나 비밀번호가 가려져 있어요 | 연결 상태와 기존 로그인 방식 | 미연동을 가입 불가로, 숨김 표시를 비밀번호 등록 완료로 해석하지 않습니다 |
| 결제 내역이나 강좌가 없어요 | 현재 계정·빈/오류·목록 페이지·강좌 필터·직접 지급 여부 | 재결제/재가입하지 않고 학원에 원 주문·지급 여부 확인을 요청합니다 |
| 다른 사람의 계정이 계속 열려요 | 공용 기기·브라우저 자동 로그인·외부 계정 선택 | 정보 변경을 멈추고 로그아웃한 뒤 본인의 기존 계정으로 로그인해 확인합니다. 불명확하면 문의합니다 |

먼저 **학원 이름, 막힌 메뉴, 오류 문구와 발생 시각**을 알려 주세요. 추가 요청을 받으면 기기·브라우저와 학원 첫 화면 주소를 전달하되 주소창 전체나 개인 링크는 보내지 않습니다. 본인 계정과 주문을 확인하는 데 필요한 정보는 학원의 비공개 문의 경로로 필요한 범위만 전달합니다. **비밀번호·인증번호·토큰·카카오·구글 같은 소셜 로그인 후 학원 사이트로 돌아온 페이지의 주소·다른 사람의 프로필/주문은 공유하지 않습니다.** 실제 문의 연락처·본인 확인 방법·운영 시간은 아직 확인이 필요합니다. 학원에서 안내한 최신 문의 방법을 확인합니다.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 구매하거나 수강권을 받은 학원 사이트인지 확인했습니다.
- [ ] 내 프로필의 이름·이메일·휴대폰을 기존 가입 정보와 비교했습니다.
- [ ] 조회 오류와 값 없음·등록 필요 표시를 구분했습니다.
- [ ] 학부모의 자녀 이름을 학생 계정 연결·권리 이전으로 해석하지 않았습니다.
- [ ] 간편로그인의 연동/미연동만 읽고 확인을 위해 스위치를 누르지 않았습니다.
- [ ] 연결 상태·비밀번호 숨김 표시만으로 현재 로그인 방식이나 비밀번호 유무를 확정하지 않았습니다.
- [ ] 필요한 경우 구매 내역과 강좌 목록을 따로 확인하고 빈/오류·필터·직접 지급을 구분했습니다.
- [ ] 다른 계정이거나 결과가 불명확할 때 수정·재가입·재결제 대신 기존 계정 확인을 우선했습니다.
- [ ] 계정 확인 중 불필요한 변경·인증·재생·다운로드를 하지 않고 개인정보를 공유하지 않았습니다.
