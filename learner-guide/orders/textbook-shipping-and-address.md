# 교재 배송과 배송지 확인하기

<figure><img src="../.gitbook/assets/branding/page-headers/orders/textbook-shipping-and-address-v2.png" alt="교재 배송과 배송지 확인하기 대표 이미지"><figcaption></figcaption></figure>

교재가 오지 않거나 배송지를 확인해야 한다면 **구매한 사이트·계정 → 원 주문(해당 상품을 구매한 주문)·교재 확인 → 학원이 안내한 배송 정보 확인 → 필요한 내용 문의** 순서로 준비합니다. 결제완료·송장 등록·실제 발송·수령은 서로 다른 결과입니다.

**먼저 확인하세요:** 어떤 주문의 교재인지, 배송 확인이 필요한지 주소 정정이 필요한지 정리합니다. 학원의 접수 답변만으로 주소 변경·택배 인계·환불이 끝난 것은 아니므로 해당 결과도 확인해야 합니다.

## 시작 전 확인 <a href="#before-you-start" id="before-you-start"></a>

| 확인할 것 | 내용 |
| --- | --- |
| 사이트와 계정 | 교재를 구매한 학원 사이트와 계정인지 확인합니다. 보호자나 다른 계정의 주문이 현재 계정에 자동 합쳐지는 것은 아닙니다 |
| 배송 대상 | 구매한 구성에 실물 교재가 포함됐는지 확인합니다. 강좌·영상·디지털 자료는 택배 배송 대상과 구분합니다 |
| 원 주문 | 주문번호·상품명·교재명과 수량을 준비합니다. 강좌 개수나 주문 대표 이름만으로 교재 수량을 판단하지 않습니다 |
| 문의 목적 | 배송 정보 확인·미수령·상품/수량 차이·주소 정정 중 어떤 도움이 필요한지 구분합니다. 취소/반품/교환 신청과도 다릅니다 |
| 개인정보 | 주문번호는 필요한 학원 담당자에게만 전달합니다. 전체 주소·연락처·공동현관 비밀번호를 공개 글이나 화면 캡처에 넣지 않습니다 |

## 1. 원 주문과 배송할 교재 확인하기 <a href="#step-1" id="step-1"></a>

1. **마이페이지 → 구매 내역 → 결제**에서 해당 주문을 찾습니다. 자세한 방법은 [주문·결제 내역 확인하기](order-and-payment-history.md)를 참고합니다.
2. 주문번호·상품을 대조합니다. 묶음 상품이라면 포함 교재와 추가로 선택한 교재를 구분합니다.
3. 교재 구성이나 수량이 상세에 충분히 보이지 않으면 주문번호와 구매한 상품명을 학원에 알려 확인합니다. 현재 상세 카드만으로 모든 옵션·구성품·수량이 펼쳐진다고 가정하지 않습니다.

**결제완료는 배송 대상 생성·발송 완료를 뜻하지 않습니다.** 0원 주문도 실제 교재 제공 범위를 별도로 확인합니다. 배송 정보가 안 보인다는 이유로 같은 상품을 다시 구매하거나 새 주문서를 열어 주소를 바꾸려 하지 않습니다.

> **화면 예시 준비 중** · 원 주문과 확인할 교재를 먼저 특정합니다.

## 2. 배송 상태의 의미 구분하기 <a href="#step-2" id="step-2"></a>

원 주문 상세의 **배송 정보**에서 해당 교재/배송을 확인합니다. 생성 대기 안내와 실제 배송 건, **상품 준비 중·발송 완료·배송 취소**를 구분하고 아래 기준을 함께 읽습니다. 화면의 안내만으로 실제 택배 인계·수령을 확정하지 않습니다.

| 구분 | 의미·확인할 것 |
| --- | --- |
| 배송 대상 생성 확인 중 | 결제 이후 실제 배송 건이 만들어졌는지 확인하는 단계입니다. 배송 건이 아직 보이지 않는 것과 배송 취소·배송 불필요는 다릅니다 |
| 배송 대기 | 배송 대상이 생성된 단계입니다. 화면에서는 배송 준비와 함께 **상품 준비 중**으로 표시될 수 있습니다 |
| 배송 준비 | 포장·출고 준비 단계입니다. **상품 준비 중**이라는 같은 문구여도 학생의 직접 주소 정정 조건은 배송 대기와 다릅니다 |
| 발송 완료 | 발송 처리된 단계입니다. 택배사의 이동 상황·실제 수령 여부는 별도로 확인합니다. 이 상태를 수령 완료로 읽지 않습니다 |
| 배송 취소 | 해당 교재 배송의 취소 결과입니다. 혼합 주문의 강좌·자료까지 포함한 주문 전체 취소나 실제 환불 반영과 같다고 단정하지 않습니다 |

배송 정보의 **배송 조회**는 택배사와 송장 정보를 이용하는 외부 조회 경로입니다. 조회 링크가 있다고 실제 택배 접수·인계·수령이 완료된 것은 아닙니다. 링크가 없으면 표시된 판매자 문의 안내를 따르고 임의 사이트에 정보를 넣지 않습니다. 실제 외부 조회 결과와 배송 진행 상황은 아직 확인이 필요합니다.

주문 배지나 문의 접수만으로 출고일·도착일·운송장 반영 시간을 확정할 수 없습니다. 수령하지 못했는데 완료로 안내받았거나 구성/수량이 다르면 원 주문·교재·실제 상황을 나눠 문의합니다.

> **화면 예시 준비 중** · 배송 표시와 실제 발송·수령을 구분합니다.

## 3. 주소록과 주문·배송 주소 구분하기 <a href="#step-3" id="step-3"></a>

| 주소의 종류 | 의미 | 오해하지 않을 것 |
| --- | --- | --- |
| 주소록 | 구매할 때 선택할 수 있도록 저장한 주소 | 주소록·기본 배송지를 바꿔도 이미 주문한 교재의 배송지가 자동으로 정정되는 것은 아닙니다 |
| 주문 당시 주소 | 해당 주문을 만들 때 기록한 주소 | 배송지를 정정하더라도 원 주문의 기록을 새 주소로 덮어쓰는 것은 아닙니다 |
| 배송 건의 주소 | 해당 배송을 처리하는 데 사용하는 수령 정보 | 어떤 주문/배송 건인지 특정해 변경 가능 여부와 실제 반영을 확인해야 합니다 |

주소를 확인할 때는 수령인·연락처·우편번호·기본 주소·상세 주소·배송 요청사항 중 어떤 항목이 잘못됐는지 구분합니다. 화면에서 확인할 수 없는 값은 학원 담당자에게 확인합니다. 주소록에 원하는 주소가 있다는 사실만으로 이번 배송에 적용됐다고 판단하지 않습니다.

주소 확인만을 위해 결제 화면으로 다시 이동하거나 새 주문·배송을 만들지 않습니다. 구매 단계의 배송지 선택 화면을 이미 결제한 주문의 주소 정정 화면으로 사용하지 않습니다.

> **화면 예시 준비 중** · 주소록 변경은 기존 배송 주소 변경과 다릅니다.

## 4. 배송지 정정 조건 확인하기 <a href="#step-4" id="step-4"></a>

배송지를 직접 바꾸기 전에는 **본인 배송·배송 대기·발송 이력 없음** 조건을 확인합니다. 원 주문 상세의 **배송 정보 → 배송지 변경**이 표시되는 대상에서 수령 정보/요청사항을 대조하고 저장 후 같은 배송의 결과를 확인합니다. 버튼이 보이는 것과 저장 시점에 변경이 허용되는 것은 다릅니다. 변경 충돌이나 발송 이력 때문에 저장이 거절되면 반복 저장하지 않고 학원에 문의합니다.

| 상황 | 정정 문의 시 확인할 것 |
| --- | --- |
| 배송 대상 생성 전이거나 생성 여부 불명확 | 기존 주문의 배송 생성 여부부터 확인합니다. 주소록 수정이나 새 주문으로 해결됐다고 판단하지 않습니다 |
| 배송 대기이고 발송 이력이 없어요 | 학생 직접 정정 조건에 해당할 수 있습니다. 현재 변경 가능한지와 대상 배송 건을 학원에 확인합니다 |
| 배송 준비로 진행됐어요 | 학생 직접 정정 조건과 다릅니다. 발송 이력이 없으면 운영자가 처리할 수 있는 조건이 따로 있지만, 문의만으로 변경을 보장하지 않습니다 |
| 발송 완료·배송 취소 또는 발송 이력이 있어요 | 기존 배송지 정정 대상이 아닙니다. 가능한 후속 대응을 학원에 문의합니다. 관리자에게 상태를 되돌려 달라고 요구하지 않습니다 |
| 준비 상태로 다시 바뀌었어요 | 과거 발송 사실은 남습니다. 상태 보정이나 송장 해제로 주소 정정 자격이 복원되는 것은 아닙니다 |
| 다른 곳에서 동시에 변경됐어요 | 현재 배송 상태와 최근 변경 내용을 학원에 확인합니다. 예전 정보로 덮어쓰거나 같은 요청을 반복하지 않습니다 |

학원에 요청을 보낸 것과 정정이 저장된 것, 출고 담당자가 변경 내용을 확인한 것은 각각 다릅니다. 처리 결과를 안내받으면 **대상 주문/교재·바뀐 수령 정보·아직 출고 전인지**를 다시 확인합니다. 상세 주소와 배송 요청사항을 각각 유지할지 지울지 처리 담당자와 확인합니다. 이 정보는 처리에 필요한 담당자에게만 전달합니다.

> **화면 예시 준비 중** · 허용 조건과 실제 저장 결과를 따로 확인합니다.

> **동작 예시 준비 중** · 기존 배송 정보와 주소 변경 가능 여부를 읽습니다.

## 5. 상황별로 학원에 문의하기 <a href="#step-5" id="step-5"></a>

| 상황 | 먼저 전달할 내용 |
| --- | --- |
| 배송 정보가 없어요 | 주문번호·상품/교재명·결제 확인 시각과 배송 대상 생성 여부를 확인해 달라는 요청 |
| 상품 준비 중에서 바뀌지 않아요 | 안내받은 문구·확인 시각과 출고 준비/일정 확인 요청. 같은 문구만으로 주소 정정 가능 여부를 판단하지 않음 |
| 송장을 받았는데 조회가 안 돼요 | 안내받은 택배사·송장과 조회한 시각/문구. 실제 인계 여부와 정보 일치 확인 요청 |
| 발송됐다고 하는데 못 받았어요 | 대상 교재·미수령 사실·안내받은 상태/시각. 수령 완료를 임의로 확정하거나 직접 반품 처리하지 않음 |
| 교재 종류나 수량이 달라요 | 원 주문의 교재·수량과 실제 받은 내용을 비교합니다. 사진에는 차이가 보이도록 남기고, 송장 라벨의 수령인·주소·연락처·바코드는 가린 뒤 담당자 안내에 따라 전달합니다 |
| 배송지를 바꾸고 싶어요 | 원 주문·교재·바꿀 항목과 현재 배송/발송 여부 확인 요청. 전체 주소는 확인된 개별 창구로 전달 |
| 주소록은 바꿨는데 배송 주소가 달라요 | 주소록 변경과 이미 생성된 배송 건의 정정이 별개임을 설명하고 해당 건의 실제 주소 확인 요청 |
| 취소했는데 배송 안내가 와요 | 취소 신청/확정 결과와 배송 안내를 나눠 전달. 임의 재취소·재결제·송장/주소 변경으로 해결하지 않음 |

문의는 [사이트에 1:1 문의하기](../communication/site-inquiries.md)를 참고합니다. 로그인할 수 없으면 학원이 제공한 별도 연락처로 문의합니다. 1:1 문의를 남긴 것만으로 정식 취소·반품·교환 신청이 접수되거나 배송지가 정정된 것은 아닙니다.

### 문의 내용 예시 <a href="#inquiry-example" id="inquiry-example"></a>

```text
문의 목적: 교재 배송 확인 / 배송지 정정 가능 여부 확인
주문번호: 내 주문의 번호
상품·교재: 구매한 상품명 / 확인할 교재명과 수량
확인한 내용: 안내받은 배송 상태·시각 / 조회 문구 / 실제 받은 내용
필요한 도움: 출고 여부 확인 / 교재·수량 확인 / 바꿀 항목 확인
주소 정정이 필요하다면: 수령인·연락처·상세 주소 등 바꿀 항목 이름만 우선 작성
```

전체 주소·연락처가 필요하면 학원이 안내한 **본인 확인이 가능한 개별 창구**로 전달합니다. 공개 Q&A·공지 댓글에는 올리지 않습니다. 비밀번호·인증번호·결제 키·공동현관 비밀번호·타인의 주문/배송 정보는 보내지 않습니다. 송장 라벨 사진은 수령인·주소·연락처·바코드 등 개인 배송 정보를 가립니다.

> **화면 예시 준비 중** · 필요한 정보만 정리해 학원에 문의합니다.

## 완료 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 구매한 학원 사이트·계정과 원 주문번호를 확인했다.
- [ ] 실물 교재와 강좌/디지털 자료, 포함/추가 교재·수량을 구분했다.
- [ ] 결제완료·배송 대상 생성·송장 등록·발송·실제 수령을 구분했다.
- [ ] 상품 준비 중이라는 문구만으로 정정 가능 여부나 도착일을 판단하지 않았다.
- [ ] 주소록·주문 당시 주소·배송 건의 주소가 다름을 확인했다.
- [ ] 학생 직접 정정과 운영자 처리 조건, 발송 이력/최신 정보 제한을 구분했다.
- [ ] 문의 접수와 정정 저장/출고 전달·취소/환불 완료를 구분했다.
- [ ] 새 주문·재결제·상태 보정·주소록 수정으로 기존 배송 문제를 우회하지 않았다.
- [ ] 필요한 정보만 문의하고 실제 주소/연락처·송장 라벨을 공개하지 않았다.
