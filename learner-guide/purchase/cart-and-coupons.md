# 장바구니와 쿠폰 이용하기

> **검토용 가이드** · 실제 서비스 화면·동작 확인과 이미지 보완이 남아 있습니다. 본문의 실행 보류·주의사항을 먼저 확인하세요.

장바구니에서 **구매할 상품을 선택**하고, 보유한 쿠폰을 **현재 선택한 상품에 직접 적용**합니다. 쿠폰을 받거나 코드를 등록하는 것과 할인 적용은 다릅니다. 주문서로 이동하기 전에 구성·금액·구매조건을 확인합니다.

**완료 기준:** 구매할 상품만 선택하고, 사용할 쿠폰의 조건과 실제 적용 할인액을 확인합니다. 장바구니 금액과 최종 주문 금액을 구분하며, 구성이나 할인이 불명확하면 주문서 작성을 진행하지 않습니다. 이미 진행 중인 주문이 있다면 새 주문보다 기존 주문 확인을 우선합니다.

## 시작 전 준비

| 준비할 것 | 확인할 내용 |
| --- | --- |
| 학원 사이트와 구매 계정 | 쿠폰을 받은 계정과 구매할 계정이 같은지 확인합니다. 다른 계정으로 자동 이전되지 않습니다 |
| 구매할 상품·교재 옵션 | 상품 구성·가격·이용 기간과 필요한 추가 교재를 확인합니다. 이미 구매/지급된 콘텐츠는 재구매부터 하지 않습니다 |
| 쿠폰 정보 | 보유 쿠폰 또는 학원이 안내한 코드, 사용 기한·최소 주문금액·최대 할인 조건을 준비합니다 |
| 진행 중인 주문 | 결제창을 닫았거나 결과가 불명확한 주문이 있다면 기존 주문과 쿠폰 상태부터 확인합니다 |

상품 조건은 [상품 구성·가격·이용 기간 확인하기](product-and-access-period.md), 계정은 [내 계정과 로그인 방식 확인하기](../account/check-account-and-login-method.md)를 참고합니다. 학원이 직접 수강권을 지급했다면 장바구니와 결제를 거칠 필요가 있는지 먼저 확인합니다.

## 먼저 내 상황 고르기

| 상황 | 먼저 할 일 | 구분할 것 |
| --- | --- | --- |
| 아직 로그인하지 않았어요 | 학원 사이트에서 기존 계정으로 로그인 | 비로그인 임시 장바구니와 계정 장바구니 |
| 상품 일부만 구매하고 싶어요 | 전체선택·상품별 체크 상태 확인 | 선택 해제와 장바구니 삭제 |
| 쿠폰 코드를 받았어요 | 쿠폰 등록 후 보유 목록 확인 | 등록 성공과 주문 할인 적용 |
| 받을 수 있는 쿠폰이 보여요 | 조건 확인 후 받기 | 받음과 사용 완료 |
| 쿠폰이 있는데 선택이 안 돼요 | 기간·최소 금액·다른 주문 사용 중 안내 확인 | 보유 상태와 현재 주문 적용 가능 여부 |
| 이미 결제를 시도했어요 | 기존 주문·결제 결과 확인 | 새 주문 생성과 기존 주문 재확인 |

## 1. 장바구니 열고 계정 확인하기

1. 학원 사이트의 **장바구니 아이콘**을 누릅니다. 좁은 화면에서 아이콘이 보이지 않으면 로그인 상태의 **메뉴 열기** 안도 확인합니다. 사이트 메뉴 설정에 따라 장바구니 진입이 표시되지 않을 수 있습니다.
2. 장바구니의 상품명과 현재 로그인 계정을 확인합니다. **담김**이나 장바구니 숫자는 결제·수강권 지급 완료를 뜻하지 않습니다.
3. 비로그인이라면 **로그인하고 결제하기**로 기존 계정에 로그인합니다. 계정이 없는 경우에만 회원가입을 진행합니다.
4. 로그인 후 상품 목록을 다시 확인합니다. 비로그인 중 담은 상품이 모두 같은 구성으로 옮겨졌다고 가정하지 않습니다.

비로그인 장바구니는 해당 브라우저의 임시 저장 목록입니다. 다른 기기·브라우저에서 같은 목록을 보장하지 않으며 교재 옵션도 그대로 보존된다고 가정하지 않습니다. 로그인에 성공해도 장바구니 병합은 별도로 실패하거나 일부 상품이 제외될 수 있습니다.

**장바구니가 비어있습니다**가 나오면 계정·사이트·로그인 전후와 조회 상태를 먼저 확인합니다. 빈 표시만으로 미구매·전체 삭제·병합 성공을 확정하지 않습니다. 가입/로그인 절차는 [회원가입·로그인하기](../account/signup-and-login.md)를 참고합니다.

> **화면 예시 준비 중** · 로그인 후 구매할 상품을 다시 확인합니다.

## 2. 구매할 상품 선택하고 필요 없는 항목 정리하기

1. **전체선택 N/M**과 상품별 체크박스를 확인합니다. 처음에는 전체가 선택될 수 있고, 주문서에서 돌아온 경우 이전 선택이 남을 수 있으므로 구매할 항목을 직접 점검합니다.
2. 이번에 구매하지 않을 상품은 체크를 해제합니다. 선택 해제는 이번 구매 대상에서 빼는 것이며 목록에서 삭제하는 것과 다릅니다.
3. 아예 목록에서 제거하려면 해당 상품의 **휴지통 아이콘**, 여러 상품이면 삭제할 항목만 체크한 뒤 **선택삭제**를 누릅니다. 삭제 전 상품명·선택 개수를 확인합니다.
4. 삭제 후에는 다시 조회한 목록에서도 제거되었는지 확인합니다. 화면에서 잠시 사라진 것만으로 저장 성공을 확정하지 않습니다.
5. 남은 선택 상품과 **상품 금액**을 확인합니다. 모든 선택을 해제하면 주문서 작성을 진행할 수 없습니다.

### 옵션 교재는 별도로 확인하기

현재 장바구니 상품 행에는 본체 가격이 보이고, 옵션 교재의 이름·개별 금액·변경 버튼은 보이지 않을 수 있습니다. 반면 **상품 금액에는 옵션 비용과 묶음 할인이 반영될 수 있어** 상품 행 가격을 더한 값과 다를 수 있습니다.

필요한 교재가 포함되었는지, 원치 않는 옵션이 담겼는지 확인할 수 없다면 **합계나 장바구니 개수만으로 구성 확정을 하지 않습니다**. 장바구니에서 옵션 선택·수량 변경이 항상 가능하다고 가정하지 말고 학원에 확인합니다. 목록/상세·PC/모바일·로그인 전후의 옵션 차이 때문에 삭제·재담기를 반복하는 방식도 해결책으로 단정하지 않습니다.

> **화면 예시 준비 중** · 선택 해제와 삭제를 구분하고 옵션 구성을 확인합니다.

## 3. 보유 쿠폰과 조건 확인하기

1. **마이페이지 → 구매 내역 → 쿠폰**을 엽니다. PC/모바일의 메뉴 진입 위치는 구분해서 확인합니다.
2. **쿠폰 상태**에서 **사용 가능** 또는 **사용 완료 · 기간 만료**를 선택합니다. 여러 페이지가 있으면 페이지 이동도 확인합니다.
3. 쿠폰명·원/% 할인·최소 주문금액·최대 할인액·사용 가능 시각을 확인합니다. 표시된 경우에만 해당 조건을 읽습니다.
4. 사용할 쿠폰이 있는지 확인한 뒤 장바구니의 쿠폰 선택 단계로 이동합니다. 쿠폰함의 **사용 가능**은 현재 선택 상품에 바로 적용된다는 뜻이 아닙니다.

| 표시·상태 | 의미 | 다음 확인 |
| --- | --- | --- |
| 사용 가능 | 보유 쿠폰의 기본 상태 | 현재 주문 금액·기한·다른 주문 점유 여부에 따라 적용 불가일 수 있음 |
| 사용 완료 | 이미 사용된 쿠폰 | 새 주문에 다시 사용할 수 있다고 가정하지 않음 |
| 기간 만료 | 사용 가능 기한이 지난 쿠폰 | 새로 받기/등록하면 기한이 자동 연장된다고 가정하지 않음 |
| 취소됨 | 취소 상태의 발급 쿠폰 | 자동 재발급·복구를 약속하지 않고 학원에 확인 |
| 다른 주문에서 사용 중 | 다른 주문에 예약·점유되어 현재 주문에 적용할 수 없는 상태 | 결제 성공과 같지 않음. 기존 주문과 처리 상태를 먼저 확인 |

마지막 행은 장바구니의 적용 불가 안내입니다. 쿠폰함에 별도 예약 탭이나 해제 버튼이 있다고 안내하지 않습니다. 쿠폰함이 비어 보여도 필터·페이지·현재 계정·조회 상태를 확인하며 소멸이나 미발급을 단정하지 않습니다.

> **화면 예시 준비 중** · 보유 상태와 현재 주문 적용 가능 여부는 다릅니다.

> **동작 예시 준비 중** · 쿠폰함과 등록 위치를 확인합니다.

## 4. 쿠폰 코드 등록하기

1. 쿠폰 화면에서 **쿠폰 등록**을 누릅니다.
2. 학원이 안내한 **쿠폰 코드**를 입력하고 잘못 복사한 공백이나 문자가 없는지 확인합니다.
3. **등록**을 누른 뒤 결과를 기다립니다. 입력만 하거나 등록 창을 닫는 것은 등록 완료가 아닙니다.
4. 성공 결과의 쿠폰명·할인 조건·기한을 읽고 **완료**를 눌러 닫습니다. 보유 목록에서도 확인합니다.
5. 장바구니에서는 이 쿠폰을 다시 직접 선택하고 적용합니다. **등록 성공은 주문 자동 적용이 아닙니다.**

장바구니의 **쿠폰 선택 → 쿠폰 적용** 창에서도 코드를 등록할 수 있습니다. 등록 완료 안내 뒤 사용할 쿠폰을 선택하고 **적용하기**를 누르는 단계가 따로 필요합니다.

**이미 발급받은 쿠폰**이면 반복 등록보다 현재 계정의 보유 목록·사용/만료 상태를 확인합니다. 유효하지 않은 코드·만료·수량 소진 안내는 코드와 조건을 확인한 뒤 문의합니다. 결과가 불명확하면 무작정 등록을 반복하지 않습니다.

> **화면 예시 준비 중** · 코드 등록 후 주문에는 직접 선택해 적용합니다.

## 5. 받을 수 있는 쿠폰 받기

1. 쿠폰 화면의 **받을 수 있는 쿠폰**에서 쿠폰명과 할인 표시를 확인합니다.
2. 받을 쿠폰의 **받기**를 누르고 결과를 기다립니다. 이 동작은 파일 다운로드가 아니라 내 계정에 쿠폰을 발급받는 절차입니다.
3. **쿠폰을 받았습니다** 안내·**받음** 표시와 보유 목록을 확인합니다. 사용할 수 있는 기한·최소 주문금액·최대 할인 조건은 보유 쿠폰에서도 확인합니다.
4. 장바구니에서 사용할 쿠폰을 직접 선택합니다. **받음**은 할인 적용이나 사용 완료가 아닙니다.

받을 수 있는 쿠폰 카드에는 모든 조건이 표시되지 않을 수 있습니다. **지금 받을 수 있는 쿠폰이 없습니다**가 나오거나 받기에 실패하면 현재 계정·조회 상태·기존 발급 여부·기간/수량 안내를 확인합니다. 보유 쿠폰이 없다는 뜻으로 해석하거나 반복 발급을 시도하지 않습니다.

> **화면 예시 준비 중** · 쿠폰 받기는 발급이며 할인 적용이 아닙니다.

## 6. 장바구니에 쿠폰 적용하기

1. 로그인한 장바구니에서 구매할 상품을 선택하고 **결제 확인 → 쿠폰 선택**을 누릅니다.
2. **쿠폰 적용** 창에서 사용할 쿠폰과 **서버 계산 예상 할인액**을 확인합니다. 적용할 수 없는 쿠폰에는 사유가 표시될 수 있습니다.
3. 적용 가능한 쿠폰 **하나**를 선택하고 **적용하기**를 누릅니다. 선택만 한 뒤 창을 닫으면 적용 확정이 아닙니다.
4. 계산 결과를 기다린 뒤 장바구니 패널의 **쿠폰명·쿠폰 할인·최종 결제 금액**을 확인합니다. 창이 닫혔다는 사실만으로 성공을 판단하지 않습니다.
5. 적용을 취소하려면 장바구니의 적용 쿠폰 옆 **X 아이콘(쿠폰 선택 취소)**을 사용하고 할인 표시가 제거되었는지 확인합니다. 창 안의 **취소**는 그 창의 선택을 해제하는 동작이므로 이미 적용한 쿠폰의 취소와 구분합니다.

쿠폰은 한 번에 하나만 선택합니다. 여러 쿠폰 중 최대 할인이 자동 선택된다거나 원/% 할인이 무조건 그대로 차감된다고 가정하지 않습니다. 최소 금액·최대 할인액과 현재 상품 선택에 따라 실제 할인액이 달라집니다.

**상품 선택을 바꾸면 적용 조건과 금액을 다시 확인합니다.** 최소 주문금액 아래로 내려가거나 기한이 지나면 쿠폰이 해제될 수 있습니다. 전부 선택 해제·상품 삭제 후에도 이전 할인이 유지된다고 가정하지 않습니다.

> **화면 예시 준비 중** · 적용 후 쿠폰명과 할인액을 확인합니다.

## 7. 적용이 안 되거나 금액이 달라질 때

| 안내·상황 | 확인할 것 | 다음 행동 |
| --- | --- | --- |
| 사용 기간 만료 / 아직 시작되지 않음 | 보유 쿠폰의 기한과 적용 안내 | D-day만으로 판단하지 않고 실제 조건을 확인합니다. 재등록으로 연장을 시도하지 않습니다 |

> **화면 예시 준비 중** · 적용 불가 안내를 확인하고 기존 주문과 구분합니다.

## 8. 구매조건과 주문서 진입 전 확인하기

1. **구매조건**과 **개인정보처리방침**의 내용 보기에서 적용할 조건을 읽습니다. 문서가 안 열리거나 내용이 없으면 결제 전에 학원에 확인합니다.
2. 선택 상품·옵션·쿠폰명/할인·합계를 다시 확인합니다. 상품 표시 할인과 쿠폰·배송비를 임의로 합산해 최종액을 확정하지 않습니다.
3. 구매 준비가 끝난 경우에만 **주문서 작성**을 누릅니다. 재검사에서 구매 불가 상품 안내가 나오면 해당 상품과 판매 상태를 확인합니다.
4. 쿠폰을 적용할 수 없어 해제되었다는 안내가 나오면 할인 없는 상태로 이어질 수 있습니다. **기대한 할인액과 금액을 확인하지 않은 채 다음 결제를 진행하지 않습니다.**

장바구니의 **최종 결제 금액**은 구매 확정이나 결제 완료가 아닙니다. 쿠폰 미적용·해제 상태에서는 옵션/묶음 등을 계산한 임시 합계가 표시될 수 있고, 쿠폰 적용 계산 후에는 배송비가 포함된 값일 수 있습니다. 장바구니에는 배송비 항목이 따로 보이지 않을 수 있으므로 **배송비 무료로 단정하지 않습니다**. [결제하고 무료 상품 신청하기](payment-and-free-order.md)에서 주문의 서버 재검사 금액·배송비·필수 조건과 결과를 확인합니다.

**주문서 작성은 화면 구경용 버튼이 아닙니다.** 주문서 진입 또는 배송지 선택 뒤 주문 생성과 쿠폰/재고 예약 절차가 시작될 수 있고, 0원 주문도 신청 처리로 이어질 수 있습니다. 결제 버튼을 누르지 않았다는 이유로 아무 변경이 없다고 판단하지 않습니다. 이미 주문을 진행 중이라면 장바구니 왕복·새로고침·재주문으로 쿠폰을 풀려 하지 말고 기존 주문과 학원 안내를 먼저 확인합니다.

구매조건 안내 문구와 결제 단계의 필수 동의는 구분합니다. 장바구니에 없는 동의 체크박스를 찾거나 문구가 보인다는 이유로 결제 단계 동의까지 끝났다고 보지 않습니다. 결제/무료 신청과 주문 결과 확인은 [결제 안내](payment-and-free-order.md)에서 확인합니다.

> **화면 예시 준비 중** · 금액과 조건 확인 뒤 구매할 때만 주문서로 이동합니다.
