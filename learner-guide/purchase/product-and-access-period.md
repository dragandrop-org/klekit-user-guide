# 상품 구성·가격·이용 기간

> **검토용 가이드** · 실제 서비스 화면·동작 확인과 이미지 보완이 남아 있습니다. 본문의 실행 보류·주의사항을 먼저 확인하세요.

<figure><img src="../.gitbook/assets/branding/page-headers/purchase/product-and-access-period-v2.png" alt="상품 구성·가격·이용 기간 확인하기 대표 이미지"><figcaption></figcaption></figure>

구매 전 **어떤 강좌·교재·디지털 자료가 포함되는지**, **표시 가격과 추가 비용**, **강좌 이용 기간**을 확인합니다. 상품 이름이나 이미지 하나만 보고 교재 포함·무제한 이용을 판단하지 않습니다.

**구매 전 확인:** 포함된 강좌·자료, 교재 포함/별도 옵션 여부, 가격과 이용 기간을 읽습니다. 상품의 표시 가격과 최종 주문 금액은 다를 수 있습니다. 수강기한의 일수와 실제 시작·종료일도 따로 확인하고, 불명확한 조건은 구매 전에 학원에 문의하세요.

## 시작 전 준비 <a href="#before-you-start" id="before-you-start"></a>

| 준비할 것 | 확인할 내용 |
| --- | --- |
| 학원 사이트와 상품 링크 | 학원에서 안내한 사이트·상품명이 맞는지 확인합니다. 다른 학원이나 이름이 비슷한 상품과 구분합니다 |
| 필요한 구성 | 강좌만 필요한지, 실물 교재·별도 디지털 자료도 필요한지 정합니다 |
| 기존 구매·지급 여부 | 이미 구매하거나 학원이 수강권을 지급했다면 재구매보다 기존 계정·권리를 먼저 확인합니다 |
| 이용 일정 | 필요한 강좌의 제공 일수와 이용 시작·종료 조건을 확인할 수 있어야 합니다. 설명이 없으면 임의로 날짜를 계산하지 않습니다 |

현재 계정은 [내 계정과 로그인 방식 확인하기](../account/check-account-and-login-method.md)를 참고합니다. 학원이 직접 지급한 강좌를 찾는 중이라면 새 상품 구매부터 진행하지 않습니다.

## 먼저 내 상황 고르기 <a href="#choose-your-situation" id="choose-your-situation"></a>

| 상황 | 먼저 볼 곳 | 확인할 것 |
| --- | --- | --- |
| 어떤 상품인지 모르겠어요 | 상품명·유형·상품소개 | 강좌/교재/디지털 자료/패키지와 실제 포함 콘텐츠 |
| 교재가 같이 오는지 궁금해요 | 상품구성·상품소개·옵션 안내 | 포함 교재와 별도 추가 교재, 수량·추가 금액·배송 조건 |
| 할인 가격인지 궁금해요 | 취소선 가격·할인 표시·현재 가격 | 상품 할인과 옵션/묶음·쿠폰·배송비를 구분 |
| 언제까지 들을 수 있나요 | 목록의 기간·상세의 수강기한·학원 안내 | 강좌 제공 일수와 본인 수강권의 실제 시작·종료일 |
| 상품이 없거나 상세가 안 열려요 | 사이트·검색/필터·상품 링크·오류 | 삭제·품절·판매 중지로 단정하지 않고 학원에 확인 |

## 1. 상품 목록에서 상세 열기 <a href="#step-1" id="step-1"></a>

1. 학원에서 안내한 상품 목록이나 상품 링크를 엽니다. 사이트 메뉴 이름은 학원 설정에 따라 다를 수 있습니다.
2. 목록의 유형 선택에서 **전체 / 강좌 / 교재 / 디지털 자료 / 패키지**를 확인합니다.
3. 이름으로 찾으려면 **제목 검색**에 입력하고 **Enter**를 누릅니다. 입력만 한 상태와 검색 적용을 구분합니다.
4. 추천·분류 화면에 원하는 상품이 없으면 **전체**와 검색어·유형을 확인합니다. 전체 목록에 페이지 이동이 있으면 다른 페이지도 확인합니다.
5. 상품 **제목 또는 이미지**를 눌러 상세를 엽니다. 장바구니나 미리보기 아이콘은 상세 정보만 여는 버튼과 구분합니다.

추천·분류 탭은 등록된 분류가 있는 사이트에서 표시됩니다. 원하는 상품이 없으면 **강좌 / 교재 / 디지털 자료 / 패키지 중 해당 유형을 직접 선택**해 확인합니다. **검색 결과가 없습니다 / 등록된 상품이 없습니다**만으로 실제 미등록이나 판매 종료를 확정하지 않습니다. 검색 조건·조회 상태를 확인하고 계속 찾을 수 없으면 학원에 문의합니다.

> **화면 예시 준비 중** · 제목이나 이미지에서 상품 상세를 엽니다.

## 2. 상품과 포함 콘텐츠 구분하기 <a href="#step-2" id="step-2"></a>

상품은 구매하는 판매 단위이고, 콘텐츠는 그 상품으로 제공받을 강좌·교재·자료입니다. 같은 콘텐츠가 다른 구성·조건의 상품에 포함될 수 있으므로 상품명과 포함 목록을 함께 봅니다.

| 화면 유형 | 확인할 내용 | 혼동하지 않을 것 |
| --- | --- | --- |
| 강좌 | 강좌 소개·강의목차·제공 일수 | 강좌 이미지에 교재가 있다고 실물 교재까지 포함되는 것은 아님 |
| 교재 | 교재 이름·상품 소개·표시된 수량/서지 정보 | 교재 구매가 자동으로 영상 수강권을 주는 것은 아님 |
| 디지털 자료 | 자료 이름·상품 소개·제공 방식 | 다운로드 자료와 실물 배송 교재는 다름 |
| 패키지 | 구성품별 강좌/교재/디지털 자료 이름·종류·수량 | 여러 강좌만 묶인 상품이라고 단정하지 않음. 동종/혼합 구성을 직접 확인 |

상세의 **상품소개**에서 설명을 읽습니다. 강좌는 **강의목차**, 그 외 상품은 **상품구성** 탭으로 이동합니다. **수강 후기**는 참고 정보이며 현재 상품의 구성·가격·이용 조건을 대신하지 않습니다.

> **화면 예시 준비 중** · 상품 유형과 실제 포함 구성을 함께 확인합니다.

> **동작 예시 준비 중** · 구매 전에 소개와 목차·구성을 읽습니다.

### 패키지 구성 확인하기 <a href="#section-5" id="section-5"></a>

1. **콘텐츠 구성 / 상품 구성**에서 항목별 이름과 **강좌 / 교재 / 디지털 자료**를 확인합니다.
2. 강좌는 강의 개수·목차, 교재는 표시된 **수량 N권**, 디지털 자료는 **다운로드 자료** 안내를 확인합니다.
3. 포함되어야 할 항목이 빠졌거나 이름이 모호하면 구매 전에 문의합니다. **등록된 구성 콘텐츠가 없습니다**는 무료 추가 제공이나 전체 콘텐츠 포함을 뜻하지 않습니다.

`상품 구성 (N개)`는 구성 항목 수입니다. 교재 N권·강의 N개·자료 파일 N개와 같은 숫자로 해석하지 않습니다. 교재의 저자·출판사·ISBN·페이지는 표시되는 경우에만 참고하고, 여러 교재의 정보가 각각 모두 표시된다고 가정하지 않습니다.

> **화면 예시 준비 중** · 구성 항목 수와 교재 수량·강의 개수는 다릅니다.

## 3. 포함 교재와 별도 옵션 확인하기 <a href="#step-3" id="step-3"></a>

| 보이는 정보 | 확인 방법 |
| --- | --- |
| 상품구성에 교재가 있음 | 해당 교재의 이름·수량과 상품 설명의 포함 조건을 확인합니다 |
| 목록에 교재 N권·묶음 할인 또는 추가 교재 안내가 있음 | 별도 옵션 안내일 수 있습니다. 상품 본체 포함인지, 추가 선택/금액이 필요한지 구분합니다 |
| 상품 이미지나 소개에 교재 사진만 있음 | 포함 증거로 삼지 않습니다. 구성 목록과 학원 안내를 확인합니다 |
| 수업자료 표시가 있음 | 강의에서 제공하는 첨부 자료 안내와 별도 판매 디지털 자료·실물 교재를 구분합니다 |

옵션 선택 화면이 표시되는 경우 **교재 이름·체크 상태·추가 가격**을 확인합니다. 선택이 미리 되어 있어도 무료 포함을 뜻하지 않습니다. 상세와 목록, 로그인 여부·기기별로 옵션 표시나 담기는 구성이 다를 수 있으므로 **항상 같은 교재가 자동 포함된다고 가정하지 않습니다**.

이 문서에서는 구매 전 구성을 확인합니다. 구매할 상품 선택·쿠폰은 [장바구니와 쿠폰 이용하기](cart-and-coupons.md), 주문 구성·결제는 [결제하고 무료 상품 신청하기](payment-and-free-order.md)를 참고합니다. 장바구니에서 옵션의 상세 정보나 변경 버튼이 보이지 않을 수 있으므로 필요한 교재가 담겼는지 불명확하면 먼저 확인합니다. 확인을 위해 구매 버튼을 시험하거나 필요 없는 교재까지 담지 않습니다.

> **화면 예시 준비 중** · 포함 교재와 별도 추가 교재를 구분합니다.

## 4. 가격과 추가 비용 확인하기 <a href="#step-4" id="step-4"></a>

1. 현재 상품 가격을 확인합니다. 할인 상품에는 취소선 가격과 **% 할인 / 원 할인** 표시가 함께 보일 수 있습니다.
2. **무료** 표시라면 해당 상품의 표시 가격이 0원인 상태로 읽습니다. 모든 옵션·배송비까지 0원이거나 신청·지급이 이미 끝났다는 뜻은 아닙니다.
3. 교재 옵션·묶음 할인·쿠폰·배송비가 따로 적용되는지 확인합니다. 할인율을 임의로 더하거나 상품 표시 가격에 모든 추가 항목이 포함되었다고 계산하지 않습니다.
4. 이후 장바구니·주문 단계에서 실제 선택한 구성과 **최종 결제 금액**을 다시 확인합니다. 상세를 보는 것만으로 현재 가격의 재고나 구매 조건이 예약되지는 않습니다.

| 구분 | 의미 |
| --- | --- |
| 상품 표시 가격 | 지금 보고 있는 상품 본체의 기본/할인 가격 |
| 별도 옵션·묶음 할인 | 추가 상품과 함께 선택하는 조건에 따른 가격. 기본 구성 포함과 구분 |
| 쿠폰 | 보유·등록과 실제 주문 적용이 별도인 할인 |
| 배송비 | 교재가 포함된 주문의 배송 조건에 따라 확인할 비용 |
| 주문 최종 금액 | 선택한 상품/옵션·할인·쿠폰·배송비가 반영된 주문 결과에서 확인할 금액 |

이미 구매한 경우 현재 상품 가격이 이전 주문 금액을 바꾸거나 차액 환불을 자동으로 확정하지 않습니다. 가격이나 구성 안내가 서로 다르면 결제 전에 확인합니다.

> **화면 예시 준비 중** · 상품 표시 가격은 최종 주문 금액과 다를 수 있습니다.

## 5. 이용 기간 확인하기 <a href="#step-5" id="step-5"></a>

강좌가 포함된 상품은 제공 일수를 확인합니다. PC 상세에서는 **수강기한 N일**이 표시될 수 있고, 목록에서는 같은 일수가 개월 형태로 보일 수 있습니다.

**목록의 개월 표시는 일수를 줄여 보여주는 표기일 수 있습니다.** 예를 들어 90일을 3개월로 표시하더라도 달력의 세 달과 같은 만료일을 보장하는 것은 아닙니다. 시작·종료 조건과 지급된 수강권의 실제 기간은 별도로 확인합니다.

1. 목록과 상세, 학원 안내의 기간이 같은 조건인지 비교합니다.
2. 이용이 언제 시작되는지, 본인에게 언제까지 제공되는지 안내를 확인합니다. 구매일·첫 재생일·학원 수업 시작일 중 하나를 모든 상품의 기준으로 임의 지정하지 않습니다.
3. 모바일 상세에 기간이 보이지 않으면 목록·PC 상세 또는 학원 안내로 확인합니다. **기간 미표시를 무제한으로 해석하지 않습니다.**
4. 강좌 여러 개가 포함되어도 구성품마다 다른 기간을 고를 수 있다고 가정하지 않습니다. 교재·자료의 보관/다운로드 기간이나 배송일을 강좌 수강기한과 같게 보지 않습니다.
5. 이미 구매하거나 지급받은 강좌는 현재 상품 안내가 아니라 본인 수강권의 실제 기간을 확인합니다. 상품 기간 변경이 기존 수강권을 자동 연장하는 것은 아닙니다.

상품의 총 **강의 시간**은 영상 분량이며 이용 가능한 기간이 아닙니다. 이용 기간이 0일로 표시되거나 보이지 않아도 평생 이용할 수 있다는 뜻은 아닙니다. 불명확하면 구매 전 학원에 확인합니다.

> **화면 예시 준비 중** · 수강기한 일수와 실제 이용 시작·종료일을 구분합니다.

## 6. 목차와 미리보기 확인하기 <a href="#step-6" id="step-6"></a>

1. 강좌의 **강의목차**에서 단원 제목과 강의 개수를 확인합니다. 단원 제목을 누르거나 **모두 펼치기 / 모두 접기**로 목록을 읽습니다.
2. **수업자료** 안내는 강의에서 제공하는 자료가 있다는 표시로 읽습니다. 자료의 실제 내용·파일 개수·무료 공개 다운로드를 보장하는 것은 아닙니다.
3. **미리보기** 버튼이 실제로 제공되는 강좌라면 해당 버튼으로 안내된 영상을 확인할 수 있습니다. 모달의 미리보기 목록은 전체 강의 목록과 다릅니다.
4. 이용을 마치면 미리보기를 닫습니다. **미리보기를 불러올 수 없습니다**가 나오면 해당 상태·기기/브라우저를 확인하고 문의합니다. 재생 실패를 상품 미포함이나 권리 지급 실패로 단정하지 않습니다.

패키지 구성에서 **미리보기** 표식만 보이고 실행 버튼이 없을 수 있습니다. 표식만으로 모든 강의를 눌러 재생할 수 있다고 판단하지 않습니다. **강좌 보기**는 개별 강좌 소개로 이동하는 것이며 포함 강좌의 수강권 지급 완료 버튼이 아닙니다.

미리보기는 구매·전체 수강권·자료 지급이 아닙니다. 영상 창을 열면 재생이 시작되거나 외부 영상 제공자에 연결될 수 있습니다. 단순히 소개 화면만 보는 것과 다르며, 시청 URL은 복사하거나 공유하지 않습니다.

> **화면 예시 준비 중** · 미리보기는 전체 수강권이나 자료 지급이 아닙니다.

## 7. 구매 전 마지막 확인 <a href="#step-7" id="step-7"></a>

상세의 강좌 상품에는 **수강 신청하기**, 다른 상품에는 **바로 구매하기**, 별도로 **장바구니에 담기 / 담김**이 보일 수 있습니다. 이 버튼은 상세 내용 펼치기가 아니라 구매 준비 동작입니다. **담김**은 장바구니 상태이며 결제 완료·수강 가능·교재 발송을 뜻하지 않습니다.

조건을 확인했다면 [장바구니와 쿠폰 이용하기](cart-and-coupons.md)에서 구매할 상품과 할인을 확인합니다. 주문서 진입은 주문 생성으로 이어질 수 있으므로 단순 확인용으로 반복하지 않습니다. 결제·무료 신청은 [결제 안내](payment-and-free-order.md)에서 확인합니다. 이미 구매/지급받았다면 현재 계정과 기존 내역을 먼저 확인합니다. 구성·기간·비용이 불명확하면 구매를 진행하기 전에 학원에 문의합니다.

| --- | --- | --- |

| 상품 정보를 불러오지 못했다고 나와요 | 링크·조회 오류·현재 판매 가능 여부 | 안내된 다시 시도로 화면을 다시 열어 확인하고 계속되면 문의합니다. 품절·판매 중지·삭제의 정확한 원인을 추측하지 않습니다 |
| 교재가 포함인지 모르겠어요 | 구성 목록·별도 옵션·상품 설명 | 교재 사진이나 교재 N권 표시만으로 무료 포함을 판단하지 말고 구매 전에 확인합니다 |
| 구성 이름이나 교재 정보가 부족해요 | 실제 항목별 제목·수량·설명 | 다른 구성품의 정보로 채우지 말고 학원에 정확한 구성을 문의합니다 |
| 가격이 목록·상세·예전 주문과 달라요 | 현재 상품 할인·옵션/묶음·쿠폰·배송비·이전 구매 시점 | 현재 표시와 원 주문(해당 상품을 구매한 주문)을 구분합니다. 최종액이 불명확하면 결제하지 않고 문의합니다 |
| 무료인데 구매 버튼이 있어요 | 상품 본체 가격·추가 상품/배송비 | 무료 표시와 신청/지급 완료는 다릅니다. 최종 주문은 [결제하고 무료 상품 신청하기](payment-and-free-order.md)에서 별도로 확인합니다 |
| 모바일에서 기간이 안 보여요 | 목록·PC 상세·학원 안내 | 무제한으로 추측하지 말고 제공 일수·시작/종료 조건을 확인합니다 |
| 목차에 미리보기 표식만 있어요 | 실제 실행 버튼 유무·단일 강좌/패키지 | 표식만으로 클릭 가능을 가정하지 않습니다. 학원에서 제공한 미리보기 경로를 확인합니다 |

문의에는 **학원 사이트 이름, 상품명·공개 상품 주소, 확인하려는 구성/가격/기간, 오류 문구·발생 시각, 기기/브라우저**를 적습니다. 현재 계정·주문 정보는 학원 비공개 경로로 필요한 범위만 전달하며 비밀번호·인증번호·결제정보·재생/다운로드 URL은 공유하지 않습니다. 실제 문의 창구·운영 시간은 아직 확인이 필요합니다. 학원에서 안내한 최신 문의 방법을 확인합니다.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 학원 사이트·상품명·유형이 찾던 상품과 일치합니다.
- [ ] 상품과 포함 강좌·교재·디지털 자료를 구분했습니다.
- [ ] 패키지의 항목 수와 교재 수량·강의 개수를 구분했습니다.
- [ ] 포함 교재와 별도 옵션, 수업자료와 별도 판매 자료를 구분했습니다.
- [ ] 상품 표시 가격과 옵션/할인·쿠폰·배송비·최종 주문 금액을 구분했습니다.
- [ ] 무료 표시나 담김을 신청·결제·지급 완료로 해석하지 않았습니다.
- [ ] 강의 시간·제공 일수·본인 수강권의 시작/종료일을 구분하고 미표시를 무제한으로 판단하지 않았습니다.
- [ ] 미리보기 표식/실행 버튼과 전체 수강권을 구분했습니다.
- [ ] 이미 구매/지급받았거나 조건이 불명확한 경우 재결제보다 계정·학원 확인을 우선했습니다.
