# 교재 반품·교환 신청하기

> **이용 전 확인** · 사용할 수 있는 기능과 화면이 아직 확인되지 않은 항목이 있습니다. 화면이나 안내가 다르면 학원에 확인하고, 문서에서 멈추도록 안내한 작업은 진행하지 마세요.

<figure><img src="../.gitbook/assets/branding/page-headers/cancellations/request-return-or-exchange-v2.png" alt="교재 반품·교환 신청하기 대표 이미지"><figcaption></figcaption></figure>

교재를 반품하거나 교환하려면 **원 주문(해당 상품을 구매한 주문)·교재 확인 → 발송·수령·사유 정리 → 최신 조건·비용 확인 → 학원이 안내한 정식 경로 확인 → 같은 신청의 처리 결과 확인** 순서로 준비합니다. 회수 주소와 방법을 확인하기 전에 교재를 임의로 보내지 않습니다.

**먼저 준비하세요:** 해당 주문의 교재·수량과 반품 또는 동일 교재 교환을 원하는 이유를 정리합니다. 아직 발송되지 않았다면 출고 전 취소인지 학원에 확인합니다. 문의·접수·회수만으로 끝난 것은 아닙니다. 반품은 검수·실제 환불을, 교환은 재배송·실제 수령과 처리 완료를 확인합니다.

아래 조건이 학원의 공개 약관과 실제 신청 화면에 어떻게 적용되는지는 아직 확인이 필요합니다. 신청 전에 학원에 적용 조건과 신청 방법을 확인하세요. 이 안내는 법정 반품·교환 기준이나 법률 검토가 완료된 안내는 아닙니다. 화면과 안내가 다르거나 신청이 제한되면 실제 상황을 학원에 알려 확인합니다.

## 시작 전 확인 <a href="#before-you-start" id="before-you-start"></a>

| 확인할 것 | 내용 |
| --- | --- |
| 사이트·계정 | 교재를 구매한 학원 사이트와 본인 계정인지 확인합니다. 타인의 계정·주문으로 신청하지 않습니다 |
| 원 주문·교재 | 주문번호·상품/교재명과 묶음 안에서 대상이 되는 교재를 특정합니다. 같은 이름의 다른 구매와 구분합니다 |
| 수량·기존 신청 | 구매 수량·이미 취소된 수량·이번 요청 수량, 같은 교재의 진행 중 신청을 확인합니다 |
| 발송·수령 | 실제 발송 안내와 원 교재를 받은 날짜·시각, 현재 교재 상태를 정리합니다 |
| 원하는 처리·사유 | 반품인지 동일 교재 교환인지, 단순 변심인지 하자·오배송 등인지 구체적으로 설명합니다 |
| 개인정보 | 주문번호·연락처·주소는 필요한 담당자에게만 전달합니다. 공개 글에는 올리지 않습니다 |

## 1. 원 주문·교재와 원하는 처리 구분하기 <a href="#step-1" id="step-1"></a>

1. **마이페이지 → 구매 내역 → 결제**에서 원 주문을 찾습니다. [주문·결제 내역 확인하기](../orders/order-and-payment-history.md)를 참고합니다.
2. 주문 대표 상품명과 실제 대상 교재를 구분하고 구매·남은·요청 수량을 정리합니다. 구성이나 수량이 충분히 보이지 않으면 학원에 확인합니다.
3. 같은 교재의 신청이 이미 진행 중이면 새 신청보다 기존 접수 건의 유형·수량·상태를 먼저 확인합니다.

| 원하는 처리 | 구분 |
| --- | --- |
| 출고 전 취소 | 실제 발송 전 교재 취소입니다. [상품 취소·환불 신청하기](request-cancellation.md)에서 다룹니다 |
| 반품 | 발송된 교재의 회수·검수 후 환불 여부와 금액을 확인하는 절차입니다 |
| 교환 | 발송된 교재를 회수·검수하고 **동일 교재**로 재배송하는 절차입니다. 다른 교재·판본으로 바꾸거나 차액을 결제하는 절차가 아닙니다 |
| 발송·수령 사실 불명확 | 송장이 없거나 상태가 비어 있다는 이유만으로 출고 전 취소 또는 반품 가능으로 확정하지 않습니다 |

**반품·교환 신청 한 건은 원 주문의 교재 구성품 하나와 그 신청 수량**을 대상으로 합니다. 여러 교재·강좌가 섞인 주문 전체를 한 번에 반품/교환하거나, 교환하려고 먼저 취소·재구매하지 않습니다. 교재 구성 확인은 [상품 구성·가격·이용 기간 확인하기](../purchase/product-and-access-period.md)를 참고합니다.

> **화면 예시 준비 중** · 원 교재와 원하는 처리 유형을 확인합니다.

> **신청 기능 확인 필요**
> 실제 신청 화면의 제공 여부·이용 권한과 선택·조건 조회·제출 결과는 아직 확인이 필요합니다. 먼저 학원에 이용 가능한 정식 신청 경로를 확인하세요. 경로가 확인되지 않으면 임의로 제출하지 말고 아래 문의 항목을 정리합니다.

학원이 해당 경로를 안내했고 원 주문에 **배송 정보 → 반품·교환 신청**이 제공되는 경우에만 다음 내용을 참고합니다. 신청 유형·대상 교재·신청 수량·사유를 확인하고, **조건 확인**으로 받은 최신 결과를 읽습니다. **신청하기**는 단순 조회가 아니라 실제 제출입니다. 버튼/예상 결과만으로 접수·회수·전액 환불·교환 완료를 확정하지 않습니다. 조건이 바뀌거나 진행 신청이 있으면 기존 결과부터 확인합니다.

## 2. 수령일·신청일과 실제 사유 정리하기 <a href="#step-2" id="step-2"></a>

원 교재 수령일은 **처음 주문한 교재를 실제 받은 시점**입니다. 회수 교재가 학원에 도착한 날이나 교환 교재를 받은 날과 다릅니다. 구매자가 전달한 수령일도 검수에서 확인된 수령 사실과 구분하므로, 날짜를 추측하거나 기간에 맞춰 바꾸지 않습니다.

| 확인할 항목 | 정책·문의 기준 |
| --- | --- |
| 일반 반품·교환 기간 | 이 가이드의 일반 정책은 한국 시간 기준 **수령 다음 날부터 7일째 마지막 시각까지**입니다. 결제일부터 7일 또는 수령 시각부터 168시간으로 계산하지 않습니다 |
| 신청 시점 | 정식 신청의 접수 시점과 문의·회수·검수 시점을 구분합니다. 반품 승인 재검토에서도 원 신청 시점과 확인된 원 수령 사실을 사용합니다 |
| 수령일 불명확·당일 신청·기간 경계 | 원 수령 사실과 원하는 처리를 학원에 확인합니다. 문의를 남겼다고 정식 신청 기한이 늘어나지는 않습니다 |
| 하자·오배송 등 | 구체적인 문제와 발견 시각을 설명합니다. 판매자 측에 책임이 있는 문제를 판매자 귀책이라고 합니다. 이 사유는 일반 기간 판정과 구분되지만 선택만으로 귀책 인정·무료 처리·승인이 확정되지는 않습니다 |
| 교재 상태 | 실제 훼손·필기·누락 등 상태를 그대로 전달합니다. 일반 반품은 검수에서 확인한 중대한 가치 감소 등에 따라 제한될 수 있습니다 |

예를 들어 10월 1일에 받은 교재의 이 가이드의 일반 정책 기간은 **10월 2일 0시부터 10월 8일 마지막 시각까지**입니다. 수령 당일이나 10월 9일 이후를 이 기간에 포함해 계산하지 않습니다. 공개 약관과의 대조가 필요한 검토 기준이며, 이 예시만으로 법적 신청 가능 여부를 단정하지 않습니다.

발송 근거가 확인되지 않거나 원 수령일이 빠짐·미래 시각으로 입력된 경우에는 사실 확인이 먼저입니다. 수령일을 다르게 쓰거나 단순 변심을 하자 사유로 바꿔 제한을 우회하지 않습니다. 배송 근거는 [교재 배송과 배송지 확인하기](../orders/textbook-shipping-and-address.md)를 참고합니다.

> **화면 예시 준비 중** · 신청 입력과 실제 수령 근거는 별개입니다. 화면·동작 확인 후 추가합니다.

## 3. 최신 조건·예상 환불액과 비용 확인하기 <a href="#step-3" id="step-3"></a>

예상 결과는 같은 교재·수량·사유에 대한 시스템의 최신 판정으로 확인합니다. 실제 신청 화면의 선택·조회·제출 절차는 아직 확인이 필요합니다. 진행 방법이 불명확하면 임의로 제출하지 말고 아래 항목을 학원에 확인합니다. **예상액 조회는 신청 접수·회수 예약·환불 실행이 아닙니다.**

| 구분 | 확인할 것 |
| --- | --- |
| 반품의 예상액 미확정 | 회수·검수·귀책/비용 등의 확인이 남을 수 있습니다. 빈 값·미확정을 0원 또는 주문 총액으로 바꾸지 않습니다 |
| 일반 반품 비용 | 구매 당시 교재의 결제 배분액·수량과 검수에서 확정된 반품 배송비를 기준으로 시스템에서 계산합니다. 최초 배송비 환급과 구분합니다 |
| 판매자 귀책 반품 | 귀책·검수 확인 결과를 봅니다. 확정된 귀책 반품은 반품 배송비를 차감하지 않는 경로이며, 최초 배송비 환급은 원 배송비 배분/잔액·남은 교재에 따라 확인합니다 |
| 교환의 예상 취소액 0원 | 교환은 금액 취소와 다른 경로입니다. 0원 표시를 무료 교환·배송비 납부 완료·환불 완료로 해석하지 않습니다 |
| 회수·교환 배송비 | 적용 금액·부담 주체·납부 방법을 학원에 확인합니다. 설정된 비용이 자동 청구·자동 납부됐다고 가정하지 않습니다 |
| 조건 변경·신청 제한 | 최신 안내와 원 교재/수량·수령/발송·기존 신청·결제 근거를 확인합니다. 과거 예상액으로 반복 신청하거나 다른 유형으로 우회하지 않습니다 |

일반 반품은 최초 배송비를 함께 환급하는 정책이 아닙니다. 반품 배송비 차감은 확정 근거를 사용하며 환급 대상 금액을 넘겨 마이너스 환불액을 만들지 않습니다. 판매자 귀책 반품의 최초 배송비도 무조건 주문 배송비 전액이 아니라, 해당 수량의 배분액 또는 마지막 유효 교재의 남은 최초 배송비 등 시스템에서 확인한 근거로 구분합니다. 근거가 부족하면 금액은 미확정일 수 있습니다.

현재 상품가·화면 단가×수량·주문 총액이나 무료배송 여부만으로 이번 반품·교환 비용을 계산하지 않습니다. 비용 안내가 서로 다르면 같은 주문·신청을 기준으로 학원에 확인합니다.

**에스크로**는 결제한 돈을 결제업체 등이 보관했다가 상품을 받은 뒤 판매자에게 지급하는 방식입니다. **실제 에스크로 결제의 구매확정 전 부분 금액 취소에는 별도 제한**이 있습니다. 반품이 막힌다고 전체 주문 취소로 우회하지 않습니다. 동일 교재 교환은 금액 취소와 다른 경로지만 수량·발송·수령 등 자체 조건은 확인해야 합니다. 에스크로 결제인지 모르겠다면 같은 주문을 기준으로 학원에 확인합니다.

> **화면 예시 준비 중** · 서버 예상 결과와 실제 비용/환불을 나눕니다. 화면·동작 확인 후 추가합니다.

## 4. 회수·검수 안내 확인하기 <a href="#step-4" id="step-4"></a>

정식 신청 경로가 확인되면 학원 안내에 따라 진행합니다. 학생용 회수 신청 메뉴·버튼의 제공 여부는 아직 확인이 필요합니다. 반송 전에는 **대상 교재·수량, 반송/회수 주소, 택배사·방법, 비용·부담 주체, 일정과 연락 방법**을 확인합니다.

최초 발송지나 옛 송장 주소가 현재 반품 주소와 같다고 가정하지 않습니다. 회수 승인이 기록됐다고 택배 기사 방문이 자동 예약되거나 반송이 완료된 것은 아닙니다. 학원이 안내한 실제 회수 방식·일정을 따르며 교재를 임의 주소로 먼저 보내지 않습니다.

| 단계 | 구분할 결과 |
| --- | --- |
| 문의·신청 접수 | 문의 또는 정식 신청이 기록된 단계인지 확인합니다. 회수 예약·승인과 다릅니다 |
| 회수 안내·승인 | 대상과 방법을 확인하는 단계입니다. 실제 택배 접수·기사 방문·교재 이동과 구분합니다 |
| 회수 교재 도착 | 검수를 위한 물품 도착입니다. 원 교재 수령일 또는 검수 통과와 다릅니다 |
| 검수 | 교재 상태·수량 등 확인 단계입니다. 반품 금액·귀책/비용 확정이나 교환 재배송 완료를 뜻하지 않습니다 |
| 후속 처리 | 반품의 환불과 동일 교재 교환의 재배송·수령을 나눠 확인합니다 |

사진·추가 증빙이 필요하면 학원이 안내한 본인 확인이 가능한 개별 창구로 전달합니다. 검수 결과·재입고 수량·귀책·비용을 학생이 직접 확정하거나, 날짜·배송 상태를 임의로 수정하려 하지 않습니다. 신청 화면에 별도의 첨부파일 업로드 기능이 있다고 가정하지 않습니다.

## 5. 반품 환불과 교환 재배송 결과 구분하기 <a href="#step-5" id="step-5"></a>

| 처리 | 확인할 결과 |
| --- | --- |
| 반품 검수 통과 | 확정된 대상/수량·귀책·비용과 최신 환불 판정을 확인합니다. 검수 통과만으로 환불 완료가 아닙니다 |
| 반품 처리 완료 | 해당 교재/수량의 확정 환불액과 서비스 처리 결과를 확인합니다. 주문 전체가 취소됐다고 판단하지 않습니다 |
| 실제 카드/계좌 반영 | 서비스 환불 처리와 결제수단의 실제 반영을 구분합니다. 소요일은 학원·결제수단 안내를 확인합니다 |
| 교환 재배송 | 원 주문 배송과 교환 교재의 새 배송을 구분합니다. 송장 등록만으로 실제 수령·교환 완료를 판단하지 않습니다 |
| 교환 수령·완료 | 같은 신청의 교환 교재·수량·실제 수령과 최종 처리 결과를 확인합니다. 수령 기록 뒤에도 결과 반영이 남을 수 있습니다 |
| 거절·결과 불명확 | 안내받은 사유·시각과 기존 신청을 학원에 확인합니다. 변경/철회·재접수 버튼이 있다고 가정하지 않습니다 |

교환은 원 주문의 교재를 동일 교재로 바꿔 다시 배송하는 절차입니다. 원 결제 취소·자동 재구매·차액 결제·자동 재고 증감이 함께 처리된다고 가정하지 않습니다. 원 송장만 보이거나 교환 수령 후 상태가 늦게 반영돼도 새 신청·재배송을 반복하지 않습니다.

반품 완료 안내와 실제 환불이 다르면 같은 신청·확정 금액·확인 시각을 알려 문의합니다. 증빙은 [영수증과 거래명세서 확인하기](../orders/receipt-and-invoice.md)를 참고합니다.

> **화면 예시 준비 중** · 신청 단계와 실제 물류·금융 결과를 구분합니다. 화면·동작 확인 후 추가합니다.

> **동작 예시 준비 중** · 기존 신청의 단계와 결과를 읽는 예시입니다. 화면·동작 확인 후 추가합니다.

## 6. 상황별로 학원에 문의하기 <a href="#step-6" id="step-6"></a>

| 상황 | 먼저 전달할 내용 |
| --- | --- |
| 발송·수령일이나 신청 가능 여부가 불명확해요 | 원 주문·교재·수량, 실제 받은 날짜/시각 또는 모르는 사실, 원하는 처리·사유 |
| 하자·오배송이 있거나 수령 당일 교환하고 싶어요 | 교재명·받은 수량·문제와 발견 시각, 원 수령일. 사유별 확인과 정식 신청 경로 요청 |
| 수량·교재가 다르게 표시되거나 기존 신청이 있어요 | 원 구매/요청 수량·대상 교재, 기존 신청 식별정보·유형·상태. 중복 신청 전 확인 요청 |
| 비용·예상액이 없거나 안내와 달라요 | 같은 신청·표시 금액/미확정 문구·확인 시각, 귀책/배송비 근거·부담 주체·납부 방법 확인 요청 |
| 반송 주소·회수 방법을 모르거나 회수가 늦어요 | 대상 교재·수량, 안내받은 방법/일정·현재 상황. 임의 반송·중복 택배 예약 전 확인 요청 |
| 교재가 도착했는데 검수·환불 소식이 없어요 | 같은 신청·회수/도착 안내 시각·현재 문구. 검수/확정 금액·후속 처리 확인 요청 |
| 교환인데 원 송장만 보이거나 새 배송이 움직이지 않아요 | 같은 교환 신청·교재/수량, 원 배송과 새 배송에서 확인한 안내·시각. 재배송 결과 확인 요청 |
| 받았는데 완료 상태가 아니거나 거절됐어요 | 실제 받은 교환 교재/수량·시각 또는 거절 사유, 기존 신청 결과와 남은 절차 확인 요청 |
| 사유·수량 변경이나 철회를 원해요 | 기존 신청과 바꾸려는 내용. 중복 신청·재구매보다 허용된 후속 절차 확인 요청 |

### 문의 내용 예시 <a href="#inquiry-example" id="inquiry-example"></a>

```text
문의 목적: 교재 반품 가능 여부 / 동일 교재 교환 / 기존 처리 결과 확인
주문번호·교재: 내 주문번호 / 실제 대상 교재 하나
수량: 구매한 수량 / 이미 취소한 수량 / 이번 요청 수량
원 수령·교재 상태: 실제 받은 날짜·시각 또는 모름 / 하자·필기·누락 등 실제 상황
원하는 처리·사유: 반품 또는 동일 교재 교환 / 구체적인 사유와 발견 시각
기존 신청·회수 안내: 식별정보·접수 시각·상태 / 안내받은 방법·일정이 있다면 기재
확인한 결과: 비용·미확정·회수/검수·환불/교환 배송 안내와 확인 시각
필요한 도움: 정식 신청 경로 / 회수 방법·비용 / 기존 처리 결과 확인
```

문의 방법은 [사이트에 1:1 문의하기](../communication/site-inquiries.md)를 참고합니다. 로그인할 수 없으면 학원이 제공한 별도 연락처로 문의합니다. **문의 등록만으로 정식 반품·교환 신청, 회수 예약, 환불·재배송이 완료되거나 기한이 연장되지는 않습니다.**

주소·연락처는 담당자가 필요하다고 안내한 개별 창구로만 전달합니다. 공개 Q&A·공지 댓글에는 주문/배송 정보를 올리지 않습니다. 사진에는 타인 정보·송장 바코드/주소·연락처를 가리고, 비밀번호·인증번호·결제 키·전체 카드/계좌·배송 조회/파일 URL을 보내지 않습니다.

> **화면 예시 준비 중** · 교재·수량·수령 사실과 필요한 도움만 정리해 문의합니다.

## 완료 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 구매한 학원 사이트·계정과 원 주문·교재 하나를 확인했다.
- [ ] 출고 전 취소·반품·동일 교재 교환, 구매/남은/요청 수량과 기존 신청을 구분했다.
- [ ] 원 교재 수령일·정식 신청 시점과 회수 도착일·교환 교재 수령일을 구분했다.
- [ ] 신청 기간·사유·교재 상태를 사실대로 정리하고, 아직 확인되지 않은 학원 약관과 적용 조건을 문의했다.
- [ ] 예상액 미확정·실제 0원과 반품 환불·교환 비용을 구분했다.
- [ ] 회수 주소·방법·비용·일정 확인 전 임의 반송·중복 택배 예약을 하지 않았다.
- [ ] 접수·회수·도착·검수·환불/재배송·최종 완료를 구분했다.
- [ ] 같은 신청의 확정 금액/실제 환불 또는 동일 교재의 재배송·수령 결과를 확인하도록 정리했다.
- [ ] 필요한 정보만 문의하고 개인정보·송장/주소·금융/조회 URL은 공개하지 않았다.
