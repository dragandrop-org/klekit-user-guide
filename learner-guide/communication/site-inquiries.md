# 사이트에 1:1 문의하기

<figure><img src="../.gitbook/assets/branding/page-headers/communication/site-inquiries-v2.png" alt="사이트에 1:1 문의하기 대표 이미지"><figcaption></figcaption></figure>

계정·결제·수강 이용 등 사이트 이용에 도움이 필요하면 **마이페이지 → 1:1 문의**에 내용을 남깁니다. **기존 문의 확인 → 문의 작성 → 저장 결과 확인 → 답변 읽기 → 필요한 내용 이어 묻기** 순서로 이용합니다.

**문의한 뒤:** 내 문의 목록에서 등록한 글과 답변을 확인합니다. 접수 알림이나 답변 완료 표시는 환불·배송·수강권 변경까지 끝났다는 뜻은 아닙니다. 답변에 안내된 다음 행동과 실제 처리 결과를 확인하세요.

## 시작 전 확인 <a href="#before-you-start" id="before-you-start"></a>

| 확인할 것 | 내용 |
| --- | --- |
| 사이트와 계정 | 문의할 학원 사이트와 내 계정이 맞는지 확인합니다. 1:1 문의는 로그인 후 이용하며 다른 계정의 문의가 자동으로 합쳐지는 것은 아닙니다 |
| 문의 종류 | 수업 내용·문제 풀이 질문은 [학습 Q&A](learning-qna.md)를 이용합니다. 사이트 1:1 문의와 외부 상담 채널은 별도 창구입니다 |
| 기존 문의 | 같은 내용을 이미 남겼다면 해당 문의에서 이어갑니다. 답변이 늦거나 저장 결과가 불명확하다고 같은 문의를 반복 등록하지 않습니다 |
| 관련 정보 | 상품·강좌명, 발생 시각·화면 문구, 필요하면 해당 주문번호를 준비합니다. 수강생 본인의 계정·수강·구매와 관련해 문의할 내용을 정리합니다 |
| 개인정보 | 비밀번호·인증번호·카드 전체 번호·주민등록번호·타인 정보는 본문이나 이미지에 넣지 않습니다. 1:1이라는 이름만으로 이미지까지 비공개 보호된다고 판단하지 않습니다 |

로그인이 안 될 때는 로그인 후에만 열 수 있는 문의 화면 대신 [아이디 찾기·비밀번호 재설정](../account/find-account-and-reset-password.md)을 확인하거나 학원이 별도로 안내한 연락처로 문의합니다.

## 1. 내 문의 목록 열기 <a href="#step-1" id="step-1"></a>

1. 학원 사이트에 로그인한 뒤 **마이페이지 → 1:1 문의**를 엽니다. PC에서는 마이페이지 메뉴, 모바일에서는 사이트의 마이페이지 메뉴에서 찾습니다.
2. 문의 목록의 **제목·상태·작성일**을 확인합니다. PC는 표, 모바일은 카드로 표시될 수 있습니다.
3. 상태 필터에서 **전체 / 답변 대기 / 답변 중 / 답변 완료**를 선택합니다. 보이지 않는 문의는 먼저 **전체**로 바꿔 확인합니다.
4. PC는 페이지 번호, 모바일은 **더 보기**가 있을 때 추가 목록을 확인합니다. 필요한 제목이나 행/카드를 누르면 상세로 이동합니다.

| 상태 | 읽는 방법 |
| --- | --- |
| 답변 대기 | 답변 처리 대기 상태입니다. 접수 담당자 배정·정해진 답변 시간까지 보장하는 표시는 아닙니다 |
| 답변 중 | 답변 진행 상태입니다. 기존 답변이 있거나 추가 문의가 이어진 경우도 있으므로 상세 내용을 확인합니다 |
| 답변 완료 | 답변 처리 상태입니다. 학생의 읽음/만족 확인이나 결제·환불·배송 업무 완료와 다릅니다 |

`등록된 문의가 없습니다.`는 현재 필터에서 조회된 문의가 없다는 표시입니다. `문의 목록을 불러오는 데 실패했습니다.`와 구분하고, 목록을 불러오는 중에는 기다립니다. 검색창·유형별 필터·정렬 메뉴가 보이지 않으면 상태 필터와 페이지 이동으로 확인합니다.

> **화면 예시 준비 중** · 기존 문의와 답변 상태를 먼저 확인합니다.

## 2. 문의 제목과 내용 작성하기 <a href="#step-2" id="step-2"></a>

1. 목록에서 **문의 하기**를 누릅니다.
2. **문의 제목**에 확인받을 내용을 짧게 적습니다.
3. **문의 내용**에 대상·발생 상황·이미 확인한 내용·원하는 도움을 순서대로 적습니다. 제목/내용은 모두 필요하며 빈 줄만 입력하지 않습니다.
4. 강좌·상품·주문을 구분해야 하면 본문에 적습니다. 현재 작성 화면에는 별도 문의 유형·강좌 선택·주문 연결·공개/비공개 선택란이 없습니다.

| 항목 | 작성 예시 |
| --- | --- |
| 제목 | 구매한 수학 기본반이 내 강좌에 보이지 않습니다 |
| 대상 | 수학 기본반 / 해당 주문번호는 필요한 경우에만 입력 |
| 발생 상황 | 오늘 오후 3시 PC에서 로그인했지만 내 강좌 목록에 보이지 않습니다 |
| 확인한 내용 | 구매한 계정으로 로그인했고 내 강좌의 필터를 전체로 확인했습니다 |
| 요청할 도움 | 해당 계정의 강좌 이용 가능 여부를 확인해 주세요 |

**상담시간과 답변 소요 시간은 학원의 실제 안내를 확인합니다.** 작성 화면에 상담시간 문구가 표시되더라도 모든 학원의 운영시간이나 답변 기한으로 일반화하지 않습니다. 지정 담당자·실시간 채팅·SMS/이메일 답변 알림도 보장하지 않습니다.

**취소·뒤로 이동·새로고침 후 자동 임시저장/복원을 기대하지 않습니다.** 필요한 초안은 개인정보 없이 별도로 보관하고 긴 내용은 핵심부터 정리합니다.

> **화면 예시 준비 중** · 제목과 내용에 대상·발생 상황·필요한 도움을 적습니다.

## 3. 이미지가 필요하면 확인하기 <a href="#step-3" id="step-3"></a>

화면 오류를 설명할 때만 필요한 부분의 이미지를 추가합니다. 주문·계정 화면은 이름·연락처·주소·결제 정보와 주소창을 업로드 전에 가립니다.

1. 편집기의 이미지 삽입 기능으로 이미지를 추가합니다. 파일 선택/붙여넣기 방식은 기기·브라우저에 따라 다를 수 있습니다.
2. **이미지 업로드 중...** 표시가 사라지고 본문에 이미지가 나타나는지 확인합니다.
3. 형식·용량 오류가 나오면 표시된 조건을 확인합니다. 이미지를 넣지 못하더라도 오류 문구와 발생 상황은 글로 남깁니다.
4. 이미지의 글씨가 잘 읽히는지, 가려야 할 정보가 남아 있지 않은지 다시 확인한 뒤 문의를 저장합니다.

**문의 본문에 접근할 수 있는 사람을 제한하더라도 이미지의 개별 주소까지 보호된다고 볼 수는 없습니다.** 민감한 증빙·원본 자료를 이미지로 보내지 않습니다. 이미지를 선택하면 문의를 저장하기 전에도 파일이 업로드될 수 있으며 **취소**하거나 댓글을 삭제했다고 해당 파일이 즉시 지워졌다고 판단하지 않습니다. 이미지 삽입 기능으로 PDF·영상·압축파일도 첨부할 수 있다고 가정하지 않습니다.

> **화면 예시 준비 중** · 오류 확인에 필요한 화면만 남기고 개인정보와 주소창을 가린 뒤 업로드 결과를 확인합니다.

> **동작 예시 준비 중** · 문의할 내용을 정리하고 저장 전에 다시 확인합니다.

## 4. 저장하고 접수 결과 확인하기 <a href="#step-4" id="step-4"></a>

1. 제목·본문·대상 정보와 이미지 표시를 마지막으로 확인합니다. 이미지 업로드 중에는 저장하지 않습니다.
2. **저장**을 한 번 누르고 처리 결과를 기다립니다. 제목/내용 오류가 나오면 해당 입력을 확인합니다.
3. **문의가 접수되었습니다.** 알림 후 돌아온 목록에서 **전체** 필터와 같은 제목·작성일을 확인합니다. 다른 상태 필터를 선택했다면 전체로 바꿔 찾습니다.
4. 해당 문의의 상세를 열어 제목·본문·이미지가 의도한 내용인지 확인합니다. 새 문의는 답변 대기 상태로 시작합니다.

오류·네트워크 끊김 등으로 결과가 불명확하면 입력을 필요한 범위에서 보관하고 목록에서 같은 문의가 등록됐는지 먼저 확인합니다. 성공 알림이 없다는 이유만으로 다시 저장하지 않습니다. 목록 이동은 문의 저장 결과 확인과 별개이며 답변/업무 처리 완료도 아닙니다.

> **화면 예시 준비 중** · 내 목록과 상세에서 문의 접수 내용을 확인합니다.

## 5. 답변 읽고 추가 문의 남기기 <a href="#step-5" id="step-5"></a>

1. 내 문의 목록에서 해당 제목을 엽니다. **목록으로**를 누르면 목록으로 돌아갑니다. 필터·페이지가 그대로 복원된다고 가정하지 않습니다.
2. 문의 본문 아래 대화에서 작성자·작성 시각·내용을 읽습니다. **답변** 배지는 운영자가 등록한 답변임을 나타내고, **관리자** 배지는 운영자 댓글에 표시될 수 있습니다. 본인 댓글과 구분합니다.
3. `아직 답변이 등록되지 않았습니다.`가 보이면 추후 같은 문의에서 확인합니다. 안내 문구가 없더라도 학생의 추가 댓글만 있을 수 있으므로 실제 담당자 답변을 읽습니다.
4. 같은 문의를 보완하려면 하단 **추가 문의 작성**에 짧게 적고 **등록**을 한 번 누릅니다. 새 댓글이 대화에 나타나는지 확인합니다. 댓글별 **답글 달기** 버튼이 따로 있다고 가정하지 않습니다.
5. 목록의 상태와 실제 답변을 다시 확인합니다. 답변이 완료된 문의에 새 댓글을 등록하면 **답변 중** 상태로 돌아가도록 처리됩니다. 목록의 갱신이 늦거나 다르면 화면을 다시 열어 확인하고 담당자 알림/자동 배정까지 완료됐다고 해석하지 않습니다.

추가 문의 입력은 답변 완료 상태에서도 가능합니다. 학습 Q&A와 상태 처리 방식이 다릅니다. **새 댓글 등록과 기존 댓글 수정·삭제는 다른 동작**이며, 기존 댓글을 수정했다고 답변 중 상태로 다시 바뀐다고 판단하지 않습니다.

다른 주문·새로운 주제라면 새 문의로 구분합니다. 환불·반품·교환 등을 문의했다고 정식 신청이 자동 접수되거나 기한이 연장되는 것은 아닙니다. 학원 안내와 별도 신청/처리 결과를 확인합니다.

> **화면 예시 준비 중** · 답변을 읽고 같은 문의는 추가 문의로 이어갑니다.

## 6. 내가 쓴 댓글을 수정하거나 삭제하기 <a href="#step-6" id="step-6"></a>

현재 학생 화면에는 **문의 원문의 제목/내용 수정·문의 전체 삭제 메뉴가 없습니다.** 원문을 정정해야 하면 같은 문의에 추가 댓글로 설명하거나 학원에 요청합니다. 운영자 메뉴·다른 주소로 변경을 시도하지 않습니다.

| 하려는 일 | 절차와 주의 |
| --- | --- |
| 내 추가 댓글 수정 | 본인 댓글의 **더보기 → 수정**을 열어 내용을 확인하고 **저장**합니다. 저장한 뒤 대화를 다시 확인합니다. **취소**를 누르면 변경 내용이 저장되지 않습니다. |
| 내 추가 댓글 삭제 | 본인 댓글의 **더보기 → 삭제** → **댓글을 삭제하시겠습니까?** 확인창에서 대상 확인. 마지막 **삭제**를 누르기 전에 해당 댓글을 삭제해도 되는지 다시 확인합니다 |
| 담당자 답변 정정 요청 | 운영자 답변/다른 사람 댓글은 직접 수정하지 않습니다. 추가 문의에서 확인이 필요한 부분을 적습니다 |

**삭제된 댓글의 복구는 보장되지 않습니다.** 내 댓글 삭제는 문의 전체 삭제·원문 수정·업로드 이미지 즉시 제거와 다릅니다. 메뉴가 없거나 처리가 거절되면 계정·본인 댓글 여부를 확인하고 학원에 문의합니다.

> **화면 예시 준비 중** · 문의 원문과 본인 추가 댓글의 관리 범위를 구분합니다.

## 문의를 등록하거나 확인할 수 없을 때 <a href="#section-8" id="section-8"></a>

| 상황 | 확인할 것·다음 행동 |
| --- | --- |
| 1:1 문의를 열려는데 로그인이 필요해요 | 학원 사이트·가입 계정을 확인합니다. 로그인 불가라면 계정 복구 안내나 학원의 별도 연락처를 이용합니다 |
| 등록된 문의가 없습니다. | 상태 필터를 전체로 바꾸고 사이트·계정·작성일을 확인합니다. 조회 오류와 구분합니다 |
| 문의 목록/내용을 불러오지 못해요 | 화면의 재시도·목록으로를 이용합니다. 삭제/차단으로 단정하거나 다른 문의 주소를 추측하지 않습니다 |
| 저장/등록에 실패했어요 | 제목·내용·이미지 진행/실패 문구를 확인합니다. 같은 문의/댓글이 이미 보이는지 먼저 확인하고 반복 제출하지 않습니다 |
| 상담시간이 학원 안내와 달라요 | 학원의 공지/별도 연락처에서 실제 운영시간을 확인합니다. 화면의 고정 문구를 답변 기한 보장으로 해석하지 않습니다 |
| 답변 완료인데 해결이 안 됐어요 | 답변 내용을 읽고 필요한 보완을 추가 문의로 남깁니다. 처리 상태와 실제 수강/결제/환불/배송 결과를 나눠 확인합니다 |
| 추가 문의 뒤 목록 상태가 그대로예요 | 내 댓글이 실제로 등록됐는지 확인한 뒤, 화면을 다시 열어 목록 상태가 바뀌었는지 확인합니다. 새 문의를 반복 생성하거나 상태를 직접 바꾸지 않습니다 |
| 이미지가 안 보이거나 댓글 메뉴가 없어요 | 업로드 오류·본문 표시·본인 계정/댓글을 확인합니다. 민감한 원본을 재전송하거나 다른 계정으로 우회하지 않습니다 |

> **화면 예시 준비 중** · 결과를 확인한 뒤 필요한 정보만 학원에 전달합니다.

## 학원에 별도로 연락할 때 <a href="#section-9" id="section-9"></a>

학원 사이트, 문의 제목·작성일, 필요한 상품/강좌·주문번호, 발생 시각·기기/브라우저와 화면 문구를 전달합니다. 문의 원문과 추가 댓글 중 어느 단계인지, 같은 내용이 이미 등록돼 있는지도 함께 설명합니다.

**비밀번호·인증번호·토큰/세션·카드 전체 번호·파일/시청 URL·타인 문의·민감한 원본 이미지는 보내지 않습니다.** 캡처에서 실제 학생 정보와 주소창을 가립니다. 외부 상담 채널의 대화가 사이트 1:1 문의 목록에 자동 합쳐지거나 운영자가 즉시 확인한다고 보장하지 않습니다.

## 완료 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 기존 문의를 찾아본 뒤, 학습 질문이 아닌 이용 문의에 대상·문제 상황·필요한 도움을 적었습니다.
- [ ] 개인정보 없는 이미지의 업로드·표시와 문의 등록 결과를 확인했습니다. 자동 임시저장이나 확정되지 않은 답변 기한에 의존하지 않습니다.
- [ ] 답변과 내 댓글을 읽고 필요한 다음 행동을 확인합니다. 답변 완료 표시와 환불·배송 등 실제 업무 결과는 따로 확인합니다.
- [ ] 추가 문의와 본인 댓글 수정·삭제는 허용된 메뉴·상태에서 진행하고 결과를 확인합니다. 문의 원문 수정·전체 삭제 기능은 제공된다고 가정하지 않습니다.
- [ ] 결과가 불명확하면 중복 제출·권한 우회 없이 필요한 최소 정보만 문의합니다. 상담 시간은 학원이 안내한 내용을 확인합니다.
