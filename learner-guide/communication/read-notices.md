# 공지사항 확인하기

> **검토용 가이드** · 실제 서비스 화면·동작 확인과 이미지 보완이 남아 있습니다. 본문의 실행 보류·주의사항을 먼저 확인하세요.

<figure><img src="../.gitbook/assets/branding/page-headers/communication/read-notices-v2.png" alt="공지사항 확인하기 대표 이미지"><figcaption></figcaption></figure>

학원 일정과 수업 안내는 사이트의 **공지사항**에서 확인합니다. **중요** 공지와 검색 결과에서 필요한 글을 열고, 본문의 대상·일정·준비물과 첨부파일을 확인한 뒤 **목록으로** 돌아옵니다.

**완료 기준:** 해당 공지가 나에게 적용되는지와 필요한 일정을 확인하고, 필요한 첨부가 있다면 실제 저장된 파일의 내용까지 확인합니다. 조회수나 제목 확인만으로 내용을 모두 읽었다고 판단하지 않습니다.

## 시작 전 확인 <a href="#before-you-start" id="before-you-start"></a>

| 확인할 것 | 내용 |
| --- | --- |
| 학원 사이트 | 안내받은 사이트 주소와 학원이 맞는지 확인합니다. 다른 학원 사이트의 비슷한 제목과 혼동하지 않습니다 |
| 공지의 대상 | 강좌·반·날짜와 학원 안내를 대조합니다. 모든 공지가 전체 학생에게 적용되는 것은 아닙니다 |
| 자료 위치 | 공지에 붙은 첨부파일은 아래 안내에서 확인합니다. [강의 첨부 자료](../resources/lecture-materials.md)·[별도 구매/지급 자료](../resources/my-digital-resources.md)와 구분합니다 |
| 질문할 내용 | 일정·이용 문의와 학습 질문을 구분합니다. 공지 상세에 댓글·질문 작성 기능이 있다고 가정하지 않습니다 |

## 1. 공지사항 목록 열기 <a href="#step-1" id="step-1"></a>

1. 학원 사이트에서 **공지사항** 메뉴를 엽니다. 상위 메뉴 이름·위치는 학원 설정과 PC/모바일 화면에 따라 다를 수 있습니다.
2. 게시판 탭이 표시되면 공지사항에 해당하는 탭인지 확인합니다. 탭이 없는 사이트도 있으므로 항상 **게시판 → 공지사항**으로 표시된다고 가정하지 않습니다.
3. PC에서는 **번호·제목·작성일·조회수**가 있는 표, 모바일의 좁은 화면에서는 제목·날짜·조회가 있는 카드 목록을 확인합니다.
4. 메뉴가 없거나 홈으로 돌아가면 사이트 주소·학원 안내를 확인하고 문의합니다. 임의의 게시글 주소를 만들어 접근하지 않습니다.

공지사항이 재원생에게만 공개된다고 가정하지 않습니다. 공개 공지에 학생 정보나 개인 자료를 올려 달라고 요청하지 않으며, 예상하지 못한 민감한 내용이 보이면 복사·공유하지 말고 학원에 알립니다.

> **화면 예시 준비 중** · 학원 사이트의 공지사항 메뉴를 확인합니다.

## 2. 중요 공지와 목록 정보 읽기 <a href="#step-2" id="step-2"></a>

| 표시 | 읽는 방법 |
| --- | --- |
| 중요 | 학원이 상단에 고정한 공지입니다. 작성일과 본문의 적용 기간을 함께 확인합니다 |
| 작성일·날짜 | 공지를 작성한 날짜입니다. 수업일·신청 마감일·마지막 수정 시각과 같은 뜻이 아닙니다 |
| 조회수·조회 | 글의 조회 집계입니다. 내가 읽었는지·특정 학생이 확인했는지 알려주는 표시가 아닙니다 |
| 일반 공지 제목 | 필요한 제목이나 행/카드를 눌러 상세로 이동합니다. 제목 일부가 잘리면 상세에서 전체 제목을 확인합니다 |

PC에서는 페이지를 바꿔도 중요 공지가 다시 상단에 보일 수 있습니다. 같은 공지가 새로 등록된 것으로 보지 않습니다. 중요 표시가 없다고 읽을 필요가 없는 것도 아니며, 가장 위의 글이 언제나 가장 최근에 작성된 글은 아닙니다.

목록의 조회수는 학생별 **읽음·미읽음·확인 완료**를 뜻하지 않습니다. 별도의 읽음 처리 버튼이 있다고 가정하지 말고, 학원이 확인/신청을 요청했다면 본문에 안내된 방법과 기한을 따릅니다.

> **화면 예시 준비 중** · 중요 표시와 작성일을 함께 확인합니다.

## 3. 검색하고 다른 공지 찾기 <a href="#step-3" id="step-3"></a>

1. **제목, 내용으로 검색** 입력란에 찾을 단어를 입력합니다. 예를 들어 학원이 안내한 반 이름이나 일정 제목을 사용합니다.
2. `Enter(엔터)`를 눌러 검색을 적용합니다. 입력만 바꾸거나 왼쪽 돋보기 모양을 누르는 것만으로 검색이 적용됐다고 판단하지 않습니다.
3. 결과가 갱신될 때까지 기다린 뒤 제목·작성일을 확인합니다. 갱신 중에는 이전 결과가 잠시 보일 수 있습니다.
4. PC는 목록 아래 페이지 번호로 이동합니다. 모바일은 **더 보기**가 있으면 눌러 추가 목록을 확인하고, `불러오는 중…`이면 기다립니다.
5. 검색을 해제하려면 입력 내용을 모두 지우고 **Enter**를 다시 누릅니다. 검색을 새로 적용하면 목록 시작 부분으로 돌아갑니다.

검색은 제목·본문을 대상으로 합니다. 첨부파일의 파일명이나 파일 속 글자까지 검색된다고 가정하지 않습니다. 검색 결과에서는 중요 공지도 검색 조건에 맞는 항목인지 확인합니다.

검색 중 `등록된 공지사항이 없습니다.`가 나오면 검색 결과가 없을 수 있습니다. 검색을 해제해 다시 확인하고, 이 문구만으로 학원에 공지가 하나도 없다고 단정하지 않습니다. 더 보기가 계속 실패하거나 같은 목록만 보이면 반복 조작 대신 현재 검색어·기기와 오류를 학원에 전달합니다.

> **화면 예시 준비 중** · 검색을 적용하고 기기별 목록 이동을 이용합니다.

> **동작 예시 준비 중** · 공지 목록에서 검색하고 다른 항목을 찾습니다.

## 4. 상세 본문에서 대상과 일정 확인하기 <a href="#step-4" id="step-4"></a>

1. 필요한 공지의 제목·행/카드를 누릅니다.
2. 상세에서 **전체 제목·중요 표시(있는 경우)·작성자·작성일**을 확인합니다.
3. 본문에서 대상 강좌/반, 적용 날짜·시간, 준비물·신청 방법·기한을 읽습니다. 작성일을 실제 수업일이나 신청 기한으로 대신 사용하지 않습니다.
4. 내용이 기존 안내와 다르거나 적용 대상이 불명확하면 공지 제목과 해당 문구를 학원에 확인합니다.

공지 상세를 여는 동작은 조회 집계에 반영될 수 있지만, 내 수강 진도·학습 완료나 학원의 학생별 확인 완료와 같지 않습니다. 숫자를 확인하려고 반복 새로고침하지 않습니다. 화면의 작성일만으로 최신 수정본임을 확정하지 않습니다.

본문에 링크가 있으면 연결 대상과 목적을 먼저 확인합니다. 공지의 글을 읽은 것만으로 별도 폼 신청·상담·구매가 완료되는 것은 아니며 비밀번호·인증번호를 요구하는 예상 밖 화면은 학원에 확인합니다.

> **화면 예시 준비 중** · 본문에서 적용 대상과 필요한 일정을 확인합니다.

## 5. 필요한 첨부파일 받기 <a href="#step-5" id="step-5"></a>

첨부가 표시되면 본문 아래에 **첨부파일 N개**, 각 **파일명 버튼**과 **KB/MB 용량**이 나타납니다. 내 자료의 받음 상태나 강의실 수업 옆 자료 버튼과는 다른 화면입니다.

1. 공지 본문에서 필요한 파일을 확인하고 파일명·용량을 대조합니다. 어떤 파일인지 불명확하면 학원에 먼저 확인합니다.
2. 필요한 **파일명 버튼**을 한 번 누른 뒤 브라우저 다운로드 내역이나 새 창/탭을 확인합니다. 여러 파일이면 필요한 파일을 개별로 확인합니다.
3. 자동 다운로드됐다면 완료/실패와 실제 저장 위치를 확인합니다. 새 창에 파일이 열렸다면 미리보기와 기기 저장을 구분하고, 브라우저에서 제공하는 저장 기능이 있으면 이용합니다.
4. PC의 선택한 폴더나 모바일의 파일 보관 위치에서 저장된 파일을 열고 공지에 맞는 내용인지 확인합니다. 오류 안내 문서·빈 파일·예상과 다른 내용이면 정상 다운로드로 보지 않습니다.

이미 요청했다면 저장 여부부터 확인합니다. 모바일에서도 모든 문서가 사진 앱/갤러리에 저장되는 것은 아니며, 기기별 메뉴·저장 위치·파일 열기 방법은 다를 수 있습니다. 임의의 프로그램 설치·확장자 변경·보안 설정 해제로 해결하려 하지 않습니다.

첨부 영역이 없다는 사실만으로 파일 미제공을 확정하지 않습니다. 본문에 첨부 안내가 있는데 파일이 안 보이거나 일부만 보이면 학원에 확인합니다. 다운로드 성공 알림·진행 표시·전체 파일 일괄 받기가 있다고 가정하지 않으며 버튼 클릭·새 창 열림만으로 저장 성공을 판단하지 않습니다.

이 화면의 공지 첨부에는 내 자료의 **취소 제한·10분 주소 확인창** 안내를 그대로 적용하지 않습니다. 받은 파일과 파일 주소는 학원이 허용한 범위에서만 사용하고 다른 사람에게 임의로 공유하지 않습니다.

> **화면 예시 준비 중** · 필요한 첨부파일을 받아 실제 내용을 확인합니다.

## 6. 이전글과 다음글 확인하고 목록으로 돌아가기 <a href="#step-6" id="step-6"></a>

1. 상세 아래 **다음글**, **이전글**에 제목이 있으면 제목을 확인한 뒤 필요한 글만 엽니다. **없음**은 해당 이동 대상이 없다는 표시입니다.
2. 이동한 글에서도 제목·대상·일정을 다시 확인합니다. 이전글/다음글이 검색 결과나 중요 공지의 표시 순서를 그대로 따르는 것은 아닙니다.
3. 목록으로 돌아갈 때는 상세 상단의 **목록으로**를 누릅니다.
4. 검색어·페이지·더 보기 상태가 그대로 남아 있다고 가정하지 말고 현재 목록을 확인합니다. 필요하면 검색을 다시 적용합니다.

> **화면 예시 준비 중** · 글 제목을 확인해 이동하거나 목록으로 돌아갑니다.

## 공지를 찾거나 열 수 없을 때 <a href="#section-8" id="section-8"></a>

| 상황 | 확인할 것·다음 행동 |
| --- | --- |
| 공지 메뉴가 없거나 홈으로 돌아가요 | 학원 사이트와 안내받은 메뉴를 확인하고 문의합니다. 메뉴가 보이지 않는다고 게시글·첨부파일의 접근까지 제한됐다고 판단하지 않습니다 |
| 등록된 공지사항이 없습니다. | 검색어를 지우고 Enter로 해제합니다. 빈 검색 결과와 전체 공지 없음은 구분합니다 |
| 공지사항을 불러오지 못했습니다. | 빈 목록과 조회 오류는 다릅니다. 화면의 재시도를 이용하고 반복되면 문의합니다. 상세 오류에서는 목록으로 돌아가 대상 제목을 확인합니다 |
| 검색해도 결과가 그대로예요 | Enter 적용 여부와 갱신 상태를 확인합니다. 첨부 내용까지 검색되는 것으로 판단하지 않습니다 |
| 중요 공지가 여러 페이지에 보여요 | 고정 공지가 반복 표시되는 경우입니다. 제목·작성일을 확인하며 새 등록/중복 공지로 단정하지 않습니다 |
| 모바일 더 보기가 계속 실패해요 | 현재 검색어·기기·표시 문구를 전달합니다. 주소의 숫자를 바꿔 제한을 우회하거나 계속 누르지 않습니다 |
| 전달받은 공지 링크가 열리지 않아요 | 같은 학원 사이트인지 확인하고 목록에서 제목을 찾습니다. 삭제/변경/제공 상태를 오류 문구만으로 확정하거나 다른 글 주소로 시험하지 않습니다 |
| 첨부가 없거나 일부만 보여요 | 본문의 파일 안내와 실제 첨부 영역을 대조하고 학원에 확인합니다. 영역 없음만으로 미등록을 단정하지 않습니다 |
| 파일을 못 찾거나 내용이 이상해요 | 다운로드 내역·저장 위치·파일명/내용을 확인하고 기기·오류 문구를 전달합니다. 반복 클릭·보안 해제를 우선 해결책으로 쓰지 않습니다 |
| 내 대상이 아닌 민감한 내용이 보여요 | 내용/파일을 복사·전달하지 말고 공지 제목과 발생 상황만 학원에 알립니다. 직접 주소로 다른 비공개 글을 시험하지 않습니다 |

> **화면 예시 준비 중** · 빈 결과와 조회·파일 저장 문제를 구분합니다.

## 학원에 문의할 때 <a href="#contact-academy" id="contact-academy"></a>

학원 사이트, 공지 제목·작성일, 적용 대상/일정 중 궁금한 부분, 검색어·PC 페이지 또는 모바일 더 보기 상태, 발생 시각·기기/브라우저와 화면 문구를 전달합니다. 첨부 문제는 파일명과 표시 용량·실제 저장/열기 여부도 함께 확인합니다.

**비밀번호·인증번호·토큰/세션·첨부 파일 URL·민감한 공지 본문은 보내지 않습니다.** 캡처는 학생 정보·주소창·개인 파일을 가린 뒤 전달합니다. 로그인할 수 없거나 사이트 메뉴를 찾을 수 없으면 로그인 후 1:1 문의 대신 학원이 별도로 안내한 연락처로 문의합니다.

## 완료 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 학원 사이트와 공지사항 메뉴를 확인했다.
- [ ] 중요 표시·작성일·조회수를 공지 적용일/학생별 읽음과 구분했다.
- [ ] 검색 입력과 Enter 적용·해제 방법을 확인했다.
- [ ] PC 페이지 이동과 모바일 더 보기·빈 결과/오류를 구분했다.
- [ ] 전체 제목·본문의 대상·일정·준비물/기한을 확인했다.
- [ ] 공지 첨부와 강의 첨부·별도 내 자료를 구분했다.
- [ ] 필요한 파일은 저장 위치에서 열어 실제 내용을 확인했다.
- [ ] 이전글/다음글과 목록으로 이동 후 현재 검색/목록 상태를 확인했다.
- [ ] 민감한 내용·파일 주소를 공유하거나 비공개 접근을 시험하지 않고 필요한 최소 정보만 문의했다.
