# 결제한 강의·자료가 없어요

<figure><img src="../.gitbook/assets/branding/page-headers/troubleshooting/missing-purchased-content-v2.png" alt="결제했는데 강의나 자료가 보이지 않아요 대표 이미지"><figcaption></figcaption></figure>

**같은 학원 사이트와 본인 계정인지 확인한 뒤, 원 주문(해당 상품을 구매한 주문)과 구매한 구성에 맞는 목록을 확인합니다.** 강좌나 자료가 보이지 않는다는 이유로 다시 결제하거나 무료 신청을 반복하지 않습니다.

## 먼저 내 상황 구분하기 <a href="#choose-your-situation" id="choose-your-situation"></a>

| 지금 상황 | 먼저 확인할 것 | 연결 안내 |
| --- | --- | --- |
| 로그인한 계정이 확실하지 않아요 | 학원 사이트·내 프로필·기존 가입 방식 | [내 계정 확인하기](../account/check-account-and-login-method.md) · [로그인·계정 문제 해결 안내](login-and-account.md) |
| 승인/출금 안내는 왔는데 사이트 결과가 불명확해요 | 원 주문번호·시각·금액과 현재 결제 내역 | [결제 결과 확인하기](../purchase/payment-and-free-order.md) |
| 결제 내역은 있는데 강좌나 자료가 없어요 | 구매 구성·대상 목록·필터·조회 오류·이용 상태 | 아래 순서대로 확인합니다 |
| 학원에서 수강권이나 자료를 지급했다고 안내받았어요 | 지급 대상 계정·강좌/자료명·지급 안내 | 주문이 없어도 지급받을 수 있습니다. 결제부터 다시 하지 않습니다 |
| 일부 강좌나 자료만 보여요 | 원 상품에 포함된 각 구성과 보이는/보이지 않는 대상 | 한 항목이 보이는 것만으로 전체 지급을 확정하지 않습니다 |
| 항목은 있는데 이용할 수 없어요 | 기간·이용불가·오류 문구와 취소/환불 진행 여부 | 목록 누락과 이용 제한을 나눠 확인합니다 |

## 1. 학원 사이트와 본인 계정 확인하기 <a href="#step-1" id="step-1"></a>

1. 학원이 안내한 사이트 이름·주소와 현재 사이트가 같은지 확인합니다.
2. **계정 설정 → 내 프로필**에서 본인의 이메일을 확인하고, 구매하거나 지급받은 기존 계정과 비교합니다. 이름·사진이 같다는 이유만으로 같은 계정이라고 보지 않습니다.
3. 카카오·구글로 로그인했다면, 로그인 방식뿐 아니라 선택한 카카오·구글 계정도 이전에 사용한 계정과 같은지 확인합니다. 프로필 조회 오류가 나면 먼저 [로그인·계정 문제 해결 안내](login-and-account.md)를 따릅니다.

보호자 명의로 결제했거나 다른 계정의 주문이 확인되면, 학원이 안내한 비공개 경로로 수강 계정 확인을 요청합니다. **다른 계정의 구매가 학생 계정으로 자동 이전되거나 합쳐지는 것은 아닙니다.** 새 계정 가입·연락처 변경·소셜 연결/해제로 해결하려 하지 않습니다. 타인의 정보가 보이면 주문·학습·개인정보 열람/변경을 중단합니다.

> **화면 예시 준비 중** · 구매하거나 지급받은 학원 사이트와 본인 계정을 먼저 확인합니다.

## 2. 다시 결제하지 말고 원 주문 확인하기 <a href="#step-2" id="step-2"></a>

구매했다면 **마이페이지 → 구매 내역 → 결제**에서 주문명·금액·시점을 비교하고 해당 주문을 엽니다. PC의 다른 페이지나 모바일의 더 보기가 표시되면 이어서 확인합니다. 상세의 **주문번호·주문 상태·상품명·결제 금액**을 기록합니다. 자세한 조회 방법은 [주문·결제 내역 확인하기](../orders/order-and-payment-history.md)를 참고합니다.

| 확인한 결과 | 다음에 할 일 | 단정하지 않을 것 |
| --- | --- | --- |
| 결제완료 주문이 있어요 | 아래 구매 구성과 실제 강좌/자료 목록을 각각 확인합니다 | 결제완료가 모든 구성의 지급·현재 이용 가능·교재 발송 완료를 뜻하지 않음 |
| 결제대기·입금대기 또는 승인 진행 안내가 있어요 | 원 주문과 표시된 안내를 학원에 확인합니다 | 주문 생성·외부 인증·완료 제목만으로 결제 확정이나 즉시 수강을 보장하지 않음 |
| 승인/출금 안내는 있는데 주문이 없거나 오류예요 | 결제 시각·금액·수단 종류와 알고 있는 원 주문번호로 문의합니다 | 빈 목록이나 오류가 미결제·출금 없음·안전한 재결제의 증거가 아님 |
| 결제 내역을 불러오지 못했어요 | 조회 오류로 구분하고 목록의 다시 불러오기를 확인합니다. 계속 실패하면 문의합니다 | 오류 화면을 주문 0개로 해석하지 않음 |
| 주문을 찾을 수 없다고 나와요 | 본인 계정·원 주문 정보를 확인하고 해결되지 않으면 문의합니다 | 주문 삭제·미구매·권한 문제 중 하나로 원인을 확정하지 않음 |
| 0원 신청을 했어요 | 같은 계정의 원 주문과 실제 제공 목록을 확인합니다 | 무료 완료 문구만 믿거나 무료 신청을 반복하지 않음 |
| 학원에서 직접 지급받았어요 | 학원의 지급 안내와 대상 계정·강좌/자료명을 확인합니다 | 구매 내역이 없다는 이유로 미지급이나 재구매 필요를 단정하지 않음 |

현재 결제 목록이 모든 대기·실패 주문을 보여주는 것은 아닙니다. 목록에서 찾지 못해도 기존 결제가 없었다고 판단하지 않습니다. 환불 진행 배지가 보이면 주문/항목 상태와 함께 확인합니다.

**결제 결과가 불명확할 때는 주문서·결제 완료 주소를 다시 열거나 새 주문·다른 결제수단으로 반복하지 않습니다.** 기존 주문 확인과 학원 문의를 우선합니다. 지급 지연이 정해진 시간 안에 자동으로 해결된다고 가정하지 않습니다.

> **화면 예시 준비 중** · 결제 결과가 불명확해도 새 결제보다 원 주문 확인을 우선합니다.

원 주문 상세의 **구성 콘텐츠 처리 상태**에서 강좌·자료·교재별 준비/처리 실패·확인 필요와 대상 수량을 나눠 확인합니다. 구성별 처리 안내나 배송·신청 정보가 표시돼도 실제 수강이나 자료 수신까지 완료됐다는 뜻은 아닙니다. 과거 주문의 지급 복구·보류 안내가 있더라도 학생용 복구 버튼이 제공되거나 자동으로 다시 지급된다고 가정하지 않습니다. 원 주문·이용 권한과 오류 문구를 학원에 전달합니다.

## 3. 구매한 구성에 맞는 곳에서 찾기 <a href="#step-3" id="step-3"></a>

![구매자 계정 기준의 구성별 확인 경로 개념도입니다. 강좌·별도 자료·실물 교재는 찾는 곳이 다르며 결제 완료는 제공·발송 완료가 아닙니다.](../.gitbook/assets/concepts/purchased-content-routes-v1.png)

상품명과 강좌명·자료명이 다를 수 있습니다. 구매할 때 안내받은 구성과 원 주문을 대조합니다. 현재 상품 소개가 바뀌었거나 주문 화면에 옵션·수량이 충분히 보이지 않으면 학원에 구매 당시 구성을 확인합니다. 목록의 **강좌 N개** 같은 요약만으로 실제 포함 강좌 수나 전체 지급 수를 확정하지 않습니다.

| 구매하거나 지급받은 대상 | 찾을 곳 | 잘못 찾기 쉬운 경우 |
| --- | --- | --- |
| 강좌 | **마이페이지 → 내 학습 → 수강중 강좌** | 상품 제목과 강좌 제목이 다르거나 일부 상태 필터에만 보이지 않을 수 있음 |
| 별도 디지털 자료 | **마이페이지 → 내 학습 → 내 자료** | 강좌 목록이나 구매 내역에서 다운로드 버튼만 찾으면 놓칠 수 있음 |
| 강의에 첨부된 자료 | 해당 강좌/수업의 강의실 커리큘럼 **자료** 안내 | 별도 내 자료에 반드시 등록되는 것은 아님. 확인용 자료 클릭은 다운로드를 실행할 수 있음 |
| 교재만 포함된 상품 | 원 주문과 학원의 교재 배송 안내 | 교재만 샀다면 강좌나 디지털 자료가 생기는 것은 아님 |
| 강좌·자료·교재 묶음 | 포함된 각 대상의 경로를 따로 확인 | 한 강좌·한 파일이 보인다는 이유로 전체 구성 지급/배송을 확정하면 안 됨 |

구성 확인은 [상품 구성·가격·이용 기간](../purchase/product-and-access-period.md), 첨부자료는 [강의 첨부 자료](../resources/lecture-materials.md), 별도 자료는 [디지털 자료 이용](../resources/my-digital-resources.md)을 참고합니다. 교재 배송은 [교재 배송과 배송지 안내](../orders/textbook-shipping-and-address.md)에서 별도로 확인합니다.

강의실의 **자료** 버튼이나 내 자료의 최종 **다운로드**를 권리 확인용으로 누르지 않습니다. 다운로드 URL 발급은 이용 이력을 만들 수 있고, 강의실 진입·재생도 학습 기록에 영향을 줄 수 있습니다. 항목이 안 보이는 문제는 우선 목록과 안내를 기준으로 정리합니다.

> **화면 예시 준비 중** · 강좌·별도 자료·강의 첨부자료는 찾는 곳이 다릅니다.

## 4. 강좌 목록의 필터와 이용 기간 확인하기 <a href="#step-4" id="step-4"></a>

1. **내 학습 → 수강중 강좌**에서 먼저 **전체**를 선택합니다. 필요하면 수강중·완료·만료 필터와 다른 페이지도 확인합니다.
2. 목록을 불러오는 중인지, 빈 목록인지, **수강 중인 강좌를 불러오지 못했습니다.** 같은 조회 오류인지 구분합니다. 오류가 계속되면 문구와 발생 시각을 기록합니다.
3. 대상 강좌의 이름과 표시된 이용 기간·종료일을 학원 안내와 비교합니다. **N일**은 남은 날짜가 아니며, 종료 날짜만으로 정확한 종료 시각을 확정하지 않습니다.
4. 강좌가 보이지만 만료·비활성 상태이거나 이용 제한이 나오면 목록 누락과 별도 문제로 정리합니다. **다시 구매하기**를 기존 권리 복구·기간 자동 연장 버튼으로 보지 않습니다.

**전체 필터가 모든 과거 지급을 빠짐없이 보여주는 것은 아닙니다.** 취소/회수·삭제 등으로 목록에서 제외되는 경우가 있을 수 있으며, 목록만으로 정확한 원인을 확정하지 않습니다. 수강중·완료 표시 역시 현재 재생 권한이나 무제한 이용을 뜻하지 않습니다.

강좌 찾기 정상 절차는 [내 강의 찾고 수강 시작하기](../learning/find-course-and-start.md), 기간과 학습 표시는 [수강 기간과 학습 현황](../learning/access-period-and-progress.md)을 참고합니다. 이미 강좌/수업은 찾았고 영상만 재생되지 않는다면 구매 누락과 구분해 오류 문구·영상 종류·이용 환경을 문의에 적습니다. 재생을 반복해 지급 여부를 시험하지 않습니다.

> **화면 예시 준비 중** · 전체와 다른 페이지를 확인하고 빈 목록과 조회 오류를 구분합니다.

> **동작 예시 준비 중** · 새 결제나 콘텐츠 이용 없이 대상 목록과 필터를 확인합니다.

> **화면 예시 준비 중** · 강좌 목록 표시와 현재 이용 권한·기간은 별도로 확인합니다.

## 5. 내 자료의 필터와 이용 상태 확인하기 <a href="#step-5" id="step-5"></a>

1. **내 학습 → 내 자료**에서 **전체**를 선택합니다. 받음·미받음 필터와 다른 페이지도 확인합니다.
2. **지급된 자료가 없습니다.**, **해당 상태의 자료가 없습니다.**, `내 자료를 불러오지 못했습니다.`를 구분합니다. 조회 오류는 미지급을 확정하는 결과가 아닙니다.
3. 자료명·파일명·지급일과 표시 상태를 확인합니다. 상세가 열리지 않으면 해당 문구를 기록하고, 자료가 삭제되었다고 단정하지 않습니다.
4. **이용불가**로 표시되거나 이용할 수 없으면 현재 상태를 학원에 확인합니다. 버튼이 활성이라는 이유로 모든 이용 조건이 충족되었다고 보지 않습니다.

**받음·미받음은 구매/미구매를 구분하는 필터가 아닙니다.** 받음이나 최초 다운로드 시각이 있어도 해당 기기에 파일 저장·열기가 완료되었다는 뜻은 아닙니다. 확인하려고 다운로드 주소 발급을 반복 요청하지 않습니다. 이미 자료는 찾았고 저장/파일 열기만 안 된다면 지급 누락과 별도 문제로 정리합니다.

같은 제목이 여러 개여도 지급일·파일명을 함께 비교하고 임의로 하나를 지우거나 재구매하지 않습니다. 구매 당시 제공 파일과 현재 판매 파일이 다를 수 있으며, 최신 파일로 자동 교체된다고 기대하지 않습니다. 화면에 없는 버전 선택·이용 기간 필터·만료 카운트다운을 이용할 수 있다고 가정하지 않습니다.

> **화면 예시 준비 중** · 내 자료의 필터·파일 정보와 이용 상태를 확인합니다.

## 6. 일부만 없거나 취소 이력이 있을 때 <a href="#step-6" id="step-6"></a>

| 상황 | 정리할 것 | 하지 않을 일 |
| --- | --- | --- |
| 묶음 강좌·자료 중 일부만 없어요 | 원 상품 구성, 보이는 대상과 없는 대상의 정확한 이름, 확인한 목록/필터 | 한 항목으로 전체 지급을 확정하거나 묶음을 다시 구매하지 않음 |
| 같은 제목인데 다른 파일 같아요 | 자료명·파일명·지급일과 구매 당시 안내 | 최신판으로 자동 교체된다고 가정하거나, 이름이 같다는 이유만으로 같은 지급 항목이라고 단정하지 않습니다. |
| 학원 지급 안내와 계정/기간이 달라요 | 안내받은 대상 계정·강좌/자료명·기간과 현재 표시 | 새 계정을 만들거나 이용 권한 이전·재지급을 직접 시도하지 않음 |
| 취소/환불 신청 뒤 이용이 안 돼요 | 원 주문·신청 대상·현재 표시와 실제 이용 제한 | 취소·환불을 신청했다고 환불이 끝난 것으로 판단하지 않습니다. 결제완료 표시만으로 현재 이용할 수 있다고 판단하지도 않습니다. |
| 부분취소 주문의 일부 콘텐츠가 안 보여요 | 취소한 대상과 계속 이용하려는 대상을 구분 | 주문 전체를 취소하거나 재결제해 확인하지 않음 |

취소·환불 이력이 있다면 [취소·반품·교환 처리 상태 확인하기](../cancellations/request-status.md)를 함께 참고합니다. 권리 제한·복구 반영과 실제 환불 결과는 별도입니다. 화면 문구만으로 지급 지연·회수·만료 등 원인이나 자동 복구 여부를 확정하지 않습니다.

## 해결되지 않으면 학원에 문의하기 <a href="#section-8" id="section-8"></a>

목록·계정·구매 구성을 확인했는데도 찾을 수 없거나 결과가 서로 다르면, 같은 원 주문 또는 지급 안내를 기준으로 [사이트 1:1 문의](../communication/site-inquiries.md)에 정리합니다. 로그인할 수 없으면 학원이 별도로 안내한 연락처를 사용합니다. 실제 문의처·운영 시간·본인 확인 방식은 아직 확인이 필요합니다. 학원이 안내한 문의 경로를 이용합니다.

먼저 **문제 대상·화면 문구·발생 시각**을 알려 주세요. 아래 추가 정보는 알고 있거나 학원에서 확인을 요청한 경우에만 전달하면 됩니다.

| 알려 줄 내용 | 필요한 범위 |
| --- | --- |
| 보이지 않는 강좌·자료 | 학원 이름과 정확한 강좌/자료명. 강의 첨부 자료인지 별도 자료인지도 알려 주세요 |
| 화면 문구·발생 시각 | 목록이 비어 있는지 오류나 이용불가 안내가 나오는지, 언제부터인지. 캡처는 개인정보를 가립니다 |
| 구매·직접 지급 확인이 필요할 때 | 구매한 경우에는 주문번호·주문명·시각·금액·표시 상태를, 직접 지급받은 경우에는 학원의 안내·대상 계정/기간을 비공개 경로로 전달합니다. |
| 추가 요청을 받았을 때 | 확인한 목록·필터·페이지, 묶음 중 없는 항목, 결제 승인/출금 안내와 주문 화면의 차이, PC/휴대폰·브라우저를 알려 주세요 |
| 사이트·본인 확인이 필요할 때 | 학원 첫 화면 주소와 본인 확인에 필요한 최소 정보만 비공개 경로로 전달합니다. 개인 파일 주소나 주소창 전체는 보내지 않습니다 |

문의 예시:

> 오늘 오후부터 자료 B가 내 자료 목록에 보이지 않습니다. 같은 학원 사이트의 기존 계정으로 로그인했고, 구매한 주문은 결제완료로 보입니다. 오류 안내는 없고 재결제나 다운로드는 하지 않았습니다. 구매 구성과 자료 지급 상태를 확인해 주세요.

> **화면 예시 준비 중** · 원 주문 또는 지급 안내와 보이지 않는 대상을 정리해 문의합니다.

**비밀번호·인증번호·접속 인증이나 결제 처리에 쓰이는 정보(토큰·결제키)·결제 완료 화면의 주소·결제 후 학원 사이트로 돌아온 페이지의 주소·다운로드 URL·전체 카드/계좌번호·다른 학생 정보는 보내지 않습니다.** 캡처는 필요한 오류 영역만 남기고 이름·전화번호 등 개인정보가 보이지 않게 가립니다. 학원 문의가 즉시 지급·기간 연장·계정 통합/권리 이전을 보장하지 않습니다. 강좌·자료가 없거나 결제 결과가 다르면 현재 보이는 상태를 학원에 알려 주세요. 지급 재처리·정산·결제 복구가 필요한지는 담당자가 확인합니다. 학생이 직접 처리하려 하지 않습니다.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 구매하거나 지급받은 학원 사이트와 본인 계정이 맞는지 확인했습니다.
- [ ] 구매한 경우에는 원 주문을, 직접 지급받은 경우에는 학원의 지급 안내를 기준으로 확인했습니다.
- [ ] 승인/출금·완료 문구와 주문 상태·실제 콘텐츠 지급을 구분했습니다.
- [ ] 강좌·별도 자료·강의 첨부자료·교재의 포함 구성과 이용 경로를 구분했습니다.
- [ ] 강좌의 전체/상태 필터·다른 페이지·빈 목록/조회 오류·기간 표시를 확인했습니다.
- [ ] 내 자료의 전체/받음/미받음·파일명·지급일·이용불가/오류를 구분했습니다.
- [ ] 묶음 일부 누락·직접 지급·취소/환불 이력과 현재 이용 제한을 별도로 정리했습니다.
- [ ] 확인용 재가입·재결제·무료 재신청·재생/다운로드·권리 변경을 하지 않았습니다.
- [ ] 해결되지 않으면 비밀정보를 제외한 원 주문/지급 정보와 없는 대상을 학원에 문의할 준비를 했습니다.
