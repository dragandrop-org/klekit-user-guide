# 로그인이나 계정 확인이 안 돼요

<figure><img src="../.gitbook/assets/branding/page-headers/troubleshooting/login-and-account-v2.png" alt="로그인이나 계정 확인이 안 돼요 대표 이미지"><figcaption></figcaption></figure>

**학원 사이트와 기존 계정을 먼저 확인하고, 막힌 단계에 맞는 안내를 선택합니다.** 오류가 난다는 이유만으로 새로 가입하거나 계정을 연결·해제하지 않습니다.

## 먼저 확인하기 <a href="#check-first" id="check-first"></a>

| 확인할 것 | 확인 방법 | 주의할 점 |
| --- | --- | --- |
| 학원 사이트 | 학원이 안내한 사이트 이름·주소와 현재 화면을 비교합니다 | 다른 학원 사이트나 운영자 로그인 화면으로 들어간 것은 아닌지 확인합니다 |
| 기존 가입 방식 | 이메일, 카카오, 구글 중 이전에 사용한 방식을 떠올립니다 | 같은 이름·같은 제공자만으로 같은 계정이라고 단정하지 않습니다 |
| 현재 로그인 상태 | 이미 로그인되어 있다면 계정 설정의 내 프로필에서 본인 이메일을 확인합니다 | 헤더 이름·사진만으로 계정을 확정하지 않습니다. 프로필 조회 오류와 값 없음을 구분합니다 |
| 막힌 단계 | 로그인 입력, 인증 발송, 인증 확인, 아이디 결과, 비밀번호 저장, 카카오·구글 같은 소셜 로그인 후 학원 사이트로 돌아오기 중 어디인지 확인합니다 | 여러 단계를 한 번에 반복하지 말고 현재 오류 문구와 발생 시각을 기록합니다 |

> **화면 예시 준비 중** · 학원 사이트와 기존 가입 방식을 먼저 확인합니다.

> **동작 예시 준비 중** · 막힌 단계에 맞는 계정 안내로 이동합니다.

## 내 상황에 맞는 안내 선택하기 <a href="#section-2" id="section-2"></a>

| 지금 상황 | 먼저 볼 내용 | 연결 안내 |
| --- | --- | --- |
| 이메일이나 비밀번호가 기억나지 않아요 | 아이디와 비밀번호 중 모르는 항목을 구분합니다 | [아이디 찾고 비밀번호 재설정하기](../account/find-account-and-reset-password.md) |
| 로그인 정보를 입력했는데 오류가 나요 | 아래 이메일 로그인 점검부터 확인합니다 | [회원가입·로그인하기](../account/signup-and-login.md) |
| 인증번호가 오지 않거나 확인되지 않아요 | 수신 대상·최신 번호·화면 오류를 확인합니다 | 아래 인증 점검 |
| 카카오/구글 로그인 뒤 가입 화면이나 오류가 나요 | 같은 제공자와 이전에 사용한 실제 외부 계정인지 확인합니다 | 아래 소셜 로그인 점검 |
| 로그인했지만 내 계정인지 모르겠어요 | 내 프로필의 이메일과 알고 있는 기존 계정을 비교합니다 | [내 계정과 로그인 방식 확인하기](../account/check-account-and-login-method.md) |
| 로그인은 됐는데 강의나 자료가 없어요 | 계정 확인과 구매·지급·이용 기간을 나눠 확인합니다 | [내 강의 찾고 수강 시작하기](../learning/find-course-and-start.md) · [디지털 자료 이용하기](../resources/my-digital-resources.md) |

## 이메일 로그인이 안 될 때 <a href="#section-3" id="section-3"></a>

1. 아이디에는 **가입할 때 사용한 전체 이메일 주소**를 입력했는지 확인합니다. 이름·휴대폰 번호나 아이디 찾기에 나온 별표 포함 주소를 그대로 입력하지 않습니다.
2. 자동 완성된 이메일이 다른 계정은 아닌지 확인합니다. 비밀번호를 입력할 때 키보드 입력 상태·대소문자·불필요한 공백도 확인합니다. 비밀번호를 문의나 캡처에 넣지 않습니다.
3. 이메일을 모르면 **아이디 찾기**, 이메일은 알지만 비밀번호를 모르면 **비밀번호 재설정**을 선택합니다. 상세 절차는 [계정 복구 안내](../account/find-account-and-reset-password.md)를 따릅니다.

**“이메일 또는 비밀번호를 확인해주세요.”라는 문구만으로 어느 항목이 틀렸는지 알 수 없습니다.** 계정이 없거나 비밀번호가 다른 경우 등이 같은 문구로 표시될 수 있습니다. 미가입으로 단정해 다른 이메일로 가입하거나 여러 사람의 계정을 시험하지 않습니다.

인터넷 연결·요청 제한·서버 오류가 표시되면 문구와 발생 시각을 기록합니다. 제한 안내가 있을 때 로그인·인증 버튼을 계속 누르지 않습니다. 해결되지 않으면 아래 문의 기준에 따라 학원에 확인합니다. 오류별로 정확히 얼마나 기다리거나 몇 번 다시 시도해야 하는지는 아직 확인이 필요합니다.

> **화면 예시 준비 중** · 공통 오류 문구만으로 미가입이나 비밀번호 오류를 단정하지 않습니다.

## 인증번호가 오지 않거나 확인되지 않을 때 <a href="#section-4" id="section-4"></a>

아이디 찾기는 **등록한 휴대폰 인증**, 비밀번호 재설정은 **가입 이메일 인증**을 사용합니다. 입력한 연락처가 가입 당시 등록한 연락처와 같은지 먼저 확인합니다.

| 증상 | 확인할 것 | 다음 행동 |
| --- | --- | --- |
| 문자가 오지 않아요 | 등록한 휴대폰 번호·국가 선택, 문자 수신/차단 상태, 발송 실패·제한 안내 | 입력 대상부터 확인합니다. 연속 재발송하지 말고 해결되지 않으면 학원에 문의합니다 |
| 이메일이 오지 않아요 | 전체 가입 이메일·오타, 스팸함/차단, 발송 오류 | 다른 주소로 새 가입하기 전에 기존 주소를 확인합니다 |
| 번호가 맞지 않거나 만료 안내가 나와요 | 입력한 전화번호나 이메일로 받은 인증번호인지, 성공한 재발송 뒤 가장 최근에 받은 번호인지, 화면의 남은 시간·오류 | 화면의 새 인증 안내를 따릅니다. 재발송 성공 전의 번호가 계속 유효하다고 보지 않습니다 |
| 요청/입력 횟수 제한이 나와요 | 제한이 발송 단계인지 확인 단계인지, 현재 문구 | 반복 입력·재발송을 멈춥니다. 번호나 계정을 바꿔 제한을 우회하지 않습니다 |
| 예전 번호·이메일을 사용할 수 없어요 | 가입 당시 연락처를 기억하는지, 기존 소셜 방식이 있는지 | 다른 사람의 연락처로 인증하지 말고 학원이 안내한 비공개 경로로 본인 확인 방법을 문의합니다 |

**인증 완료 표시와 아이디 확인·비밀번호 저장 완료는 다른 단계입니다.** 화면 타이머가 남아 있어도 서버에서 만료 오류가 날 수 있으며, 오류 문구 하나만으로 단순 오입력이라고 단정하지 않습니다. 인증번호·인증 메일 링크는 학원 문의에도 보내지 않습니다.

> **화면 예시 준비 중** · 수신 대상과 현재 오류를 확인하고 제한 시 반복 요청을 멈춥니다.

## 아이디 결과나 비밀번호 저장이 불명확할 때 <a href="#section-5" id="section-5"></a>

| 결과 | 확인할 것 | 주의할 점 |
| --- | --- | --- |
| 이메일 일부만 보여요 | 가려진 이메일과 가입일시를 참고해 본인이 알고 있는 전체 주소와 비교합니다 | 별표를 추측해 여러 이메일로 로그인하지 않습니다. 가려진 이메일 전체를 화면에서 복원할 수 있다고 가정하지 않습니다 |
| 아이디가 여러 개예요 | 실제 구매하거나 수강권을 지급받았던 기존 계정인지 확인합니다 | 가입일·이름·같은 휴대폰만으로 구매 계정을 확정하거나 계정 통합을 시도하지 않습니다 |
| 가입된 아이디가 없다고 나와요 | 학원 사이트·등록했던 번호·가입 방식이 맞는지 다시 확인합니다 | 과거 가입·탈퇴 상태까지 확정하는 결과가 아닙니다. 기존 이용 이력이 있다면 재가입 전에 문의합니다 |
| 결과 화면 새로고침/뒤로 가기 후 오류가 나요 | 결과를 이미 확인했는지, 현재 인증 만료/잘못된 접근 안내가 있는지 | 결과 주소는 공유·재사용하는 복구 링크가 아닙니다. 반복 조회하지 말고 필요한 경우 정상 찾기 화면의 안내를 따릅니다 |
| 새 비밀번호를 저장할 수 없어요 | 화면 조건·확인 입력 일치·이전과 다른 값인지, 인증 후 저장 단계의 오류 | 비밀번호 값은 공유하지 않습니다. 인증 완료만으로 저장 성공이라고 보지 않습니다 |
| 저장을 눌렀지만 완료인지 모르겠어요 | 완료 안내를 봤는지, 새 비밀번호로 본인 계정에 로그인할 수 있는지 | 곧바로 재설정을 반복하지 않습니다. 같은 사이트에서 로그인 결과를 확인하고 불명확하면 문의합니다 |
| 소셜 로그인 전용 안내가 나와요 | 이전에 사용한 카카오/구글 제공자와 실제 계정 | 아래 카카오·구글 로그인 안내를 확인합니다. 카카오·구글로 가입했어도 비밀번호가 있는 계정이 있습니다. |

비밀번호 변경 완료 뒤에는 로그인 결과와 본인 프로필을 별도로 확인합니다. 변경이 외부 카카오/구글 비밀번호를 바꾸거나 수강권을 자동 복구한다는 뜻은 아닙니다.

> **화면 예시 준비 중** · 아이디 찾기 결과를 참고하되 전체 주소와 구매 계정을 별도로 확인합니다.

> **화면 예시 준비 중** · 이메일 인증·비밀번호 저장·로그인 결과를 구분합니다.

## 카카오·구글 로그인이 안 될 때 <a href="#section-6" id="section-6"></a>

| 증상 | 확인할 것 | 다음 행동 |
| --- | --- | --- |
| 외부 인증을 취소했거나 학원 화면으로 돌아오지 못했어요 | 선택한 제공자·실제로 사용한 외부 계정, 현재 취소/오류 문구 | 버튼을 누른 것만으로 로그인 완료로 보지 않습니다. 학원 로그인 화면에서 기존 방식을 확인하고 같은 오류가 계속되면 문의합니다 |
| 외부 인증 뒤 가입/추가 정보 화면이 나와요 | 같은 학원·같은 제공자·이전에 사용한 실제 카카오/구글 계정인지 | 기존 회원이라면 새 가입 완료 전에 멈추고 계정을 확인합니다. 다른 계정으로 가입해도 기존 구매/수강권이 자동 이전되지 않습니다 |
| 다른 사람의 계정이나 정보가 보여요 | 현재 학원 프로필이 본인의 것인지 | 타인의 주문·학습·개인정보 열람/변경을 중단합니다. 정식 로그아웃 후 본인의 기존 계정으로 로그인하고 계속 잘못 표시되면 학원에 문의합니다 |
| 소셜 계정 자체에 로그인할 수 없어요 | 카카오/구글에서 본인 계정 접근이 가능한지 | 외부 계정 복구는 해당 제공자의 절차를 따릅니다. 학원 비밀번호 재설정과 구분합니다 |

소셜 로그인 후에는 학원 사이트의 내 프로필에서 본인 계정인지 확인합니다. **간편로그인의 연동/미연동 표시는 현재 로그인 방식이나 외부 계정의 이메일을 알려주는 표시가 아닙니다.** 확인을 위해 스위치를 켜거나 연결을 해제하지 않습니다.

보안 설정 해제·인증 우회·주소창의 인증 주소 복사/수정·반복 새로고침을 공통 해결책으로 사용하지 않습니다. 학원으로 돌아온 주소에는 인증정보가 포함될 수 있으므로 문의에 전체 주소를 붙이지 않습니다.

> **화면 예시 준비 중** · 기존 회원에게 가입 화면이 나오면 같은 외부 계정인지 먼저 확인합니다.

## 로그인 후 계정을 확인할 수 없을 때 <a href="#section-7" id="section-7"></a>

1. [계정 확인 안내](../account/check-account-and-login-method.md)에 따라 **계정 설정 → 내 프로필**을 확인합니다. 이름만 같다고 본인 계정으로 확정하지 않습니다.
2. **“프로필 정보를 불러오지 못했습니다.”** 같은 조회 오류를 계정 삭제·미가입·다른 계정의 증거로 해석하지 않습니다. 이메일 `-`나 휴대폰 `등록 필요` 표시도 조회 오류와 구분합니다.
3. 로그인 만료·다시 로그인 안내가 실제로 나오면 같은 학원 사이트의 기존 방식으로 로그인합니다. 단순 조회 오류를 고치려고 연락처 변경·비밀번호 재설정·소셜 연결/해제·탈퇴를 실행하지 않습니다.
4. 탈퇴 대기/철회나 약관 재동의 안내가 나오면 일반 로그인 실패와 구분합니다. 상태를 모르는 채 복구·탈퇴 철회·재동의를 시험하지 말고 학원에 확인합니다. 계정 복구 가능 기간과 이용 권한 복원 여부는 아직 확인이 필요하며, 복구를 보장하지 않습니다.

본인 계정으로 로그인했지만 강좌·자료가 없다면 로그인 문제와 분리합니다. [내 강의 찾기](../learning/find-course-and-start.md)·[내 자료 이용](../resources/my-digital-resources.md)·[주문 내역](../orders/order-and-payment-history.md)을 확인하되, 학원이 직접 지급한 수강권은 주문이 없을 수 있습니다. 재가입·재결제·확인용 재생/다운로드를 해결책으로 실행하지 않습니다.

> **화면 예시 준비 중** · 본인 계정 확인과 조회 오류를 나누고 필요한 정보로 학원에 문의합니다.

## 해결되지 않으면 학원에 문의하기 <a href="#section-8" id="section-8"></a>

로그인할 수 있다면 [사이트 1:1 문의](../communication/site-inquiries.md)를 이용할 수 있습니다. **로그인하지 못하는 경우에는 학원이 별도로 안내한 연락처를 이용합니다.** 실제 연락처·운영 시간·본인 확인 방식은 아직 확인이 필요합니다. 1:1 문의를 이용할 수 없는 경우에는 학원이 안내한 별도 문의 경로를 확인합니다.

먼저 **문제 대상·화면 문구·발생 시각**을 알려 주세요. 아래 추가 정보는 알고 있거나 학원에서 확인을 요청한 경우에만 전달하면 됩니다.

| 알려 줄 내용 | 필요한 범위 |
| --- | --- |
| 학원 사이트·막힌 단계 | 학원 이름, 이메일/카카오/구글 중 사용한 로그인 방식, 멈춘 화면 |
| 화면 문구·발생 시각 | 오류 문구나 개인정보를 가린 캡처, 언제부터인지. 재현을 위해 인증을 반복하지 않습니다 |
| 추가 요청을 받았을 때 | PC/휴대폰·브라우저, 기존 가입 방식과 수신 대상 확인 여부, 완료 안내를 봤는지 |
| 본인 확인이 필요할 때 | 학원이 안내한 비공개 경로에서 필요한 최소 정보만 전달합니다. 사이트 주소를 요청받으면 학원 첫 화면 주소만 보내고 인증용 링크나 주소창 전체는 보내지 않습니다 |

문의 예시:

> 학원 사이트에서 기존 구글 로그인 후 추가 정보 입력 화면으로 이동합니다. 오늘 오후부터 발생했으며 휴대폰 브라우저를 사용했습니다. 같은 제공자인지는 확인했지만 기존에 사용한 외부 계정인지 확인이 필요합니다. 새 가입은 완료하지 않았습니다. 기존 수강 계정 확인 방법을 안내해 주세요.

**비밀번호·인증번호·인증 메일 링크·인증 결과 페이지의 주소·카카오·구글 같은 소셜 로그인 후 학원 사이트로 돌아온 페이지의 주소·토큰·외부 계정 선택 목록·다른 학생 정보는 보내지 않습니다.** 스크린샷도 필요한 오류 영역만 남기고 이름·전화번호 등 개인정보가 보이지 않게 가립니다. 학원 문의가 자동 계정 통합·수강권 이전이나 즉시 해결을 보장하지 않습니다.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 학원이 안내한 사이트와 현재 로그인 화면이 맞는지 확인했습니다.
- [ ] 기존 가입 방식과 현재 막힌 단계를 구분했습니다.
- [ ] 공통 로그인 오류만으로 미가입·비밀번호 오류를 단정하지 않았습니다.
- [ ] 인증 수신 대상·최신 번호·현재 오류를 확인하고 제한 시 반복 요청을 멈췄습니다.
- [ ] 아이디 찾기에서 이메일 일부가 가려진 경우, 계정이 여러 개 나온 경우, 계정이 없다고 나온 경우를 구분했습니다. 결과 주소를 다시 열어 생긴 오류도 따로 확인했습니다.
- [ ] 인증 완료·비밀번호 저장·로그인 성공을 별도로 확인했습니다.
- [ ] 소셜 가입 화면·잘못된 계정·탈퇴/재동의 안내를 재가입이나 연결 해제로 우회하지 않았습니다.
- [ ] 본인 프로필 확인과 강좌/자료·주문/직접 지급 확인을 분리했습니다.
- [ ] 해결되지 않으면 비밀정보를 제외하고 학원의 실제 문의 경로로 필요한 정보를 준비했습니다.
