## 이용에 문제가 있나요 <a href="#troubleshooting" id="troubleshooting"></a>

- [로그인이나 계정 확인이 안 돼요](troubleshooting/login-and-account.md)
- [결제했는데 강의나 자료가 보이지 않아요](troubleshooting/missing-purchased-content.md)
- [영상이 재생되지 않거나 끊겨요](troubleshooting/video-and-audio.md)
- [자료 다운로드나 교재 배송에 문제가 있어요](troubleshooting/resources-and-shipping.md)

결제·다운로드·신청 결과가 불명확하면 같은 계정과 원래 주문부터 확인합니다. 재구매·무료 재신청·연속 다운로드로 문제를 해결하려 하지 않습니다.

## 학원에 문의할 때 <a href="#contact-academy" id="contact-academy"></a>

학원 사이트 이름, 상품·강좌명, 주문번호, 문제가 생긴 시각, 화면 문구를 필요한 범위만 전달하세요. 비밀번호·인증번호·전체 카드나 계좌번호·개인 파일 주소는 보내지 않습니다. 로그인할 수 없다면 학원이 별도로 안내한 연락처를 이용하세요.
