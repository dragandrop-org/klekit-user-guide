# 배송 설정하기

<figure><img src="../.gitbook/assets/branding/page-headers/orders-and-shipping/shipping-settings-v2.png" alt="배송 설정하기 대표 이미지"><figcaption></figcaption></figure>

**업무 대상:** 주문 확인·콘텐츠 제공·교재 배송을 맡은 담당자용 안내입니다. 강사는 학생이 알려 준 문제와 대상을 정리해 해당 운영자에게 전달하세요. 실제 작업 가능 범위는 본인 계정의 권한을 확인하세요.

교재를 판매하기 전에 기본 택배사, 출고지·반품지, 최초 배송비와 반품·교환 비용을 정리합니다. 배송 설정은 상품별 재고나 개별 주문의 송장·배송지를 바꾸는 작업과 다릅니다.

**조건부 무료배송은 상품 할인 후·쿠폰 적용 전 교재 금액 합계로 판단합니다.** 강좌·디지털 자료 금액은 제외합니다. 반품비·교환비는 무료배송 여부와 관계없이 각각 설정한 금액을 안내하며, 두 비용이 같은 금액이어야 하는 것은 아닙니다.

**준비 순서:** 적용 범위 확인 → 택배사·출고지·반품지 준비 → 기본 배송비·무료배송 기준 결정 → 반품비·교환비 결정 → 저장 결과·신규 주문 반영 확인

## 시작 전 준비 <a href="#before-you-start" id="before-you-start"></a>

| 준비할 것 | 확인 기준 |
| --- | --- |
| 담당 계정 | 배송 설정 조회·변경 권한이 있는 운영자 계정 |
| 실제 출고 방식 | 사용할 택배사와 출고 담당자·연락처 |
| 주소 | 출고지의 우편번호·주소·상세 주소, 별도 반품지 사용 여부 |
| 최초 배송비 | 기본 배송비와 조건부 무료배송 사용 여부·기준 금액 |
| 반품·교환 비용 | 각각 안내할 반품비·교환비와 운영 담당자의 확인 |
| 변경 범위 | 신규 주문 적용과 기존 주문·확정 비용을 구분할 변경 기록 |

설정값은 판매자가 실제로 사용할 운영 기준으로 정합니다. 아래 예시 금액은 계산 설명용이며 클킷의 기본값이나 권장 요금이 아닙니다.

## 메뉴 위치 <a href="#menu-location" id="menu-location"></a>

**배송 관리 → 배송 설정**에서 기본 택배사·무료배송 기준·기본 배송비·출고지·반품지·반품 배송비·교환 배송비와 **저장** 항목을 확인합니다. 실제 서비스에서 메뉴가 표시되는지, 담당 계정으로 변경할 수 있는지와 저장 결과는 아직 확인이 필요합니다. 메뉴가 보인다는 이유만으로 운영 설정을 시험 변경하지 않습니다.

아래는 설정값을 준비할 때와 저장 후에 확인할 항목입니다. 정산 설정·학생 주소록 등 다른 메뉴로 대신 처리하거나, 확인되지 않은 방법으로 설정을 변경하지 않습니다.

> **화면 예시 준비 중** · 현재 설정과 신규 주문 적용 범위를 나눠 확인합니다.

## 1. 설정 적용 범위 확인하기 <a href="#step-1" id="step-1"></a>

교재가 포함된 주문에 사용할 배송비 정책을 준비합니다. 강좌·디지털 자료만 있는 주문에 교재 배송비를 더하지 않습니다. 교재가 여러 개여도 최초 배송비는 주문당 한 번 적용하는 기준입니다.

| 설정 상황 | 확인할 것 |
| --- | --- |
| 처음 설정 | 실제 택배사·출고지·비용 기준을 모두 준비 |
| 기존 설정 변경 | 현재 저장값과 변경할 항목·적용 시점 확인 |
| 배송비 정책을 사용하지 않음 | 최초 배송비 계산과 실제 배송 업무를 구분 |

**배송비 정책 비활성화는 배송 중지나 배송 대상 취소를 뜻하지 않습니다.** 현재 확인된 계산 기준에 따르면, 배송비 정책이 없거나 비활성화되어 있으면 최초 배송비는 0원입니다. 배송비를 받을 계획이라면 설정 적용 상태와 신규 주문의 확정 금액을 반드시 확인하세요.

기본 배송비를 0원으로 정한 경우도 조건부 무료배송과 구분합니다. 0원은 유효한 금액이며 빈 값·미설정과 같은 의미가 아닙니다.

## 2. 기본 택배사·출고지·반품지 준비하기 <a href="#step-2" id="step-2"></a>

### 기본 택배사 <a href="#section-5" id="section-5"></a>

이 가이드에서 다루는 택배사는 **CJ대한통운·한진택배**입니다. 실제 운영 화면에서 제공하는 최종 목록은 아직 확인이 필요하므로 사용할 택배사가 표시되는지 먼저 확인하세요.

목록에 없는 택배사를 다른 이름으로 선택하지 않습니다. 기본 택배사 설정만으로 계약·택배 접수·송장 발급·실제 발송이 자동 진행되는 것은 아닙니다.

### 출고지와 반품지 <a href="#section-6" id="section-6"></a>

| 주소 구분 | 준비할 정보 | 주의할 점 |
| --- | --- | --- |
| 출고지 | 발송인/출고 담당자, 연락처, 우편번호, 주소, 필요한 상세 주소 | 사업장 주소와 실제 출고지가 같은지 확인 |
| 출고지를 반품지로 사용 | 반품을 실제로 받을 수 있는지 확인 | 출고 가능 주소가 반드시 회수 가능한 주소인 것은 아님 |
| 별도 반품지 | 반품 수령 담당자, 연락처, 우편번호, 주소, 필요한 상세 주소 | 별도 사용을 정했다면 반품지 정보도 준비 |

활성 설정에는 기본 택배사와 출고지가 필요합니다. 별도 반품지를 사용하면 해당 주소도 필요합니다. 연락처·우편번호·기본 주소는 빈 값으로 두지 않고, 동·층·호수 등 필요한 상세 주소도 확인합니다.

여기서 정하는 출고지·반품지는 **구매자의 배송지나 주소록이 아닙니다.** 기존 주문의 수령 주소를 정정하는 절차와 혼동하지 않습니다.

> **화면 예시 준비 중** · 실제 출고·반품을 처리할 택배사와 주소를 확인합니다.

## 3. 기본 배송비·무료배송 기준 정하기 <a href="#step-3" id="step-3"></a>

| 항목 | 준비 기준 |
| --- | --- |
| 기본 배송비 | 조건부 무료배송 기준을 충족하지 않을 때의 최초 배송비. 0원 이상 정수 원 단위 |
| 조건부 무료배송 | 사용할지 먼저 결정. 사용한다면 1원 이상의 기준 금액 |
| 기준 미사용 | 교재 주문에 기본 배송비를 적용하는 기준. 실제 설정 방법은 아직 확인되지 않았으므로 담당자에게 확인 |

조건부 무료배송을 사용하지 않는 것과 기준 금액 0원은 다릅니다. 현재 화면에는 **무료 배송** 스위치와 기준 입력이 있습니다. 스위치·기준 금액·기본 배송비의 저장 결과와 실제 신규 주문 비용을 함께 확인하고, 스위치를 교재 배송 자체의 중지로 해석하지 않습니다.

### 무료배송 계산 예시 <a href="#free-shipping-example" id="free-shipping-example"></a>

기본 배송비 **3,000원**, 무료배송 기준 **30,000원**으로 정했다고 가정합니다. 교재 금액은 상품 할인 후·쿠폰 적용 전 금액입니다.

| 강좌·자료 금액 | 교재 금액 합계 | 쿠폰 할인 | 최초 배송비 | 이유 |
| --- | --- | --- | --- | --- |
| 0원 | 29,000원 | 0원 | 3,000원 | 교재 금액이 기준 미만 |
| 0원 | 30,000원 | 5,000원 | 0원 | 쿠폰 적용 전 교재 금액이 기준 이상 |
| 100,000원 | 20,000원 | 0원 | 3,000원 | 강좌·자료 금액을 무료배송 판정에 더하지 않음 |

기준 금액과 **같아도** 무료배송 조건을 충족합니다. 쿠폰 때문에 최종 결제 금액이 기준 아래로 내려가도 상품 할인 후·쿠폰 적용 전 교재 금액으로 판단합니다.

패키지의 무료배송 여부를 판단할 때는 교재에 배분된 구성 금액과 상품 할인을 기준으로 합니다. 패키지 전체 가격을 교재 금액으로 간주하거나 운영자가 화면에서 새로 계산한 값으로 주문 배송비를 덮어쓰지 않습니다. 실제 주문에서는 클킷에서 확정한 배송비를 확인하세요.

> **화면 예시 준비 중** · 상품 할인 후·쿠폰 전 교재 금액으로 무료배송 여부를 대조합니다.

## 4. 반품 배송비·교환 배송비 정하기 <a href="#step-4" id="step-4"></a>

반품비와 교환비는 **서로 독립된 두 설정**입니다. 각각 0원 이상의 정수 원 단위로 준비합니다.

**무료배송 주문을 위한 별도의 왕복 반품비를 새로 설정할 수 있다고 안내하지 않습니다.** 반품비에 최초 배송비를 더하거나, 무료배송이라는 이유로 교환비를 반품비 대신 사용하지 않습니다.

반품비 **3,000원**, 교환비 **6,000원**으로 정한 예시는 다음과 같습니다. 동일한 설정·적용 조건을 비교한 설명이며 실제 환불 확정 금액이 아닙니다.

| 최초 배송 조건 | 안내할 반품비 | 안내할 교환비 |
| --- | --- | --- |
| 배송비를 결제한 주문 | 3,000원 | 6,000원 |
| 기준 금액 충족으로 무료배송 | 3,000원 | 6,000원 |
| 기본 배송비가 0원인 무료배송 | 3,000원 | 6,000원 |

설정값과 실제 반품 검수·귀책 판단·환불 차감액은 별도로 확인합니다. 기존 주문은 해당 주문에 저장된 정책과 확정 내역을 기준으로 확인하며 현재 설정으로 다시 계산하지 않습니다.

**교환비 설정은 자동 비용 결제나 자동 교환품 재배송 기능이 아닙니다.** 실제 회수·교환 안내와 비용 처리는 확인된 운영 절차를 따릅니다.

예전 화면의 왕복 반품비 입력란이 보이면 해당 금액을 반품비에 더하거나 임의로 값을 맞추지 않습니다. 현재 사용하는 화면과 그 항목에 적용되는 정책을 담당자에게 확인합니다.

> **화면 예시 준비 중** · 무료배송 여부와 관계없이 반품비·교환비를 각각 확인합니다.

## 5. 저장·반영 결과 확인하기 <a href="#step-5" id="step-5"></a>

현재 화면의 **저장**은 실제 배송 설정을 변경할 때 사용합니다. 운영에 사용할 값을 반영할 때만 아래 순서로 진행하세요. 오류를 재현하려고 저장하지 않습니다. 저장에 실패하거나 다른 담당자의 변경과 충돌하면 최신 설정부터 확인합니다.

1. 현재 설정을 조회하고 준비한 값과 비교합니다.
2. 변경할 택배사·주소·비용·적용 상태를 확인합니다.
3. 확인된 화면에서 값을 입력·저장한 뒤 설정을 다시 조회합니다.
4. 택배사·출고지·반품지·기본 배송비·무료배송 기준·반품비·교환비가 의도한 값인지 확인합니다.

**설정 저장과 주문 반영은 별개입니다.** 신규 주문의 확정 배송비가 설정과 다르면 담당 운영자에게 확인합니다. 기존 주문에는 소급 적용되지 않으며, 반영 여부를 시험하려고 실제 학생 주문을 새로 만들지 않습니다.

다른 담당자의 변경으로 저장이 거절되면 최신 설정을 다시 확인하고 변경 내용을 비교합니다. 오래된 값으로 최신 설정을 덮어쓰거나 저장을 무조건 반복하지 않습니다.

저장 성공 알림만으로 신규 주문의 배송비나 기존 주문·반품 처리 결과까지 확인된 것은 아닙니다. 해당 주문·처리 내역을 따로 확인하고, 설정을 조회하지 못한 경우와 설정이 없는 경우도 구분합니다.

> **동작 예시 준비 중** · 설정을 저장한 뒤 의도한 택배사·주소·비용이 유지되는지 확인합니다.

## 6. 기존 주문과 설정 변경 구분하기 <a href="#step-6" id="step-6"></a>

설정 변경은 신규 주문에 적용할 기준을 바꾸는 작업입니다. 이미 생성된 주문의 배송비·저장된 정책·확정 환불/검수 비용을 소급 변경하지 않습니다.

| 변경·문의 | 구분할 것 |
| --- | --- |
| 무료배송 기준을 낮춤 | 새 주문 계산과 기존 주문의 확정 배송비 |
| 반품비·교환비를 바꿈 | 새 정책 안내와 기존 주문·확정 처리 내역 |
| 출고지·반품지를 바꿈 | 새 설정과 이미 생성된 배송 건에 저장된 정보 |
| 학생 주소를 바꾸려 함 | 사이트 배송 설정과 주문별 배송지 정정 |

과거 주문의 정정이 필요하면 대상 주문·배송·처리 근거부터 확인하고 별도 절차를 따릅니다. 배송 설정을 바꾸면 모든 기존 배송 정보가 자동 수정됐다고 안내하지 않습니다.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 실제 화면에서 메뉴·권한과 입력·저장 순서를 확인했습니다.
- [ ] 기본 택배사와 실제 출고지·반품지를 확인했습니다.
- [ ] 기본 배송비·조건부 무료배송 사용 여부·기준 금액을 구분했습니다.
- [ ] 상품 할인 후·쿠폰 적용 전 교재 금액으로 무료배송을 대조했습니다.
- [ ] 반품비·교환비를 각각 확인하고 구 왕복 반품비를 합산하지 않았습니다.
- [ ] 저장 후 설정을 다시 확인했습니다. 신규 주문 반영 결과와 아직 확인하지 못한 항목을 구분하고, 차이가 있으면 담당 운영자에게 확인했습니다.
- [ ] 기존 주문·배송·확정 비용과 새 설정을 구분했습니다.

## 자주 막히는 부분 <a href="#troubleshooting" id="troubleshooting"></a>

| 상황 | 확인할 것 |
| --- | --- |
| 배송 설정 메뉴가 없어요 | 배송 관리 → 배송 설정이 보이지 않으면 실제 서비스의 메뉴 제공 여부·담당 계정 권한·조회 오류를 확인합니다. 다른 설정 메뉴나 확인되지 않은 방법으로 우회하지 않습니다 |
| 정책을 껐는데 배송 대상이 남아 있어요 | 배송비 정책 비활성화와 배송 중지·배송 취소는 별도입니다 |
| 무료배송 기준을 넘었는데 배송비가 있어요 | 강좌·자료를 제외한 상품 할인 후 교재 금액과 해당 주문의 저장 기준을 확인합니다 |
| 쿠폰 적용 후 기준 미만인데 무료배송이에요 | 무료배송은 쿠폰 적용 전 교재 금액으로 판단합니다 |
| 기본 배송비가 0원인데 반품비가 있어요 | 최초 배송비·반품비·교환비는 별도 설정입니다 |
| 왕복 반품비 입력이 따로 보여요 | 현재 사용하는 화면과 해당 항목의 적용 기준을 담당자에게 확인합니다. 반품비에 더하거나 임의로 맞추지 않습니다 |
| 저장이 거절됐어요 | 금액·택배사·필수 주소·권한과 다른 담당자의 변경 여부를 확인합니다 |
| 설정을 바꿨는데 이전 주문 금액은 그대로예요 | 기존 주문의 확정 금액·정책은 새 설정으로 소급 변경하지 않습니다 |
| 교환비를 넣었는데 자동 결제가 안 돼요 | 이 설정은 비용 안내 기준이며 자동 교환 결제·재배송은 현재 안내 범위가 아닙니다 |
