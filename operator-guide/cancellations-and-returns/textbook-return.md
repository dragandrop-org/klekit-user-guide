# 교재 반품 처리하기

> **검토용 가이드** · 실제 서비스 화면·동작 확인과 이미지 보완이 남아 있습니다. 본문의 실행 보류·주의사항을 먼저 확인하세요.

발송된 교재의 반품 신청을 확인하고, 실제 회수·검수 결과에 따라 환불과 재입고를 처리할 때 사용합니다. 출고 전 취소는 [구성품별 취소·환불](component-cancellation-and-refund.md), 동일 교재 재배송은 [교재 교환 처리하기](textbook-exchange.md)로 구분합니다.

**회수 승인·입고·검수 합격 기록만으로 환불되거나 재고가 늘어나지는 않습니다. 검수 후 최신 금액을 확인하고 별도 승인한 뒤, 금융 확정과 배송·재고 후속 결과까지 확인합니다.**

**확인 순서:** 반품 신청·원 배송 확인 → 수동 회수 준비·승인 기록 → 실제 회수·입고 기록 → 실물 검수·필수값 확인 → 검수 합격 기록 → 최신 금액 확인·[별도 승인](request-review-approve-and-reject.md) → 환불·반품 수량·재입고 결과 확인

아래는 클킷 서비스 정책을 확인하기 위한 기준입니다. 법정 반품 기준이나 법률 검토 완료를 뜻하지 않습니다. 최종 제품 정책·화면·운영 책임을 확인한 뒤 공개 안내로 확정합니다.

## 시작 전 준비

| 준비할 것 | 확인 기준 |
| --- | --- |
| 사이트·담당 권한 | 해당 사이트의 신청 조회와 회수/검수·승인/거절 권한 구분 |
| 신청·주문 | 반품 신청 식별정보·주문번호·구매자와 대상 교재 구성품 하나 |
| 수량·원 배송 | 구매/신청/기처리 수량, 실제 발송 근거와 유효 배송 항목 |
| 날짜·사유 | 원 신청 시각, 구매자 입력 수령일, 확인할 실제 수령 사실·신청 사유 |
| 회수 담당 | 외부 연락·택배 회수·반품 수령 장소·실물 보관·검수 담당과 연락 경로 |
| 비용·재고 근거 | 원 주문 금액·최초 배송비, 회수 비용, 판매 재고로 돌릴 수량과 원 재고 소비 근거 |

실제 회수와 클킷 기록은 다른 업무입니다. 회수·검수 담당자를 정하지 않은 채 자동 회수가 접수됐다고 안내하지 않습니다. 공개 촬영은 승인된 테스트 환경·주문·교재로 하며 학생 주소·연락처·송장·주문 정보를 보호합니다.

## 메뉴 위치

현재 **결제/정산관리 → 취소·반품·교환 내역 → 해당 반품 상세**에 회수 승인·입고 기록·검수 결과 기록·취소 승인 연결이 있습니다. 실제 회수/입고와 화면 기록·검수 합격과 별도 환불 승인을 구분합니다. 배포/권한·금융/재고 결과는 검수 대기입니다.

아래는 현재 연결된 업무의 단계별 검수 기준입니다. 검수 창의 원 수령일·귀책/가치 감소·반품비·재입고 수량·사유를 확인하되 초기값을 실물 확정값으로 보지 않습니다. 화면 밖의 요청·상태 덮어쓰기·DB 수정으로 우회하지 않습니다.

## 1. 발송 후 반품 신청과 날짜 확인하기

반품은 교재 구성품 하나·신청 수량을 대상으로 합니다. 발송 전 취소·교환·이미 처리된 신청과 구분하고 같은 주문의 다른 구성품을 섞지 않습니다.

| 확인 항목 | 판단 기준 |
| --- | --- |
| 신청 유형·대상 | 교재 반품인지, 원 구성품·구매/신청/기처리 수량이 맞는지 확인 |
| 원 배송 | 실제 발송 근거·배송 수량과 해당 주문/구매자 일치. 송장이나 현재 상태명만으로 확정하지 않음 |
| 구매자 입력 수령일 | 접수 자료이며 자동 수령 인증이 아님 |
| 운영자 확인 수령일 | 학생이 원 교재를 실제 받은 시각. 원 신청 시각보다 나중일 수 없음 |
| 원 신청 시각 | 단순 변심 기한 재판정의 기준. 회수·검수 처리일로 바꾸지 않음 |
| 반품 입고·검수 기록 시각 | 운영자가 반품을 받거나 기록한 단계의 시각. 학생의 원 수령일과 다름 |

단순 변심은 **한국 시간 기준 원 수령일 다음 날부터 7일째 끝까지 신청한 경우**를 기준으로 검수에서 다시 판단합니다. 예를 들어 10월 1일 수령했다면 일반 신청 기간은 10월 2일부터 10월 8일 끝까지입니다. 수령 당일 신청·미래 수령일·원 신청 후의 수령 시각을 같은 조건으로 취급하지 않습니다.

회수나 검수가 늦어졌다고 원 신청일을 처리일로 바꿔 기한을 새로 시작하거나, 지연만으로 일괄 거절하지 않습니다. 하자·오배송은 단순 변심 기한만으로 거절하지 않고 실제 귀책·실물 근거로 별도 판단합니다.

수령·발송·수량이 불명확하면 해당 근거를 확인합니다. 원 배송을 미출고 상태로 되돌리거나 신청 수량·날짜를 임의 수정해 진행하지 않습니다.

> **화면 예시 준비 중** · 원 신청일과 학생 수령일을 확인합니다. 반품 입고일과는 다릅니다.

## 2. 수동 회수 준비와 승인 기록 남기기

1. 최신 신청·상태·처리 권한과 해당 신청의 적용 결과를 확인합니다. 적용 대기나 근거 불명확은 먼저 확인합니다.
2. 실제 회수 담당자·외부 연락 방법·수령 장소와 회수할 교재·수량을 대조합니다.
3. 확인된 신규 화면에서 회수 승인과 구체적인 처리 사유·수동 회수 근거를 기록합니다.
4. 같은 신청의 최신 상세에서 회수 단계·기록 시각·이력을 확인합니다.
5. 확정된 운영 경로로 실제 회수 업무를 진행하고, 외부 접수·실물 도착 여부를 별도로 확인합니다.

**클킷의 회수 승인 기록은 택배사 자동 회수 접수가 아닙니다.** 기록만으로 회수가 시작·완료됐다고 안내하거나 환불을 실행하지 않습니다. 외부 접수 시점·회수 안내 방식과 담당자 책임은 공개 전 운영 검수에서 확정합니다.

처리 사유는 비워둘 수 없습니다. 신청과 무관한 개인정보·인증정보를 넣지 않으며 독립 메모·회수 송장 등록·첨부 업로드 기능이 있다고 가정하지 않습니다.

## 3. 실물이 도착한 뒤 입고 기록하기

회수된 교재가 담당 장소에 실제 도착하면 대상 주문·구성품·수량을 대조한 뒤 입고를 기록합니다. 택배 회수 접수나 이동 중 상태를 입고 완료로 대신 기록하지 않습니다.

| 실물 확인 | 주의할 점 |
| --- | --- |
| 대상 교재 | 이름만 같아도 다른 주문·교재·판본일 수 있으므로 원 구성품과 대조 |
| 신청/도착 수량 | 신청보다 적거나 다른 교재가 오면 검수 담당자에게 확인. 신청 수량을 임의 변경하지 않음 |
| 현재 단계 | 회수 승인 이후 입고로 진행. 단계를 건너뛰거나 완료 상태를 덮어쓰지 않음 |
| 기록 결과 | 같은 신청을 재조회해 입고·검수 단계와 처리 이력 확인 |

클킷의 입고 기록 시각을 학생이 원 교재를 받은 시각으로 사용하지 않습니다. 외부 회수 지연·분실·수량 불일치를 입고 성공으로 감추지 않고 담당자에게 전달합니다.

> **화면 예시 준비 중** · 실제 회수·실물 도착을 확인하고 단계별 처리 기록을 대조합니다.

## 4. 실물 검수와 필수값 확정하기

반품 교재를 확인한 뒤 아래 항목을 함께 대조합니다. **학생의 원 수령일과 반품 입고일, 신청 수량과 재입고 수량은 서로 다릅니다.**

| 필수 항목 | 확인 기준 |
| --- | --- |
| 확인 수령일 | 학생이 원 교재를 받은 실제 시각·시간대. 원 신청 시각 이후가 아닌지 확인 |
| 귀책 | 실물·배송 사실에 따라 단순 변심 또는 판매자 귀책으로 확인. 입력 사유만으로 확정하지 않음 |
| 현저한 가치 감소 | 사용·훼손 등 확인. 단순 변심에서 현저한 가치 감소가 있으면 합격 처리하지 않음 |
| 확정 반품비 | 이번 회수에서 확인한 0원 이상의 원 단위 정수 비용. 안내 설정값과 구분 |
| 재입고 가능 수량 | 판매 재고로 되돌릴 수량, 0부터 신청 수량까지. 회수·신청 수량 전체로 자동 확정하지 않음 |
| 처리 사유 | 판단 근거와 후속 확인 내용을 구체적으로 기록 |

재입고 수량 0은 정상 값입니다. 하자 교재를 환불할 수 있다는 사실과 다시 판매할 수 있다는 판단은 다릅니다. 신청 수량이 2개이고 판매 가능한 교재가 1개라면 재입고 가능 수량은 1개로 구분하며, 실제 원 주문·재고 근거와 함께 확인합니다.

### 합격 기록

입고 후 검수값·사유를 확인하고 검수 합격을 기록합니다. 저장 후 최신 상세의 확인 수령일·귀책·비용·재입고 수량·이력을 다시 대조합니다. **검수 합격은 아직 환불·재입고 완료가 아닙니다.**

현재 계약에서 합격 기록을 같은 동작으로 다시 수정하거나 회수·입고 단계로 되돌리는 절차는 없습니다. 잘못된 값을 발견하면 최신 상태와 저장된 근거를 담당자에게 전달하고 허용된 후속 업무를 확인합니다. 비용·재입고 수량을 반복 저장해 덮어쓰지 않습니다.

### 불합격 또는 확인 부족

불합격은 별도 검수 불합격 저장 기능을 가정하지 않고, 거절 가능한 상태에서 [사유와 함께 거절하기](request-review-approve-and-reject.md)를 따릅니다. 거절 기록과 해당 신청의 제한 해제 적용도 따로 확인합니다.

정보가 부족한 경우와 불합격을 구분합니다. 값이 필수라는 이유로 날짜·귀책·비용·재입고 수량을 추정하지 않습니다. 강좌·자료 전용 귀책 인정이나 이용 기록 이의 심사를 교재 검수에 대신 사용하지 않습니다.

> **화면 예시 준비 중** · 검수값과 재입고 가능 수량을 확인합니다. 합격 기록만으로 환불되지는 않습니다.

## 5. 비용과 최신 환불액 확인하기

검수 합격 후 최신 신청 기준으로 승인 전 조건·금액을 다시 확인합니다. 검수에서 확인한 귀책·수령일·비용과 원 신청일, 최신 배송·원 결제·재고 소비 근거를 사용합니다.

| 비용 구분 | 단순 변심 | 판매자 귀책 |
| --- | --- | --- |
| 교재 금액 | 원 구성품의 신청 수량 결제 배분액 | 원 구성품의 신청 수량 결제 배분액 |
| 최초 배송비 반환 | 반환하지 않음 | 일부 반품은 원 주문 배분 근거, 마지막 유효 교재 반품은 남은 최초 배송비로 서버 판단 |
| 반품비 차감 | 검수에서 확정한 비용을 이번 취소 금액 상한 안에서 차감 | 구매자 환불액에서 차감하지 않음 |

**최초 배송비·안내 반품비·검수 확정 반품비·실제 차감액·최종 환불액을 나누어 확인합니다.** 무료배송이었다고 최초 발송비를 새로 더하거나 구 왕복 반품비를 자동 선택하지 않습니다. 현재 [배송 설정](../orders-and-shipping/shipping-settings.md) 금액을 과거 원 주문 배송비·이미 확정한 비용 대신 사용하지 않습니다.

확정 비용이 이번 취소 금액보다 커도 실제 차감은 금액 상한까지입니다. 서버 결과를 사용하며 음수 환불이나 초과 비용의 자동 추가 청구를 안내하지 않습니다. 적격한 0원과 미확정 금액은 다릅니다.

판매자 귀책 일부 반품의 과거 배송비 배분 근거가 없으면 예상액이 미확정이거나 승인이 제한될 수 있습니다. 마지막 교재의 남은 최초 배송비도 이미 반환한 금액을 제외해 확인합니다. 현재 상품가·현재 정책으로 원 금액을 추정하지 않습니다.

반품비를 뺀 실제 환불액이 원 교재 배분액보다 작다고 해서 남은 교재 원금이 늘어나는 것은 아닙니다. 처리 수량에 대응하는 원 금액은 별도로 소비하므로 이후 반품 가능액을 직접 다시 계산하지 않습니다.

> **화면 예시 준비 중** · 검수 후 최신 환불액을 확인하고 배송비 반환과 반품비 차감을 구분합니다.

> **동작 예시 준비 중** · 검수 저장 후 최신 조건·금액을 다시 확인합니다. 승인은 별도 단계입니다.

## 6. 별도 승인 후 환불·배송·재입고 결과 확인하기

최신 승인 전 결과가 처리 가능하고 금액이 확정됐으면 [승인·결과 확인](request-review-approve-and-reject.md)을 따릅니다. 합격 기록에 쓰인 이전 상태·금액으로 승인하지 않습니다. 실제 에스크로·원 결제 잔액·근거 부족 제한은 [구성품별 취소·환불 처리하기](component-cancellation-and-refund.md)도 함께 확인합니다.

| 최신 결과 | 확인할 것 |
| --- | --- |
| 검수 합격·반품 진행 | 금액 확인과 별도 승인 필요. 환불·재입고 완료 아님 |
| 환불 처리 중 | 같은 신청의 상태·결과 확인. 승인·취소·거절을 반복하지 않음 |
| 금융 확정·후속 대기 | 확정액과 배송 항목 처리 수량·검수 재입고·제한 해제 후속 결과 구분 |
| 반품 완료 | 해당 신청의 금융 확정과 배송/재고 후속 결과를 대조. 카드/계좌 반영 시점과 구분 |
| 거절 | 구체적인 사유·이력과 해당 신청 제한 해제 확인. 환불·재입고 성공이 아님 |

금융 확정 후 후속 처리에서 **검수로 확정한 재입고 수량만 원 소비 근거에 따라 한 번 복원**합니다. 검수 단계에서 재고를 먼저 수동 증가시키거나 후속 장애를 중복 재입고로 해결하지 않습니다. 재입고 0이면 증가·가짜 재고 이력을 만들지 않습니다.

원 배송의 발송/수령 이력은 보존하며 반품한 교재의 처리 수량과 남은 수량을 확인합니다. 반품을 이유로 발송된 원 배송을 미출고 취소 상태로 되돌리거나 남은 교재·다른 구성품을 한꺼번에 취소하지 않습니다.

원 재고 소비 근거가 누락·불일치하면 처리가 제한될 수 있습니다. 재고 소비 수량이 0으로 기록된 경우에는 검수 수량만 보고 재고 증가를 기대하지 말고 원 근거와 실제 결과를 확인합니다. 결과가 불명확하면 같은 신청·확정액·검수 수량·배송/재고 이력을 담당자에게 전달하고 임의 보정·새 취소를 하지 않습니다.

> **화면 예시 준비 중** · 금융 확정과 배송·재입고 후속 결과를 확인합니다. 검수 수량과 실제 복원은 구분합니다.

## 완료 후 확인

- [ ] 원 주문·반품 신청·교재 구성품 하나·신청/기처리 수량·실제 발송을 확인했습니다.
- [ ] 원 신청 시각·학생 수령일·반품 입고/검수 기록 시각을 구분했습니다.
- [ ] 단순 변심 기한은 확인 수령일과 원 신청일로 판단하고 귀책은 별도로 확인했습니다.
- [ ] 외부 회수와 클킷 회수 승인·입고·검수 기록을 구분했습니다.
- [ ] 확인 수령일·귀책·가치 감소·확정 비용·재입고 수량·사유를 대조했습니다.
- [ ] 검수 저장 후 최신 값·단계·이력을 확인하고 불합격/근거 부족을 구분했습니다.
- [ ] 원 배송비 반환·반품비 차감·최종 환불액과 미확정/0원을 확인했습니다.
- [ ] 최신 금액 재확인·별도 승인과 금융 확정·전체 완료를 구분했습니다.
- [ ] 검수 재입고 수량·원 소비 근거·실제 배송/재고 결과와 남은 구성품을 확인했습니다.
- [ ] 중복 환불·수동 재고 증가·원 배송 되돌리기 없이 결과를 안내했습니다.

## 자주 막히는 상황

| 상황 | 확인할 것 |
| --- | --- |
| 기존 환불 화면에서 반품 단계를 찾을 수 없음 | 새 반품 화면 제공 여부 확인. 기존 승인·거절이나 화면 밖의 요청로 대신 처리하지 않음 |
| 회수 승인했는데 물건이 오지 않음 | 외부 회수 접수·담당자·실물 도착 별도 확인. 자동 접수/입고 완료로 안내하지 않음 |
| 검수가 늦어져 일반 기한을 넘음 | 처리일이 아니라 원 신청일과 확인 수령일로 재판정 |
| 확인 수령일·수량·가치 감소로 저장 제한 | 원 신청 시각·실물·허용 수량/귀책 확인. 잘못된 값으로 합격하지 않음 |
| 합격 기록을 수정하거나 단계 재처리할 수 없음 | 최신 상태·확정값·이력 확인 후 담당자에게 전달. 덮어쓰기·단계 되돌리기 금지 |
| 검수 합격했는데 환불·재고가 그대로임 | 최신 금액 확인·별도 승인·금융 확정·후속 결과 구분 |
| 일부 귀책 반품 예상액이 없음 | 원 배송비 배분·잔액·배송/재고 소비 근거 확인. 현재 가격으로 추정하지 않음 |
| 재입고가 0이거나 신청 수량보다 적음 | 검수에서 판매 가능한 수량과 실제 소비/증감 근거 확인. 전량 수동 증가 금지 |
| 금액·상태 충돌 또는 응답 불명확 | 같은 신청 최신 상세·이력 재조회. 재취소·재입고 반복 금지 |
