# 구성품별 취소·환불 처리하기

<figure><img src="../.gitbook/assets/branding/page-headers/cancellations-and-returns/component-cancellation-and-refund-v3.png" alt="구성품별 취소·환불 처리하기 대표 이미지"><figcaption></figcaption></figure>

**업무 대상:** 취소·반품·교환 처리를 맡은 담당자용 안내입니다. 해당 처리 업무를 맡지 않은 강사·질답 조교는 환불을 확정하거나 승인하지 말고 학생의 요청을 처리 담당자에게 전달하세요. 실제 작업 가능 범위는 본인 계정의 권한을 확인하세요.

묶음상품을 포함한 주문에서 어떤 구성품을 취소하는지 확인하고, 해당 유형의 조건에 맞춰 환불 가능 여부와 금액을 검토할 때 사용합니다. 교재 발송 후 반품·교환의 회수·검수·재배송은 별도 가이드에서 다룹니다.

**한 신청은 구매 당시 구성품 하나와 신청 수량을 대상으로 합니다. 예상액은 서버 계산 결과를 사용하며, 학습 진도율·현재 상품가·주문 총액으로 대신 계산하지 않습니다.**

**확인 순서:** 원 주문·구성품·수량 확인 → 유형별 최신 이용/발송 사실 확인 → 서버 예상액·처리 경로 확인 → 필요한 귀책/이용 기록 심사 → 최신 금액 재확인 → [승인·거절·결과 확인](request-review-approve-and-reject.md)

아래는 구성품별 환불 조건을 확인할 때 참고할 내용입니다. 실제 적용되는 정책과 처리 화면은 아직 확인이 필요한 부분이 있으므로, 처리 전에 담당자에게 확인하세요. 법정 환불 기준이나 법률 검토가 완료된 안내는 아닙니다.

## 시작 전 준비 <a href="#before-you-start" id="before-you-start"></a>

| 준비할 것 | 확인 기준 |
| --- | --- |
| 사이트·담당 권한 | 해당 사이트의 신청 조회와 심사·처리 권한 구분 |
| 원 주문·신청 | 주문번호·신청 식별정보와 구매자 일치 |
| 구매 당시 구성 | 구성품 하나의 유형·이름·구매 수량·결제 배분액 |
| 남은 범위 | 이미 취소된 수량·금액, 같은 구성품의 진행 중 신청 |
| 유형별 근거 | 구매 수강권·이용 기록, 자료 URL 발급, 교재 배송·발송 이력 |
| 결제 조건 | 원 결제 잔액·금액 근거, 실제 에스크로와 구매확정 여부 |

확인하려고 실제 학생 계정으로 영상을 재생하거나 자료를 다운로드하지 않습니다. 새 이용 기록·URL 발급이 취소 조건을 바꿀 수 있습니다.

## 메뉴 위치와 역할 <a href="#menus-and-roles" id="menus-and-roles"></a>

구성품별 신청 경로가 제공되는 환경에서는 학생 주문 상세의 **구성품 취소 신청**으로 조건·예상액을 확인하고 신청합니다. 운영자는 **결제/정산관리 → 취소·반품·교환 내역**에서 귀책·이용 기록을 심사하고, 승인 전에 최신 조건·금액·처리 가능 여부를 확인합니다. 주문 전체 취소·품목 취소·환불 버튼과 구성품별 신청은 다른 처리이므로 서로 대신 사용하지 않습니다.

| 역할 | 이 가이드에서 다루는 범위 |
| --- | --- |
| 구매자 | 본인 주문의 구성품·수량·사유 선택, 예상액 확인·신청. 이용 가능한 신청 경로를 먼저 확인 |
| 운영자 | 접수된 신청의 원 주문·이용/발송 근거·사유 심사, 최신 금액 확인·승인/거절·결과 확인 |

운영자가 구매자 대신 로그인하거나 신청 대상·수량·환불액을 임의로 바꾸지 않습니다. 실제 권한·변경 조건·금액·환불 처리 결과는 아직 확인되지 않았습니다. 담당자에게 사용 가능한 경로를 확인하기 전에는 진행하지 말고, 다른 버튼이나 화면 밖의 방식으로 대신 처리하지 않습니다.

## 1. 구성품 하나와 취소 수량 확인하기 <a href="#step-1" id="step-1"></a>

| 확인 항목 | 주의할 점 |
| --- | --- |
| 구성품 식별 | 같은 상품·이름·유형이라도 다른 구매 구성품을 섞지 않음 |
| 구매/신청 수량 | 원 구매 수량과 이번 신청 수량 구분. 이미 처리된 수량과 남은 신청 가능 수량 확인 |
| 진행 중 신청 | 같은 구성품에 진행 중 신청이 있으면 기존 신청 조회. 새 수량으로 다시 접수됐다고 판단하지 않음 |
| 묶음상품 | 강좌·교재·자료 각각 조건 확인. 한 신청에 여러 구성품을 넣거나 일반 혼합 주문 전체 취소로 처리하지 않음 |
| 구매 당시 금액 | 할인·쿠폰·세금이 반영된 원 구성품 결제 배분액 확인 |

수량별 원 단위 배분과 이미 처리한 금액 때문에 단가에 수량을 곱한 값과 취소액이 다를 수 있습니다. 남은 상품 가격을 다시 정하거나 원 주문 할인·쿠폰·세금 정보를 수정하지 않습니다.

> **화면 예시 준비 중** · 원 주문의 구성품 하나와 신청할 수량을 확인합니다.

## 2. 예상 취소액과 처리 경로 확인하기 <a href="#step-2" id="step-2"></a>

**현재 신청 화면의 제공 여부와 처리 결과는 아직 확인되지 않았습니다.** 담당자가 해당 신청 경로를 확인한 경우에만 아래 항목을 참고합니다. 화면이 없거나 안내가 다르면 진행하지 말고 담당자에게 확인하세요.

1. **구매자**는 본인 주문의 구성품 하나·수량·신청 유형·사유를 선택합니다.
2. 서버가 계산한 가능 여부·제한 사유·예상 취소액·처리 경로를 확인합니다.
3. 신청 가능한 결과라면 상세 사유·연락처와 확인한 금액으로 신청합니다. 미확정 금액의 심사 접수와 금액 확정 신청을 구분합니다.
4. 조건·금액 변경 안내가 나오면 최신 결과를 다시 확인합니다. 이전 금액으로 자동 제출하지 않습니다.
5. 접수 후 같은 신청의 최신 상태와 해당 권리의 적용 결과를 확인합니다. 이미 진행 중인 신청이 다시 확인되면 새 신청이 접수된 것으로 안내하지 않습니다.

**예상액 조회만으로 신청·이용 제한·환불이 실행되지는 않습니다.** 접수 시 이용 기록·URL 발급·발송·잔액을 다시 확인하므로 조회 때 가능했어도 접수 결과가 달라질 수 있습니다.

| 예상 결과 | 해석·후속 업무 |
| --- | --- |
| 자동 취소 경로·금액 확정 | 접수 후 처리 결과 확인. 자동 경로 표시 자체가 환불 완료는 아님 |
| 관리자 심사·예상액 있음 | 이용 근거·최신 금액을 확인한 뒤 별도 승인 |
| 관리자 심사·예상액 미확정 | 사유·근거 확인이 필요. 0원으로 바꾸거나 임의 금액 입력하지 않음 |
| 신청 제한 | 서버 제한 사유와 실제 조건 확인. 근거 부족·기간·이용·발송·잔액·에스크로를 구분 |
| 실제 0원 | 미확정과 다름. 취소 조건 충족 여부와 후속 처리 결과 확인. 결제대행사(PG)를 통한 환불 입금이 발생한다고 안내하지 않음 |

신청 가능 표시는 심사 접수 가능을 뜻할 수도 있습니다. 이를 자동 승인이나 환불액 확정으로 설명하지 않습니다. 운영자도 구매자가 처음 확인한 예상액을 승인 시 그대로 사용하지 않습니다.

> **화면 예시 준비 중** · 서버의 최신 예상액과 처리 경로를 확인합니다. 조회만으로 접수·환불되지는 않습니다.

## 3. 강좌는 구매 수강권의 실제 이용 근거 확인하기 <a href="#step-3" id="step-3"></a>

일반 취소는 유효한 구매 수강권과 검증된 이용 근거를 기준으로 판단합니다. 화면의 학습 진도율이나 다른 주문에서 시청한 누적 기록을 이번 구매의 이용률로 대신 사용하지 않습니다.

| 현재 근거 | 일반 취소 판단 |
| --- | --- |
| 유효한 권리·검증된 실제 이용률 0% | 해당 구성품·수량의 원 결제 배분액 전액, 자동 취소 경로 |
| 검증된 일부 이용 | 미이용분 비례 금액을 서버 계산하고 관리자 승인 |
| 전체 이용 | 일반 취소 제한. 귀책·이용 기록 이의는 해당 심사 사유로 별도 확인 |
| 수강 기간 만료 또는 비활성 권리 | 일반 취소 제한. 만료를 이유로 귀책 심사까지 일괄 거절하지 않음 |
| 구매 당시 총 재생시간·권리 귀속·시청 근거 부족 | 관리자 심사·예상액 미확정. 시청 기록 없음과 조회 불가를 구분 |
| 강의 첨부 자료 URL 발급 근거 있음 | 자료 이용 환산 근거가 없으면 심사·예상액 미확정. 임의 0%/100%로 환산하지 않음 |

미이용분은 **신청 수량의 원 결제 배분액 × 미이용 비율을 원 단위로 내림**한 서버 금액입니다. 고유 시청 구간과 구매 당시 총 재생시간으로 계산하며, 같은 구간을 반복 재생한 시간을 단순 누적하지 않습니다. 소수 초 이용을 버려 0%로 만들지도 않습니다.

현재 강좌의 영상 추가·삭제·교체로 과거 구매의 총 재생시간을 다시 계산하지 않습니다. 외부 영상·미확정 길이·과거 주문의 스냅샷(구매 당시 보관한 구성·영상 길이 기록) 부족도 무조건 미이용으로 판단하지 않습니다.

**학습 진도율만으로 이번 구매의 취소 가능 여부나 환불액을 판단하지 않습니다.** 화면의 기간·이용 기준이 이 안내와 다르거나 예상 환불액을 확인할 수 없다면, 처리를 진행하지 말고 환불 담당자에게 확인하세요. 실제 화면과 환불 조건이 일치하는지는 아직 확인되지 않았습니다.

> **화면 예시 준비 중** · 이번 구매의 실제 이용 근거를 확인합니다. 학습 진도율과는 다릅니다.

## 4. 디지털 자료는 기간과 URL 발급 이력 확인하기 <a href="#step-4" id="step-4"></a>

일반 취소는 **결제 시각부터 정확히 7×24시간 이내이며, 해당 구매 자료의 다운로드 URL 발급 이력이 없고 이용 권한이 유효한 경우**가 대상입니다. 기간 끝 시각은 포함하지만 그 이후는 제한됩니다.

예를 들어 10월 1일 오후 2시에 결제했다면 일반 기간 경계는 10월 8일 오후 2시입니다. 날짜만 보고 10월 8일 자정까지 가능하다고 안내하지 않습니다.

| 확인 항목 | 판단 기준 |
| --- | --- |
| 결제 시각·현재 시각 | 기간을 시각 단위로 대조. 신청·승인·실행의 최신 재판정 확인 |
| 권리·구매 파일 버전 | 이번 주문에 지급된 자료 권리·파일 버전인지 확인 |
| 최초 URL 발급 | 발급 이력이 있으면 일반 취소 제한. 실제 파일 수신 여부와 별개 |
| 이력 조회 불가 | 발급 없음으로 단정하지 않음. 심사·근거 확인 필요 |
| 파일 하자·제공 실패·이용 기록 이의 | 일반 취소와 다른 심사 경로. 사유 입력만으로 환불액 확정하지 않음 |

다운로드 버튼을 눌렀지만 파일 저장이 실패했어도 URL 발급 기록이 생길 수 있습니다. 파일을 삭제하거나 현재 자료 파일을 교체해도 과거 발급 사실을 없애는 것은 아닙니다.

신청 전 예상액을 확인한 뒤 URL이 발급되면 일반 취소 조건이 달라질 수 있습니다. 접수됐다는 이유만으로 승인 시점의 기간·발급·권리 확인을 생략하지 않습니다. 취소 가능 여부를 확인하려고 실제 자료를 시험 다운로드하지 않습니다.

> **화면 예시 준비 중** · 기간과 최초 URL 발급 이력을 확인합니다. 실제 파일 수신 여부와 구분합니다.

## 5. 교재는 실제 발송 여부와 배송비 확인하기 <a href="#step-5" id="step-5"></a>

| 배송 근거 | 이어서 할 업무 |
| --- | --- |
| 대기/준비·발송 이력 없음·유효 수량 확인 | 출고 전 구성품 취소 가능 여부와 서버 금액 확인 |
| 발송 사실 있음 | 일반 취소가 아닌 반품/동일 교재 교환 경로 확인 |
| 이미 배송 취소됨 | 일반 출고 전 취소 가능으로 판단하지 않음. 원 신청·처리 결과 확인 |
| 배송 없음·수량/상태 불일치·근거 불명확 | 출고 전으로 추정하지 않고 심사·배송 근거 확인 |

**송장만 저장된 것과 실제 발송 이력이 생긴 것은 다릅니다.** 송장 유무만으로 취소 가능 여부를 판단하지 않습니다. 발송 후 상태를 대기/준비로 되돌려도 원 발송 이력이 남아 있으면 출고 전 조건을 복원하는 것이 아닙니다.

출고 전 취소액은 원 구성품의 신청 수량 배분액을 사용합니다. 취소 후 주문에 유효한 교재가 남으면 최초 배송비를 함께 취소하지 않으며, 마지막 유효 교재 수량을 취소할 때는 서버가 남은 최초 배송비를 반영합니다.

일부 취소로 현재 무료배송 기준을 못 채워도 남은 상품을 새 가격으로 계산하거나 배송비를 임의 추가하지 않습니다. 최초 배송비·이전에 취소된 배송비·이번 배송비 취소액을 구분하며 과거 주문의 원 금액 근거가 부족하면 추정하지 않습니다.

발송 후 **단순 변심 반품·동일 교재 교환의 신청 기간은 한국 시간(KST) 기준 원 수령일 다음 날부터 7일째 끝까지**입니다. 원 신청일을 기준으로 판단하며, 나중에 회수·입고·검수한 날짜로 신청 기한을 다시 시작하지 않습니다. 수령 당일·8일째 신청과 미래 수령일은 구분해 확인합니다.

하자·오배송 등 판매자 귀책은 별도 근거와 처리 조건을 확인합니다. 단순 변심 기한만으로 일괄 거절하거나 사유 선택만으로 전액 환불·교환 완료를 확정하지 않습니다. 반품의 확인 수령일·검수 입력과 교환 단계 입력은 서로 다릅니다.

발송 후 회수·검수·반품비·재입고는 [교재 반품 처리하기](textbook-return.md), 동일 교재 교환의 수동 재배송·수령·동기화는 [교재 교환 처리하기](textbook-exchange.md)를 확인하세요. 반품을 출고 전 취소로 처리하거나 원 배송 상태를 되돌리지 않습니다.

> **화면 예시 준비 중** · 실제 발송 사실과 남은 교재를 확인하고 서버 배송비 취소액을 대조합니다.

## 6. 귀책 인정과 이용 기록 이의 심사하기 <a href="#step-6" id="step-6"></a>

아래는 강좌·디지털 자료의 접수된 신청을 심사하는 기준입니다. 교재의 귀책·하자는 별도 교재 검수에서 확인합니다. 실제 심사 화면의 필수 입력과 저장 결과는 아직 확인이 필요합니다. 담당자와 사용 가능한 화면·처리 방법을 확인한 뒤 진행하세요.

| 심사 | 확인·저장할 것 | 다음 단계 |
| --- | --- | --- |
| 판매자 귀책 | 해당 사유로 접수된 하자·제공 실패 등의 근거와 구체적인 인정 사유 | 인정 내용을 저장한 뒤 최신 신청을 다시 조회하고, 승인 전에 조건·금액·처리 가능 여부 확인. 해당 구성품·수량의 원 결제 배분액 전액을 서버 계산하고 별도 승인 |
| 이용 기록 이의 | 해당 사유로 접수된 신청의 이번 구매 권리 원본 기록과 제외 인정 사유 | 이번 계산에서 제외할 기록을 저장하고 남은 정상 이용·기간·권리를 재판정. 별도 관리자 승인 유지 |

귀책 사유를 선택했다는 사실만으로 전액 환불을 확정하지 않습니다. 이용 기록 이의 인정도 판매자 귀책 전액 인정과 다르며, 정상 기록이나 일반 기간·권리 제한을 모두 없애는 처리가 아닙니다.

이용 기록 이의 심사는 아래 순서로 원본 기록과 심사 결과를 확인합니다.

1. 현재 신청·사유·상태·권한을 확인하고 이번 구매 권리에 속한 원본 목록을 조회합니다.
2. 시청 구간, 강의 자료 또는 디지털 URL 발급 기록의 시각·대상을 대조합니다. 목록이 비었다는 사실과 조회 불가를 구분합니다.
3. 오류로 확인된 원본 기록만 선택하고 구체적인 제외 인정 사유를 작성합니다. 다른 주문·사용자 기록을 선택하지 않습니다.
4. 심사 내용을 저장하고 같은 신청의 최신 이력·상태를 다시 확인합니다.
5. 승인 전에 최신 결과를 다시 조회해 남은 정상 근거·처리 가능 여부·서버 금액을 확인합니다.
6. 최신 조회 결과에서 처리가 가능한 것으로 확인되면 [신청 확인·승인·거절하기](request-review-approve-and-reject.md)의 별도 승인 절차로 진행합니다. 제한·미확정·충돌이면 현재 근거와 허용된 후속 업무부터 확인합니다.

원본 시청/발급 기록과 학습 진도는 보존합니다. 직접 시청시간·진도율·환불액을 입력하거나 로그를 삭제하는 심사는 아닙니다. 제외한 기록 외 정상 기록을 다시 확인하므로 인정 후에도 미확정 또는 제한 결과가 나올 수 있습니다.

심사 저장은 PG 취소·자동 승인·환불 완료가 아닙니다. 불인정·중복 심사·동시 처리도 최신 신청을 재조회하고 [신청 확인·승인·거절하기](request-review-approve-and-reject.md)의 허용된 거절/결과 확인 기준을 적용합니다. 첨부 업로드·열람 기능은 아직 확인되지 않았으므로 필요한 자료 전달 방법은 담당자에게 확인합니다.

> **화면 예시 준비 중** · 귀책 인정과 이용 기록 이의를 구분합니다. 심사 저장 후 금액을 다시 확인합니다.

> **동작 예시 준비 중** · 원본 기록은 보존하고 심사 이후 최신 조건·금액을 다시 확인합니다.

## 7. 실제 에스크로·금액 근거 부족 확인하기 <a href="#step-7" id="step-7"></a>

구매확정 전 **실제 에스크로 결제**의 구성품 취소·반품은 부분 금액 취소 제한을 확인해야 합니다. 취소하려는 구성품 하나의 금액이 주문 전액과 같더라도 이 제한을 우회하지 않습니다.

기존 전체 취소 예외도 별도 검증이 필요합니다. 모든 구성품이 자동 취소 조건을 충족하고, 기존 취소·진행 신청이 없으며, 원 결제 금액·면세액과 전체 취소 계산이 일치해야 합니다. 에스크로라는 이유만으로 무조건 전체 취소할 수 있다고 안내하지 않습니다. 실제 결제 화면과 결제사 처리·구매확정 결과는 아직 확인이 필요합니다. 처리 전에 담당자에게 확인하세요.

구매확정 후에는 일반 구성품 정책을 적용합니다. 금액 취소가 없는 교환은 별도 교환 조건으로 판단하며 부분 환불 제한과 혼동하지 않습니다.

원 결제 잔액·과거 취소 귀속·원 주문 금액 근거가 맞지 않으면 처리가 제한될 수 있습니다. 현재 상품가로 과거 금액을 채우거나 기존 취소 수량을 0으로 바꿔 우회하지 않습니다.

## 8. 최신 승인과 구성품별 결과 확인하기 <a href="#step-8" id="step-8"></a>

심사 이후 승인·거절·처리 중/완료 확인은 [신청 확인·승인·거절하기](request-review-approve-and-reject.md)를 따릅니다. 이미 자동 실행 중인 신청도 결과부터 확인하며 수동 승인·새 신청을 반복하지 않습니다.

| 대상 | 금융 확정 이후 대조할 결과 |
| --- | --- |
| 강좌 | 이번 구매 수강권의 회수·기간 결과. 다른 주문 권리·기존 학습/이용 기록까지 삭제하지 않음 |
| 디지털 자료 | 해당 구매 파일 버전의 권리·새 URL 발급 제한 결과. 이미 받은 파일이나 기존 기록을 원격 삭제한다고 안내하지 않음 |
| 출고 전 교재 | 취소 수량·남은 유효 배송 수량과 원 구매에서 소비한 재고의 복원 결과. 단순 예약 해제로 안내하거나 중복 재고 증가·남은 교재의 출고 중지로 대신 처리하지 않음 |
| 혼합 주문 | 취소하지 않은 구성품·권리·금액 보존. 결제 잔액 0원만으로 주문의 모든 권리를 회수하지 않음 |

출고 전 취소의 재고 복원은 원 구매의 소비 근거와 신청 수량을 대조합니다. 원 소비 수량이 0이면 재고를 늘리지 않으며, 근거가 없거나 수량이 맞지 않으면 임의 재고 증가로 보완하지 않습니다. 반품의 검수 재입고 수량과는 다른 기준입니다.

확정 취소액이 보여도 전체 완료·후속 적용은 따로 확인합니다. 결과가 불명확하면 같은 신청을 조회하고 담당자에게 전달하며, 중복 환불·권리 수동 삭제·재고 수동 증가로 해결하지 않습니다. 실제 카드/계좌 반영 시점도 별도입니다.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 원 주문의 구성품 하나·구매/신청/기취소 수량·진행 신청을 확인했습니다.
- [ ] 원 결제 배분액과 서버 예상액을 사용하고 현재 상품가·단가·총액으로 대체하지 않았습니다.
- [ ] 강좌의 구매 당시 총 재생시간·해당 수강권 이용 근거와 학습 진도율을 구분했습니다.
- [ ] 디지털의 시각 단위 기간·최초 URL 발급·구매 파일 버전·권리를 확인했습니다.
- [ ] 교재의 실제 발송 이력·유효 수량·최초 배송비와 반품/교환 신청 기간·경로를 구분했습니다.
- [ ] 귀책 인정·이용 기록 이의·일반 조건을 구분하고 원본 기록을 보존했습니다.
- [ ] 심사 후, 승인 전에 최신 조건·금액을 다시 확인했습니다.
- [ ] 에스크로·잔액·과거 근거 부족·동시 처리 상황에서 임의 변경이나 중복 처리를 하지 않았습니다.
- [ ] [신청 확인·승인·거절하기](request-review-approve-and-reject.md) 기준으로 상태·확정액·대상 권리/배송/재고와 남은 구성품을 확인했습니다.
