# 상품 판매·결제가 안 돼요

> **검토용 가이드** · 실제 서비스 화면·동작 확인과 이미지 보완이 남아 있습니다. 본문의 실행 보류·주의사항을 먼저 확인하세요.

<figure><img src="../.gitbook/assets/branding/troubleshooting-illustration-v1.png" alt="문제 해결 대표 이미지"><figcaption></figcaption></figure>

상품이 보이지 않거나 구매할 수 없을 때, 금액·쿠폰이 예상과 다를 때, 결제 결과가 불명확할 때 운영자가 확인할 순서입니다. **판매 전 설정 문제와 이미 생성된 주문의 결제 문제를 먼저 구분합니다.**

승인·출금 안내를 받았거나 기존 결제를 진행했다면 **같은 원 주문의 결과부터 확인하세요.** 상품 설정을 바꾸거나 새 주문·재결제·무료 재신청을 반복해 기존 결제 결과를 확인하지 않습니다.

> **문제 해결 시 주의**
> 관련 안내의 정상 절차를 오류 복구 방법으로 처음부터 반복하지 마세요. 먼저 같은 주문·파일·신청의 최신 결과를 확인하고 본문의 실행 보류 조건을 따르세요.

## 먼저 증상 고르기 <a href="#section-1" id="section-1"></a>

| 지금 상황 | 먼저 확인할 것 | 이어서 볼 안내 |
| --- | --- | --- |
| 관리자에는 있는데 학생에게 상품이 안 보여요 | 같은 사이트·상품, 판매 상태와 진열/연결 | 아래 1번 |
| 판매 중인데 구매할 수 없어요 | 판매 준비 안내·포함 콘텐츠·재고·판매자·플랜/권한 | 아래 2번 |
| 가격·쿠폰·배송비가 예상과 달라요 | 상품 구성과 할인, 주문에 저장된 금액 | 아래 3번 |
| 구매 조건이나 배송 정보가 변경됐다고 나와요 | 변경 안내와 기존 주문/결제 시도 유무 | 아래 3번 |
| 결제창을 닫았거나 실패/처리 중 화면이에요 | 원 주문·발생 시각·금액과 승인/출금 안내 | 아래 4번 |
| 결제 완료인데 강좌·자료가 없어요 | 구매 구성과 해당 계정의 실제 제공 결과 | 아래 5번 · [구매 후 지급 확인](../orders-and-shipping/content-fulfillment-check.md) |

사이트·계정이 다르거나 타인의 주문/개인정보가 보이면 열람·변경을 중단합니다. 강사·질답조교에게 조회 권한이 없다면 학생 비밀번호를 받거나 다른 계정으로 우회하지 말고 학원의 지정 운영자에게 전달합니다.

> **화면 예시 준비 중** · 같은 상품의 관리자 상태와 학생에게 보이는 위치를 구분합니다.

## 1. 상품이 보이지 않을 때 <a href="#step-1" id="step-1"></a>

1. 학생이 이용 중인 학원 사이트와 관리 중인 사이트가 같은지 확인합니다. 상품명과 실제 연결한 콘텐츠명도 대조합니다.
2. 관리자의 **상품 목록**에서 검색·종류·판매 상태 등 적용한 조건을 확인하고 대상 상품을 찾습니다. 조회 오류와 빈 검색 결과를 구분합니다.
3. 상품 상세에서 **상품 판매 상태**와 **판매 준비 안내**를 각각 확인합니다. 강좌·교재·자료를 만들거나 발행한 것만으로 상품 판매가 시작된 것은 아닙니다.
4. 학생에게 안내한 메뉴·상품 진열에 해당 상품이 연결돼 있는지 담당자가 확인합니다. 관리자 상세나 미리보기에서 보인다고 학생 화면에도 노출됐다고 판단하지 않습니다.
5. 상품이 있지만 연결 위치가 다르거나 조회가 계속 실패하면 사이트·상품명·안내받은 경로·오류 문구를 정리합니다.

| 확인 결과 | 다음에 확인할 것 | 바로 하지 않을 일 |
| --- | --- | --- |
| 콘텐츠만 있고 상품을 찾지 못함 | [상품 생성·콘텐츠 연결](../products-and-coupons/create-products-and-connect-content.md)에 따라 기존 상품 존재와 구성을 확인 | 같은 콘텐츠의 상품을 반복 생성하지 않음 |
| 상품이 판매 중지로 표시됨 | 중지 사유와 담당자의 판매 계획 확인 | 오류 확인을 위해 판매를 임의 재개하지 않음 |
| 상품은 있지만 안내한 메뉴에서 안 보임 | [페이지·메뉴 구성](../site-and-communication/pages-and-menus.md)의 연결·게시/공개 구분 확인 | 다른 페이지의 빌더를 저장/게시해 문제를 해결하려 하지 않음 |
| 조회 오류 또는 대상 상품을 확인할 수 없음 | 오류·현재 조건·계정 역할 확인 후 운영 담당자에게 전달 | 빈 목록을 상품 삭제·미등록으로 단정하지 않음 |

정상 설정 절차는 [상품 만들기](../products-and-coupons/create-products-and-connect-content.md)와 [재고·판매 상태](../products-and-coupons/stock-and-sales-status.md)를 참고합니다. 판매 중지·콘텐츠 비공개·상품 삭제·기존 주문 취소는 서로 다른 작업입니다.

## 2. 판매 중인데 구매할 수 없을 때 <a href="#step-2" id="step-2"></a>

**판매 중 표시는 판매 준비 조건을 모두 통과했다는 뜻이 아닙니다.** 상품 목록/상세의 판매 준비 안내에서 어떤 조건이 부족한지 먼저 확인합니다. 안내가 없거나 읽을 수 없으면 정상 판정으로 대신하지 않습니다.

| 표시되는 제한·증상 | 읽어서 확인할 것 | 정상 절차 연결 |
| --- | --- | --- |
| 구성품이 필요함 | 상품 유형과 연결된 강좌·교재·자료가 의도한 구성인지 | [상품 구성](../products-and-coupons/create-products-and-connect-content.md) |
| 포함 콘텐츠를 공개해야 함 | 각 콘텐츠의 저장·발행/활성 상태. 상품 상태와 별도로 확인 | [판매 준비 체크리스트](../getting-started/sales-readiness-checklist.md) |
| 판매 파일·대표 이미지가 준비되지 않음 | 연결된 자료의 파일·처리/저장 결과와 대표 이미지 | [디지털 자료·파일](../content-management/digital-resource-and-files.md) |
| 재고 부족·품절 | 포함 교재별 보유/예약·가용 수량과 상품에서 제공할 수량 | [공유 재고·판매 상태](../products-and-coupons/stock-and-sales-status.md) |
| 유료 강좌 기간이 필요함 | 강좌 포함 여부와 저장된 수강 일수. 달력 날짜와 실제 학생 종료일은 구분 | [가격·기간 설정](../products-and-coupons/price-discount-and-valid-days.md) |
| 판매자 자격·정산 정보 확인이 필요함 | 신청/심사 상태와 판매 가능 안내. 계좌 저장만으로 통과 판단하지 않음 | [판매자 등록·심사](../sellers-and-settlements/seller-registration-and-review.md) |
| 등록/판매 기능·플랜·사용량 제한 | 상품에 포함된 콘텐츠 종류, 현재 플랜/체험·한도와 작업 권한 | [플랜·체험](../subscription-and-usage/plan-trial-and-subscription-start.md) · [사용량·팩](../subscription-and-usage/usage-and-additional-packs.md) |
| 버튼이 없거나 변경이 거절됨 | 담당 역할·권한, 현재 조건과 오류 문구 | [판매 준비 체크리스트](../getting-started/sales-readiness-checklist.md) |

교재 재고는 연결 상품 사이에서 공유합니다. 화면의 보유 수량만 보고 구매 가능 수량을 확정하지 않으며, 부족한 수량을 통과시키려고 가상의 입고를 기록하거나 예약을 임의로 해제하지 않습니다. 묶음상품은 포함된 한 콘텐츠의 문제로 전체 구매가 제한될 수 있습니다.

플랜 제한을 해결하려고 무료/유료 구분·상품 유형을 바꾸거나 체험 신청·팩 구매·플랜 변경을 반복하지 않습니다. 필요한 설정 보완은 원인을 확인한 담당자가 정상 가이드에 따라 별도로 진행하고 결과를 확인합니다.

> **화면 예시 준비 중** · 판매 중 표시와 판매 준비 조건을 따로 확인합니다.

## 3. 금액·쿠폰·구매 조건이 다를 때 <a href="#step-3" id="step-3"></a>

먼저 **아직 구매를 시작하지 않은 상품 확인**인지, **이미 생성된 주문의 금액 확인**인지 나눕니다. 현재 상품 가격을 바꿔 과거 주문의 결제 금액을 맞추지 않습니다.

| 비교할 내용 | 확인 기준 |
| --- | --- |
| 상품 구성 | 단일/묶음·포함 콘텐츠·추가 옵션과 수량. 상품 수나 이름만으로 전체 구성을 확정하지 않음 |
| 상품 금액 | 구성 금액·상품 할인 전 합계·할인 후 가격을 구분 |
| 쿠폰 | 생성·대상 회원에게 발급·등록/수령·사용 조건·주문 적용 여부를 구분 |
| 배송비 | 교재 포함 여부와 해당 주문의 배송비. 상품 자체가 무료여도 최종 주문은 유료일 수 있음 |
| 원 주문의 금액 | 주문번호·생성/결제 시각과 저장된 상품/쿠폰 할인·배송비·최종액. 현재 설정으로 과거 금액을 재계산하지 않음 |

쿠폰이 만들어졌거나 회원에게 발급됐다는 안내만으로 이번 주문에 적용된 것은 아닙니다. 쿠폰의 유효기간·최소 금액·적용/예약·사용 상태를 확인하고, 일부 발급이나 적용 결과가 불명확하면 같은 쿠폰·대상 내역을 먼저 확인합니다. 반복 발급이나 다른 쿠폰 생성으로 기존 주문 문제를 해결하지 않습니다.

정상 조건은 [가격·할인·기간](../products-and-coupons/price-discount-and-valid-days.md), [과세·면세 설정](../products-and-coupons/tax-settings.md), [쿠폰 만들고 발급하기](../products-and-coupons/create-and-issue-coupons.md)를 기준으로 확인합니다. 학생의 쿠폰 확인은 수강생 가이드의 **장바구니와 쿠폰 이용**에 연결합니다.

> **화면 예시 준비 중** · 현재 상품 가격과 원 주문에 기록된 금액을 구분합니다.

### 조건 변경 안내가 나오면 <a href="#section-5" id="section-5"></a>

| 안내·상황 | 확인 순서 |
| --- | --- |
| 상품·가격·구매 조건이 변경됨 | 결제를 멈추고 기존 주문/결제 시도 유무부터 확인합니다. 이후 최신 구성·금액과 변경 내용을 담당자가 대조합니다 |
| 쿠폰을 다시 선택하라는 안내 | 같은 주문의 생성/결제 상태와 쿠폰의 최신 조건을 확인합니다. 옛 할인액을 기대하며 반복 제출하지 않습니다 |
| 배송지 정보를 다시 확인하라는 안내 | 이미 생성된 주문과 주소 확인 단계를 구분합니다. 주소록 수정이 기존 주문·배송 주소를 자동으로 바꾼다고 보지 않습니다 |
| 화면 금액과 결제창 금액이 다름 | 승인 진행을 중단하고 원 주문·금액·발생 시각을 정리해 문의합니다 |
| 상품이 무료인데 결제 금액이 있음 | 배송비·유료 옵션·다른 상품과 최종 금액을 따로 확인합니다 |

**주문서는 단순 조회 화면이 아닙니다.** 조건이 맞으면 주문·쿠폰/재고 예약이 생성되고, 최종 0원 주문은 신청 처리가 이어질 수 있습니다. 현재 배송 상품에는 배송 정보를 확인한 뒤 주문 생성을 진행하는 연결이 있으므로, 문제 확인용으로 주문서에 다시 들어가거나 **이 배송지로 결제 계속하기**를 누르지 않습니다. 이미 결제를 시도한 학생에게 조건 확인을 이유로 재주문을 권하지 않습니다.

> **화면 예시 준비 중** · 조건이 변경되면 원 주문부터 확인하고 추가 결제를 멈춥니다.

## 4. 원 주문과 결제 결과 확인하기 <a href="#step-4" id="step-4"></a>

결제를 진행했다면 관리자 **결제/정산관리 → 결제 내역**에서 기존 주문을 찾습니다. 이름·주문명·기간·수단·상태 조건을 확인하고, **주문번호·구매자·금액·시점**으로 같은 주문인지 대조합니다. 자세한 검색/조회는 [주문·결제 상태 확인하기](../orders-and-shipping/order-and-payment-status.md)를 참고합니다.

학생에게는 본인 계정의 **마이페이지 → 구매 내역 → 결제**에서 이미 생성된 주문을 확인하도록 안내합니다. 학생의 화면과 운영자 화면은 같지 않으며, 아래 처리 안내가 모든 관리자 메뉴에 같은 배지로 표시된다고 가정하지 않습니다.

| 보이는 상태·안내 | 확인할 것 | 기다림·문의 기준 |
| --- | --- | --- |
| 결제 대기 | 원 주문의 최신 상태와 실제 승인/출금 안내 유무 | 대기 표시만으로 미승인·안전한 재결제를 확정하지 않음 |
| 결제 결과를 확인 중 | 원 주문 상태와 화면의 갱신 안내 | 안내된 상태 갱신을 확인하되 기한 내 자동 해결을 약속하지 않음. 계속 불명확하거나 승인/출금과 다르면 문의 |
| 구매한 콘텐츠를 준비 중 | 결제 결과와 구성품별 제공 결과 | 결제 실패로 해석하지 않음. 일부 누락/변화 없음이면 아래 5번과 문의로 연결 |
| 입금 대기 | 해당 주문의 실제 제공 계좌·기한과 확인된 입금 반영 | 결제 완료와 구분. 계좌가 확인되지 않거나 알림과 다르면 문의하고 임의 송금하지 않음 |
| 결제 결과 확인 필요·이전 주문 결과 확인 안내 | 원 주문의 결제/처리 기록과 현재 이용 가능한 대상 | 학생에게 자동 복구·즉시 지급을 보장하지 않고 담당자가 확인 |
| 실패·만료·취소·원결제 되돌림 관련 안내 | 같은 주문의 최종 결제/취소 결과와 외부 승인/출금 안내 | 오류 제목만으로 미결제·환불 완료를 단정하지 않음. 불일치하면 문의 |
| 결제/주문 완료 | 승인 금액과 구매 구성·실제 제공 결과 | 아래 5번에서 권리·배송과 별도로 확인 |
| 목록/상세 조회 오류·주문을 찾을 수 없음 | 사이트·구매 계정·조회 조건·알고 있는 원 주문번호 | 빈 목록과 조회 실패를 구분. 찾지 못했다는 이유로 재결제하지 않음 |

> **화면 예시 준비 중** · 원 주문의 상태와 승인/출금 안내를 대조합니다.

> **동작 예시 준비 중** · 기존 주문을 찾아 상태와 금액을 확인하는 예시입니다.

### 언제 기다리고 언제 멈추나요 <a href="#section-7" id="section-7"></a>

원 주문이 처리 중이고 같은 주문의 상태 갱신이 안내될 때만 해당 결과를 기다립니다. 처리 중·조회 오류·추가 확인 필요는 서로 다릅니다. 고정 대기 시간을 안내하거나, 기다린 뒤 같은 결제를 다시 누르면 해결된다고 설명하지 않습니다.

**승인·출금 안내와 사이트 상태가 다르거나 원 결과를 확인할 수 없다면 추가 결제를 중단하고 문의합니다.** 실패 화면의 **다시 결제하기**도 새 결제가 안전하다는 증거가 아닙니다. 원 주문의 실패/미승인 결과와 해당 주문의 재시도 허용 여부가 확인된 경우에만 담당자의 안내에 따라 진행합니다. 다른 수단·다른 계정으로 우회하지 않습니다.

결제 결과/복귀 주소는 확인을 위한 공유 링크가 아닙니다. 다시 열면 상태 조회뿐 아니라 승인 요청이 이어질 수 있습니다. 주소창 수정·브라우저 저장정보 삭제·새 탭/새로고침으로 결제를 복구하도록 안내하지 않습니다.

## 5. 0원 완료와 구매 후 제공을 따로 확인하기 <a href="#step-5" id="step-5"></a>

0원 주문은 결제수단 선택이나 외부 승인 알림이 없을 수 있습니다. 완료 제목·주소에 0원이라는 표시가 있다는 이유만으로 신청/지급을 확정하지 않고, **같은 계정의 원 주문과 현재 처리 상태**를 확인합니다. 결과가 없거나 불명확하면 무료 신청도 반복하지 않습니다.

| 결제 후 확인할 대상 | 구분할 결과 | 연결 안내 |
| --- | --- | --- |
| 강좌 | 주문 완료·수강권 지급·이용 기간·실제 재생은 별도 | [구매 후 지급 확인](../orders-and-shipping/content-fulfillment-check.md) |
| 별도 디지털 자료 | 자료 권리/목록·다운로드 주소 발급·실제 저장/열기는 별도 | 수강생 가이드의 **강의나 자료가 보이지 않을 때** |
| 교재 | 배송 대상 생성·송장·실제 인계/발송·수령은 별도 | 수강생 가이드의 **교재 배송과 배송지** |
| 묶음상품 | 포함된 각 구성품의 결과를 확인. 한 항목만으로 전체 성공을 확정하지 않음 | [구매 후 지급 확인](../orders-and-shipping/content-fulfillment-check.md) |
| 학원 직접 지급 | 유료/0원 주문과 별개로 지급 안내·대상 계정·권리를 확인 | [수강권·기간 관리](../members-and-operations/enrollment-and-access-period.md) |

결제 상태를 확인하려고 영상을 재생하거나 자료 다운로드를 누르지 않습니다. 학습 기록·자료 발급 이력이 생길 수 있습니다. 지급이 보이지 않는 문제를 재결제·중복 수강권 지급·임의 기간 연장·취소 후 재구매로 맞추지 않습니다. 구성품 누락·재생/자료 이용은 [영상·자료·수강권 점검](video-resource-and-access.md), 사이트/플랜·사용량 제한은 [사이트·구독·사용량 점검](site-subscription-and-usage.md)으로 구분해 넘깁니다.

> **화면 예시 준비 중** · 주문 완료와 구성품별 제공·실제 이용은 별도입니다.

## 6. 해결되지 않으면 운영 담당자에게 전달하기 <a href="#step-6" id="step-6"></a>

강사·질답조교는 학원의 지정 운영자에게 전달합니다. 운영자는 권한 내에서 원 상품/주문을 대조하고 해결되지 않으면 확인된 클킷 지원 경로로 문의합니다. 학생에게 내부 처리·다른 학생의 정보를 노출하거나 연락처·처리 기한을 임의로 약속하지 않습니다.

| 전달할 정보 | 필요한 범위 |
| --- | --- |
| 사이트·역할 | 학원 사이트 식별 정보·담당 역할. 인증/민감 쿼리를 뺀 주소 |
| 판매 전 문제 | 상품명·종류·포함 콘텐츠, 판매 상태·판매 준비 안내, 학생이 찾던 메뉴 |
| 기존 주문 문제 | 원 주문번호·발생 시각/시간대·금액·수단 종류와 보이는 결제/처리 상태 |
| 결과 차이 | 승인/출금 안내 유무, 원 주문과 학생 표시의 차이, 일부 누락된 구성 |
| 이미 한 일 | 조회한 메뉴·조건·오류 문구, 결제/재시도를 이미 했다면 시각과 마지막 결과 |
| 참고 화면 | 필요한 상태/오류 영역만 남긴 마스킹 화면·기기/브라우저 종류 |

가상 문의 예시:

> 같은 학원 사이트의 상품 A가 판매 중으로 보이지만 학생에게 재고 부족 안내가 나옵니다. 연결 교재와 상품 구성은 확인했고 재고 조정·주문 생성은 하지 않았습니다. 공유 재고와 예약 수량을 포함해 판매 제한 사유를 확인해 주세요.

> 기존 주문은 결제 결과 확인 중으로 보이고 학생은 같은 금액의 승인 안내를 받았습니다. 원 주문번호·시각·수단 종류를 정리했으며 재결제·무료 재신청·수동 지급은 하지 않았습니다. 해당 주문의 승인 결과와 후속 제공 상태를 확인해 주세요.

> **화면 예시 준비 중** · 확인한 상태와 이미 한 일을 정리해 담당자에게 전달합니다.

문의 식별자는 확인된 비공개 지원 경로에 필요한 최소한으로 제공합니다. **비밀번호·인증번호·토큰·결제키·전체 카드/계좌번호·전체 주소·학생 명단·인증/결제 결과/다운로드 URL·개발자 도구·네트워크 요청 기록 원문은 보내지 않습니다.** 직접 DB 수정·내부 복구 CLI·worker 재실행은 강사/학생의 해결 절차가 아닙니다.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 판매 전 설정 문제와 기존 주문의 결제 문제를 구분했습니다.
- [ ] 같은 사이트·상품·구매 계정이며 담당 조회 권한 안에서 확인했습니다.
- [ ] 콘텐츠 상태·상품 판매 상태·판매 준비 안내·학생 노출을 구분했습니다.
- [ ] 제한 사유에 따라 구성·파일/이미지·재고·기간·판매자·플랜/권한을 확인했습니다.
- [ ] 상품 할인·쿠폰·배송비와 원 주문에 저장된 금액을 나눴습니다.
- [ ] 조건 변경이 있으면 기존 주문/결제 시도부터 확인하고 반복 제출하지 않았습니다.
- [ ] 원 주문번호·구매자·금액·시점과 처리/승인 안내를 대조했습니다.
- [ ] 대기·입금 대기·추가 확인 필요·조회 오류·완료를 구분했습니다.
- [ ] 0원 신청·직접 지급·구성품별 제공과 실제 이용/배송을 구분했습니다.
- [ ] 불명확한 결과는 재결제·권리/재고 변경 없이 최소 정보로 문의할 준비를 했습니다.

위 체크는 문의/점검 정리 기준이며 실제 결제 성공·복구 완료·판매 준비 승인 기록이 아닙니다.
