# 영상·자료·수강권 이용에 문제가 있어요

> **검토용 가이드** · 실제 서비스 화면·동작 확인과 이미지 보완이 남아 있습니다. 본문의 실행 보류·주의사항을 먼저 확인하세요.

<figure><img src="../.gitbook/assets/branding/page-headers/troubleshooting/video-resource-and-access-v1.png" alt="영상·자료·수강권 이용에 문제가 있어요 대표 이미지"><figcaption></figcaption></figure>

영상이 올라가지 않거나 연결 후 재생되지 않을 때, 구매한 강좌·자료가 보이지 않거나 자료를 받을 수 없을 때 운영자가 확인할 순서입니다. **파일 전송·수업 연결·발행/공개·이용 권리·실제 재생/저장은 서로 다른 단계**입니다.

먼저 문제가 발생한 단계와 대상을 구분하세요. 업로드·결제·다운로드 결과가 불명확하다는 이유로 같은 파일을 반복 업로드하거나 재결제·수강권 재지급·자료 발급을 반복하지 않습니다.

> **문제 해결 시 주의**
> 관련 안내의 정상 절차를 오류 복구 방법으로 처음부터 반복하지 마세요. 먼저 같은 주문·파일·신청의 최신 결과를 확인하고 본문의 실행 보류 조건을 따르세요.

## 먼저 증상 고르기 <a href="#section-1" id="section-1"></a>

| 지금 상황 | 먼저 확인할 것 | 이어서 볼 안내 |
| --- | --- | --- |
| 영상 파일 선택·업로드가 막혀요 | 파일 종류·용량 안내·권한/사용량과 오류가 난 단계 | 아래 1번 |
| 전송은 끝난 것 같은데 수업에 영상이 없어요 | 업로드 목록·미연결/연결됨·해당 수업의 연결 파일 | 아래 2번 |
| 관리자에서는 보이는데 학생에게는 안 보여요 | 작업본/발행 결과·공개/미리보기와 학생의 실제 권리 | 아래 3번·4번 |
| 결제했거나 지급받았는데 강좌·자료가 없어요 | 같은 계정·원 주문 또는 직접 지급 안내·구매 구성 | 아래 4번 |
| 영상 준비 중·재생 오류·소리/끊김이 있어요 | 수업/영상 종류·현재 오류·기기/브라우저 | 아래 5번 |
| 자료가 없거나 다운로드 오류가 나요 | 강의 첨부/별도 자료 구분·권리/파일·발급/저장 단계 | 아래 6번 |
| 파일을 바꿨는데 학생은 예전 자료를 받아요 | 현재 파일과 해당 주문/권리에 연결된 파일 구분 | 아래 6번 |

강사·질답조교는 담당 강좌와 부여된 조회 권한 안에서 확인합니다. 학생 비밀번호를 받거나 다른 사람의 계정으로 재현하지 않습니다. 사이트가 다르거나 타인의 주문·자료·개인정보가 보이면 열람/변경을 중단하고 지정 운영자에게 전달합니다.

## 1. 업로드 전에 막히는지 확인하기 <a href="#step-1" id="step-1"></a>

강좌 생성·수정 화면의 **영상 업로드 및 섹션 구성**, 수업의 **영상 관리** 또는 **강의 영상 일괄 업로드** 중 어디에서 막혔는지 확인합니다. 파일 선택 전, 전송 중, 완료 안내 뒤의 오류를 구분합니다.

| 확인할 것 | 점검 기준 |
| --- | --- |
| 업로드 대상 | 강의 영상인지, 강의 첨부자료인지, 별도 판매하는 디지털 자료인지 구분 |
| 영상 형식·크기 | [강의 영상 업로드 파일 기준](../content-management/video-upload.md)과 실제 오류 안내 확인. 선택창에 보인다고 허용 파일로 확정하지 않음 |
| 원본과 변환본 | 원본을 따로 보관. 확장자 이름만 바꾸지 않으며 지원 확장자와 내부 코덱/실제 처리 결과를 구분 |
| 계정·강좌 | 같은 사이트·담당 강좌/수업과 업로드 권한인지 확인 |
| 사용량 제한 | 저장 공간·구독/기능 제한 안내가 있다면 학원 운영자가 [사용량·팩](../subscription-and-usage/usage-and-additional-packs.md)에서 조건 확인 |
| 전송 환경 | 실패 시각·기기/브라우저·이미 발생한 절전/연결 변경 등 확인 가능한 상황 기록. 모든 오류를 네트워크 문제로 단정하지 않음 |

영상의 실제 허용 목록과 파일 선택창·설명 문구가 다를 수 있습니다. 지원 여부는 파일 기준 가이드와 실제 오류를 함께 확인합니다. 안내에 형식이 빠져 있더라도 확장자 이름만 바꿔 허용된 파일처럼 업로드하지 않습니다. 별도 자료에는 [디지털 자료·파일 기준](../content-management/digital-resource-and-files.md)을 적용하고 영상의 용량 한도를 그대로 사용하지 않습니다.

용량을 줄일 필요가 있으면 [영상 용량 줄이기](../content-management/video-optimization.md)를 참고해 원본과 별도의 변환본을 준비합니다. 권장 설정이 서비스의 필수 규격이나 모든 영상의 처리 성공을 보장하는 것은 아닙니다. 실제 재업로드·교체는 기존 파일/연결 결과를 확인한 뒤 담당자가 필요한 범위에서 진행합니다.

> **화면 예시 준비 중** · 업로드 대상과 파일 기준·권한 안내를 먼저 확인합니다.

## 2. 업로드 완료와 수업 연결을 나누기 <a href="#step-2" id="step-2"></a>

같은 강좌의 업로드 목록과 대상 수업의 연결 파일을 먼저 대조합니다. 파일명만 같아도 다른 파일일 수 있으므로 보이는 크기·날짜·길이와 업로드 시점을 함께 확인합니다.

| 보이는 결과 | 확인할 것 | 바로 하지 않을 일 |
| --- | --- | --- |
| 진행률이 끝까지 갔지만 완료 안내가 없음 | 전송 뒤 완료 통지/연결 단계인지, 목록에 실제 파일이 남았는지 | 진행률만으로 전체 성공·실패를 단정하고 다시 올리지 않음 |
| 일괄 업로드의 일부만 실패 | 성공·대기·실패 파일을 구분하고 저장된 파일부터 확인 | 성공한 파일까지 전체 재업로드하지 않음 |
| 미연결 목록에 영상이 있음 | 아직 수업에 연결하거나 수업을 생성하지 않은 상태인지 | 수업이 없다는 이유로 같은 영상을 다시 올리지 않음 |
| 수업은 있는데 연결 영상이 없음/다름 | 대상 강좌·섹션·수업과 저장된 연결 파일 확인 | 확인용으로 연결 해제·파일 삭제·동일 연결 저장을 반복하지 않음 |
| 업로드 오류인데 파일이 목록에 있음 | 파일 저장과 연결 요청 중 어느 결과가 남았는지 | 파일 저장까지 취소됐다고 가정하지 않음 |
| 영상 길이를 읽지 못했다는 안내 | 파일 전송/연결 결과와 길이 누락을 따로 확인 | 길이 없음만으로 파일 전송 실패나 정상 재생을 확정하지 않음 |
| 세션·주소 만료 또는 응답 없음 | 기존 파일·현재 연결과 마지막 오류 확인 후 담당자에게 전달 | 서명 주소를 수정/공유하거나 같은 전송을 연속 요청하지 않음 |

개별 업로드는 파일 저장 후 수업 연결까지 이어질 수 있고, 일괄 업로드는 파일을 올린 뒤 **미연결/연결됨**을 따로 확인합니다. 창을 닫거나 취소했다고 이미 저장된 파일·연결이 모두 되돌아간 것은 아닙니다.

확인 후 필요한 연결·수업 생성·교체는 [강의 영상 업로드](../content-management/video-upload.md)의 정상 절차로 진행합니다. **연결 변경·연결 해제·파일 삭제는 서로 다르며**, 파일을 지웠다가 다시 올리는 방식을 기본 복구로 사용하지 않습니다. 진행 중인 전송이 화면을 닫아도 계속되거나 안전하게 취소된다고 보장하지 않습니다.

> **화면 예시 준비 중** · 파일 업로드와 수업 연결은 서로 다른 결과입니다.

## 3. 저장·발행·공개 범위 확인하기 <a href="#step-3" id="step-3"></a>

작업본에 있는 영상과 학생에게 발행된 영상은 다를 수 있습니다. 같은 수업명인지, 마지막 저장/발행 후 어떤 파일·영상 종류가 연결됐는지 확인합니다.

| 확인 항목 | 구분할 것 | 정상 절차 연결 |
| --- | --- | --- |
| 강좌 저장·발행 | 작업본 저장과 학생에게 반영된 발행 결과 | [강좌 등록·수정](../content-management/course-create-and-edit.md) |
| 수업 구성 | 섹션/수업·순서·공개·미리보기와 영상 연결 | [커리큘럼 구성](../content-management/curriculum.md) |
| 직접 업로드 영상 | 파일 업로드·수업 연결·학생 재생 가능 | [영상 업로드](../content-management/video-upload.md) |
| 외부 영상 | YouTube/Vimeo 종류·저장된 링크/길이와 외부 재생 제한 | [외부 영상 연결](../content-management/external-video.md) |
| 계정별 결과 | 관리자/강사 미리보기와 구매/지급받은 학생의 실제 이용 권리 | 아래 4번 |

관리자 미리보기 성공은 학생 수강권·기간·취소 보류·시청 제한 통과의 증거가 아닙니다. 학생 문제를 재현하려고 강의실에 들어가거나 재생을 시작하면 진도·재생 세션/이용 근거가 생길 수 있습니다. 우선 기존 오류/안내와 저장·권리 상태를 대조합니다. 추가 재생 확인은 사전에 허용된 테스트 범위에서만 진행합니다.

> **화면 예시 준비 중** · 학생에게 발행된 수업과 실제 이용 권리를 따로 확인합니다.

## 4. 결제하거나 지급받았는데 강좌·자료가 없을 때 <a href="#step-4" id="step-4"></a>

먼저 같은 학원 사이트와 실제 구매/지급 대상 계정인지 확인합니다. 동명이인·보호자 계정·다른 소셜 계정의 구매가 자동으로 합쳐지거나 학생 계정으로 이전되는 것은 아닙니다.

1. 구매했다면 **원 주문번호·시각·금액·구매 구성**과 현재 처리 상태를 대조합니다. 결제 결과가 불명확하면 [상품 판매·결제 문제 점검](product-sales-and-payment.md)을 먼저 따릅니다.
2. 직접 지급이라면 학원의 지급 안내·대상 계정·강좌/자료명·기간을 확인합니다. 구매 내역이 없다는 이유로 다시 결제하지 않습니다.
3. 강좌는 학생의 **마이페이지 → 내 학습 → 수강중 강좌**, 별도 자료는 **내 학습 → 내 자료**에서 확인할 대상입니다. 강의 첨부자료는 해당 수업의 자료와 구분합니다.
4. 강좌의 **전체/수강중/완료/만료**, 내 자료의 **전체/받음/미받음**과 다른 페이지를 구분합니다. 빈 목록과 조회 오류를 같은 결과로 보지 않습니다.
5. 운영자는 권한이 있으면 **회원 관리 → 회원 목록 → 회원 상세 → 수강 내역**에서 같은 회원/강좌의 상태·기간을 확인합니다. 이 화면을 별도 자료 권리나 모든 구성품 지급 결과 화면으로 사용하지 않습니다.

| 확인 결과 | 운영자가 정리할 것 |
| --- | --- |
| 일부 강좌·자료만 보임 | 구매 당시 포함 구성과 보이는/없는 대상을 각각 기록. 한 항목으로 전체 지급 완료를 확정하지 않음 |
| 강좌는 있으나 만료/이용 제한 | 원 권리·현재 기간·취소/환불 진행 여부를 구분. 화면 날짜만으로 정확한 만료 시각을 확정하지 않음 |
| 지급 성공 안내와 현재 목록이 다름 | 기존 권리·예약/복수 권리·건너뜀·처리 결과를 담당자가 확인. 무조건 재지급하지 않음 |
| 자료는 있으나 이용불가/발급 오류 | 아래 6번에서 권리·파일·발급 단계를 구분 |
| 주문이 콘텐츠 준비 중 또는 결과 확인 필요 | 같은 주문의 현재 처리 상태와 유효 구성 확인. 자동 복구 시간이나 즉시 지급을 약속하지 않음 |

수강권·자료 권리는 [구매 후 콘텐츠 지급](../orders-and-shipping/content-fulfillment-check.md)에서 확인하고, 수강권 변경 기준은 [수강권·기간 관리](../members-and-operations/enrollment-and-access-period.md)를 참고합니다. **문제 확인용 지급·기간 연장·회수·무료 재신청·재결제를 하지 않습니다.** 변경이 필요하다면 원인·기존 권리·영향 범위를 담당자가 먼저 확인합니다.

> **화면 예시 준비 중** · 같은 계정의 원 주문·지급 안내와 현재 권리를 대조합니다.

> **동작 예시 준비 중** · 기존 학습 목록에서 대상과 상태를 확인하는 예시입니다.

## 5. 영상 준비 중·재생 오류·끊김을 구분하기 <a href="#step-5" id="step-5"></a>

학생에게 이미 나타난 문구·강좌/수업·영상 종류와 기기/브라우저를 확인합니다. **영상 준비 중**이라는 표시만으로 변환이 진행 중이거나 정해진 시간 뒤 재생된다고 안내하지 않습니다.

| 표시·증상 | 먼저 확인할 것 | 하지 않을 추정·복구 |
| --- | --- | --- |
| 영상 준비 중 | 해당 수업의 영상 연결·발행과 계정/권리·조회 오류 여부 | 준비 중을 변환 진행의 증거로 삼거나 반복 업로드하지 않음 |
| 이 영상 파일을 재생할 수 없음 | 원 파일·연결 영상·발생 기기와 오류 문구 | 주소 재발급이나 확장자 이름 변경으로 모든 오류가 해결된다고 안내하지 않음 |
| 영상을 불러오지 못함/주소 갱신 오류 | 연결 결과·권리/기간·시청 제한과 이미 발생한 네트워크 상황 | 모든 오류를 인터넷 속도 또는 로그인 문제로 단정하지 않음 |
| 화면은 나오지만 소리가 없음/끊김 | 일반/외부 재생기, 학생의 기기/음량·이미 확인한 환경 차이 | 지원하지 않는 공통 화질·음량 메뉴나 최소 속도 수치를 만들지 않음 |
| 관리자만 재생 가능 | 관리자/학생의 대상 수업·발행·미리보기·실제 권리 차이 | 관리자 재생으로 학생 접근까지 정상 판정하지 않음 |
| YouTube/Vimeo 오류·외부 안내 | 저장된 영상 종류/링크와 외부 플레이어의 실제 안내 | 공유 키·학생 외부 계정·직접 URL을 받아 우회하거나 무조건 공개로 바꾸지 않음 |
| 진도·이어보기·외부 시청 상태가 다름 | 재생 위치·완료 수업/진도·외부 재생 상태를 구분 | 저장정보 삭제·반복 시청·강제 완료로 맞추지 않음 |

학생의 기기·소리·끊김 확인은 수강생 가이드의 **영상 재생 문제 점검**에 연결합니다. 일반 영상과 외부 재생기는 오류 표시·기록 방식이 다르며 **다시 시도** 버튼도 모든 원인의 해결을 보장하지 않습니다. 무한 새로고침·재시도·직접 영상 주소 공유·보안 설정 해제를 안내하지 않습니다.

시청 사용량이나 사이트 구독 관련 제한이 보이면 학원 운영자가 확인합니다. 학생에게 클킷 플랜/팩 구매를 요구하거나, 기존 권리를 바꿔 제한을 우회하지 않습니다. 사이트·구독/사용량 점검은 [사이트·구독·사용량 문제](site-subscription-and-usage.md)로 넘깁니다. 외부 영상은 일반 영상의 진도/이어보기와 같은 것으로 설명하지 않습니다.

> **화면 예시 준비 중** · 영상 준비 중 표시만으로 처리 원인을 단정하지 않습니다.

## 6. 자료가 없거나 다운로드가 안 될 때 <a href="#step-6" id="step-6"></a>

먼저 **강의 첨부자료**인지 **별도 디지털 자료**인지 구분합니다. 공지 첨부나 교재 배송도 다른 업무입니다. 자료 버튼이 없다고 파일이 삭제됐다고 판단하지 말고 담당자가 저장된 연결·공개/이용 상태와 조회 오류를 확인합니다.

| 확인 단계 | 확인할 것 | 주의할 점 |
| --- | --- | --- |
| 강의 첨부자료 | 해당 강좌·수업에 연결된 자료와 학생의 이용 기간/권한 | 자료 버튼은 파일 주소 발급·이용 기록을 만들 수 있음. 확인용으로 누르지 않음 |
| 내 자료 목록/상세 | 실제 대상 계정·자료명·파일명·지급일·이용 가능 상태와 필터/오류 | 이용 가능 표시는 현재 발급 조건 전체나 파일 검사 완료의 증거가 아님 |
| 다운로드 발급 실패 | 마지막 오류·시각과 원 권리/파일·취소/환불 등 보류 여부를 담당자가 확인 | 일반 오류만으로 보류·파일 검사·권한 중 하나를 원인으로 단정하지 않음 |
| 받음/미받음 | 자료 발급 이력과 기기 실제 저장 결과를 구분 | 받음은 실제 전송·저장·열기 성공을 보장하지 않음 |
| 창은 열렸지만 파일이 없음 | 이미 요청한 파일의 브라우저 다운로드 내역·저장 위치와 실제 오류 | 새 창이나 발급 성공 안내만으로 완료 판정하지 않고 반복 발급하지 않음 |
| 저장됐지만 열리지 않음 | 파일명·크기·확장자와 사용한 앱의 오류만 확인 | 차단/경고를 무시해 실행하거나 파일을 공개 문의에 첨부하지 않음 |
| 파일 교체 후 예전 자료가 나옴 | 관리자의 현재 파일과 주문 생성 시 기록된 버전·해당 권리의 실제 지급 파일을 구분 | 결제 승인 시 최신본이 다시 선택되거나 기존 구매자 파일이 자동 변경된다고 보지 않음. 임의 복원/재지급 금지 |

한 수업에 첨부된 여러 파일 중 일부만 받았다면 이미 받은 파일과 실패한 대상을 먼저 나눕니다. 자료 버튼을 다시 눌러 전체 파일을 반복 요청하도록 안내하지 않습니다.

이미 발급한 자료라면 기기에 남은 다운로드 내역부터 확인합니다. **발급 실패나 응답 유실은 이용 이력이 없다는 증거가 아니며**, 반복 발급은 추가 기록을 만들 수 있습니다. 자료를 다운로드했다는 사실과 취소/환불의 최종 판단도 같지 않습니다. 이 안내는 기존 취소·환불 기준을 바꾸지 않습니다.

파일 검사·차단·추가 확인 안내가 있다면 담당자가 파일/권리 상태를 확인합니다. 검사 중이라는 배지가 없는 일반 발급 오류를 검사 진행으로 대신 설명하거나, 일정 시간 뒤 자동 해제·모든 파일 안전을 보장하지 않습니다. 다운로드 주소·옛 파일 주소를 직접 입력해 접근 제한을 우회하지 않습니다.

학생에게는 수강생 가이드의 **강의 첨부자료**와 **내 디지털 자료**를 안내합니다. 실패한 단계는 수강생 가이드의 **자료 다운로드 문제 점검**과 함께 확인합니다. 관리자의 파일 등록/교체는 [디지털 자료·파일 관리](../content-management/digital-resource-and-files.md)에서 별도로 확인합니다.

> **화면 예시 준비 중** · 자료 발급 이력과 실제 기기 저장·열기는 다릅니다.

## 7. 기다릴 조건과 문의할 조건 정리하기 <a href="#step-7" id="step-7"></a>

같은 대상이 실제 처리 중이라고 확인되고 상태 갱신이 안내된 경우에만 그 결과를 기다립니다. 전송 대기·연결 누락·발행 미반영·이용 제한·조회 오류·확인 필요를 모두 기다리면 해결되는 상태로 묶지 않습니다. 고정 대기 시간·자동 복구를 약속하지 않습니다.

| 문의로 넘길 상황 | 전달할 내용 |
| --- | --- |
| 업로드/연결 결과가 서로 다르거나 일부 파일만 실패 | 강좌/수업·파일 확장자/크기·발생 단계/시각·목록과 연결 결과 |
| 관리자와 학생 결과가 다르거나 구성 일부가 없음 | 같은 사이트/대상 계정·원 주문 또는 지급 안내·보이는/없는 구성·발행/기간 |
| 재생·자료 발급 오류가 계속되거나 현재 결과를 확인할 수 없음 | 실제 오류 문구·기기/브라우저·일반/외부 영상 또는 자료 종류·이미 한 행동과 마지막 결과 |
| 취소/환불·권리 보류·파일 검사/버전이 관련된 것으로 보임 | 원 주문/권리와 현재 보이는 상태를 구분해 지정 운영자에게 전달. 원인을 단정하지 않음 |
| 타인 정보·예상 밖 권한 또는 의심 파일/경고 | 열람/변경·발급/실행을 중단하고 필요한 최소 정보만 비공개로 전달 |

강사·질답조교는 지정 운영자에게, 운영자는 해결되지 않으면 확인된 클킷 지원 경로로 문의합니다. 원 주문·권리·파일의 식별 정보는 확인된 비공개 경로에 필요한 최소한으로 제공합니다. 화면에서 제공되는지 확인되지 않은 복구 버튼이나 수동 재지급을 학생·강사에게 안내하지 않습니다.

가상 문의 예시:

> 강좌 A의 수업 B에서 파일 전송은 끝난 것으로 보이지만 연결 오류가 표시됐습니다. 같은 강좌 업로드 목록에는 파일이 있고 수업 연결은 확인되지 않습니다. 파일 확장자/크기·발생 시각·오류 문구를 정리했으며 재업로드·연결 해제·파일 삭제는 하지 않았습니다. 저장된 파일과 수업 연결 결과를 확인해 주세요.

> 학생의 원 주문은 완료로 보이고 강좌는 전체 목록에 있지만 별도 자료 C는 발급 오류가 납니다. 자료의 파일명·지급일과 기기/오류 시각을 정리했으며 반복 발급·재결제·권리 변경은 하지 않았습니다. 해당 권리와 제공 파일의 현재 이용 조건을 확인해 주세요.

> **화면 예시 준비 중** · 문제가 발생한 단계와 마지막 결과를 정리해 전달합니다.

**비밀번호·인증번호·토큰·원본 영상/유료 자료·학생 명단·전체 연락처/주소·결제키·영상/다운로드/인증 URL·외부 공유 키·개발자 도구·네트워크 요청 기록 원문은 보내지 않습니다.** 승인되지 않은 파일 전송·직접 DB/CLI·worker 재실행·보안 해제는 이 안내의 해결 절차가 아닙니다.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 영상·첨부자료·별도 자료와 문제가 발생한 단계를 구분했습니다.
- [ ] 같은 사이트·강좌/수업·대상 계정이며 담당 조회 권한 안에서 확인했습니다.
- [ ] 파일 기준·원본/변환본·권한/사용량 오류를 구분했습니다.
- [ ] 전송·완료 안내·업로드 목록·수업 연결과 부분 성공을 따로 확인했습니다.
- [ ] 작업본/발행·공개/미리보기와 학생 이용 권리를 구분했습니다.
- [ ] 구매자는 원 주문, 직접 지급은 지급 안내를 기준으로 구성·필터·기간을 확인했습니다.
- [ ] 준비 중·재생 오류·일반/외부 영상·진도/시청 상태를 구분했습니다.
- [ ] 자료의 권리/파일·발급·받음 표시와 실제 저장/열기를 구분했습니다.
- [ ] 확인용 재업로드·연결/삭제·재지급/연장·재결제·재생/발급을 반복하지 않았습니다.
- [ ] 처리 중과 확인 필요를 나누고 최소 정보로 담당자에게 문의할 준비를 했습니다.

이 체크리스트는 점검 내용과 문의 정보를 정리하기 위한 것입니다. 모두 확인했더라도 실제 오류 재현·재생/저장 성공·권리 복구나 서비스 화면·동작의 확인 완료를 뜻하지 않습니다.
