# 회원 정보·이용 내역 확인하기

> **검토용 가이드** · 실제 서비스 화면·동작 확인과 이미지 보완이 남아 있습니다. 본문의 실행 보류·주의사항을 먼저 확인하세요.

**회원 관리 → 회원 목록**에서 회원을 찾고 상세 화면의 **수강 내역 / 결제 내역 / 회원 메모**를 확인합니다. 회원 가입 여부·수강 상태·결제 결과는 서로 다른 정보입니다.

**완료 기준:** 찾으려는 회원이 맞는지 확인하고, 적용된 검색/필터와 해당 회원의 수강·결제·메모를 권한 범위 안에서 확인합니다. 메모를 수정했다면 저장 후 같은 회원을 다시 열어 대조합니다. 내역이 비어 있거나 일부 정보가 가려졌다면 실제 정보 없음과 권한 제한을 구분합니다.

이 페이지는 회원 조회와 메모 안내입니다. 결제·지급 결과는 [주문·결제 상태](../orders-and-shipping/order-and-payment-status.md)와 [구매 후 콘텐츠 지급](../orders-and-shipping/content-fulfillment-check.md), 취소·환불은 [신청 확인·승인·거절](../cancellations-and-returns/request-review-approve-and-reject.md)에서 확인합니다. 수강권 지급·연장·회수는 [수강권·이용 기간 관리하기](enrollment-and-access-period.md)에서 별도로 다룹니다.

## 시작 전 준비

| 준비할 것 | 확인 기준 |
| --- | --- |
| 사이트·계정 | 조회할 회원이 가입한 사이트의 관리자 화면인지 확인합니다. 다른 사이트의 같은 이름 회원과 혼동하지 않습니다 |
| 회원 식별 정보 | 이름·이메일·전화번호 중 확인 가능한 정보를 준비합니다. 동명이인은 확인 권한이 있는 다른 정보도 대조합니다 |
| 조회 권한 | 회원 목록 조회와 개인정보 원문·결제·메모 열람은 다를 수 있습니다. 조회된다고 내보내기나 수강권 변경까지 가능한 것은 아닙니다 |
| 회원 유형 | 학부모 가입 허용 여부를 확인합니다. 유형 탭·자녀 표시는 해당 설정이 켜진 화면에서 확인합니다 |
| 메모 작업 | 기존 메모를 읽고 수정할 권한과 변경 필요성을 확인합니다. 실제 회원 메모를 연습·촬영 목적으로 바꾸지 않습니다 |
| CSV 작업 | 필요할 때만 내보내기 권한·플랜·파일 대상과 공유 범위를 확인합니다. 유형 필터와 실제 파일 결과는 아래 확인 대기를 따릅니다 |

회원 목록은 학생·학부모 회원을 찾는 화면입니다. 아직 수강권이 없는 가입 회원도 포함될 수 있으며 운영자를 포함한 모든 계정 목록이나 현재 유효한 수강생만의 명단이 아닙니다. 운영자로 지정된 계정이 이 목록에서 빠져도 회원 탈퇴로 판단하지 말고 [운영자 목록](operator-assignment-and-roles.md)에서 확인합니다.

## 먼저 흐름 확인하기

**회원 목록 → 검색 실행 → 필터·정렬 적용 → 회원 식별 → 상세 탭 확인 → 필요 시 메모 저장·재조회** 순서입니다. 정보를 확인하려고 수강권 지급·연장·회수나 주문 취소를 실행하지 않습니다.

| 확인할 정보 | 위치 | 구분할 것 |
| --- | --- | --- |
| 이름·연락처·유형 | 회원 목록·상세의 회원 정보 | 원문/마스킹, 학생/학부모, 자녀 이름 표시 |
| 강좌·진도·상태·종료일 | 상세의 수강 내역 | 구매한 상품 수·수강권·학습 진도는 같은 정보가 아닙니다 |
| 주문명·번호·결제 정보 | 상세의 결제 내역 | 전체 주문 관리·환불 처리·정산 잔액과 다릅니다 |
| 담당자가 기록한 내용 | 상세의 회원 메모 | 자동저장·학생 질문 답변·전체 활동 로그가 아닙니다 |
| 회원 파일 | 목록의 CSV 다운로드 | 화면 조회와 파일 내보내기 권한·대상은 별도로 확인합니다 |

## 1. 회원 검색하기

1. **회원 관리 → 회원 목록**으로 이동합니다.
2. **이름, 이메일, 전화번호 검색** 입력란에 확인할 정보를 입력합니다.
3. **검색**을 누르거나 Enter로 검색을 실행합니다. 입력 중인 글자만 바뀐 상태와 검색이 적용된 상태를 구분합니다.
4. 적용된 검색어와 결과 목록을 확인합니다. 이름·이메일·전화번호 중 하나의 검색 범위를 고르는 별도 선택란이 있다고 가정하지 않습니다.
5. 원하는 회원이 없으면 남아 있는 강좌·수강 상태·유형 조건도 확인합니다. 동명이인은 이름만 보고 상세 업무를 진행하지 않습니다.

**회원 목록을 불러오지 못했습니다.**는 조회 오류입니다. 화면의 재시도로 다시 조회하고 회원이 없다고 판단하지 않습니다. **검색된 결과가 없습니다.**는 적용된 조건의 빈 결과, **등록된 회원이 없습니다.**는 조건 없는 목록의 빈 상태입니다. 다른 사이트의 가입 여부나 회원 계정 삭제까지 뜻하지 않습니다.

> **화면 예시 준비 중** · 검색을 실행하고 적용된 검색어와 회원 목록을 확인합니다. 조회 실패와 빈 결과는 다릅니다.

## 2. 필터·정렬 적용하고 결과 범위 확인하기

1. **필터**를 열어 **수강 상태**와 **강좌별** 조건을 고릅니다. 강좌는 필요한 항목을 선택합니다.
2. **적용하기**를 누릅니다. **취소**하거나 적용하지 않고 닫은 선택을 최종 조건으로 판단하지 않습니다.
3. 정렬을 바꾸려면 **정렬 → 정렬 순서**에서 기준을 고른 뒤 이 창의 **적용하기**도 누릅니다.
4. 적용 조건 표시와 목록을 확인합니다. 조건이 많으면 **+숫자**를 열어 나머지 적용 조건도 확인합니다.
5. 특정 조건만 지우려면 해당 조건의 해제를, 표시된 조건을 모두 초기화하려면 **전체 해제**를 사용합니다. 회원 유형 탭만 선택한 상태라 전체 해제가 보이지 않으면 유형을 **전체**로 직접 바꿉니다.
6. 필요한 경우 **10개씩 보기 / 20개씩 보기 / 50개씩 보기**와 아래 페이지 이동을 사용합니다.

| 조건 | 현재 선택지·의미 | 주의할 점 |
| --- | --- | --- |
| 수강 상태 | 전체·수강중·수강완료·기간만료·수강취소 | 상세의 회수됨은 이 필터에 별도 선택지로 없습니다 |
| 강좌별 | 선택한 강좌 조건으로 회원 찾기 | 조건이 남아 있으면 다른 강좌 회원이 검색에서 빠질 수 있습니다 |
| 정렬 순서 | 최신순·오래된순·이름순(가나다/역순)·수강수 많은순/적은순 | 정렬은 조회 순서이며 계정·수강권 정보를 바꾸는 작업이 아닙니다 |
| 결과 수·쪽당 개수 | 현재 검색/필터에 맞는 수와 한 페이지 표시 개수 | 현재 페이지 행 수·전체 계정 수·결제 회원 수와 다릅니다 |

목록의 **수강중 강좌** 숫자는 목록에 집계된 강좌 수입니다. 전체 수강 이력 수·구매 상품 수·결제 횟수나 학생의 실제 학습 완료 증거로 사용하지 않습니다.

> **화면 예시 준비 중** · 필터와 정렬은 각각 적용하기를 눌러 반영하고 현재 결과 범위를 확인합니다.

## 3. 회원 유형과 기본 정보 확인하기

1. 학부모 가입 허용 설정이 켜져 있으면 목록의 **전체 / 학생 / 학부모** 탭에서 필요한 유형을 선택합니다. 탭 선택은 바로 목록에 적용되며 별도 적용 버튼을 찾지 않습니다.
2. 선택한 유형과 검색/강좌 조건을 함께 확인합니다. 선택 탭의 숫자는 현재 조건에 맞는 결과 수이며 다른 탭 전체 인원까지 동시에 집계한 값이 아닙니다.
3. 대상 회원 행을 눌러 상세를 엽니다. 회원 이름·이메일/전화번호와 표시된 가입 유형·회원가입일을 대조합니다.
4. 학부모의 자녀 이름이 표시되면 회원 식별 참고 정보로 확인합니다. 목록의 자녀 이름을 누르면 해당 이름 검색으로 이어질 수 있으므로 바뀐 검색어도 확인합니다.
5. 다른 회원을 찾으려면 상세 상단의 **회원 목록**으로 돌아갑니다. 이전 검색/페이지 조건이 그대로 복원된다고 가정하지 말고 다시 확인합니다.

이메일·전화번호가 가려져 보이는 것은 개인정보 원문 조회 권한 또는 담당 강좌 범위의 제한일 수 있습니다. 가려진 값을 누락·잘못된 연락처로 단정하거나 원문을 보기 위해 다른 사람의 계정을 사용하지 않습니다. 필요한 경우 권한 담당자에게 확인합니다.

학부모의 자녀 이름 표시는 자녀 계정 연결·보호자 인증·수강권 공유 완료를 뜻하지 않습니다. 학부모 가입을 허용하지 않는 화면에는 같은 유형 탭·가입 유형 항목이 없을 수 있으며 이를 회원 정보 누락으로 보지 않습니다.

> **화면 예시 준비 중** · 회원 유형과 기본 정보를 대조합니다. 자녀 이름 표시와 계정 연결은 다릅니다.

## 4. 수강 내역 확인하기

상세의 **수강 내역** 탭에서 강좌명과 아래 정보를 함께 봅니다.

| 항목 | 확인할 내용 |
| --- | --- |
| 수강 내역 | 찾는 강좌가 맞는지 확인합니다. 구매 상품명과 강좌명이 항상 같다고 가정하지 않습니다 |
| 학습 진도 | 완료 수업 수/전체 수업 수와 진도율을 확인합니다. 실제 출석·질문 해결·결제 상태를 나타내는 값은 아닙니다 |
| 수강 상태 | 수강중·수강완료·기간만료·취소·회수됨 표시를 구분합니다 |
| 수강 종료일 | 표시된 종료일 또는 **기한 없음**을 확인합니다. 기한 없음은 모든 콘텐츠를 무료로 이용한다는 뜻이 아닙니다 |
| 관리 | 지급·연장·회수는 별도 권한과 조건이 필요한 변경 업무입니다. 조회 확인용으로 실행하지 않습니다 |

**수강완료**라는 학습 상태만으로 이용 권리도 종료됐다고 판단하지 않습니다. 기간만료·취소·회수됨은 서로 다른 표시이며 상세 상태와 종료일·남은 수강권을 함께 확인해야 합니다. 기간 연장과 회수의 절차·제한은 [수강권·이용 기간 관리하기](enrollment-and-access-period.md)에서 다룹니다. 종료일 직접 수정이나 기간 단축 기능으로 설명하지 않습니다.

사이트 삭제 조건은 별도 검사입니다. 이 표의 완료 배지·회원 수만으로 삭제 가능 여부를 판단하지 않으며 [사이트 삭제 전 확인 조건](site-stop-and-delete.md)을 따릅니다.

**수강 내역이 없습니다.**가 나오면 해당 회원·사이트가 맞는지 먼저 확인합니다. 결제한 주문과 콘텐츠 지급 결과는 별도 화면에서 대조하고, 내역을 보이게 하려고 같은 수강권을 중복 지급하지 않습니다. 이 화면은 회원의 모든 접속·학습 활동 로그가 아닙니다.

> **화면 예시 준비 중** · 강좌의 진도·수강 상태·종료일을 함께 확인합니다. 확인 목적으로 수강권을 바꾸지 않습니다.

## 5. 결제 내역 확인하기

1. 상세의 **결제 내역** 탭을 엽니다.
2. **주문명·주문번호**로 확인할 거래를 식별합니다. 같은 이름의 상품을 여러 번 구매한 경우 주문번호를 구분합니다.
3. **결제금액·결제일·결제수단·주문상태**를 함께 확인합니다. `-` 표시는 표시할 정보가 없는 항목이므로 임의 값을 보완하지 않습니다.
4. 주문의 상세 구성·결제/취소 결과가 필요하면 [주문·결제 상태](../orders-and-shipping/order-and-payment-status.md)에서 같은 주문번호로 확인합니다. 이 탭에 주문번호 상세 이동 링크가 있다고 가정하지 않습니다.

이 탭은 결제된 주문과 그 부분 취소·취소·환불 상태를 확인하는 범위입니다. 결제 대기·실패·만료를 포함한 전체 주문 목록이 아니며, 표시된 결제금액을 현재 환불액·정산 잔액으로 해석하지 않습니다.

> **결제 내역 없음과 권한 제한을 구분합니다.**
> 현재 조회 계약은 소유자·매니저와 강사·스태프의 결제 표시 범위가 다릅니다. 강사·스태프 계정에서는 실제 주문이 있어도 빈 내역이 표시될 수 있습니다. 탭이 보이거나 **결제 내역이 없습니다.**가 나온다는 이유만으로 미결제라고 안내하지 말고, 조회 권한이 있는 담당자가 해당 주문을 확인해야 합니다.

> **화면 예시 준비 중** · 주문번호와 상태를 확인합니다. 결제 내역 없음은 권한 제한 때문일 수도 있습니다.

## 6. 회원 메모 확인하고 저장하기

회원 메모는 담당자가 해당 회원에 관해 기록하는 내용입니다. 학생에게 보내는 답변이나 [Q&A](../site-and-communication/qna-answer.md) 등록, 여러 항목의 변경 이력 목록이 아닙니다.

1. **회원 메모** 탭을 열고 기존 내용을 읽을 수 있는지 확인합니다. 빈칸이어도 열람 권한이 없어 내용이 가려진 경우일 수 있습니다.
2. 읽기·수정 권한과 대상 회원을 확인한 뒤 필요한 내용을 **500자 이내**로 입력합니다. 비밀번호·인증정보나 불필요한 개인정보를 적지 않습니다.
3. **저장**을 누르고 **메모가 저장되었습니다.** 안내를 확인합니다. 입력란에 글이 보이는 것만으로 저장된 것은 아닙니다.
4. 저장 후 같은 회원 상세를 다시 열어 **회원 메모** 내용을 대조합니다. 조회 갱신이 끝나기 전 입력란에 남은 글자만으로 결과를 확인하지 않습니다.
5. 실패·결과 불명확이면 필요한 입력안을 안전하게 보존하고 최신 메모부터 확인합니다. 저장을 반복하거나 다른 운영자의 내용을 덮어쓰지 않습니다.

**기존 메모를 읽을 수 없다면 새 내용으로 덮어쓰지 않습니다.** 읽기와 수정 권한은 별개이고, 입력란에 입력할 수 있어도 저장이 허용된다는 뜻은 아닙니다. 현재 저장 계약에는 소유자/매니저 역할과 메모 변경 권한 제한이 있으므로 강사·스태프의 수정 가능 여부를 버튼만으로 판단하지 않습니다.

메모는 수동 저장입니다. 저장 전 다른 탭이나 페이지로 이동하면 입력 내용이 사라질 수 있으므로 먼저 저장 여부를 확인합니다. 현재 계약은 빈 메모 저장을 허용하지 않으므로 **전체를 비워 저장**하는 방식의 삭제를 안내하지 않습니다. 삭제가 필요하면 담당자에게 지원 절차를 확인합니다. 같은 메모를 여러 운영자가 수정할 때는 최신 내용을 확인하고 작업을 조율합니다.

> **화면 예시 준비 중** · 기존 메모를 읽고 저장한 뒤 다시 열어 확인합니다. 입력만 한 내용과 저장 결과를 구분합니다.

## 7. 회원 CSV가 필요한 경우

> **확인 대기:** 학생/학부모 유형 필터가 실제 CSV에도 그대로 적용되는지는 확인이 필요합니다. 유형별 명단이 필요하면 파일의 실제 대상을 확인하기 전 배포·발송용 명단으로 사용하지 않습니다.

1. 목록의 **CSV 다운로드**가 보이는지, 내보내기 권한·플랜과 업무상 필요가 있는지 확인합니다. 목록을 볼 수 있다고 다운로드도 허용되는 것은 아닙니다.
2. 검색을 실행하고 강좌·수강 상태·정렬·회원 유형 조건을 확인합니다. 다운로드 직전 입력만 바꾸고 검색/적용을 빼먹지 않습니다.
3. 승인된 범위에서 **CSV 다운로드**를 누르고 결과를 확인합니다. 다운로드 중 반복 클릭하지 않습니다.
4. 받은 파일의 열·회원·건수·개인정보 표시가 의도한 대상과 맞는지 대조합니다. 현재 보이는 한 페이지의 행만 내려받는다고 가정하지 않으며, 완료 알림이나 파일 생성만으로 대상이 맞다고 판단하지 않습니다.
5. 대상이 다르거나 실패하면 공유하지 말고 담당자에게 조건과 오류를 확인합니다. 파일은 승인된 보관/공유 범위에서만 사용합니다.

CSV는 회원 데이터 파일입니다. 수강권 지급·연장·회수용 일괄 가져오기, 결제·환불 처리나 모든 활동의 백업 파일로 설명하지 않습니다. 실제 파일 범위·개인정보 원문/마스킹·유형 필터 검수는 남아 있습니다.

> **화면 예시 준비 중** · 파일의 회원·건수·개인정보 범위를 대조합니다. 유형별 명단은 실제 대상 검수 전 공유하지 않습니다.

> **동작 예시 준비 중** · 적용 조건을 확인하고 해당 회원의 수강·결제·메모를 권한 범위 안에서 확인합니다.

## 완료 후 확인

- [ ] 조회할 사이트와 회원이 맞고 동명이인을 구분했습니다.
- [ ] 검색 실행과 필터/정렬의 적용하기를 구분하고 실제 적용 조건을 확인했습니다.
- [ ] 회원 유형·현재 결과 수·페이지 범위를 확인하고 자녀 표시를 계정 연결로 해석하지 않았습니다.
- [ ] 개인정보 마스킹·권한 제한과 실제 정보 누락을 구분했습니다.
- [ ] 강좌·진도·수강 상태·종료일을 함께 확인하고 확인 목적으로 수강권을 바꾸지 않았습니다.
- [ ] 결제 내역의 역할별 범위·주문번호/상태를 확인하고 빈 내역을 미결제로 단정하지 않았습니다.
- [ ] 메모를 변경했다면 읽기/수정 권한·500자 제한·저장·재진입 결과를 확인했습니다.
- [ ] CSV가 필요했다면 권한/플랜·유형 필터 확인 대기·실제 파일 대상을 확인하고 승인된 범위에서만 사용했습니다.

| 필터·정렬을 골라도 목록이 안 바뀌어요 | 각각의 창에서 적용하기를 눌렀는지 확인합니다. 취소/닫기를 적용 완료로 보지 않습니다 |
| 전체 해제가 안 보여요 | 검색/필터 칩이 있는지 확인합니다. 유형 탭만 선택했다면 전체 탭으로 직접 바꿉니다 |
| 회원이 있는데 검색 결과가 없어요 | 사이트·검색어·강좌/수강 상태·유형을 확인하고 조건을 해제합니다. 조회 실패와 빈 결과도 구분합니다 |
| 학부모·자녀 항목이 안 보여요 | 학부모 가입 허용 설정과 회원 유형을 확인합니다. 자녀 이름 표시는 계정 연결이나 권리 공유 증거가 아닙니다 |
| 이메일·전화번호가 가려져 있어요 | 개인정보 원문 조회 권한과 담당 강좌 범위를 확인합니다. 가려진 값을 연락처 누락으로 고치지 않습니다 |
| 수강 내역은 있는데 결제가 없어요 | 조회 역할과 수동/관리용 수강권 가능성, 같은 주문번호를 대조합니다. 수강권 존재가 유료 구매 증거는 아닙니다 |
| 기간만료·회수됨이 보여요 | 수강 상태·종료일·권리 결과를 확인합니다. 조회를 위해 중복 지급하거나 주문 환불을 실행하지 않습니다 |
| 메모 입력은 되는데 저장이 안 돼요 | 수정 권한·소유자/매니저 역할·500자·빈 내용·오류를 확인합니다. 입력란 활성은 저장 권한 증거가 아닙니다 |
| 메모가 빈칸이거나 저장 후 내용이 달라요 | 읽기 권한·최신 조회·다른 담당자 변경 여부를 확인합니다. 빈칸 위에 덮어쓰기나 반복 저장하지 않습니다 |
| CSV에 다른 유형이나 예상 밖 회원이 있어요 | 유형 필터 계약·파일 대상/건수를 확인합니다. 화면 조건이 파일에도 동일하다고 가정하거나 검수 전 공유하지 않습니다 |
