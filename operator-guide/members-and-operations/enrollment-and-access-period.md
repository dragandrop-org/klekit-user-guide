# 수강권·이용 기간 관리하기

> **검토용 가이드** · 실제 서비스 화면·동작 확인과 이미지 보완이 남아 있습니다. 본문의 실행 보류·주의사항을 먼저 확인하세요.

<figure><img src="../.gitbook/assets/branding/account-and-permissions-illustration-v1.png" alt="회원·권한 대표 이미지"><figcaption></figcaption></figure>

**회원 관리 → 회원 목록 → 회원 상세 → 수강 내역**에서 개별 회원의 강좌 수강권을 지급하거나 기간을 연장하고, 회수 가능한 관리자 수강권을 회수합니다. **지급·연장·회수는 서로 다른 작업**이며 주문 생성·결제 취소·환불을 대신하지 않습니다.

**완료 기준:** 대상 회원·강좌·변경 사유와 기존 상태를 확인하고 필요한 작업만 한 번 실행한 뒤, 최신 수강 내역의 강좌·종료일·상태·진도와 실제 이용 결과를 대조합니다. 성공 안내만으로 선택한 모든 강좌의 지급, 특정 날짜까지의 이용, 모든 수강권의 종료를 확정하지 않습니다.

회원 검색·식별과 조회 권한은 [회원 정보·이용 내역 확인하기](member-information-and-history.md)를 먼저 확인합니다. 구매한 주문의 지급 문제는 [구매 후 콘텐츠 지급](../orders-and-shipping/content-fulfillment-check.md), 거래 상태는 [주문·결제 상태](../orders-and-shipping/order-and-payment-status.md), 취소·환불은 [신청 확인·승인·거절](../cancellations-and-returns/request-review-approve-and-reject.md)에서 다룹니다.

## 시작 전 준비 <a href="#before-you-start" id="before-you-start"></a>

| 준비할 것 | 확인 기준 |
| --- | --- |
| 대상 회원·사이트 | 같은 사이트에 가입한 회원인지, 동명이인은 아닌지 확인합니다. 학부모에게 지급한 권리가 자녀 계정으로 공유된다고 가정하지 않습니다 |
| 대상 강좌 | 정확한 강좌명과 게시 여부·담당 강사를 확인합니다. 상품 전체·교재·디지털 자료를 함께 지급하는 화면이 아닙니다 |
| 변경 사유·기간 | 신규 지급인지 기존 기간 연장인지, 회수할 이유가 무엇인지 확인하고 승인된 기간·범위를 준비합니다 |
| 기존 수강 내역 | 변경 전 강좌·상태·종료일/기한 없음·진도를 확인합니다. 구매 권리·수동 지급·관리용 접근·연장 권리가 함께 있을 수 있습니다 |
| 작업 권한 | 조회·지급·연장·회수는 별도 권한입니다. 소유자·매니저·강사 역할과 담당 강좌 범위, 사이트 플랜·구독 제한도 확인합니다 |
| 연습·화면 촬영 | 실제 회원에게 연습용으로 지급·연장·회수하지 않습니다. 촬영은 실행 범위가 승인된 가상 회원·테스트 강좌만 사용합니다 |

스태프 등 모든 운영 역할이 같은 작업을 할 수 있는 것은 아닙니다. 버튼이 보여도 역할·담당 강좌·플랜·구독 상태에 따라 처리가 제한될 수 있습니다. 메뉴가 없거나 처리가 거절되면 권한과 사이트 이용 조건을 담당자에게 확인하세요. 다른 사람의 계정으로 우회하지 않습니다.

## 먼저 작업 구분하기 <a href="#choose-your-task" id="choose-your-task"></a>

| 필요한 업무 | 진입 위치·버튼 | 바뀌는 것과 주의할 점 |
| --- | --- | --- |
| 회원에게 강좌를 새로 지급 | 목록의 해당 회원 액션 메뉴 → 수강권 지급, 또는 상세의 수강 내역 → 수강권 지급 | 선택 강좌에 관리자 지급 권리를 추가합니다. 이미 이용 중이거나 예약권이 있으면 지급이 제한되거나 건너뛸 수 있습니다 |
| 기존 강좌의 기간을 늘림 | 상세의 수강 내역 → 해당 강좌 관리의 점 세 개 메뉴 → 기간 연장 | 연장 일수를 추가하고 남은 권리와 기간을 다시 계산합니다. 최종 종료일 직접 수정·기간 단축이 아닙니다 |
| 관리자 지급 권리를 회수 | 같은 관리 메뉴 → 회수 → 확인 창의 회수 | 해당 강좌의 회수 가능한 관리자 권리를 함께 정리합니다. 구매 권리 취소·환불·회원 삭제가 아닙니다 |
| 구매 후 강좌가 안 보임 | 주문의 결제·콘텐츠 지급 결과 대조 | 확인 없이 수동 지급해 중복 권리를 만들지 않습니다 |

**회원 식별 → 변경 전 내역 확인 → 작업/기간 결정 → 최종 실행 → 최신 내역과 이용 결과 확인** 순서로 진행합니다. 강좌 상세의 일괄 지급, 상품 단위 지정·주문 기반 재등록, 일괄 연장·회수는 이 개별 회원 절차와 구분합니다.

> **화면 예시 준비 중** · 대상 회원과 강좌의 현재 상태를 확인하고 필요한 작업을 구분합니다.

## 1. 회원에게 강좌 수강권 지급하기 <a href="#step-1" id="step-1"></a>

1. [회원 목록](member-information-and-history.md)에서 회원을 찾고 상세의 **수강 내역**을 확인합니다. 이미 있는 강좌의 기간을 늘릴 목적이면 신규 지급 대신 아래 기간 연장을 검토합니다.
2. 상세의 **수강권 지급**을 누릅니다. 목록에서는 해당 회원 행의 점 세 개 액션 메뉴 → **수강권 지급**으로도 열 수 있습니다.
3. 창 상단의 회원 이름을 확인하고 지급할 강좌를 선택합니다. 필요한 경우 **강좌 보기**로 새 탭에서 강좌를 확인한 뒤 돌아와 선택 상태를 다시 확인합니다.
4. **수강중** 표시로 선택이 잠긴 강좌는 새 지급 대상에서 제외합니다. 선택 가능한 강좌라도 예약권·다른 담당자의 동시 처리로 실행 시 건너뛸 수 있습니다.
5. **지급 일수**에서 **직접입력** 또는 **캘린더 지정**을 선택합니다. 아래 일수 안내에 따라 값을 입력하고 캘린더의 **총 N일**도 확인합니다.
6. 여러 강좌를 선택했다면 같은 지급 일수가 모두 적용되는지 확인합니다. 강좌별로 다른 기간이 필요하면 한 번에 묶지 않고 대상을 나누어 처리합니다.
7. 회원·선택 강좌·일수를 다시 확인하고 창 아래 **수강권 지급**을 한 번 누릅니다. 선택과 입력만으로 지급되지 않으며, 실행하지 않으려면 최종 버튼을 누르기 전에 **닫기**로 나옵니다.
8. **수강권이 지급되었습니다.** 안내 후 같은 회원의 최신 수강 내역에서 선택한 강좌별 반영 여부·상태·종료일·진도를 대조합니다. 일부가 없거나 결과가 불명확하면 재지급부터 하지 말고 기존 권리와 처리 결과를 확인합니다.

선택 가능한 강좌는 게시된 같은 사이트 강좌이며 강사는 담당 강좌 범위로 제한됩니다. `지급 가능한 강좌가 없습니다.`가 보이면 게시 여부·담당 범위·조회 오류를 확인합니다. 목록이 비어 있어도 사이트에 강좌가 전혀 없다는 뜻은 아닙니다.

**수강중 표시만으로 중복 권리 검사가 끝난 것은 아닙니다.** 아직 수강을 시작하지 않은 예약권이 있어도 새 지급이 제한될 수 있습니다. 성공 안내에는 강좌별로 지급을 건너뛴 사유가 모두 나오지 않으므로, 선택한 각 강좌가 수강 내역에 반영됐는지 확인하세요.

> **화면 예시 준비 중** · 강좌와 대상을 확인합니다. 선택 가능 표시만으로 중복 지급 검사가 끝난 것은 아닙니다.

## 2. 지급 일수와 캘린더 구분하기 <a href="#step-2" id="step-2"></a>

<figure><img src="../.gitbook/assets/branding/learning-period-progress-illustration-v1.png" alt="수강 일정 달력과 학습 체크리스트"><figcaption></figcaption></figure>

| 입력 방식 | 확인할 것 | 잘못 해석하기 쉬운 부분 |
| --- | --- | --- |
| 직접입력 | 화면에서 1~365일 사이의 정수를 입력합니다. 예: 30 | 0일·소수·음수·빈 입력은 지급/연장 값이 아닙니다. 0을 무제한으로 입력하지 않습니다 |
| 캘린더 지정 | 오늘부터 선택일까지를 오늘·선택일 포함 일수로 환산하며 총 N일을 확인합니다 | 최종 만료 시각을 직접 저장하는 방식이 아닙니다. 오늘 선택은 0일이 아니라 1일입니다 |
| 입력 방식 변경 | 바꾼 방식의 입력값·선택 날짜·환산 일수를 다시 확인합니다 | 다른 방식에서 입력했던 값을 그대로 적용했다고 가정하지 않습니다 |
| 최종 종료일 | 처리 후 수강 내역의 종료일 또는 기한 없음을 확인합니다 | 선택 날짜의 자정/23:59 종료나 기존 기간과의 단순 일치를 보장하지 않습니다 |

이 화면의 캘린더는 오늘부터 365일 분량까지 선택합니다. 예를 들어 오늘을 선택하면 총 1일, 내일을 선택하면 총 2일로 환산됩니다. 기간은 입력한 일수×24시간으로 계산되므로, 캘린더를 정확한 시각의 예약 종료 기능으로 사용하지 않습니다.

특히 **기간 연장에서는 오늘 기준으로 환산한 일수를 기존 권리와 함께 계산**합니다. 남은 구매/수동/연장 권리가 여럿이거나 기한 없는 권리가 있으면 선택 날짜와 최종 종료일은 다를 수 있습니다. 특정 날짜·시각까지의 이용 약속이 필요하면 최종 반영 결과를 먼저 확인해야 합니다.

수강 내역의 종료일은 날짜만 표시하고 시각은 표시하지 않습니다. 날짜가 같아 보여도 정확한 만료 시각까지 같다는 뜻은 아닙니다. 필요한 경우 담당자에게 최종 시각을 확인하며 화면에 없는 시각 입력란을 찾거나 임의로 보완하지 않습니다.

> **화면 예시 준비 중** · 캘린더는 오늘을 포함한 일수로 환산합니다. 처리 후 최종 종료일을 다시 확인합니다.

## 3. 기존 수강 기간 연장하기 <a href="#step-3" id="step-3"></a>

1. 회원 상세의 **수강 내역**에서 대상 강좌·현재 상태·종료일/기한 없음·진도를 확인합니다.
2. 해당 강좌 행 **관리**의 점 세 개 메뉴 → **기간 연장**을 누릅니다. 다른 강좌 행을 연 것은 아닌지 확인합니다.
3. **수강기간 연장** 창에서 **직접입력** 또는 **캘린더 지정**을 선택하고 연장할 일수를 확인합니다. 화면 입력 범위는 1~365일입니다.
4. 캘린더를 사용했다면 오늘 기준 **총 N일**과 기존 종료일을 함께 확인합니다. 선택한 날짜로 기존 종료일을 바꾸는 작업이 아닙니다.
5. 승인된 회원·강좌·연장 일수를 확인하고 **적용**을 한 번 누릅니다. 입력만 했거나 **닫기**로 나온 상태를 연장 완료로 보지 않습니다.
6. **수강 기간이 연장되었습니다.** 안내 후 같은 회원·강좌의 최신 종료일·상태·진도를 다시 확인합니다.
7. 만료된 수강이나 복수/무제한 권리가 있다면 실제 이용 가능 여부도 별도로 확인합니다. 오류·결과 불명확이면 먼저 재조회하고 같은 연장을 반복하지 않습니다.

> **확인 대기:** 연장 창의 **수강 시작일로부터 365일까지 설정 가능** 문구와 실제 오늘 기준 일수 환산·기간 재계산을 구분해야 합니다. 이를 전체 수강 기간의 365일 상한이나 선택 날짜와 최종 만료일의 일치 근거로 사용하지 않습니다. 문구·최종 결과 검수 전 날짜 지정 연장 안내를 확정하지 않습니다.

기한 없는 권리가 남아 있으면 일수를 입력해도 종료일이 **기한 없음**으로 유지될 수 있습니다. 연장은 기간을 줄이거나 무제한 권리를 유한 기간으로 바꾸는 기능이 아닙니다. 원하는 날짜를 만들기 위해 회수·재지급을 임의로 조합하지 않습니다.

연장은 학습 진도를 초기화하는 기능이 아닙니다. 만료된 수강의 기간을 연장해도 진도가 0%로 초기화됐다고 판단하지 마세요. 성공 안내와 별도로 최신 진도와 학습 화면의 이용 가능 여부를 확인합니다.

> **화면 예시 준비 중** · 연장할 일수를 확인해 적용한 뒤 최종 기간·상태·진도를 대조합니다.

## 4. 회수 가능한 관리자 수강권 회수하기 <a href="#step-4" id="step-4"></a>

> **회수 전 확인:** 이 작업은 해당 회원·강좌의 회수 가능한 관리자 지급·관리용 접근·연장 권리를 함께 정리합니다. 최근 연장 한 건만 선택해 취소하는 절차가 아닙니다. 구매 수강권은 회수하지 않으며, 회수 후 이용이 계속될 수도 있습니다. 대상과 영향을 확인하지 못했다면 최종 회수를 누르지 않습니다.

1. 회원·강좌·회수 사유와 현재 수강 상태·종료일을 확인합니다. 구매 권리가 남아 있는지 확인할 수 없으면 담당자에게 먼저 확인합니다.
2. 대상 강좌 행의 **관리 → 점 세 개 메뉴 → 회수**를 엽니다. 회수 권한이 있고 현재 회수 가능한 관리자 수강권이 있어야 메뉴가 표시됩니다.
3. **수강권 회수** 창에 표시된 강좌명과 **회수 시 유의사항**을 읽습니다. 구매 수강권이 남아 있으면 수강 상태가 유지될 수 있다는 안내를 확인합니다.
4. 승인된 대상·영향이 맞을 때만 확인 창의 **회수**를 한 번 누릅니다. 구매 취소·환불이나 계정 삭제가 필요한 상황이면 이 버튼으로 대신 처리하지 않습니다.
5. **수강권을 회수했습니다.** 안내 후 같은 강좌의 최신 수강 상태·종료일·남은 권리·실제 이용 결과를 확인합니다. 메뉴가 사라졌거나 회수 성공 안내가 나왔다는 이유만으로 모든 이용 권리가 종료됐다고 판단하지 않습니다.

회수 가능한 관리자 권리가 여러 개이면 강좌 단위로 함께 처리될 수 있습니다. 이 창에는 권리별 체크박스나 회수할 일수 입력란이 없습니다. 일부 기간만 단축하거나 최근 지급 한 건만 되돌리는 기능으로 설명하지 않습니다.

**회수**가 안 보이면 회수 권한이 없거나 현재 회수 가능한 관리자 권리가 없는 경우일 수 있습니다. 구매 권리만 남았거나 만료 등으로 회수 대상이 없는 상태와 구분합니다. 회수 메뉴를 만들기 위해 추가 지급·연장하지 않습니다.

> **화면 예시 준비 중** · 회수 가능한 관리자 권리를 강좌 단위로 정리합니다. 구매 수강권은 회수하지 않습니다.

## 5. 변경 결과 다시 확인하기 <a href="#step-5" id="step-5"></a>

성공 안내 후 조회 갱신이 끝난 최신 화면을 확인합니다. 필요하면 같은 회원 상세를 다시 열어 변경 전 기록과 대조하며, 오래 열린 화면만 보고 다시 실행하지 않습니다.

| 작업 | 재확인할 것 | 완료로 단정하지 않을 것 |
| --- | --- | --- |
| 지급 | 선택한 강좌별 반영 여부·수강 상태·종료일·진도, 건너뛴 강좌의 기존/예약 권리 | 성공 안내가 선택한 모든 강좌의 새 지급을 뜻함 |
| 연장 | 변경 전후 종료일·상태·진도·실제 이용 가능 여부 | 선택 날짜=최종 종료일, 자동 진도 초기화, 새 결제 생성 |
| 회수 | 남은 권리·종료일·상태와 실제 이용, 구매 권리 보존 | 무조건 회수됨으로 표시, 즉시 모든 접근 종료, 주문 취소·환불 |
| 결과 불명확/실패 | 대상·시도 시각·입력 일수·현재 상태와 오류 안내 | 오류가 났으므로 미처리, 반복 실행해도 같은 결과만 발생 |

수강 내역 표는 강좌별 요약입니다. 이 표만으로 개별 구매/지급/연장 권리의 모든 내역을 확인할 수는 없습니다. 회수 범위나 남은 권리가 불명확하면 담당자에게 확인하고 추가 변경을 중단합니다.

사이트를 삭제하려면 [사이트 중지·삭제하기](site-stop-and-delete.md)의 별도 조건을 확인합니다. 이 표의 수강완료·회수됨 표시나 성공 안내만으로 사이트를 삭제할 수 있다고 판단하지 마세요. 삭제 조건을 맞추려고 수강권을 회수하지 않습니다.

수강중·수강완료·기간만료·취소·회수됨은 서로 다른 표시입니다. 학습 완료와 이용 기간 종료를 동일시하지 않으며, **기한 없음**도 모든 콘텐츠의 무료 이용이나 구매 완료를 뜻하지 않습니다.

구매 권리와 관리자 연장 권리가 함께 있으면 회수 후 이용 기간이 짧아지면서 수강은 유지될 수 있습니다. 결과가 예상과 다르면 주문·남은 수강권·종료일을 담당자와 함께 확인합니다. 구매 권리를 없애려고 회수를 반복하거나 결과를 시험하려고 환불하지 않습니다.

> **화면 예시 준비 중** · 성공 안내와 별도로 최신 내역·남은 권리·실제 이용 결과를 확인합니다.

> **화면 예시 준비 중** · 실패하거나 결과가 불명확하면 다시 실행하기 전에 최신 상태를 확인합니다.

> **동작 예시 준비 중** · 대상과 강좌·일수를 확인해 지급하고 같은 회원의 최신 수강 내역과 대조합니다.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 대상 사이트·회원·강좌와 변경 사유가 맞는지 확인했습니다.
- [ ] 지급·연장·회수와 주문/환불·일괄 처리를 구분했습니다.
- [ ] 작업별 권한·담당 강좌·플랜/구독 조건을 확인했습니다.
- [ ] 지급 강좌와 공통 지급 일수·수강중/예약권·건너뜀 가능성을 확인했습니다.
- [ ] 직접입력/캘린더의 1~365일과 총 N일을 확인하고 선택 날짜를 최종 만료 시각으로 단정하지 않았습니다.
- [ ] 연장 전후 종료일/기한 없음·상태·진도를 대조하고 결과 불명확 시 반복 연장하지 않았습니다.
- [ ] 회수 범위와 구매 권리 보존을 확인하고 최근 한 건 취소·환불로 안내하지 않았습니다.
- [ ] 최신 수강 내역과 필요한 실제 이용 결과를 확인했습니다.
- [ ] 실패·예상과 다른 결과는 대상/조건/시각·오류를 정리하고 추가 변경 전에 담당자와 확인했습니다.

## 자주 막히는 부분 <a href="#troubleshooting" id="troubleshooting"></a>

| 상황 | 확인할 것 |
| --- | --- |
| 수강권 지급 버튼이 안 보여요 | 조회와 지급 권한은 다릅니다. 역할·지급 권한·담당 범위를 확인하고 다른 계정으로 우회하지 않습니다 |
| 지급할 강좌가 없어요 | 같은 사이트의 게시된 강좌·강사 담당 범위·조회 오류를 확인합니다. 상품 전체 목록이 아닙니다 |
| 수강중으로 잠겨 선택할 수 없어요 | 기존 이용 권리를 확인합니다. 기간을 늘릴 목적이면 기간 연장을 검토하며 중복 지급용으로 회수하지 않습니다 |
| 선택은 됐는데 새 지급이 없어요 | 예약권·동시 처리·기존 권리로 건너뛸 수 있습니다. 강좌별 최신 결과를 확인하고 무작정 다시 지급하지 않습니다 |
| 지급/적용 버튼을 누를 수 없어요 | 강좌 선택·정수 1~365일·총 N일과 처리 중 여부를 확인합니다. 빈 입력·0일은 무제한이 아닙니다 |
| 캘린더 날짜와 종료일이 달라요 | 오늘 포함 일수 환산·기존 복수/무제한 권리·날짜만 표시하는 종료일을 구분합니다. 선택일 23:59 종료를 보장하지 않습니다 |
| 연장 후에도 기한 없음이에요 | 무제한 권리가 남아 있을 수 있습니다. 유한 기간으로 바꾸려고 회수·재지급을 임의로 조합하지 않습니다 |
| 만료 수강을 연장했는데 결과가 예상과 달라요 | 최종 시각·상태·진도·학습 화면 이용을 확인합니다. 성공 안내만으로 재활성화/진도 초기화를 확정하지 않습니다 |
| 기간 연장/회수 메뉴가 안 보여요 | 각 작업 권한과 현재 회수 가능한 관리자 수강권이 있는지 확인합니다. 두 항목이 모두 없으면 관리 메뉴 자체가 없을 수 있습니다 |
| 회수했는데 학생이 계속 수강해요 | 구매 등 남은 권리를 확인합니다. 회수는 모든 권리 종료·주문 취소·환불이 아닙니다 |
| 회수 실패 후 창이 닫혔어요 | 최신 수강 내역과 회수 가능 상태부터 다시 확인합니다. 대상 없음/동시 변경을 무시하고 반복하지 않습니다 |
| 체험/만료 사이트에서 일부 작업만 실패해요 | 지급과 연장/회수의 구독·기능 조건이 다를 수 있습니다. 조회 가능이 변경 가능을 뜻하지 않습니다 |
| 처리 중 끊겼거나 오류가 났어요 | 대상·입력·시각과 최신 결과를 확인합니다. 특히 같은 연장을 다시 적용하면 기간이 추가될 수 있으므로 미처리로 단정하지 않습니다 |
