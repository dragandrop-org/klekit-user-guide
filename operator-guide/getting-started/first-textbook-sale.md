# 첫 교재 판매하기

> **검토용 가이드** · 실제 서비스 화면·동작 확인과 이미지 보완이 남아 있습니다. 본문의 실행 보류·주의사항을 먼저 확인하세요.

<figure><img src="../.gitbook/assets/branding/page-headers/getting-started/first-textbook-sale-v2.png" alt="첫 교재 판매하기 대표 이미지"><figcaption></figcaption></figure>

**업무 대상:** 판매 준비를 맡은 운영자용 안내입니다. 강사는 담당 콘텐츠를 준비하고, 사이트 개설·판매 설정은 해당 운영자에게 요청하세요. 실제 작업 가능 범위는 본인 계정의 권한을 확인하세요.

교재 콘텐츠를 등록하고 판매 상품에 연결한 뒤, 재고·배송 기준과 구매 후 출고 결과를 확인합니다. **교재 등록, 상품 판매 시작, 결제 완료, 배송 대상 생성, 송장 저장, 실제 발송과 수령은 서로 다른 단계**입니다.

**진행 순서:** 판매 준비 확인 → 교재 등록·재고 → 상품 구성·가격/과세 → 배송 기준 → 판매 상태·학생 표시 → 원 주문/배송 대상·주소 대조 → 출고·송장·발송 결과 확인

**완료 기준:** 같은 주문의 교재·유효 수량·결제 상태·확정 배송비와 실제 출고할 배송 정보를 대조하고, 승인된 범위의 송장/발송 결과를 구분해 확인합니다. 배송 화면·주소나 필수 결과가 확인되지 않았다면 첫 판매 흐름을 확인 완료로 표시하지 않습니다. 문서 작성은 운영 판매·결제·택배 접수·실물 발송 승인이 아닙니다.

## 이번에 만들 예제 <a href="#example" id="example"></a>

| 구분 | 설명용 예시 |
| --- | --- |
| 교재 | 중등 수학 일차방정식 연습장 1판 |
| 상품 구성 | 교재 콘텐츠 하나를 포함한 **교재** 유형, 제공 수량 1권 |
| 최초 재고 | 10권, 재고 부족 알림 기준 3권 |
| 상품 금액·할인 | 유료, 구성 금액 20,000원, 할인없음 |
| 배송비 | 기본 3,000원, 조건부 무료배송 기준 30,000원 |
| 반품비·교환비 | 각각 3,000원·6,000원 |
| 출고 준비 | 실제 지원을 확인한 택배사·출고 담당자·출고지·반품지 |
| 포함하지 않는 것 | 강좌·별도 디지털 자료·옵션·쿠폰·여러 권 구성 |

수량·금액은 설명용이며 기본값·권장 요금이나 실제 재고/결제/출고 승인이 아닙니다. 운영 재고에는 실사한 수량을, 가격·비용에는 담당자가 확정한 기준을 사용합니다. 실제 발송 없이 진행한 검수는 물류 완료로 표시하지 않습니다. 학원 방문 수령이나 부분 출고 기능을 이 예제로 가정하지 않습니다.

## 시작 전 확인 <a href="#before-you-start" id="before-you-start"></a>

- [ ] 사용할 사이트와 담당 계정의 콘텐츠·상품·재고·배송 조회/변경 권한을 구분했습니다.
- [ ] [판매 준비 체크리스트](sales-readiness-checklist.md)의 플랜/체험·판매자·공개/문의 조건을 확인했습니다.
- [ ] 기존 교재와 연결 상품이 있는지 확인하고 같은 교재를 중복 등록하지 않기로 했습니다.
- [ ] 사용할 표지·교재 정보·실제 재고와 포장/인계 담당자를 준비했습니다.
- [ ] 배송 설정·구매자의 주소 확인·배송 처리 화면의 실제 제공 여부와 남은 조건을 정리했습니다.
- [ ] 등록/판매 작업과 구매·재고 예약/차감·송장/발송 검수의 대상·금액·허용 동작을 별도로 정했습니다.

**유료 상품 등록·판매 제한은 교재에도 확인합니다.** 기본 Free 시작과 상위 플랜 14일 체험을 구분하고, 제한을 무료 등록이나 쿠폰 후 0원 주문으로 우회하지 않습니다. [플랜·체험](../subscription-and-usage/plan-trial-and-subscription-start.md), [판매자 신청·심사](../sellers-and-settlements/seller-registration-and-review.md)의 확인 대기를 유지합니다. 판매자 승인·계좌 인증·실제 정산금 지급은 별도 결과입니다.

## 1. 교재 정보와 표지 등록하기 <a href="#step-1" id="step-1"></a>

1. 관리자 **콘텐츠 관리 → 콘텐츠 생성**에서 **교재**를 선택하고 **다음 단계**로 이동합니다.
2. **교재명 입력**, **상세 설명 입력**, **교재 썸네일 업로드**, **교재 카테고리 선택**을 확인합니다.
3. **교재 소개 페이지 설정**에 대상·목차·판본 등 학생이 구분할 내용을 준비합니다.
4. **교재 정보**에서 저자·출판사를 입력하고, ISBN·페이지 수·출간일은 확인된 정보가 있을 때만 입력합니다.

이름과 표지에서 판본을 구분합니다. 표지의 **3:4 비율·900×1200px 이상 권장 안내**를 참고하되 이를 모든 이미지의 업로드 강제 규격으로 확대하지 않습니다. 최종 완료에는 표지가 필요합니다. 자체 제작 교재에 ISBN이 없다면 임의 번호를 만들지 않으며, **ISBN 입력·미입력은 면세 설정을 대신하지 않습니다.** 자세한 입력은 [교재 등록·수정하기](../content-management/textbook-create-and-edit.md)를 참고합니다.

> **화면 예시 준비 중** · 교재의 이름·판본·표지와 확인된 정보를 준비합니다.

## 2. 최초 재고와 공유 재고 확인하기 <a href="#step-2" id="step-2"></a>

**새 교재**의 **가격 및 재고**에서 정가·재고·재고 부족 알림 기준을 구분합니다. 예제에서는 실제 보유량이 10권인 상황을 가정하고 알림 기준 3권을 사용합니다. 두 재고 항목을 모두 비우면 최초 재고 설정 없이 등록됩니다. 빈칸을 재고 0권이나 무제한 판매로 해석하지 않습니다.

| 작업 | 할 일 | 확인할 결과 |
| --- | --- | --- |
| 작성 중 교재 보관 | **임시 저장** | 작업 중 콘텐츠 보관. 판매 준비 완료 아님 |
| 교재 등록 완료 | **최종 완료** 후 같은 교재 상세 재조회 | 교재명·표지·정가·게시 상태와 최초 재고/이력 |
| 기존 교재 수량 수정 | **재고 이력 → 재고 조정**에서 확인된 증감분 반영 | 최신 수량·예약·처리 후 수량과 이력. 콘텐츠 재등록으로 대신하지 않음 |

교재의 정가는 새 상품 구성 시 참고하는 금액이며 기존 상품 판매가가 자동 변경되는 것은 아닙니다. 재고 부족 알림 기준 입력만으로 실제 알림 발송이 확인된 것도 아닙니다.

**같은 교재 콘텐츠를 사용하는 상품은 재고를 공유합니다.** 보유 수량에서 예약 수량을 뺀 가용 수량이 이번 상품의 제공 수량을 충족하는지 확인합니다. 예를 들어 보유 10권·예약 3권이면 가용 수량은 7권입니다. 상세의 재고 숫자만으로 예약까지 확인했다고 판단하지 않습니다.

재고 조정의 **변동 수량**은 최종 총량이 아니라 증감분입니다. 주문 처리에서 이미 반영된 재고를 출고 시 다시 수동 차감하지 않습니다. 부족한 재고를 통과시키려고 가상 입고·예약 해제·교재 중복 생성을 하지 않습니다. 결과가 불명확하면 같은 조정을 반복하기 전에 이력을 확인합니다. 자세한 기준은 [재고·판매 상태](../products-and-coupons/stock-and-sales-status.md)를 참고합니다.

> **화면 예시 준비 중** · 공유 재고와 예약 수량을 구분해 판매 가능한 수량을 확인합니다.

## 3. 교재 상품 만들고 금액·과세 조건 정하기 <a href="#step-3" id="step-3"></a>

1. **상품 목록 → 상품 생성 → 상품 종류 선택**에서 **교재**를 선택합니다.
2. **콘텐츠 선택 → 선택하기**에서 앞서 준비한 교재 하나를 선택하고 선택 창의 **등록**을 누릅니다.
3. 상품 입력 화면에서 연결 교재·판본과 상품 제목·대표 이미지·소개를 대조합니다.
4. 선택한 교재 옆 **구성 금액**에 예제의 20,000원을 확인하고, **수강료 설정**에서 유료·할인없음을 확인합니다. 현재 화면은 교재에도 이 제목을 사용합니다.
5. 콘텐츠별 **과세 설정**을 판매자가 확인한 기준과 맞춥니다. 면세 선택 시 책임 확인이 필요하며 교재 종류·ISBN만으로 판단하지 않습니다.
6. **최종 완료**로 상품 생성 결과를 확인합니다. 배송·판매 준비가 남았다면 **비공개로 저장**으로 생성된 상품을 판매 중지 상태로 보관합니다.

**선택 등록, 상품 생성과 판매 시작은 다릅니다.** 합계 금액은 콘텐츠별 구성 금액으로 계산하므로 합계 칸을 직접 바꾸는 절차가 아닙니다. 상품 생성 화면의 **임시저장**은 현재 비활성이며, **비공개로 저장**은 입력 중 임시 저장이나 사이트 전체 비공개가 아닙니다.

이 예제는 교재만 포함하므로 강좌 수강 기간을 입력하지 않습니다. 강좌가 없는 상품에 기록된 0을 무제한 강좌 기간으로 해석하지 않습니다. 새 화면의 제공 수량은 콘텐츠당 1이며 여러 권으로 바꾸는 입력은 확인되지 않았습니다. 같은 콘텐츠를 중복 선택하거나 강좌·패키지 유형으로 바꿔 수량 제한을 우회하지 않습니다.

상세 절차는 [상품·콘텐츠 연결](../products-and-coupons/create-products-and-connect-content.md), [금액·할인·기간](../products-and-coupons/price-discount-and-valid-days.md), [과세·면세](../products-and-coupons/tax-settings.md)를 참고합니다. 이 문서는 판매자의 법률·세무 판단을 대신하지 않습니다.

> **화면 예시 준비 중** · 교재 콘텐츠를 상품에 연결하고 판매 조건을 따로 확인합니다.

## 4. 배송 기준 준비하고 실제 반영 여부 확인하기 <a href="#step-4" id="step-4"></a>

**검토한 화면에는 배송 관리 → 배송 설정과 저장 연결이 있습니다.** 아래 준비값을 해당 설정·신규 주문과 대조합니다. 사용할 사이트의 기능 제공 여부·권한·저장 결과와 주소·비용 반영은 아직 확인이 필요합니다. 메뉴가 보인다는 이유만으로 판매 준비가 끝났다고 판단하거나 화면에서 제공하지 않는 방법·다른 메뉴로 우회하지 않습니다.

| 준비 항목 | 대조할 기준 |
| --- | --- |
| 택배사·담당자 | 실제 지원 목록과 계약/포장·인계 담당자. 기본 택배사 설정만으로 접수·송장 발급이 진행되지 않음 |
| 출고지·반품지 | 실제 발송/회수 가능한 담당자·연락처·우편번호·주소·상세 주소. 구매자의 배송지와 구분 |
| 기본 배송비 | 예제 3,000원. 실제 저장된 금액·정책 적용 상태와 신규 주문 확정액을 확인 |
| 조건부 무료배송 | 예제 기준 30,000원. 상품 할인 후·쿠폰 적용 전 **교재 금액 합계**로 판단 |
| 반품비·교환비 | 예제 3,000원·6,000원. 서로 독립된 기준이며 자동 비용 결제·교환품 재배송 아님 |
| 안내·문의 | 승인된 배송/반품 정책과 실제 문의 경로·담당자. 정식 신청·실제 처리와 문의 접수 구분 |

예제의 할인 없는 교재 20,000원은 기준 30,000원 미만이므로 최초 배송비 3,000원, 상품과 배송비 합계는 **23,000원**인 계산 예시입니다. 실제 결제는 클킷에서 확정한 구성·할인/쿠폰·배송비·금액을 기준으로 하며 이 예시로 청구액을 덮어쓰지 않습니다.

교재가 여러 개여도 최초 배송비는 주문당 한 번 적용하는 기준입니다. 조건부 무료배송에는 강좌·디지털 자료 금액을 더하지 않고, 쿠폰 적용 후 금액으로 기준을 다시 판정하지 않습니다. **배송비 정책 미설정·비활성화의 최초 배송비 0원은 배송 중지나 실물 배송 불필요를 뜻하지 않습니다.** 무료 교재도 배송비가 있으면 전체 주문은 0원이 아닐 수 있습니다.

무료배송이어도 반품비·교환비는 별도 기준이며, 반품비에 최초 배송비를 임의로 더하거나 별도 왕복 반품비를 신규 항목으로 만들지 않습니다. 실제 환불 차감액·귀책 판단은 별도 처리 결과입니다. 기존 주문에는 해당 주문에 저장된 정책·확정 내역을 확인하며 새 설정으로 소급 계산하지 않습니다. 자세한 기준은 [배송 설정하기](../orders-and-shipping/shipping-settings.md)를 참고합니다.

> **화면 예시 준비 중** · 배송 정책 준비와 실제 저장/주문 반영을 구분합니다.

## 5. 판매 상태와 학생 상품 화면 확인하기 <a href="#step-5" id="step-5"></a>

배송 반영·주소 확인 등 적용 조건에 미확인이 남아 있으면 판매 개시를 보류합니다. 조건을 확인한 환경에서 신규 판매할 때는 생성 완료 화면의 **판매 시작**, 보관한 상품은 **상품 상세 → 운영 설정 → 판매 상태 변경 → 판매 중 → 변경 적용**으로 결과를 확인합니다.

| 확인 위치 | 확인할 결과 |
| --- | --- |
| 관리자 목록·상세 | 판매 상태와 대표 이미지·연결 교재·판매자/플랜·가용 재고 등의 판매 준비 안내 |
| 학생 PC·모바일 상품 화면 | 실제 진입 경로·교재/판본·제공 구성·상품 가격·배송 안내. 관리자 미리보기와 구분 |
| 부족한 조건 보완 후 | 같은 상품의 상태·조건 재조회. 재입고나 콘텐츠 복구만으로 판매 재개를 보장하지 않음 |

판매 중이어도 가용 재고 등 다른 조건 때문에 구매가 제한될 수 있습니다. 품절은 별도 상품 유형이나 선택할 판매 상태가 아닙니다. 교재가 포함된 패키지도 해당 교재 재고를 충족해야 합니다. 자세한 기준은 [재고·판매 상태 관리하기](../products-and-coupons/stock-and-sales-status.md), 학생 구성·표시는 수강생 가이드의 **상품 구성·가격·이용 기간 확인하기**를 참고합니다.

상품 메뉴·공개 페이지 연결은 상품 판매 상태와 별도입니다. [페이지·메뉴](../site-and-communication/pages-and-menus.md)의 **커스텀 빌더 대상 연결 문제 해결 전 실행 중단**을 유지하며, 운영 메인 페이지 편집·반복 게시로 상품 노출을 시험하지 않습니다. 신규 판매를 멈추는 판매 중지는 기존 주문 취소·배송 취소·재고 복원과 같은 작업이 아닙니다.

> **화면 예시 준비 중** · 판매 상태와 학생이 보는 상품·배송 안내는 별도로 확인합니다.

> **동작 예시 준비 중** · 기존 교재 상품의 연결 콘텐츠와 판매 상태를 확인하는 예시입니다.

## 6. 운영 검수: 주문·배송 대상 확인하기 <a href="#step-6" id="step-6"></a>

실제 구매 검수는 **테스트 사이트·가상 구매자·교재/재고·배송 정책·주소·허용 금액/동작**을 별도로 확정한 경우에만 진행합니다. 주문서 진입도 주문 생성·쿠폰/재고 예약으로 이어질 수 있고, 최종 0원이면 별도 결제 버튼 전 자동 처리될 수 있으므로 단순 화면 촬영으로 취급하지 않습니다.

### 구매 전 확인과 원 주문 <a href="#section-9" id="section-9"></a>

1. 구매자의 상품 구성·금액과 실제 배송비/수령 정보 확인 경로를 먼저 점검합니다. 자세한 흐름은 수강생 가이드의 **장바구니·쿠폰**, 수강생 가이드의 **결제·무료 상품 신청**을 참고합니다.
2. **저장 주소가 자동 선택됐다는 사실만으로 이번 주문의 배송지가 맞다고 판단하지 않습니다.** 기존 수강생 가이드의 **결제하고 무료 상품 신청하기**의 주소 확인/창 연결 차이를 유지하며, 수령인·주소를 확인할 수 없으면 결제 전에 멈추고 담당자에게 확인합니다. 없는 배송지 버튼을 만들거나 새 주문으로 확인하지 않습니다.
3. 승인된 환경에서 구매했다면 구매자의 **마이페이지 → 구매 내역 → 결제**에서 원 주문번호·상품·교재/수량·금액·상태를 대조합니다. 입금대기·처리 중·오류를 결제 완료로 판단하지 않습니다.
4. 운영자는 **결제/정산관리 → 결제 내역 → 상세 보기**의 같은 주문과 대조합니다. 혼합 구성·수량 표시가 불명확하면 구매 당시 기록을 담당자가 확인하며 현재 상품 구성으로 재구성하지 않습니다.

### 배송 대상과 실제 출고 주소 <a href="#section-10" id="section-10"></a>

**배송 관리와 학생 원 주문의 배송 정보에서 같은 주문을 확인합니다.** 배송 생성 대기·실제 배송 건·주소 변경 가능 여부를 나눠 읽고, 항목이 보이지 않거나 결과가 불명확하면 담당자에게 확인합니다. 임의로 주문이나 배송 건을 다시 만들지 않습니다.

| 대조할 항목 | 확인할 결과 |
| --- | --- |
| 주문 연결 | 원 주문과 해당 배송 건이 같으며 결제·취소/환불 결과를 구분 |
| 교재·유효 수량 | 주문 당시 교재·판본과 취소가 반영된 실제 출고 수량. 취소 수량을 다시 차감하지 않음 |
| 확정 배송비 | 해당 주문의 적용 정책과 확정 금액. 현재 설정으로 소급 계산하지 않음 |
| 배송 생성 | 생성 확인 중·배송 대기/준비와 실제 발송을 구분 |
| 실제 수령 정보 | 해당 배송 건의 수령인·연락처·우편번호·주소/상세 주소·요청사항을 출고 담당자와 대조 |

주소록, 주문 당시 주소, 실제 출고할 배송 건의 주소는 다릅니다. 주소록이나 사이트 출고지를 바꾸는 것으로 기존 주문의 배송지를 정정했다고 안내하지 않습니다. **구매자는 배송 대기, 운영자는 배송 대기·준비이며 양쪽 모두 발송 이력이 없어야 한다는 정정 조건**을 [배송지 변경하기](../orders-and-shipping/change-shipping-address.md)에서 확인합니다. 변경 화면의 안내와 실제 권한/저장 결과를 구분하며 발송 상태를 되돌려 주소 변경을 우회하지 않습니다.

결제 완료는 배송 대상 생성·실제 발송 완료가 아닙니다. 배송 대상이 없거나 조회가 실패해도 같은 주문을 다시 만들거나 수동 중복 배송을 만들지 않습니다. [주문·결제](../orders-and-shipping/order-and-payment-status.md)와 [구매 후 제공](../orders-and-shipping/content-fulfillment-check.md)을 참고합니다.

> **화면 예시 준비 중** · 원 주문·배송 대상·실제 수령 정보를 대조합니다.

## 7. 운영 검수: 출고·송장·발송 확인하기 <a href="#step-7" id="step-7"></a>

이 단계는 [출고·송장](../orders-and-shipping/dispatch-and-tracking.md)의 현재 **배송 관리** 진행 방법과 업무 기준을 따릅니다. **송장 저장**은 정보 저장이며, **저장 후 발송 완료**는 송장을 저장한 뒤 발송 처리를 이어갑니다. 일부만 성공할 수 있으므로 송장·상태·이력과 실제 인계·외부 처리 결과를 각각 확인합니다. 사용할 사이트의 기능 제공 여부·권한·허용 대상과 실제 물류 결과가 확인되기 전에는 실행을 보류합니다.

| 순서 | 확인할 업무 | 완료로 오해하지 않을 것 |
| --- | --- | --- |
| 최신 출고 조건 | 결제/취소·환불 확인 결과, 교재·유효 수량·주소와 실제 포장 대조 | 취소 결과가 불명확한데 송장만 입력해 출고 강행 |
| 실제 송장 준비 | 지원 택배사와 택배사에서 발급받은 해당 배송 송장 | 클킷 설정/등록이 택배 계약·접수·송장 발급·라벨 출력까지 자동 수행 |
| 송장 반영 | 확인된 화면에서 저장했다면 같은 배송의 택배사·송장 재조회 | 송장 저장만으로 발송 상태·택배 인계 완료 |
| 실제 인계·발송 기록 | 포장·인계 사실과 확인된 발송 처리 뒤 상태·시각·이력 대조 | 클킷의 발송 완료 표시가 구매자 수령·외부 결제 서비스 반영·정산 완료 |
| 배송 안내 | 최종 구매자 화면·확인된 개별 문의 경로와 실제 택배 조회 결과 구분 | 송장/조회 링크만으로 배송 중·수령 완료를 추정 |

현재 기준은 **주문 단위 합포장·단건 처리**입니다. 일부 교재만 먼저 보내거나 같은 주문에 여러 송장/배송 건을 임의로 만드는 절차, CSV 송장 업로드·일괄/부분 출고·자동 추적은 이 시나리오 범위가 아닙니다. 지원 목록에 없는 택배사를 다른 이름으로 선택하거나 가짜 송장·발송 시각을 입력하지 않습니다. 현재 출고 CSV 내보내기는 조회 결과 파일이며 출고/송장 등록과 다릅니다.

**송장 저장**은 송장 정보만 저장합니다. **저장 후 발송 완료**는 송장 저장 뒤 별도 발송 처리를 이어가므로 송장만 저장되고 발송은 실패할 수 있습니다. 같은 배송의 송장·상태·이력을 각각 확인합니다. 실제로 인계하지 않은 교재를 발송 완료로 기록하거나 중복 출고하지 않습니다.

발송 상태 보정으로 최초 발송 사실이 없어지거나 출고 전 취소·주소 정정 자격이 복원되지 않습니다. 결과가 불명확하면 기존 배송·이력부터 확인하고 상태 되돌림/재발송으로 해결하지 않습니다. 에스크로 등 외부 후속 처리도 내부 발송과 별도로 확인합니다. 학생 원 주문의 배송/주소 연결은 수강생 가이드의 **교재 배송·배송지**를 따르며 배포/실제 결과와 구분합니다.

> **화면 예시 준비 중** · 송장·발송 표시와 실제 물류 결과를 나눕니다.

| 상황 | 먼저 확인할 것 |
| --- | --- |
| 교재를 게시 완료했는데 구매할 상품이 없어요 | 교재 콘텐츠 등록과 상품 생성/판매 상태는 별개입니다. 기존 교재를 다시 만들지 않습니다 |
| 재고가 있는데 품절이거나 구매가 안 돼요 | 공유 재고·예약/가용 수량과 연결 상품의 판매 준비 조건을 확인합니다. 임의 입고로 우회하지 않습니다 |
| 여러 권을 한 상품에 넣고 싶어요 | 현재 수량 편집은 확인 대기입니다. 중복 선택/교재 재등록 대신 지원 범위를 담당자에게 확인합니다 |
| 배송 설정·출고 메뉴가 안 보여요 | 실제 제공 환경·권한·화면 제공 여부를 확인합니다. 다른 메뉴·화면 밖의 요청·CSV로 대신하지 않습니다 |
| 배송비가 예상과 다르거나 무료로 나와요 | 정책 적용 상태와 상품 할인 후·쿠폰 적용 전 교재 금액, 해당 주문 확정액을 확인합니다 |
| 수령 주소를 확인할 수 없어요 | 저장 주소 자동 선택을 정상 반영 증거로 쓰지 않습니다. 결제/출고 전 담당자에게 확인합니다 |
| 결제 완료인데 배송 대상이 없어요 | 원 주문·교재 구성·조회 오류·생성 결과를 대조합니다. 재결제·새 주문/중복 배송을 만들지 않습니다 |
| 송장을 넣었는데 준비 상태이거나 택배 조회가 안 돼요 | 송장 저장·실제 인계·발송 기록·외부 조회를 구분합니다. 임의 상태 변경·중복 출고하지 않습니다 |
| 주소록을 바꿨는데 주문 주소가 그대로예요 | 주소록·원 주문·해당 배송 주소는 별개입니다. 발송 이력·최신 조건과 실제 반영 결과를 확인합니다 |

문의에는 사이트·상품/교재·판본, 원 주문/배송 식별에 필요한 최소 정보, 기대 수량·금액과 실제 안내, 시각·오류 문구·담당 단계만 남깁니다. 전체 주소·연락처·공동현관 비밀번호·유효 송장·카드/계좌 전체 번호·인증정보는 공개 글이나 캡처로 공유하지 않습니다.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 같은 사이트의 교재 콘텐츠와 판매 상품을 구분했습니다.
- [ ] 교재명·판본·표지·선택 정보와 저장/게시 결과를 확인했습니다.
- [ ] 실제 재고·공유/예약·가용 수량과 처리 이력을 구분했습니다.
- [ ] 상품의 연결 교재·제공 수량·가격/할인·과세 조건을 확인했습니다.
- [ ] 배송 설정·주소 확인·판매 상태/학생 표시의 실제 반영과 확인 대기를 구분했습니다.
- [ ] 승인된 구매 검수에서 원 주문·결제·교재/유효 수량·배송비·배송 대상/수령 정보를 대조했습니다.
- [ ] 송장 저장·실제 인계·발송 기록·수령/외부 결과를 나누고 미확인 물류 결과를 완료로 표시하지 않았습니다.
