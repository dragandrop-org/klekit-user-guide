# 첫 디지털 자료 판매하기

> **검토용 가이드** · 실제 서비스 화면·동작 확인과 이미지 보완이 남아 있습니다. 본문의 실행 보류·주의사항을 먼저 확인하세요.

<figure><img src="../.gitbook/assets/branding/getting-started-illustration-v1.png" alt="시작하기 대표 이미지"><figcaption></figcaption></figure>

다운로드할 파일을 자료 콘텐츠로 등록하고, 학생이 구매할 상품에 연결합니다. **파일 업로드, 자료 저장, 상품 판매, 결제, 자료 권한 지급, 다운로드 주소 발급과 실제 파일 저장/열기는 서로 다른 단계**입니다.

**진행 순서:** 최종 파일 준비 → 자료 정보·업로드/저장 → 상품 연결·가격/과세 → 판매 상태·학생 표시 → 원 주문/자료 권한 → 파일 수신/내용 확인

**완료 기준:** 대상 자료·상품·파일 버전과 같은 주문의 결제/자료 권한을 대조하고, 승인된 다운로드 검수에서 실제 기기에 저장된 파일을 열어 내용을 확인합니다. 관리자 다운로드 성공, 내 자료의 받음 표시나 새 창 열림만으로 구매자 제공 완료를 판단하지 않습니다.

## 이번에 만들 예제 <a href="#example" id="example"></a>

| 구분 | 설명용 예시 |
| --- | --- |
| 자료 | 중등 수학 일차방정식 연습문제 PDF 1판 |
| 배포 파일 | `일차방정식-연습문제-v1.pdf` 하나 |
| 상품 구성 | 위 자료 하나를 포함한 **디지털 자료** 유형 상품 |
| 상품 금액·할인 | 유료, 구성 금액 10,000원, 할인없음 |
| 제공 결과 | 구매 계정의 해당 파일 버전 이용 권한과 실제 파일 수신 |
| 포함하지 않는 것 | 강좌·교재·배송·옵션·쿠폰 |

이름·금액은 설명용이며 기본값·권장 가격이나 결제 승인이 아닙니다. 실제 가격과 제공 범위는 담당자가 확정합니다. 강의실 첨부자료·공지 첨부와 별도 판매 자료는 같은 경로가 아닙니다. 이 예제에서는 **마이페이지 → 내 학습 → 내 자료**에서 받는 별도 디지털 자료를 준비합니다.

## 시작 전 확인 <a href="#before-you-start" id="before-you-start"></a>

- [ ] 사용할 사이트와 콘텐츠·상품·파일 조회/변경 담당 권한을 확인했습니다.
- [ ] [판매 준비 체크리스트](sales-readiness-checklist.md)의 플랜/체험·판매자·공개/문의 조건을 확인했습니다.
- [ ] 배포 가능한 최종 파일을 직접 열어 내용·판본·개인정보 포함 여부를 확인했습니다.
- [ ] 같은 자료가 이미 등록됐는지, 기존 상품/구매자와 파일 교체 영향이 있는지 확인했습니다.
- [ ] 실제 자료 업로드 한도·허용 형식과 저장/현재 파일 확인 범위를 정했습니다.
- [ ] 구매와 자료 권한 조회, 다운로드 주소 발급·파일 수신의 테스트 대상/금액/허용 동작을 별도로 정했습니다.

유료 등록·판매 제한은 디지털 자료에도 확인합니다. **기본 Free 시작과 상위 플랜 14일 체험, 무료 상품과 쿠폰 후 0원 주문을 구분**하며 제한을 우회하지 않습니다. [플랜·체험](../subscription-and-usage/plan-trial-and-subscription-start.md), [판매자 신청·심사](../sellers-and-settlements/seller-registration-and-review.md)의 확인 대기를 유지합니다.

## 1. 최종 파일과 자료 정보 준비하기 <a href="#step-1" id="step-1"></a>

1. 최종 PDF를 직접 열어 페이지·문제/해설·수식·표·판본을 확인합니다. 파일명만 확인하고 배포본으로 확정하지 않습니다.
2. 관리자 **콘텐츠 관리 → 콘텐츠 생성**에서 **디지털 자료**를 선택하고 **다음 단계**로 이동합니다.
3. **자료명 입력**, **상세 설명 입력**을 작성하고 필요한 썸네일·카테고리를 준비합니다.
4. **자료 소개 페이지 설정**에 포함 내용·대상·판본과 열기에 필요한 프로그램을 안내합니다. 실제 유료 파일이나 학생 개인정보를 공개 소개에 넣지 않습니다.
5. **가격 → 정가**에는 새 상품 구성 시 참고할 기준 금액을 입력합니다. 이 정가와 상품에서 정할 판매가는 구분합니다.

자료 한 개에는 **파일 하나**를 업로드합니다. 여러 파일을 함께 제공하려면 지원하는 ZIP 하나로 묶고 압축 해제·내용 열기까지 확인합니다. 이 예제는 PDF 하나이므로 ZIP은 필요하지 않습니다. 다른 확장자의 이름만 `.pdf`로 바꾸지 않습니다.

허용 형식·파일 구성은 [디지털 자료·파일 관리하기](../content-management/digital-resource-and-files.md)를 참고합니다. **영상의 5GB 기준을 디지털 자료의 확정 업로드 한도로 사용하지 않습니다.** 현재 자료 화면·운영 담당자가 확인한 형식/MIME·용량 기준을 따릅니다. 확장자 검증 통과를 파일 내용·압축 내부·악성 코드 검사 완료로 안내하지 않습니다.

> **화면 예시 준비 중** · 별도 판매할 자료와 배포할 최종 파일을 준비합니다.

## 2. 파일 업로드 뒤 자료 저장·현재 파일 확인하기 <a href="#step-2" id="step-2"></a>

1. **자료 업로드**에서 최종 파일 하나를 선택하거나 끌어 놓습니다.
2. 진행 상태와 **자료 업로드가 완료되었습니다.** 안내를 확인합니다. 선택하면 저장 버튼 전에도 업로드가 시작될 수 있습니다.
3. 파일명·오류 여부를 확인하고 작성 중이면 **임시 저장**, 자료 등록을 마치려면 **최종 완료**를 누릅니다.
4. 목록·자료 상세를 다시 열어 상태와 **자료 개요 → 자료 파일**의 현재 파일명·용량을 확인합니다.
5. 관리자 파일 수신/내용 검수도 승인된 범위에서 진행하고, 저장한 원본과 실제 현재 파일의 내용을 대조합니다.

**업로드 완료는 자료에 파일이 연결·저장됐다는 뜻이 아닙니다.** 최종 완료에는 연결할 파일이 필요합니다. 파일 없이 정보만 임시 저장한 상태를 다운로드용 자료 준비 완료로 처리하지 않습니다. 마지막 단계에서 오류가 나도 일부 정보·파일 연결이 이미 저장됐을 수 있으므로 기존 목록/상세부터 확인하고 같은 자료를 중복 생성하지 않습니다.

자료의 **게시 완료**는 콘텐츠 상태이며 상품 생성/판매 시작이 아닙니다. 관리자 현재 파일 다운로드는 구매자의 자료 권한·구매 버전·실제 수신 성공을 대신하지 않습니다. 상세 단계는 [디지털 자료·파일 관리하기](../content-management/digital-resource-and-files.md)을 따릅니다.

> **화면 예시 준비 중** · 파일 업로드와 자료 저장·연결 결과를 각각 확인합니다.

## 3. 디지털 자료 상품 연결하고 가격·과세 조건 정하기 <a href="#step-3" id="step-3"></a>

1. **상품 목록 → 상품 생성 → 상품 종류 선택**에서 **디지털 자료**를 선택합니다.
2. **콘텐츠 선택 → 선택하기**에서 앞서 등록한 자료 하나를 찾고 선택 창의 **등록**을 누릅니다.
3. 상품 입력 화면에서 연결 자료·상품 제목·대표 이미지·소개를 대조합니다. 자료명과 상품명이 비슷해도 실제 연결 대상을 확인합니다.
4. 선택한 자료 옆 구성 금액에 예제의 10,000원, **수강료 설정**에 유료·할인없음을 확인합니다. 교재/자료에도 현재 이 제목을 사용합니다.
5. 콘텐츠별 **과세 설정**을 판매자의 확인된 판단과 맞춥니다. 자료/PDF라는 종류만으로 과세·면세를 자동 확정하지 않습니다.
6. **최종 완료**로 상품 생성 결과를 확인하고, 판매 전 보관이 필요하면 **비공개로 저장**을 선택합니다.

상품 생성의 임시저장은 현재 비활성이며 비공개로 저장은 생성된 상품을 판매 중지 상태로 보관하는 선택입니다. 콘텐츠 임시 저장·사이트 전체 비공개와 다릅니다. 자료 썸네일의 선택 입력과 상품 대표 이미지의 판매 준비 조건도 구분합니다.

이 예제는 자료만 포함하므로 강좌 수강 기간과 교재 재고/배송비를 적용하지 않습니다. **강좌 기간 입력이 없다는 사실을 영구 제공·무제한 이용 보장으로 해석하지 않습니다.** 실제 자료 권한·제공 범위는 따로 확인합니다. 강좌·교재를 추가하면 패키지와 해당 구성의 기간/배송/재고 조건을 다시 점검합니다.

자세한 구성은 [상품·콘텐츠 연결](../products-and-coupons/create-products-and-connect-content.md), 금액은 [가격·할인·수강 기간 설정하기](../products-and-coupons/price-discount-and-valid-days.md), 과세 입력은 [과세·면세 정보 설정하기](../products-and-coupons/tax-settings.md)을 참고합니다. 법률·세무 판단은 이 문서로 대신하지 않습니다.

> **화면 예시 준비 중** · 자료 콘텐츠를 상품에 연결하고 별도 판매 조건을 확인합니다.

## 4. 판매 상태와 학생 상품 표시 확인하기 <a href="#step-4" id="step-4"></a>

| 상황 | 할 일 | 확인할 결과 |
| --- | --- | --- |
| 아직 판매하지 않음 | 생성 뒤 **비공개로 저장** | 같은 상품이 판매 중지 상태로 보관됨 |
| 생성 직후 판매 시작 | 적용 조건 확인 후 **판매 시작** | 목록·상세의 상태와 준비 안내 재조회 |
| 보관한 상품 판매 시작 | **상품 상세 → 운영 설정 → 판매 상태 변경 → 판매 중 → 변경 적용** | 연결 자료/파일·대표 이미지·판매자/플랜 등의 조건과 변경 결과 |

자료 게시 완료·상품 판매 중과 실제 구매 가능은 별개입니다. 준비 안내가 남거나 판매 조건을 확인하지 못했다면 완료로 처리하지 않습니다. 파일/콘텐츠 문제를 해결했다고 중지 상품이 자동 재판매된다고 안내하지 않습니다. 자세한 기준은 [재고·판매 상태](../products-and-coupons/stock-and-sales-status.md)를 참고합니다.

학생 PC/모바일에서 실제 상품 진입 경로·자료 구성·판본·가격/할인·파일 제공 안내를 대조합니다. 관리자 미리보기를 구매자 화면으로 대신하지 않습니다. 메뉴/페이지 공개와 상품 상태는 별개이며 [페이지·메뉴 구성하기](../site-and-communication/pages-and-menus.md)의 **커스텀 빌더 대상 연결 문제 해결 전 실행 중단**을 유지합니다. 학생 표시의 기존 차이는 수강생 가이드의 **상품 구성·가격**와 함께 확인합니다.

> **화면 예시 준비 중** · 판매 상태와 학생이 보는 자료 구성·가격을 따로 확인합니다.

## 5. 원 주문과 구매자 자료 권한 대조하기 <a href="#step-5" id="step-5"></a>

실제 구매는 **테스트 환경·가상 구매자·자료/파일 버전·허용 금액·동작·결과 확인 범위**를 확정한 경우에만 검수합니다. 가능하면 기존 자료 권한이 없는 가상 구매자를 기준으로 준비하며, 기존 권리가 있으면 담당자가 이번 주문과 연결된 권리를 대조합니다.

1. 구매자의 상품·장바구니에서 대상 자료와 최종 금액을 확인합니다. 자세한 구매는 수강생 가이드의 **장바구니와 쿠폰 이용하기**·수강생 가이드의 **결제하고 무료 상품 신청하기**을 따릅니다.
2. 주문서·결제는 승인된 범위에서만 진행합니다. 주문서 진입의 자동 주문/예약과 최종 0원 자동 처리를 단순 조회로 취급하지 않습니다.
3. 구매자의 **마이페이지 → 구매 내역 → 결제**, 운영자의 **결제/정산관리 → 결제 내역 → 상세 보기**에서 같은 원 주문의 계정·상품·구성·금액·상태를 대조합니다. 입금대기·처리 중·완료 제목만으로 결제/지급 완료를 판단하지 않습니다.
4. 구매자의 **마이페이지 → 내 학습 → 내 자료**에서 **전체** 조건과 페이지를 확인합니다. 자료명·파일명·지급일·상세 정보를 확인하고 빈 목록/필터 빈 결과/조회 오류를 구분합니다.
5. 이번 주문과 자료 이용 권한·파일 버전의 연결을 담당자가 대조합니다. 목록에 같은 제목이 있거나 관리자 파일을 받을 수 있다는 사실만으로 이번 구매의 권리 지급을 확정하지 않습니다.

**결제 완료와 자료 권한 지급 완료, 권한이 있음과 실제 파일 수신은 다릅니다.** 받음/미받음은 주소 발급 이력 기준이며 현재 권한·단순 취소 가능 여부를 증명하지 않습니다. 이용불가나 취소 처리 중 발급 제한을 다른 계정·직접 주소·재구매로 우회하지 않습니다.

자료가 없거나 결과가 불명확하면 원 주문·계정·구성·현재 권리와 오류부터 확인합니다. 재결제·무료 재신청·임의 재지급으로 판매 검수 결과를 맞추지 않습니다. [구매 후 제공 확인](../orders-and-shipping/content-fulfillment-check.md), 수강생 가이드의 **구매하거나 지급받은 디지털 자료**를 참고합니다. 테스트 다운로드는 별도 승인된 범위에서 진행합니다.

> **화면 예시 준비 중** · 같은 주문의 자료 권한과 해당 파일 버전을 대조합니다.

> **동작 예시 준비 중** · 필요한 자료의 목록과 상세를 확인하는 예시입니다.

## 6. 다운로드 주소와 실제 저장·열기 구분하기 <a href="#step-6" id="step-6"></a>

실제 사용할 자료의 다운로드가 별도 승인 범위에 포함된 경우에만 진행합니다. 문의 확인·이미지 촬영·취소 가능 여부 시험을 위해 실제 학생 주문에서 실행하지 않습니다.

1. 내 자료 상세의 **자료 다운로드** 또는 목록의 **다운로드** 한 곳에서 확인창을 엽니다.
2. `자료를 다운로드하시겠어요?`의 취소 제한·주소 유효 시간 안내를 읽습니다. 확인창의 취소/닫기는 주문 취소 신청이 아닙니다.
3. 필요한 파일이 맞으면 확인창의 **다운로드**를 한 번 누르고 처리 중에는 반복하지 않습니다.
4. 새 창/탭 또는 현재 화면과 브라우저 다운로드 내역에서 진행·실패·파일명을 확인합니다.
5. 현재 기기의 실제 저장 위치에서 파일을 찾아 열고, 제공 판본·페이지/수식·내용이 의도한 파일인지 확인합니다. 미리보기만 된 경우와 기기 저장을 구분합니다.

**주소 발급 이력이 남으면 단순 취소 판단에 영향을 줄 수 있습니다.** 파일 저장 실패나 창 닫힘으로 발급 이력이 자동 취소되지 않습니다. 받음·최초 다운로드·관리자 URL 발급 건수는 파일 전송/저장·열람 완료 집계가 아닙니다.

확인창의 **10분**은 임시 주소 유효 시간 안내이며 자료 이용 기간이나 파일 저장 제한시간이 아닙니다. 발급 결과·실제 만료와 현재 권한을 구분하고 오래된 주소를 수정·복사·공유해 우회하지 않습니다. 공통 발급 실패 문구만으로 이력 없음·미지급이나 검사 원인을 확정하지 않습니다.

PC·iPhone·Android·앱 내 브라우저는 저장 메뉴·위치가 같지 않습니다. PDF 미리보기/자동 다운로드·실제 저장 결과를 기기별로 확인하며 모든 자료가 갤러리에 저장된다고 안내하지 않습니다. 안전 경고가 나면 열기·반복 발급을 멈추고 담당자에게 문의합니다. 보안 해제·출처 불명 프로그램 설치·확장자 변경으로 해결하지 않습니다. 자세한 확인은 수강생 가이드의 **구매하거나 지급받은 디지털 자료 이용하기**, 문제 대응은 수강생 가이드의 **자료/배송 문제**를 참고합니다.

> **화면 예시 준비 중** · 주소 발급 이력과 실제 기기 저장·파일 열기는 다릅니다.

## 판매 후 파일을 교체해야 한다면 <a href="#section-9" id="section-9"></a>

첫 판매 전에 교체 검수를 의무적으로 실행하지 않습니다. 이후 수정본이 필요할 때 [파일 교체](../content-management/digital-resource-and-files.md)에 따라 **새 파일 업로드 → 저장 → 현재 파일 재조회**를 구분합니다. 파일 선택만으로 교체 완료가 아니며 기존 버전 파일을 삭제해 정정하지 않습니다.

| 대상 | 확인할 파일 버전 기준 |
| --- | --- |
| 기존 자료 권한을 받은 구매자 | 권한에 연결된 기존 버전. 관리자 현재 파일 변경만으로 자동 최신본 지급 아님 |
| 교체 후 새로 생성되는 주문 | 주문 생성 시점의 현재 파일 버전을 주문에 기록 |
| 교체 전 생성됐고 아직 결제 대기인 주문 | 해당 주문에 기록된 버전. 결제 시 최신 파일로 다시 바꾸는 방식 아님 |
| 관리자 자료 개요 | 현재 파일. 모든 구매자가 받는 파일과 같다는 증거 아님 |

기존 구매자에게 수정본을 제공해야 하면 대상·제공 방법을 별도로 확인합니다. 전체 버전 선택·복원·일괄 재지급 UI가 있다고 가정하지 않습니다. **파일명만으로 같은 버전인지 판단하지 않으며** 원 주문·권리 연결과 실제 내용으로 대조합니다. 파일 교체·자료 중지/삭제·상품 판매 중지·기존 권리 회수는 서로 다른 작업입니다.

> **화면 예시 준비 중** · 주문에 기록된 버전과 관리자의 현재 파일을 구분합니다.

## 자주 막히는 부분 <a href="#troubleshooting" id="troubleshooting"></a>

| 상황 | 먼저 확인할 것 |
| --- | --- |
| 파일은 올렸는데 상세에 없어요 | 업로드·자료 저장·현재 파일 연결을 구분합니다. 기존 자료부터 확인하고 중복 생성하지 않습니다 |
| 여러 파일·확장자/용량 오류가 나요 | [디지털 자료·파일 관리하기](../content-management/digital-resource-and-files.md) 허용 형식·파일 하나/ZIP 구성·실제 운영 한도를 확인합니다. 영상 한도 재사용·확장자 변경으로 우회하지 않습니다 |
| 자료는 게시 완료인데 상품이 없어요 | 자료 등록과 상품 생성/판매는 별도입니다. 기존 자료를 상품에 연결합니다 |
| 판매 시작이나 유료 선택이 막혀요 | 현재 플랜/체험·판매자·연결 자료/파일·대표 이미지 등 준비 조건을 확인합니다 |
| 결제했는데 내 자료에 없어요 | 사이트·계정·원 주문/구성·전체/페이지·조회 오류·실제 권리를 대조합니다. 재결제·임의 재지급으로 확인하지 않습니다 |
| 받음인데 파일을 못 찾거나 안 열려요 | 발급 이력과 기기 저장/열기는 별개입니다. 다운로드 내역·위치·원 파일과 오류를 확인합니다 |
| 발급 실패·안전 경고·이용불가가 나와요 | 현재 권한·파일/처리 상태와 문구를 담당자에게 확인합니다. 반복 발급·직접 주소·보안 해제로 우회하지 않습니다 |
| 새 파일로 바꿨는데 예전 파일을 받아요 | 원 주문에 기록된 버전과 권리에 연결된 파일을 확인합니다. 기존 구매자 자동 최신본 제공을 보장하지 않습니다 |

문의에는 사이트·자료/상품 이름·파일명·지급일, 원 주문 식별에 필요한 최소 정보, 현재 필터/표시 상태, 발생 시각·기기/브라우저·오류 문구와 실제 저장/열기 여부를 남깁니다. 비밀번호·인증번호·서명 다운로드 URL·토큰·유료 원문이나 개인 파일 목록은 공유하지 않습니다.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 별도 디지털 자료와 강의/공지 첨부·교재를 구분했습니다.
- [ ] 허용 형식의 최종 파일 하나와 내용·판본·개인정보를 확인했습니다.
- [ ] 업로드·자료 저장·현재 파일 연결/상태를 각각 확인했습니다.
- [ ] 상품의 연결 자료·대표 이미지·구성 금액/할인·과세와 판매 상태를 확인했습니다.
- [ ] 승인된 구매 검수에서 원 주문·자료 권한·해당 파일 버전을 대조했습니다.
- [ ] 받음/주소 발급 이력과 실제 기기 저장·파일 열기 결과를 구분했습니다.
- [ ] 취소 영향·임시 주소·기기별 차이와 파일 교체 전후의 버전 기준을 확인했습니다.
- [ ] 중복 생성·재결제·임의 재지급·반복 발급 없이 미확인 결과와 담당자를 기록했습니다.
