# 첫 강좌 판매하기

> **검토용 가이드** · 실제 서비스 화면·동작 확인과 이미지 보완이 남아 있습니다. 본문의 실행 보류·주의사항을 먼저 확인하세요.

<figure><img src="../.gitbook/assets/branding/getting-started-illustration-v1.png" alt="시작하기 대표 이미지"><figcaption></figcaption></figure>

강좌 하나에 수업과 영상을 준비하고, 학생이 구매할 상품으로 연결합니다. **강좌는 학습 콘텐츠, 상품은 판매 구성과 가격을 관리하는 단위**입니다. 강좌를 발행했다고 상품이 자동으로 판매되거나 학생에게 수강권이 지급되는 것은 아닙니다.

**진행 순서:** 판매 준비 확인 → 강좌 정보 → 수업·영상 → 강좌 발행 결과 → 상품 구성·가격/기간 → 판매 상태·방문자 확인 → 원 주문·수강 권한·재생 확인

**완료 기준:** 대상 강좌와 상품의 연결·판매 조건을 확인하고, 승인된 구매 테스트에서 같은 주문의 결제 상태·수강 권한·실제 이용 기간·학습 접근과 재생 결과를 구분해 확인합니다. 상품 생성 알림이나 결제 완료 제목만으로 전체 완료를 판단하지 않습니다.

## 이번에 만들 예제 <a href="#example" id="example"></a>

| 구분 | 설명용 예시 |
| --- | --- |
| 강좌 | 중등 수학 일차방정식 시작하기 |
| 섹션 | 일차방정식 기초 |
| 수업 | 일차방정식 기본 개념 / 기본 예제 풀이 |
| 영상 | `01-일차방정식-기본개념.mp4` / `02-기본예제-풀이.mp4` |
| 판매 상품 | 위 강좌 하나를 포함한 **강좌** 유형 상품 |
| 가격·할인 | 유료, 구성 금액 50,000원, 할인없음 |
| 수강 기간 | 직접입력 30일 |
| 포함하지 않는 것 | 교재·별도 디지털 자료·옵션·쿠폰 |

이름·금액·기간은 설명용이며 클킷의 기본값·권장 가격이나 실제 결제 승인이 아닙니다. 실제 상품에는 담당자가 확정한 값을 사용합니다. 교재나 별도 디지털 자료를 함께 판매하려면 패키지 구성을 확인하고 [판매 준비 체크리스트](sales-readiness-checklist.md)의 재고·배송·자료 제공 항목도 적용합니다. 강의에 붙이는 첨부자료와 별도 판매 자료는 같은 것이 아닙니다.

## 시작 전 확인 <a href="#before-you-start" id="before-you-start"></a>

- [ ] 사용할 사이트와 담당 계정의 콘텐츠·상품 변경 권한을 확인했습니다.
- [ ] [계정과 사이트 만들기](account-and-site-create.md)의 기존 사이트·설정 상태를 확인했습니다.
- [ ] [판매 준비 체크리스트](sales-readiness-checklist.md)의 적용 항목과 남은 조건을 정리했습니다.
- [ ] 현재 플랜·체험의 유료 등록/판매 제한과 판매자 신청·심사 상태를 확인했습니다.
- [ ] 강좌 소개·썸네일·수업 목록·사용 가능한 영상 원본을 준비했습니다.
- [ ] 실제 작업과 구매 검수의 대상·권한·금액·허용 동작을 구분했습니다.

적용 조건이 미확인이면 등록·판매 준비 완료로 넘기지 않습니다. **기본 Free 시작과 상위 플랜 14일 체험은 다르며, 체험 중 유료 등록·판매 제한을 무료 상품/쿠폰 0원 처리로 우회하지 않습니다.** 플랜은 [플랜·무료체험과 구독 시작하기](../subscription-and-usage/plan-trial-and-subscription-start.md), 판매자 준비는 [판매자 등록·심사 확인하기](../sellers-and-settlements/seller-registration-and-review.md)에서 확인합니다. 판매자 승인과 정산금 지급 완료도 구분합니다.

## 1. 강좌 기본 정보 입력하기 <a href="#step-1" id="step-1"></a>

1. 관리자 **콘텐츠 관리**에서 강좌 생성으로 들어갑니다. 콘텐츠 유형 선택이 표시되면 **강좌**를 선택합니다.
2. **기본 정보 설정**에 제목·요약·카테고리·썸네일을 입력합니다.
3. **강좌 상세 정보**에 수강 대상·학습 범위·수업 방식·준비물을 작성합니다.
4. 저장 안내와 입력 오류를 확인하고 **다음**으로 **영상 업로드 및 섹션 구성**에 이동합니다.

예제 요약은 `일차방정식의 개념을 익히고 기본 예제를 풉니다.`처럼 준비합니다. 수강생 이름·연락처·인증정보는 소개에 넣지 않습니다. 이미 같은 강좌를 만들었다면 목록에서 기존 대상을 확인하고 이어서 수정합니다. 상세 입력은 [강좌 등록·수정하기](../content-management/course-create-and-edit.md)를 참고합니다.

> **화면 예시 준비 중** · 강좌 콘텐츠의 제목과 소개를 준비합니다.

## 2. 섹션·수업을 만들고 영상 연결하기 <a href="#step-2" id="step-2"></a>

1. **섹션 및 수업 관리**에서 `일차방정식 기초` 섹션을 만듭니다.
2. 해당 섹션의 **수업 추가**로 두 수업을 준비하고 제목·순서를 확인합니다.
3. 각 수업을 열어 **영상 관리 → 새 영상 업로드**에서 맞는 파일을 선택합니다. 같은 강좌에 이미 올린 영상이면 기존 목록에서 선택합니다.
4. 업로드 결과, 해당 수업에 연결된 파일명·길이, 영상 처리 상태를 각각 확인합니다.
5. 수업 내용과 필요한 첨부자료, 섹션/수업 공개 범위와 구매 전 미리보기 대상을 확인합니다.

파일 전송 완료와 수업 연결·변환·재생 가능은 다릅니다. 처리 중·실패 상태가 남으면 판매 준비가 끝난 것으로 판단하지 않습니다. 관리자 재생 확인도 구매자 권한의 재생 확인을 대신하지 않습니다.

휴대폰 영상은 [업로드 파일 기준](../content-management/video-upload.md)을 먼저 확인하고, 필요하면 원본을 보관한 채 [영상 용량 줄이기](../content-management/video-optimization.md)로 별도 변환본을 준비합니다. 지원 확장자라도 내부 코덱의 변환 성공은 별도이며, 확장자 이름만 바꾸지 않습니다. 자세한 순서·공개 설정은 [커리큘럼 구성하기](../content-management/curriculum.md)를 참고합니다.

> **화면 예시 준비 중** · 파일 업로드, 수업 연결과 영상 처리를 각각 확인합니다.

## 3. 강좌 저장·발행 결과 확인하기 <a href="#step-3" id="step-3"></a>

| 목적 | 할 일 | 다음으로 넘어갈 기준 |
| --- | --- | --- |
| 계속 작업할 강좌 보관 | **임시 저장** 후 같은 강좌 재조회 | 소개와 섹션·수업이 저장됨. 학생 반영 완료는 아님 |
| 강좌 생성·수정 화면에서 발행 | **화면 미리보기**로 점검한 뒤 **최종 완료** | 강좌 상세의 발행 결과를 확인. 발행중·실패를 완료로 처리하지 않음 |
| 잘못된 저장/응답 유실 확인 | 기존 목록·상세의 같은 강좌 대조 | 반영 여부 확인 전 재생성·삭제·반복 발행하지 않음 |

커리큘럼 저장·완료에는 **섹션 1개 이상, 모든 섹션에 수업 1개 이상**이 필요합니다. 예제에서는 한 섹션에 두 수업이 있는지 확인합니다. 빈 섹션을 그대로 두고 완료 처리하지 않습니다.

강좌 상세의 **수업 추가**로 들어가면 작업본만 저장되는 경우가 있습니다. 모든 `완료` 버튼을 강좌 생성·수정 화면의 **최종 완료**와 같은 발행 동작으로 해석하지 않습니다. 공개 수업 설정도 모든 방문자 무료 시청을 뜻하지 않으며, 미리보기·구매자 수강 권한은 따로 확인합니다.

> **화면 예시 준비 중** · 강좌 저장과 발행 결과를 구분합니다.

## 4. 판매 상품에 강좌 연결하기 <a href="#step-4" id="step-4"></a>

1. 관리자 **상품 목록 → 상품 생성 → 상품 종류 선택**으로 이동합니다.
2. 이 예제는 **강좌**를 선택하고 **다음 단계**로 이동합니다. 여러 강좌나 교재·자료를 묶을 때는 **패키지**를 확인합니다.
3. **콘텐츠 선택 → 선택하기**에서 앞서 만든 강좌를 찾습니다.
4. 대상 강좌 하나를 선택하고 선택 창의 **등록**을 누릅니다.
5. 상품 입력 화면에서 연결한 강좌와 상품 제목·이미지·소개를 대조합니다.

선택 창의 **등록**은 선택 결과를 가져오는 동작이며 상품 생성 완료가 아닙니다. 상품 제목이 강좌 제목과 비슷해도 **실제 연결된 강좌**를 확인합니다. 새 화면의 제공 수량은 콘텐츠당 1이며 수량 편집 입력이 있다고 가정하지 않습니다. 자세한 구성은 [상품 만들고 콘텐츠 연결하기](../products-and-coupons/create-products-and-connect-content.md)를 참고합니다.

> **화면 예시 준비 중** · 판매할 상품에 의도한 강좌를 연결합니다.

## 5. 가격·수강 기간·과세 조건 정하고 생성하기 <a href="#step-5" id="step-5"></a>

| 항목 | 이 예제에서 확인할 값 | 주의할 점 |
| --- | --- | --- |
| 구성 금액 | 선택한 강좌 옆 50,000원 | 합계 칸을 직접 바꾸는 방식이 아니며 콘텐츠 정가와 구분 |
| 무료/유료·할인 | 유료, 할인없음 | 상품 가격과 주문의 쿠폰·옵션 포함 최종액은 별도 |
| 수강 기간 | 직접입력 30일 | 유료 강좌 포함 상품은 1~365일. 저장 일수와 실제 지급된 시작·종료일은 별도 |
| 과세 설정 | 판매자가 확인한 콘텐츠별 과세/면세 | 강좌라는 이유만으로 자동 면세 확정하지 않음. 면세 선택 시 책임 확인 필요 |

이 예제는 강좌만 포함하므로 교재 배송비·출고 재고 항목은 적용하지 않습니다. 실제 구성이나 옵션에 교재를 추가했다면 예제 금액을 그대로 쓰지 않고 [판매 준비 체크리스트](sales-readiness-checklist.md)의 배송/재고 항목까지 다시 확인합니다.

**수강 기간 → 캘린더 지정**을 쓰더라도 선택 날짜는 일수로 저장됩니다. 모든 학생의 고정 종료일을 설정하는 기능으로 안내하지 않습니다. 예제의 30일만으로 학생의 정확한 만료 시각을 임의 계산하지 않습니다. 무료 강좌의 기간 차이나 빈 값을 무제한 판매 지원으로 확장하지 않습니다.

입력값·대표 이미지·판매 조건을 확인한 뒤 **최종 완료**로 상품 생성 결과를 확인합니다. 이 버튼은 강좌 발행 때의 동명 버튼과 작업 대상이 다르며, **상품 생성은 판매 시작과 별도**입니다. 현재 생성 화면의 **임시저장**은 비활성이므로 입력 중 저장을 보장하지 않습니다. 오류나 응답 유실이 있으면 목록·상세부터 확인하고 같은 상품을 중복 생성하지 않습니다.

세부 입력은 [가격·할인·수강 기간](../products-and-coupons/price-discount-and-valid-days.md)과 [과세·면세 정보](../products-and-coupons/tax-settings.md)를 참고합니다. 이 문서는 과세 여부의 법률 판단을 대신하지 않습니다.

> **화면 예시 준비 중** · 상품 가격과 수강 일수를 정하고 콘텐츠별 과세 조건을 확인합니다.

## 6. 판매 상태와 학생이 보는 상품 확인하기 <a href="#step-6" id="step-6"></a>

| 상황 | 다음 작업 | 확인할 결과 |
| --- | --- | --- |
| 아직 신규 판매하지 않음 | 생성 뒤 **비공개로 저장** | 생성된 상품이 판매 중지 상태로 보관됨. 입력 중 임시 저장이나 사이트 전체 비공개와 다름 |
| 생성 직후 판매 시작 | 준비 조건 확인 후 완료 화면의 **판매 시작** | 상품 목록·상세를 다시 열어 상태와 판매 준비 안내 대조 |
| 보관한 상품 판매 시작 | **상품 상세 → 운영 설정 → 판매 상태 변경 → 판매 중 → 변경 적용** | 같은 상품의 상태 변경 결과와 부족한 조건 재확인 |

판매 시작이 거절되면 대표 이미지·연결 강좌·기간·판매자/플랜 등 해당 안내부터 확인합니다. 창이 닫혔거나 강좌가 발행됐다는 사실만으로 **판매 중**이 된 것은 아닙니다. 상태 변경·복구 후 실제 구매 가능 여부도 별도로 확인합니다. 자세한 조건은 [재고·판매 상태 관리하기](../products-and-coupons/stock-and-sales-status.md)를 참고합니다.

사이트에서 상품을 찾을 수 있는 경로와 상품 상세의 제목·포함 강좌·가격·기간을 PC/모바일에서 대조합니다. 공개 페이지·메뉴 연결과 상품 판매 상태는 별개입니다. 상품이 안 보이면 [페이지·메뉴](../site-and-communication/pages-and-menus.md)의 제공 범위와 실제 연결을 확인하고, **커스텀 빌더의 대상 연결 문제 해결 전 편집·저장·게시 중단**을 유지합니다. 관리자 미리보기를 학생 구매 화면으로 대신하지 않습니다.

학생 상품 화면의 옵션·기간 표시와 실제 구성은 아직 확인이 필요합니다. 메뉴가 보이지 않거나 모바일에서 수강기한을 확인할 수 없다면 해당 기능이 제공된다고 가정하지 않습니다. 수강생 가이드의 **상품 구성·가격·이용 기간**과 대조해 확인되지 않은 내용은 판매 안내 완료로 처리하지 않습니다.

> **화면 예시 준비 중** · 상품 판매 상태와 학생이 보는 상품 결과를 따로 확인합니다.

> **동작 예시 준비 중** · 기존 상품의 연결 강좌와 판매 상태를 확인하는 예시입니다.

## 7. 같은 주문의 결제와 실제 수강 확인하기 <a href="#step-7" id="step-7"></a>

이 단계는 **별도 승인된 테스트 사이트·구매자 계정·상품·금액·허용 동작**이 준비됐을 때만 확인합니다. 가능하면 기존 수강권이 없는 가상 구매자를 기준으로 준비하며, 이미 권리가 있다면 이번 주문에 연결된 수강권을 담당자가 대조합니다. 운영자·강사 계정의 미리보기나 학생 비밀번호를 받아 대신 로그인하는 방식은 사용하지 않습니다.

### 원 주문·결제 결과 대조 <a href="#section-10" id="section-10"></a>

1. 구매자 계정의 상품·장바구니에서 대상 강좌와 금액을 확인합니다. 실제 구매 절차는 수강생 가이드의 **장바구니·쿠폰**과 수강생 가이드의 **결제·무료 상품 신청**을 따릅니다.
2. 실행 범위가 승인된 경우에만 주문서·결제를 진행합니다. 실제 표시되는 결제수단·필수 동의·최종 금액을 확인하며 모든 사이트에 같은 결제수단이 있다고 가정하지 않습니다.
3. 결과 뒤 구매자의 **마이페이지 → 구매 내역 → 결제**에서 원 주문번호·구매 상품·금액·상태를 대조합니다. 입금대기·처리 중은 결제 완료가 아닙니다.
4. 운영자는 **결제/정산관리 → 결제 내역 → 상세 보기**에서 같은 주문을 확인합니다. 결제 상세를 구성품별 지급 완료 전용 화면으로 설명하지 않습니다.

**주문서 진입은 조건에 따라 주문 생성·예약으로 이어질 수 있으며, 최종 0원이면 별도 결제 버튼 전 자동 처리될 수 있습니다.** 결제창·완료 화면을 보기 위한 촬영용 주문서 진입도 실행 범위에 포함해야 합니다. 카드/은행 알림·완료 제목·복귀 주소만으로 결제나 권리 지급을 확정하지 않습니다. 결과가 불명확하면 기존 주문부터 확인하고 재결제·0원 재신청·승인/결제 결과 URL 재진입을 반복하지 않습니다.

### 구매한 강좌와 이용 결과 대조 <a href="#section-11" id="section-11"></a>

1. 구매자의 **마이페이지 → 내 학습 → 수강중 강좌**에서 **전체** 조건과 페이지를 확인합니다. 빈 목록과 조회 오류를 구분합니다.
2. 대상 강좌·표시 기간/종료일을 원 주문의 구성과 연결된 수강권에 대조합니다. 목록의 `N일`은 남은 날짜 수가 아니며 실제 권리·만료 상태를 함께 확인합니다.
3. 별도 승인 범위에서 활성 **썸네일**로 강의실에 들어가 강좌명·수업 제목과 목차를 확인합니다. **강좌 제목**은 소개 화면으로 이동하는 동작이므로 실제 학습 접근과 구분합니다.
4. 승인된 범위에서 영상을 재생해 대상 수업의 화면·목소리·시작/중간/끝 구간을 확인합니다. 다른 수업이 자동 선택됐다면 제목부터 확인하며 최근 시청순 복귀를 보장하지 않습니다.
5. PC/모바일의 접근·재생 결과와 확인하지 못한 항목을 각각 기록합니다. 확인하지 못했거나 실패한 항목이 있으면 첫 판매 흐름을 확인 완료로 표시하지 않습니다.

**결제 완료·수강권 지급·강의실 진입·실제 재생은 다른 결과입니다.** 강의실 진입/플레이어 조회와 재생은 이용·진도·사용량 기록으로 이어질 수 있으므로 단순 조회 촬영으로 취급하지 않습니다. 일반/외부 영상의 재생·기록 방식도 같다고 보장하지 않습니다. 자료 버튼은 다운로드로 이어질 수 있어 수강 접근 확인용으로 누르지 않습니다.

상세 확인은 [구매 후 콘텐츠 지급](../orders-and-shipping/content-fulfillment-check.md), 수강생 가이드의 **내 강의·수강 시작**, 수강생 가이드의 **PC·모바일 영상**, 수강생 가이드의 **기간·학습 현황**을 참고합니다. 실제 이용 확인은 승인된 테스트 범위에서 진행합니다.

> **화면 예시 준비 중** · 같은 주문의 결제, 수강 권한과 실제 이용 결과를 구분합니다.

## 자주 막히는 부분 <a href="#troubleshooting" id="troubleshooting"></a>

| 상황 | 먼저 확인할 것 |
| --- | --- |
| 강좌를 저장했는데 판매 상품이 없어요 | 강좌 저장/발행과 상품 생성은 별개입니다. 기존 강좌를 다시 만들지 말고 연결할 상품을 확인합니다 |
| 섹션을 만들었는데 완료가 안 돼요 | 섹션 1개 이상과 모든 섹션의 수업 유무·입력 오류를 확인합니다 |
| 영상을 올렸는데 수업이 비어 있거나 재생이 안 돼요 | 업로드·수업 연결·변환 상태·발행/공개·수강 권한을 차례로 구분합니다. 같은 파일을 반복 업로드하거나 삭제하지 않습니다 |
| 유료 선택이나 판매 시작이 막혀요 | 실제 플랜/체험·판매자 상태·상품별 판매 준비 안내를 확인합니다. 무료 등록·다른 계정으로 우회하지 않습니다 |
| 최종 완료했는데 판매 중지예요 | 상품 생성과 판매 시작을 구분합니다. 기존 상품의 판매 상태·부족한 조건을 확인합니다 |
| 판매 중인데 학생 화면에서 안 보여요 | 사이트·상품·메뉴/공개 경로·현재 제공 범위를 확인합니다. 빌더 대상 문제를 운영 메인 페이지에서 재현하지 않습니다 |
| 결제했는데 강좌가 없어요 | 원 주문·구매자 계정·구성·필터/조회 오류·실제 수강권을 대조합니다. 재결제나 확인용 수강권 지급으로 맞추지 않습니다 |
| 강좌는 있는데 기간이나 재생이 달라요 | 이번 주문에 연결된 권리·실제 기간·선택 수업·영상 상태를 확인합니다. 상품 기간 수정이 기존 권리 자동 연장은 아닙니다 |

문의에는 사이트·강좌/상품 이름, 막힌 단계, 오류 문구·시각·기기/브라우저, 구매 과정 확인 중이라면 원 주문 식별에 필요한 최소 정보를 남깁니다. 비밀번호·인증번호·카드/계좌 전체 번호·SSO/영상 URL·실제 학생 명단은 보내지 않습니다. 수강권의 별도 지급·연장·회수는 [수강권·이용 기간 관리하기](../members-and-operations/enrollment-and-access-period.md)의 별도 운영 절차이며 구매 지급 성공을 증명하는 우회 수단이 아닙니다.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 같은 사이트의 강좌와 판매 상품을 구분했습니다.
- [ ] 강좌 소개·썸네일·섹션/수업·영상 연결을 확인했습니다.
- [ ] 공개/미리보기·업로드/변환·저장/발행 결과를 각각 확인했습니다.
- [ ] 상품의 연결 강좌·대표 이미지·가격·수강 일수·과세 조건을 확인했습니다.
- [ ] 상품 생성·미판매 보관·판매 상태 변경과 방문자 결과를 구분했습니다.
- [ ] 승인된 구매 검수에서 원 주문·결제 상태와 이번 주문의 수강 권한을 대조했습니다.
- [ ] 구매자 계정의 실제 기간·강의실 대상·PC/모바일 재생과 미확인 결과를 기록했습니다.
- [ ] 오류 시 중복 생성·재결제·임의 재지급을 하지 않고 남은 조건을 담당자에게 확인했습니다.
