# 정산 계좌 등록·변경하기

<figure><img src="../.gitbook/assets/branding/page-headers/sellers-and-settlements/settlement-bank-account-v2.png" alt="정산 계좌 등록·변경하기 대표 이미지"><figcaption></figcaption></figure>

**업무 대상:** 사이트 소유자와 판매자·정산 업무 담당자용 안내입니다. 강사가 담당 강좌를 운영하기 위해 판매자 정보나 정산 계좌를 직접 등록할 필요는 없습니다. 관련 요청은 학원의 정산 담당자에게 전달하세요. 실제 작업 가능 범위는 본인 계정의 권한을 확인하세요.

정산에 사용할 계좌를 입력하고 인증 상태를 확인합니다. 실제 등록·인증·변경은 **사이트 소유자**가 진행합니다.

**계좌 정보 입력·저장, 계좌 인증, 외부 정산 계좌 반영, 실제 정산금 지급은 서로 다릅니다.** 계좌 인증 완료만으로 판매·정산 전체가 활성화됐다고 판단하지 않습니다.

**작업 순서:** 계좌 정보 확인 → 입력 → 계좌 인증 → 등록 상태 재조회 → 신청·반영 상태 별도 확인

## 시작 전 준비 <a href="#before-you-start" id="before-you-start"></a>

| 준비할 것 | 확인 기준 |
| --- | --- |
| 작업 계정 | 사이트 소유자 계정과 정산 설정 접근 권한 |
| 사업자 정보 | 사업자 정보 준비 여부. [판매자 등록 가이드](seller-registration-and-review.md) 참고 |
| 계좌 | 사용할 은행·계좌번호·예금주명 |
| 인증 정보 | 현재 인증 화면에서 요구하는 예금주의 생년월일 |
| 선택 증빙 | 통장 사본. 제출할 경우 계좌 정보와 일치하는 파일 |
| 변경 전 확인 | 기존 신청·정산·지급 진행 여부와 변경 담당자 |

생년월일과 계좌번호를 일반 문의·단체 대화방·가이드 캡처로 공유하지 않습니다. 인증 입력은 서비스의 해당 화면에서 진행하세요.

## 메뉴 위치 <a href="#menu-location" id="menu-location"></a>

관리자 화면의 **결제/정산관리 → 정산 설정**으로 이동합니다. 계좌 등록이 필요한 경우 계좌 입력 영역이 표시됩니다.

> **화면 예시 준비 중** · 실제 지급 계좌와 일치하는 정보를 입력해 인증합니다.

## 1. 계좌 정보 입력하기 <a href="#step-1" id="step-1"></a>

1. **성함**에 예금주명을 입력합니다.
2. **생년월일**에 현재 화면이 요구하는 `YYMMDD` 형식의 6자리를 입력합니다.
3. **계좌 은행**에서 사용할 은행을 선택합니다.
4. **계좌 번호**를 하이픈(`-`) 없이 입력하고 예금주·은행과 일치하는지 확인합니다.

은행이 목록에 없거나 계좌 유형에 맞는 인증 방법이 보이지 않으면 임의로 다른 은행·예금주 정보를 선택하지 않습니다. 법인 등 현재 입력 방식으로 인증 가능한지 불확실한 계좌는 담당자에게 확인하세요.

## 2. 입금 계좌 인증하기 <a href="#step-2" id="step-2"></a>

입력 정보를 확인한 뒤 **입금 계좌 인증**을 누릅니다. 인증 중에는 같은 요청을 반복하거나 계좌 정보를 동시에 바꾸지 않습니다.

인증이 성공하면 화면을 다시 열어 은행·계좌번호·예금주와 인증 상태를 확인합니다. 현재 확인한 등록 절차는 **인증 요청으로 계좌 정보를 저장하고 인증 결과를 반영하는 방식**이므로, 통장 사본을 첨부하지 않아도 인증을 시작할 수 있습니다.

인증이 실패하면 오류 안내와 입력 정보를 확인합니다. 계좌 정보가 화면에 남아 있어도 인증 완료로 판단하지 않습니다.

> **화면 예시 준비 중** · 계좌 정보와 인증 결과를 다시 확인합니다. 외부 반영 결과는 별도입니다.

> **동작 예시 준비 중** · 인증 후 저장된 정보와 인증 상태를 확인합니다. 지급 실행은 포함하지 않습니다.

### 통장 사본은 필수인가요? <a href="#section-5" id="section-5"></a>

**통장 사본 첨부는 클킷에서 선택 사항입니다.** 추가 보완을 요청받았거나 필요한 경우에만 해당 안내에 따라 준비합니다.

계좌 입력 영역에서 파일을 첨부할 수 있지만, **현재 확인한 화면의 `저장` 버튼은 통장 사본이 없으면 비활성화되는 차이가 있습니다.** 저장 버튼이 비활성화되어도 통장 사본이 필수 서류로 바뀐 것은 아닙니다. 저장이 막히면 불필요한 파일을 올려 우회하지 말고 담당자에게 확인하세요.

파일 업로드가 끝나도 계좌 정보에 증빙이 함께 저장됐는지 별도로 확인해야 합니다. 첨부·교체를 진행했다면 저장 후 다시 연 화면에서 파일 정보를 확인합니다. 계좌 인증만으로 첨부 파일까지 저장됐다고 가정하지 않습니다.

> **화면 예시 준비 중** · 통장 사본 업로드와 계좌에 저장된 결과를 구분합니다.

## 3. 기존 계좌 변경하기 <a href="#step-3" id="step-3"></a>

먼저 계좌 입력·요약 영역과 **수정** 버튼이 보이는지 확인합니다. 현재 확인한 화면은 신청 이후 계좌 영역이 표시되지 않는 경우가 있어, **모든 신청·승인 상태에서 같은 버튼으로 변경할 수 있다고 안내하지 않습니다.** 버튼이 없으면 담당자에게 변경 방법을 확인합니다.

계좌 영역과 수정 버튼이 표시되는 경우에는 다음을 확인합니다.

1. 기존 은행·계좌번호·예금주와 정산·지급 진행 여부를 확인합니다.
2. **수정**을 누릅니다. 인증된 입력란이 잠겨 있으면 **인증 초기화**로 입력 상태를 엽니다.
3. 변경할 정보를 입력하고 새 정보로 **입금 계좌 인증**을 진행합니다.
4. 증빙을 변경했다면 해당 저장 결과도 별도로 확인합니다.
5. 정산 설정을 다시 열어 변경된 정보·인증 상태를 확인합니다.

**인증 초기화 버튼을 눌렀다는 사실만으로 외부 정산 계좌가 변경된 것은 아닙니다.** 은행·계좌번호·예금주 변경에는 새 정보에 대한 인증이 필요하며, 이전 인증 결과를 그대로 적용하지 않습니다.

> **화면 예시 준비 중** · 변경한 계좌 정보를 다시 인증하고 반영 여부는 별도로 확인합니다.

## 4. 신청·계좌 반영과 지급 구분하기 <a href="#step-4" id="step-4"></a>

첫 등록 이후의 신청은 [판매자 등록·심사 확인하기](seller-registration-and-review.md)를 따릅니다. 이미 신청한 판매자의 계좌 변경은 실제 외부 반영 결과를 별도로 확인해야 합니다.

| 확인 단계 | 확인할 것 | 뜻하지 않는 것 |
| --- | --- | --- |
| 입력·저장 | 다시 연 화면에 의도한 계좌 정보가 있음 | 계좌 인증·외부 반영 완료 |
| 계좌 인증 | 해당 정보로 인증이 완료됨 | 판매 승인·지급 계좌 반영 완료 |
| 외부 계좌 반영 | 담당자가 실제 반영 결과를 확인 | 정산금 지급 완료 |
| 실제 지급 | 해당 정산 건의 지급 결과 | 모든 정산 건의 지급 완료 |

지급이 진행 중이면 새 계좌 반영이 보류될 수 있습니다. **현재 화면에서 반영·보류 결과가 명확하지 않으면 저장 또는 인증 성공만으로 다음 지급이 새 계좌로 들어온다고 확답하지 않습니다.** 반영 여부와 해당 정산 건의 지급 계좌를 담당자에게 확인하세요.

회차별 금액과 지급 결과의 구분은 [정산 금액·지급 상태 확인하기](settlement-amount-and-payout-status.md)를 참고하세요.

결과가 불명확하거나 이전 계좌가 보이면 변경·인증·신청을 반복하지 않습니다. 발생 시각과 상태·오류 문구를 정리해 확인을 요청하고, 전체 계좌번호나 생년월일은 일반 문의에 첨부하지 않습니다.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 은행·예금주·계좌번호가 의도한 정보와 일치합니다.
- [ ] 다시 조회한 화면에서 해당 계좌의 인증 상태를 확인했습니다.
- [ ] 증빙을 첨부했다면 업로드와 저장 결과를 각각 확인했습니다.
- [ ] 신청 이후 변경 가능 범위와 실제 반영 확인 방법을 확인했습니다.
- [ ] 계좌 반영과 각 정산 건의 지급 결과를 구분했습니다.

## 자주 막히는 부분 <a href="#troubleshooting" id="troubleshooting"></a>

| 상황 | 확인할 것 |
| --- | --- |
| 인증 버튼이 비활성화돼요 | 은행·예금주·계좌번호·생년월일 입력과 처리 중 여부를 확인합니다 |
| 인증이 실패했어요 | 입력 정보와 오류 안내를 확인합니다. 저장된 값이 있어도 인증 성공은 아닙니다 |
| 통장 사본 없이 저장이 안 돼요 | 선택 증빙 정책과 현재 버튼 조건의 차이입니다. 필수로 오해하거나 불필요한 서류로 우회하지 않습니다 |
| 인증 후 첨부 파일이 없어요 | 인증과 증빙 저장은 별도입니다. 실제 파일 저장·재조회 결과를 확인합니다 |
| 계좌 정보가 잠겨 있어요 | 수정 화면에서 인증 초기화 위치를 확인합니다. 새 정보는 다시 인증합니다 |
| 신청 후 수정 버튼이 없어요 | 신청 이후 계좌를 변경하는 화면·절차는 아직 확인이 필요합니다. 담당자에게 변경 방법을 확인합니다 |
| 인증은 됐는데 지급 계좌가 바뀌지 않았어요 | 외부 반영·지급 중 보류와 해당 정산 건을 확인합니다. 인증 요청을 반복하지 않습니다 |
