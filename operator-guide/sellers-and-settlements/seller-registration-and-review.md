# 판매자 등록·심사 확인하기

> **검토용 가이드** · 실제 서비스 화면·동작 확인과 이미지 보완이 남아 있습니다. 본문의 실행 보류·주의사항을 먼저 확인하세요.

<figure><img src="../.gitbook/assets/branding/seller-settlement-illustration-v1.png" alt="판매자·정산 대표 이미지"><figcaption></figcaption></figure>

유료 상품 판매를 준비하기 위해 사업자 정보와 정산 계좌를 확인하고, 판매자 신청 이후의 심사 상태를 확인합니다. 실제 신청·계좌 변경은 **사이트 소유자**가 진행합니다.

**계좌 인증, 신청 제출, 심사 승인, 상품 판매 시작, 정산금 지급은 서로 다른 단계입니다.** 이 문서는 클킷의 준비 절차를 설명하며 법적 신고 의무를 판단하는 문서가 아닙니다.

**작업 순서:** 사업자 정보 입력·인증·저장 → 정산 계좌 인증 → 신청 내용·동의 확인 → 신청 → 상태 재조회 → 판매 준비 확인

## 시작 전 준비 <a href="#before-you-start" id="before-you-start"></a>

| 준비할 것 | 확인 기준 |
| --- | --- |
| 작업 계정 | 사이트 소유자 계정과 정산 설정 접근 권한 |
| 사업자 정보 | 사업자 구분·등록번호·상호·대표자·사업장 주소 |
| 연락처 | 대표자 이메일·휴대폰 번호와 사용할 정산 담당 연락처 |
| 정산 계좌 | 은행·계좌번호·예금주와 계좌 인증 정보 |
| 선택 증빙 | 사업자등록증·통장 사본. 추가 보완 요청이 있으면 실제 안내 확인 |

강사·질답조교라는 역할만으로 판매자 신청을 대신할 수 있는 것은 아닙니다. 메뉴가 보여도 변경·제출 권한은 별도로 확인하세요.

## 메뉴 위치 <a href="#menu-location" id="menu-location"></a>

관리자 화면의 **결제/정산관리 → 정산 설정**으로 이동합니다. 사업자 정보는 **운영 → 사이트 운영 정보 → 사업자 정보**에서 확인합니다.

> **화면 예시 준비 중** · 계좌 준비와 판매자 신청 상태를 구분해 확인합니다.

## 1. 사업자 정보 준비하기 <a href="#step-1" id="step-1"></a>

1. **사이트 운영 정보**의 **사업자 정보** 탭을 엽니다.
2. 사업자 구분과 사업자등록번호를 입력하고 **번호 인증**을 누릅니다.
3. 상호명·대표자명·대표자 휴대폰 번호·대표자 이메일을 확인합니다. 법인사업자를 선택했다면 법인등록번호도 확인합니다.
4. 정산 담당자 이메일을 확인하고, **주소 검색**으로 사업장 주소를 입력합니다. 상세 주소도 확인합니다.
5. 필요한 경우 사업자등록증을 첨부하고 **저장**을 누릅니다.
6. 저장 후 화면을 다시 열어 정보와 인증 상태를 확인합니다.

번호 인증만 끝냈다고 나머지 정보까지 저장된 것은 아닙니다. 신청 전에는 실제로 저장된 상호·대표자·연락처·주소를 확인하세요.

**사업자등록증 첨부는 클킷에서 선택 사항입니다.** 신청 확인표에 첨부 항목이 표시되더라도 모두 필수라는 의미로 해석하지 않습니다. 추가 서류·본인 확인을 요청받았다면 해당 요청의 항목과 제출 방법을 따릅니다.

> **화면 예시 준비 중** · 번호 인증 후 나머지 사업자 정보를 저장하고 다시 확인합니다.

## 2. 정산 계좌 인증하기 <a href="#step-2" id="step-2"></a>

[정산 계좌 등록·변경하기](settlement-bank-account.md)에 따라 은행·계좌번호·예금주를 입력하고 인증합니다. 정산 설정을 다시 열어 **계좌 인증 완료** 상태를 확인하세요.

계좌가 인증되지 않았거나 정보가 맞지 않으면 신청을 진행하지 않습니다. 통장 사본은 선택 증빙이지만, 현재 확인한 화면에서는 첨부 여부에 따라 저장이 제한되는 차이가 있습니다. 자세한 조건은 계좌 가이드에서 확인하세요.

## 3. 정산 활성화 신청하기 <a href="#step-3" id="step-3"></a>

계좌가 인증되어 있고 아직 신청하지 않았다면 **정산 활성화 신청하기**를 눌러 제출 전 확인으로 이동합니다.

1. 사업자 정보와 정산 계좌의 인증 상태를 확인합니다.
2. **확인하기**로 필요한 정보를 점검합니다. 해당 버튼은 정보 확인 화면으로 이동하는 동작이며 신청 제출 자체가 아닙니다.
3. 개인정보 수집·이용 동의 내용을 확인합니다. 필요하면 **전문보기**를 엽니다.
4. 동의 항목을 선택하고 **정산 활성화 신청 제출**을 누릅니다.
5. 요청 결과를 확인한 뒤 정산 설정을 다시 열어 신청 상태를 확인합니다.

제출 버튼이 비활성화되어 있으면 사업자·계좌 인증과 동의 여부부터 확인합니다. 제출 중에는 버튼을 반복해서 누르거나 정보를 동시에 변경하지 않습니다.

**제출 성공 알림만으로 심사 승인이나 정산금 지급이 완료됐다고 판단하지 않습니다.** 신청 이후 상태가 그대로이거나 오류가 있으면 현재 안내를 확인하고 담당자에게 문의하세요. 결과가 불명확한 신청을 반복 제출하지 않습니다.

> **화면 예시 준비 중** · 사업자·계좌 인증과 신청 내용을 확인합니다. 증빙은 선택 조건과 구분합니다.

> **동작 예시 준비 중** · 신청 요청 후 실제 상태를 다시 확인합니다. 제출은 승인·지급 완료가 아닙니다.

## 4. 심사·보완 상태 확인하기 <a href="#step-4" id="step-4"></a>

정산 설정을 다시 열어 상태 제목과 상세 안내를 함께 확인합니다. 아래는 대표적인 확인 방식이며 실제 상태 문구와 요청 내용을 우선합니다.

| 표시·상황 | 할 일 | 주의할 점 |
| --- | --- | --- |
| 신청 전 | 저장된 사업자 정보·계좌 인증을 점검하고 신청 준비 | 정보 입력만으로 신청 완료가 아님 |
| 심사 중 | 신청 내역과 현재 안내 확인 | 정해진 기간 안의 승인을 보장하지 않음 |
| 보완 요청 | 요청된 정보·서류를 확인하고 해당 위치에서 수정·저장 | 버튼을 눌러 이동한 것과 보완 제출 완료는 다름 |
| 승인 완료 | 판매 준비 조건과 정산 관련 안내를 추가 확인 | 승인 표시만으로 상품 판매 시작·지급 완료가 아님 |

### 보완 요청을 받았다면 <a href="#section-7" id="section-7"></a>

1. 보완 항목과 사유를 확인합니다. 모든 보완이 파일 재첨부를 뜻하는 것은 아닙니다.
2. 해당 사업자 정보나 증빙을 수정하고 저장합니다.
3. 정산 설정을 다시 열어 반영 결과와 다음 안내를 확인합니다.
4. 재제출 방법이 없거나 같은 요청이 남아 있으면 담당자에게 확인합니다.

**현재 확인한 화면의 `보완 항목 제출`은 사이트 운영 정보로 이동하는 버튼입니다.** 이 버튼을 눌렀다는 이유만으로 보완 내용이 다시 제출됐다고 판단하지 않습니다. 실제 재제출 방법은 아직 확인이 필요하므로 담당자에게 안내를 받으세요.

> **화면 예시 준비 중** · 보완 요청의 수정·저장과 실제 재제출을 구분해 확인합니다.

## 5. 상품의 판매 준비 확인하기 <a href="#step-5" id="step-5"></a>

판매자 준비 이후에는 [재고·판매 상태 관리하기](../products-and-coupons/stock-and-sales-status.md)에 따라 상품별 판매 준비와 판매 상태를 확인합니다. 승인되었다고 모든 상품이 자동으로 판매 중이 되는 것은 아닙니다.

정산 계좌의 외부 반영은 [정산 계좌 등록·변경하기](settlement-bank-account.md), 회차별 금액과 실제 지급 결과는 [정산 금액·지급 상태 확인하기](settlement-amount-and-payout-status.md)에서 구분합니다. 계좌 인증·신청·승인 화면만으로 실제 지급 완료를 안내하지 마세요. 무료 상품과 할인·쿠폰 적용 후 0원 주문도 같은 조건이라고 가정하지 않습니다.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 사이트 소유자가 사업자 정보와 계좌 정보를 확인했습니다.
- [ ] 번호 인증과 사업자 정보 저장을 각각 확인했습니다.
- [ ] 계좌 인증과 신청 결과를 구분해 확인했습니다.
- [ ] 보완 요청의 수정·저장과 재제출을 구분했습니다.
- [ ] 상품 판매 준비·계좌 반영·정산금 지급을 별도로 확인할 담당자를 정했습니다.

## 자주 막히는 부분 <a href="#troubleshooting" id="troubleshooting"></a>

| 상황 | 확인할 것 |
| --- | --- |
| 메뉴나 신청 버튼이 없어요 | 사이트 소유자 여부와 접근·변경 권한을 확인합니다 |
| 번호 인증은 됐는데 신청이 안 돼요 | 사업자 정보 저장·필수 연락처·주소·계좌 인증·동의를 확인합니다 |
| 서류를 반드시 올려야 하나요? | 사업자등록증·통장 사본은 선택 증빙입니다. 실제 추가 보완 요청은 별도로 확인합니다 |
| 제출 알림 후에도 신청 전으로 보여요 | 재조회 후 현재 안내를 확인합니다. 반복 제출하지 말고 결과 확인을 요청합니다 |
| 보완 항목 제출을 눌렀는데 정보 화면이 열려요 | 현재 버튼은 화면 이동입니다. 수정·저장 후 실제 재제출 방법을 확인합니다 |
| 승인됐는데 상품이 판매되지 않아요 | 상품별 판매 준비·재고·판매 상태를 확인합니다 |
| 승인됐는데 정산금이 들어오지 않았어요 | 계좌 반영·정산 대상·지급 상태를 별도로 확인합니다. 승인만으로 지급 완료가 아닙니다 |
