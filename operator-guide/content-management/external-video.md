# 외부 영상 연결하기

> **이용 전 확인** · 실제 서비스 화면·동작이 아직 확인되지 않은 항목이 있습니다. 문서의 제한·주의사항을 따르고, **실행 보류**로 표시한 작업은 진행하지 마세요.

<figure><img src="../.gitbook/assets/branding/content-pages/external-video-v2.png" alt="외부 영상 연결하기 대표 이미지"><figcaption></figcaption></figure>

YouTube·Vimeo에 올린 영상을 수업에 연결합니다. 파일을 클킷에 업로드하는 방식과 달리 외부 서비스의 공유·재생 설정도 함께 확인해야 합니다.

**작업 순서:** 공유 URL 준비 → 연결 방식 선택 → 링크 확인 → 길이·재생 확인 → 저장·발행 확인

## 시작 전 준비 <a href="#before-you-start" id="before-you-start"></a>

| 준비할 것 | 확인 기준 |
| --- | --- |
| 강좌와 수업 | 영상을 연결할 강좌·수업과 편집 권한 |
| 영상 사용 권한 | 직접 제작했거나 수업에 사용할 권한이 있는 영상 |
| 공유 URL | YouTube·Vimeo의 HTTPS 영상 링크. 재생목록·채널 주소나 다른 사이트 주소는 사용하지 않기 |
| 외부 서비스 설정 | 수강생이 해당 사이트 안에서 재생할 수 있는 공개·임베드 설정 |
| 기존 연결 정보 | 교체할 때는 원래 영상 URL·제목과 변경 범위 기록 |

### 직접 업로드와 구분하기 <a href="#section-2" id="section-2"></a>

| 방식 | 준비할 것 | 확인할 점 |
| --- | --- | --- |
| 직접 업로드 | 영상 파일 | 파일 형식·용량, 업로드·변환·수업 연결 |
| YouTube·Vimeo 연결 | 외부 영상의 공유 URL | 링크·영상 길이, 외부 공개·임베드 설정, 수강생 재생 |

한 수업에는 영상 하나를 연결합니다. 외부 영상을 선택하는 것은 기존 영상 옆에 두 번째 영상을 추가하는 동작이 아닙니다. 직접 업로드 방법은 [강의 영상 업로드하기](video-upload.md)를 확인합니다.

## 메뉴 위치 <a href="#menu-location" id="menu-location"></a>

강좌 생성·수정 화면의 **영상 업로드 및 섹션 구성**에서 수업을 열고 **영상 관리**로 들어갑니다. **영상 연결 방식**에서 **YouTube** 또는 **Vimeo**를 선택합니다.

> **화면 예시 준비 중** · 영상이 올라간 서비스와 같은 연결 방식을 선택합니다.

## 1. 공유 URL과 재생 설정 확인하기 <a href="#step-1" id="step-1"></a>

### YouTube <a href="#youtube" id="youtube"></a>

클킷의 연결 안내는 **공개 또는 일부 공개 영상**을 대상으로 합니다. 공유 기능으로 복사한 영상 URL을 준비하고, 소유자가 외부 사이트 재생을 제한하지 않았는지 확인합니다.

**일부 공개는 수강생 전용 보안 설정이 아닙니다.** 링크를 가진 사람이 영상을 보고 다시 공유할 수 있습니다. 클킷의 수강 권한 설정이 외부 영상 원본의 공개 범위까지 바꿔 주는 것은 아닙니다. [YouTube 공개 범위 안내](https://support.google.com/youtube/answer/157177?hl=ko)

### Vimeo <a href="#vimeo" id="vimeo"></a>

일부 공개 영상을 사용할 때는 추가 공유 키인 **privacy hash가 포함된 전체 URL**을 복사합니다. 주소 끝의 공유 키나 `h` 값을 임의로 제거하지 않습니다. [Vimeo 공개 범위 안내](https://help.vimeo.com/hc/en-us/articles/12426199699985-About-video-privacy-settings)

도메인 제한을 설정했다면 실제 **수강생 사이트 도메인**을 허용했는지 확인합니다. 관리자가 미리보는 도메인과 수강생 도메인이 다르다면 각 환경의 재생 결과도 따로 확인하세요. [Vimeo 도메인 제한 안내](https://help.vimeo.com/hc/en-us/articles/30030693052305-How-do-I-set-up-domain-level-privacy)

외부 서비스의 비공개·암호·도메인 설정은 클킷에서 자동으로 해제하지 않습니다. 로그인한 영상 소유자에게만 재생되는 상태를 수강생 재생 성공으로 판단하지 않습니다.

## 2. 링크 확인하고 영상 길이 확인하기 <a href="#step-2" id="step-2"></a>

1. 영상이 올라간 서비스와 같은 연결 방식을 선택합니다.
2. **YouTube 영상 URL** 또는 **Vimeo 영상 URL**에 공유 URL을 입력합니다.
3. **링크 확인**을 누릅니다.
4. **영상 정보 확인 중** 안내가 끝나는지 확인합니다.
5. 표시된 **영상길이**와 **미리보기**의 영상·소리를 확인합니다.

링크 형식이 맞아도 외부 재생이 차단될 수 있습니다. 원하는 영상이 재생되고 길이가 확인된 뒤 저장하세요. 링크를 바꿨다면 다시 **링크 확인**을 진행합니다.

> **화면 예시 준비 중** · 링크 확인 후 영상과 길이를 확인하고 저장합니다.

## 3. 저장하고 발행 결과 확인하기 <a href="#step-3" id="step-3"></a>

수업 편집의 **변경사항 저장**을 누른 뒤 같은 수업을 다시 열어 연결 방식·영상·길이를 확인합니다. 수업에 연결 정보를 저장하는 것과 강좌를 발행해 수강생에게 반영하는 것은 별개입니다. [강좌 등록·수정하기](course-create-and-edit.md)에 따라 작업본과 발행 결과를 확인합니다.

권한 있는 수강생 계정에서 실제 수업을 열고 재생합니다. 관리자 미리보기나 외부 서비스에서 영상이 재생된다는 사실만으로 수강생도 해당 수업을 볼 수 있다고 판단하지 않습니다.

## 4. 영상 교체하거나 연결 해제하기 <a href="#step-4" id="step-4"></a>

| 작업 | 순서 |
| --- | --- |
| 다른 외부 영상으로 교체 | 서비스 선택·새 URL 입력 → 링크 확인·길이·재생 확인 → **변경사항 저장** → 재조회·발행·수강생 결과 확인 |
| 외부 연결 해제 | 연결된 영상의 **연결 해제** → 직접 업로드 화면으로 전환된 내용 확인 → **변경사항 저장** → 재조회 |
| 직접 업로드 영상으로 전환 | 외부 연결 해제 후 [영상 업로드 안내](video-upload.md)에 따라 파일을 연결하고 최종 결과 확인 |

연결 해제는 클킷 수업에서 외부 영상 연결을 끊는 작업입니다. YouTube·Vimeo 원본 삭제와 다릅니다. 기존 직접 업로드 파일로 자동 복원되거나 취소만으로 이미 실행된 업로드 작업이 되돌아간다고 가정하지 않습니다.

> **동작 예시 준비 중** · 교체한 외부 영상이 수업에 반영됐는지 확인합니다.

## 5. 진도와 시청 상태 구분하기 <a href="#step-5" id="step-5"></a>

외부 영상은 직접 업로드 영상과 같은 **진도율·이어보기 저장을 제공하는 방식이 아닙니다**. 수강생 화면의 안내와 표시된 시청 상태를 확인합니다.

| 표시·항목 | 확인할 점 |
| --- | --- |
| 시청 전·시청 시작·시청 완료 | 외부 재생 상태가 표시되는 환경에서 확인하는 재생 상태 |
| 진도율·이어보기 | 외부 영상의 시청 상태와 동일하게 해석하지 않기 |
| 수강 인정·강좌 완료율 | 영상이 끝까지 재생됐다는 표시만으로 별도 수강 인정 기준 충족을 보장하지 않기 |

**시청 완료를 전체 구간 학습의 증명으로 사용하지 마세요.** 진도 기반 운영이 필요하면 직접 업로드 방식과 실제 지원 범위를 확인합니다. 외부 영상 교체 후의 시청 상태도 다시 조회해 확인합니다.

> **화면 예시 준비 중** · 외부 영상의 시청 상태와 진도율·이어보기는 구분합니다.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 서비스 선택과 공유 URL이 일치하며 길이가 확인됩니다.
- [ ] 저장 후 다시 열어도 의도한 영상이 연결되어 있습니다.
- [ ] 작업본·발행 결과를 확인했습니다.
- [ ] 영상 소유자의 로그인에 의존하지 않는 수강생 계정으로 PC·모바일 재생을 확인했습니다.
- [ ] 외부 공개 설정·도메인 제한과 시청 상태의 의미를 확인했습니다.

## 자주 막히는 부분 <a href="#troubleshooting" id="troubleshooting"></a>

| 상황 | 확인할 것 |
| --- | --- |
| 선택한 공급자와 URL이 일치하지 않는다고 나와요 | YouTube·Vimeo 선택과 입력한 URL의 서비스를 맞춥니다 |
| 지원하지 않는 영상 URL이라고 나와요 | 공식 HTTPS 영상 공유 URL인지 확인합니다. 채널·재생목록·다른 서비스 주소는 제외합니다 |
| 영상 길이를 확인한 후 저장하라고 나와요 | 링크 확인을 다시 진행하고 외부 플레이어의 오류와 정보 확인 결과를 확인합니다 |
| YouTube 원본은 되는데 수업에서는 안 돼요 | 비공개 전환·삭제·외부 재생 제한과 소유자 로그인 여부를 확인합니다 |
| Vimeo 영상이 없다고 나와요 | 공유 키가 포함된 전체 URL과 실제 수강생 사이트의 도메인 허용 여부를 확인합니다 |
| 관리자는 되는데 수강생은 안 돼요 | 외부 서비스 설정과 클킷의 발행·공개·미리보기·수강 권한을 각각 확인합니다 |
| 외부 영상의 진도율이 쌓이지 않아요 | 직접 업로드 영상과 외부 영상의 시청 상태·진도율·이어보기 차이를 확인합니다 |
