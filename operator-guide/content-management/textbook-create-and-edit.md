# 교재 등록·수정하기

> **검토용 가이드** · 실제 서비스 화면·동작 확인과 이미지 보완이 남아 있습니다. 본문의 실행 보류·주의사항을 먼저 확인하세요.

<figure><img src="../.gitbook/assets/branding/content-pages/textbook-create-and-edit-v2.png" alt="교재 등록·수정하기 대표 이미지"><figcaption></figcaption></figure>

배송할 실물 교재의 소개·표지·정가와 최초 재고를 등록합니다. **교재 콘텐츠 등록과 판매 상품 등록은 별도 작업**입니다. 교재가 `게시 완료`여도 상품 연결·판매 설정까지 완료됐다는 뜻은 아닙니다.

등록한 교재의 판매 상품 구성은 [상품 만들고 콘텐츠 연결하기](../products-and-coupons/create-products-and-connect-content.md)를 확인합니다.

**작업 순서:** 교재 선택 → 기본 정보·표지 입력 → 교재 정보·정가·최초 재고 입력 → 저장 → 상세에서 결과 확인

## 시작 전 준비 <a href="#before-you-start" id="before-you-start"></a>

| 준비할 것 | 확인 기준 |
| --- | --- |
| 교재 등록·수정 권한 | 사용할 사이트와 담당 계정의 권한 |
| 교재 정보 | 교재명, 소개, 저자·출판사. ISBN·페이지 수·출간일은 확인된 값만 준비 |
| 표지 이미지 | 직접 사용 가능한 이미지. 잘림·글자 가독성 확인 |
| 정가 | 새 상품을 구성할 때 불러올 기준 금액. 실제 상품 판매가와 구분 |
| 최초 재고 | 실제 보유 수량과 재고 부족 알림 기준. 이미 등록된 교재라면 재등록하지 않기 |

ISBN이 없는 자체 제작 교재도 ISBN을 비워 두고 등록할 수 있습니다. **ISBN 입력은 과세·면세 설정을 대신하지 않습니다.** 판매 상품의 세금 설정은 별도로 확인합니다.

## 메뉴 위치 <a href="#menu-location" id="menu-location"></a>

관리자 **콘텐츠 관리 → 콘텐츠 생성**에서 **교재**를 선택하고 **다음 단계**를 누릅니다. 수정할 때는 기존 교재 상세에서 **콘텐츠 설정**으로 들어갑니다.

> **화면 예시 준비 중** · 배송할 실물 교재는 교재 유형으로 등록합니다.

## 1. 기본 정보와 표지 입력하기 <a href="#step-1" id="step-1"></a>

1. **교재명 입력**에 학생이 구분할 수 있는 이름을 입력합니다. 학년·과목·판본이 다르면 이름에도 차이를 표시합니다.
2. **상세 설명 입력**에 짧은 소개를 입력합니다.
3. **교재 썸네일 업로드**에서 표지를 선택하고 자르기 결과를 확인합니다.
4. **교재 카테고리 선택**에서 해당 분류를 선택합니다.
5. **교재 소개 페이지 설정**에 목차·대상·판본 등 필요한 상세 소개를 작성합니다.

표지는 화면의 **3:4 비율·900×1200px 이상 권장 안내**를 참고합니다. 이것은 표지 준비 기준이며 강의 영상의 규격이 아닙니다. **최종 완료**로 등록하려면 표지가 필요합니다.

> **화면 예시 준비 중** · 교재 소개와 표지를 입력하고 ISBN 등 선택 정보를 확인합니다.

## 2. 교재 정보·정가·최초 재고 입력하기 <a href="#step-2" id="step-2"></a>

<figure><img src="../.gitbook/assets/branding/textbook-shipping-illustration-v1.png" alt="교재와 포장 상자"><figcaption></figcaption></figure>

**교재 정보**에서 저자·출판사를 입력하고, 필요한 경우 **ISBN (선택)**·**페이지 수 (선택)**·`출간일 (선택)`을 입력합니다. 모르는 값을 임의로 만들지 않습니다.

**가격 및 재고**에서는 아래 항목을 구분합니다.

| 항목 | 입력·확인할 내용 |
| --- | --- |
| 정가 | 새 판매 상품을 구성할 때 불러올 기준 금액. 0원 이상 정수로 입력 |
| 재고 | 처음 등록하는 교재의 실제 보유 수량. 0권이면 `0`을 명시 |
| 재고 부족 알림 기준 | 재고 부족 확인에 사용할 수량. 0 이상 정수로 입력 |

최초 재고 입력은 **새 교재 등록 화면**에 있습니다. 두 재고 항목을 모두 비워 두면 최초 재고 설정 없이 등록됩니다. 빈칸을 재고 0권이나 무제한 판매로 해석하지 마세요. 재고를 관리할 교재라면 수량을 명시하고 등록 후 상세에서 결과를 확인합니다.

**교재의 정가를 바꿔도 이미 연결된 상품의 판매가가 자동으로 바뀌지는 않습니다.** 판매가·할인은 [상품 가격 설정](../products-and-coupons/price-discount-and-valid-days.md)에서 별도로 확인합니다.

> **화면 예시 준비 중** · 정가와 최초 보유 수량을 구분해 입력합니다.

## 3. 저장하고 등록 결과 확인하기 <a href="#step-3" id="step-3"></a>

| 버튼·상태 | 의미 |
| --- | --- |
| 임시 저장 | 입력한 교재를 임시 상태로 보관. 판매 준비 완료가 아님 |
| 최종 완료 | 필요한 정보를 갖춘 교재의 등록을 완료. 상품 판매 시작과는 별도 |
| 게시 완료 | 교재 콘텐츠의 상태. 연결 상품의 판매 상태·구매 가능 여부와 구분 |

버튼을 누르고 교재 상세로 이동하면 교재명·표지·소개·정가·상태를 확인합니다. 최초 재고를 입력했다면 재고 정보와 **재고 이력**도 확인합니다. 목록 또는 상세를 다시 열어 저장된 결과를 확인하세요.

**연결 상품**에서는 이 교재를 사용하는 상품을 확인합니다. 교재 등록만으로 판매 준비가 끝나는 것은 아닙니다. 실제 판매 상품의 구성·판매가·배송 설정·판매 가능 여부를 별도로 확인합니다.

> **화면 예시 준비 중** · 교재 등록 결과를 확인하고 판매 상품·재고를 별도로 관리합니다.

## 4. 기존 교재 수정하기 <a href="#step-4" id="step-4"></a>

1. 콘텐츠 목록에서 수정할 교재를 엽니다. 같은 교재를 새로 생성하지 않습니다.
2. 상세의 **콘텐츠 설정**을 누릅니다.
3. 교재 정보·소개·표지·정가 중 변경할 항목을 수정합니다.
4. 게시 완료 교재에서는 **저장**, 임시 상태에서는 **임시 저장** 또는 **최종 완료**로 의도한 상태를 선택합니다.
5. 상세를 다시 열어 변경 내용을 확인하고, 연결 상품에서도 필요한 표시·가격을 확인합니다.

기존 교재의 수량은 콘텐츠 수정 화면이 아니라 **재고 이력 → 재고 조정**에서 관리합니다. 이곳의 **변동 수량**은 최종 재고 총량이 아니라 증감분입니다. 예를 들어 10권 추가 입고는 `10`, 3권 차감은 `-3`입니다. 현재 수량·예약 상태·사유를 확인한 후 조정하세요.

공유 재고·예약·조정·품절과 상품 판매 상태는 [재고·판매 상태 관리하기](../products-and-coupons/stock-and-sales-status.md)에서 이어서 확인합니다.

다른 담당자가 먼저 수정해 저장이 거절되면 최신 상세를 다시 조회하고 변경 내용을 비교합니다. 재고 조정을 반복하거나 새 교재를 만드는 것으로 해결하지 않습니다.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 의도한 교재명·판본·소개·표지가 저장됐습니다.
- [ ] ISBN 등 선택 항목에는 확인된 정보만 입력했습니다.
- [ ] 임시 저장·게시 완료와 상품 판매 상태를 구분했습니다.
- [ ] 최초 재고를 설정했다면 상세 수량과 이력을 확인했습니다.
- [ ] 수정 후 연결 상품의 표시·판매가·판매 가능 여부를 별도로 확인했습니다.

## 자주 막히는 부분 <a href="#troubleshooting" id="troubleshooting"></a>

| 상황 | 확인할 것 |
| --- | --- |
| 교재 선택 화면이 없어요 | 해당 사이트에서 교재 등록 기능을 제공하는지와 계정 권한을 운영자에게 확인합니다 |
| ISBN이 없는데 등록해도 되나요? | ISBN은 선택값입니다. 없는 번호를 만들거나 면세 설정으로 대신 사용하지 않습니다 |
| 최종 완료가 안 돼요 | 교재명·표지, 금액·수량의 입력 오류와 화면 안내를 확인합니다 |
| 수정 화면에 재고 입력이 없어요 | 최초 재고는 새 등록에만 입력합니다. 기존 수량은 상세의 재고 이력·재고 조정을 확인합니다 |
| 정가를 바꿨는데 상품 가격은 그대로예요 | 콘텐츠 정가는 새 상품 입력의 기준값입니다. 기존 상품 판매가는 별도로 수정합니다 |
| 저장·재고 조정 결과가 불확실해요 | 상세와 이력을 재조회해 반영 여부를 확인한 뒤 다시 작업합니다. 같은 조정을 중복 실행하지 않습니다 |
| 교재 삭제가 거절돼요 | 연결 상품이나 재고 조정 이력이 있으면 삭제가 제한됩니다. 연결·이력을 확인하고 운영 담당자에게 문의합니다 |
