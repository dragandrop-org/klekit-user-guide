# 디지털 자료·파일 관리하기

> **검토용 가이드** · 실제 서비스 화면·동작 확인과 이미지 보완이 남아 있습니다. 본문의 실행 보류·주의사항을 먼저 확인하세요.

PDF·문서·ZIP 등 다운로드할 자료를 등록하고 파일을 관리합니다. **파일 업로드 완료, 자료 저장, 판매 상품 연결은 서로 다른 단계**입니다. 파일 교체도 기존 구매자 전체에게 새 파일을 자동 지급하는 작업이 아닙니다.

자료를 판매할 상품에 연결하는 방법은 [상품 만들고 콘텐츠 연결하기](../products-and-coupons/create-products-and-connect-content.md)를 확인합니다.

**작업 순서:** 파일 준비 → 디지털 자료 선택 → 정보 입력·파일 업로드 → 저장 → 현재 파일 확인 → 필요한 상품 연결·구매자 결과 확인

## 시작 전 준비 <a href="#before-you-start" id="before-you-start"></a>

| 준비할 것 | 확인 기준 |
| --- | --- |
| 자료 등록·수정 권한 | 사용할 사이트와 담당 계정의 권한 |
| 자료 정보 | 자료명, 소개, 카테고리, 정가 |
| 배포할 파일 | 직접 열어 확인한 최종본. 공유 가능한 내용과 개인정보 포함 여부 확인 |
| 판본 표시 | 파일명에 과목·단원·수정일 또는 판본을 표시해 교체 전후 구분 |
| 교체 범위 | 기존 구매자에게도 수정본을 제공해야 하는지 운영 담당자와 먼저 확인 |

### 업로드할 수 있는 형식 <a href="#supported-formats" id="supported-formats"></a>

| 종류 | 허용 확장자 |
| --- | --- |
| PDF | `.pdf` |
| 문서 | `.doc`, `.docx`, `.hwp`, `.hwpx` |
| 스프레드시트 | `.xls`, `.xlsx` |
| 프레젠테이션 | `.ppt`, `.pptx` |
| 텍스트·데이터 | `.txt`, `.csv` |
| 여러 파일을 묶은 자료 | `.zip` |

한 자료에는 **파일 하나**를 업로드합니다. 여러 파일을 함께 제공하려면 ZIP 하나로 묶고 압축을 풀어 내용이 열리는지 확인합니다. `.rar`·`.7z`, 위 목록에 없는 확장자와 이미지·오디오·영상의 직접 업로드는 이 자료 등록 방식의 지원 목록에 없습니다. 강의 영상은 [영상 업로드 안내](video-upload.md)를 따릅니다.

확장자 이름만 바꾸지 마세요. 파일 형식·MIME·용량 검증에서 거절될 수 있습니다. 용량 오류가 나오면 표시된 안내를 확인하고 운영 담당자에게 해당 자료의 업로드 한도를 확인합니다. **영상의 5GB 안내를 디지털 자료의 확정 한도로 사용하지 않습니다.**

## 메뉴 위치 <a href="#menu-location" id="menu-location"></a>

관리자 **콘텐츠 관리 → 콘텐츠 생성**에서 **디지털 자료**를 선택하고 **다음 단계**를 누릅니다. 기존 자료 수정은 자료 상세의 **콘텐츠 설정**에서 진행합니다.

> **화면 예시 준비 중** · 다운로드 자료의 소개와 새 상품 구성에 사용할 정가를 입력합니다.

## 1. 자료 정보 입력하기 <a href="#step-1" id="step-1"></a>

1. **자료명 입력**에 학생이 구분할 수 있는 이름을 입력합니다.
2. **상세 설명 입력**에 짧은 소개를 작성합니다.
3. 필요한 경우 **자료 썸네일 업로드**와 **자료 카테고리 선택**을 설정합니다.
4. **자료 소개 페이지 설정**에 포함 파일·대상·판본·열람에 필요한 프로그램 등 자료 소개를 작성합니다.
5. **가격 → 정가**에 새 상품 구성 시 불러올 기준 금액을 입력합니다.

자료 썸네일은 화면의 **16:9 비율·1280×720px 이상 권장 안내**를 참고합니다. 자료의 정가는 판매 상품 가격과 별개이며, 정가 수정이 기존 상품 판매가를 자동 변경하지 않습니다. 판매 조건은 [상품 가격](../products-and-coupons/price-discount-and-valid-days.md)과 [과세·면세 설정](../products-and-coupons/tax-settings.md)을 확인합니다.

## 2. 파일 업로드하고 저장하기 <a href="#step-2" id="step-2"></a>

1. **자료 업로드**에서 파일 하나를 선택하거나 끌어 놓습니다.
2. 업로드 진행이 끝나고 **자료 업로드가 완료되었습니다.** 안내가 나오는지 확인합니다.
3. 파일명·업로드 오류 여부를 확인합니다.
4. 작성 중이면 **임시 저장**, 사용할 자료 등록을 마치려면 **최종 완료**를 누릅니다.
5. 저장 후 자료 상세를 다시 열어 상태와 현재 파일을 확인합니다.

파일을 선택하면 저장 버튼을 누르기 전에도 업로드가 시작됩니다. **업로드 완료 안내만으로 자료에 파일이 연결·저장된 것은 아닙니다.** 업로드 중이거나 실패한 새 파일이 있다면 먼저 해당 상태를 해결합니다. 최종 완료에는 연결할 파일이 필요하며, 파일 없이 정보만 임시 저장한 자료는 아직 다운로드용 자료 준비가 끝난 상태가 아닙니다.

> **화면 예시 준비 중** · 파일 업로드 완료 뒤 자료 저장까지 진행합니다.

등록·파일 연결·상태 변경은 단계별로 처리됩니다. 마지막 단계에서 오류가 나도 앞 단계가 이미 저장됐을 수 있으므로, **콘텐츠 목록과 상세를 먼저 재조회**합니다. 저장된 자료가 있으면 해당 자료에서 이어서 작업하고 바로 같은 자료를 새로 만들지 않습니다.

## 3. 현재 파일과 등록 결과 확인하기 <a href="#step-3" id="step-3"></a>

자료 상세의 **자료 개요 → 자료 파일**에서 현재 파일명·용량을 확인합니다. 실제 파일 검수는 승인된 테스트 자료로 진행합니다. 주소 발급/파일 열기와 기기 저장/내용 확인은 별도이며, 발급 실패·만료·응답 유실이면 기존 파일/권리와 마지막 결과부터 확인하고 다운로드를 반복하지 않습니다.

**게시 완료는 자료 콘텐츠의 상태**입니다. 실제 판매를 하려면 상품 구성에서 이 자료를 연결하고 판매 설정·구매 가능 여부를 확인합니다. 관리자 다운로드 성공은 수강생 구매 권한·다운로드 성공의 증거가 아니므로 별도로 확인합니다.

> **화면 예시 준비 중** · 저장 후 현재 파일과 자료 상태를 확인합니다.

## 4. 기존 자료 수정·파일 교체하기 <a href="#step-4" id="step-4"></a>

| 작업 | 진행 방법 |
| --- | --- |
| 소개·정가만 수정 | **콘텐츠 설정**에서 정보 수정 → 새 파일은 선택하지 않기 → 저장 → 상세 재조회 |
| 파일 교체 | 새 파일의 내용을 확인 → **자료 업로드**에서 선택 → 업로드 완료 확인 → 저장 → 현재 파일 재조회·다운로드 |
| 저장 전 선택한 새 파일 취소 | 새 업로드 파일의 제거 버튼으로 선택을 취소하고 결과 확인. 저장된 현재 버전 삭제와 구분 |

게시 완료 자료의 수정 버튼은 **저장**입니다. 임시 상태에서는 **임시 저장** 또는 **최종 완료**로 의도한 상태를 선택합니다. 새 파일을 선택하지 않으면 기존 파일을 유지하고, **새 파일을 업로드한 뒤 저장하면 새 버전이 등록**됩니다.

> **동작 예시 준비 중** · 새 파일을 저장하고 현재 파일이 바뀌었는지 확인합니다. 기존 구매자의 버전은 별도입니다.

### 교체 전후 구매자는 어떤 파일을 받나요? <a href="#section-8" id="section-8"></a>

| 대상 | 파일 버전의 기준 |
| --- | --- |
| 교체 전에 이미 자료 이용 권한을 받은 구매자 | 권한에 연결된 기존 파일 버전 유지 |
| 교체 후 새로 생성되는 주문 | 주문 생성 시점의 현재 파일 버전을 주문에 기록 |
| 교체 전에 생성됐고 아직 결제를 마치지 않은 주문 | 결제 시 최신 파일로 다시 바꾸는 방식이 아니라 해당 주문에 기록된 버전 기준 |
| 관리자 자료 개요 | 자료의 현재 파일 확인. 모든 구매자가 받는 파일과 같다는 뜻이 아님 |

기존 구매자에게 수정본까지 제공해야 한다면 **파일 교체만으로 처리 완료라고 안내하지 마세요.** 대상·제공 방법을 운영 담당자와 확인합니다. 구매자가 이용할 수 있는 버전은 실제 구매 권한이 있는 테스트 계정으로 교체 전후를 나눠 검수합니다.

이 가이드는 전체 버전 목록에서 과거 버전을 선택·복원하는 기능을 전제로 하지 않습니다. 잘못 교체했다면 변경 내용을 기록하고 담당자와 정정 방법을 확인합니다. 이전 버전 파일을 직접 지워 해결하지 않습니다.

## 5. 이용 내역과 운영 설정 확인하기 <a href="#step-5" id="step-5"></a>

자료 상세의 **이용 내역**에서 **파일 버전** 수, **유효 이용 권한** 수, **다운로드 URL 발급** 수와 이용자별 내역을 확인합니다. 내역의 자료 파일·버전·이용 권한 상태·발급일시·만료일시를 함께 봅니다.

**URL 발급은 파일 전송 완료나 자료 열람 완료가 아닙니다.** 발급 건수만으로 학생이 자료를 끝까지 다운로드하거나 공부했다고 판단하지 않습니다.

> **화면 예시 준비 중** · 다운로드 URL 발급 내역은 실제 전송·열람 완료 기록과 구분합니다.

**운영 설정**의 중지·삭제는 파일 교체와 다릅니다. 게시 완료 자료는 활성 상태 그대로 삭제할 수 없습니다. 연결 상품과 구매자가 있는 자료는 영향 범위를 확인한 후 담당자가 처리합니다. **자료 삭제를 기존 권한 회수나 모든 원본 파일의 즉시 영구 삭제와 동일하게 해석하지 않습니다.**

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 허용 형식의 파일 하나를 준비했고 직접 열어 내용을 확인했습니다.
- [ ] 업로드 완료 뒤 자료 저장까지 진행했습니다.
- [ ] 상세 재조회 후 현재 파일명·내용·상태가 의도한 결과입니다.
- [ ] 자료 상태와 상품 판매 상태, 관리자 다운로드와 구매자 권한을 구분했습니다.
- [ ] 교체 시 기존 구매자와 신규 주문의 파일 버전 기준을 확인했습니다.
- [ ] 이용 내역을 실제 다운로드·열람 완료 기록으로 안내하지 않았습니다.

구매자 다운로드는 현재 자료 파일뿐 아니라 해당 권리에 지급된 파일 버전·활성/취소/복구 보류와 파일 접근 조건을 확인합니다. 내부 검사/지급 복구 상태를 사용자 배지·자동 해제·이전 버전 복원 버튼으로 안내하지 않습니다. 자료 교체가 기존 권리를 자동 최신본으로 바꾸거나 발급 실패가 이력 없음이라는 뜻은 아닙니다.

## 자주 막히는 부분 <a href="#troubleshooting" id="troubleshooting"></a>

| 상황 | 확인할 것 |
| --- | --- |
| 디지털 자료 선택 화면이 없어요 | 새 콘텐츠 관리 화면의 공개 설정과 계정 권한을 운영자에게 확인합니다 |
| 파일 형식·용량 오류가 나요 | 허용 확장자, 실제 파일 형식과 화면 안내를 확인합니다. 확장자만 바꾸지 않습니다 |
| 여러 파일이 한 번에 등록되지 않아요 | 이 화면은 단일 파일 업로드입니다. 함께 제공할 파일을 ZIP 하나로 준비합니다 |
| 업로드했는데 상세에 파일이 없어요 | 업로드 후 저장까지 했는지 확인합니다. 목록·상세에서 자료·파일 연결·상태를 각각 확인합니다 |
| 저장 중 오류가 나서 다시 등록하려고 해요 | 앞 단계가 저장됐을 수 있습니다. 기존 자료를 먼저 확인하고 같은 자료의 중복 생성을 피합니다 |
| 새 파일로 교체했는데 기존 구매자는 예전 파일을 받아요 | 기존 권한은 특정 파일 버전에 연결됩니다. 전체 구매자의 자동 최신본 제공으로 설명하지 않습니다 |
| 자료 다운로드가 안 돼요 | 관리자 현재 파일인지 구매자 권한 파일인지 구분하고, 재조회·권한 상태·화면 오류를 확인합니다 |
| 다른 담당자 수정 후 저장이 거절돼요 | 최신 상세를 다시 열어 변경된 정보와 현재 파일을 확인한 뒤 수정합니다 |
| 발급 건수가 실제 다운로드 수와 달라요 | 이용 내역은 다운로드 URL 발급 기록입니다. 파일 전송·열람 완료와는 다릅니다 |
