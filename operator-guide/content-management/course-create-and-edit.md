# 강좌 등록·수정하기

> **검토용 가이드** · 실제 서비스 화면·동작 확인과 이미지 보완이 남아 있습니다. 본문의 실행 보류·주의사항을 먼저 확인하세요.

<figure><img src="../.gitbook/assets/branding/content-management-illustration-v1.png" alt="콘텐츠 관리 대표 이미지"><figcaption></figcaption></figure>

강좌 제목·소개·썸네일을 등록하고 수업을 구성합니다. 작업 중인 내용 저장, 수강생에게 반영할 내용 발행, 상품 판매 시작은 서로 다른 단계입니다. 강좌는 학습 콘텐츠이며 가격·할인·판매 상태는 상품에서 별도로 관리합니다.

**완료 기준:** 강좌 목록에서 등록한 강좌를 찾을 수 있고, 필요한 수정이 저장되어 있으며 발행 결과까지 확인했습니다.

## 시작 전 준비 <a href="#before-you-start" id="before-you-start"></a>

| 준비할 것 | 예시·확인 기준 |
| --- | --- |
| 강좌 제목 | `중등 수학 1학기 개념 완성`처럼 대상과 주제가 드러나는 이름 |
| 강좌 요약 | 누구를 위한 강좌인지, 무엇을 배우는지 짧게 설명 |
| 강좌 카테고리 | 강좌의 과목·분류에 맞는 카테고리 |
| 썸네일 | 주제가 드러나고 작은 화면에서도 읽기 쉬운 이미지 |
| 강좌 상세 정보 | 수강 대상, 학습 범위, 수업 방식, 준비물 |
| 편집 권한 | 해당 사이트의 콘텐츠를 등록·수정할 수 있는 계정 |

## 메뉴 위치 <a href="#menu-location" id="menu-location"></a>

관리자 **콘텐츠 관리**에서 강좌 생성으로 들어갑니다. 교재·디지털 자료 선택 화면이 보이면 **강좌**를 선택합니다. 기존 강좌는 목록에서 해당 강좌를 열고 수정 화면으로 들어갑니다.

> **화면 예시 준비 중** · 콘텐츠 관리에서 새 강좌를 등록합니다.

## 1. 기본 정보 입력하기 <a href="#step-1" id="step-1"></a>

**기본 정보 설정**에서 제목·요약·카테고리·썸네일을 입력합니다. 제목에 강사명만 적기보다 과목과 학습 범위를 함께 적으면 강좌를 구분하기 쉽습니다.

| 항목 | 작성 예시 |
| --- | --- |
| 제목 | 중등 수학 1학기 개념 완성 |
| 요약 | 일차방정식의 개념부터 대표 유형 풀이까지 학습합니다. |
| 상세 정보 | 대상: 중학교 1학년 / 범위: 일차방정식 / 준비물: 교재와 필기구 |

**강좌 상세 정보**에는 긴 소개를 작성합니다. 저장 안내가 나오면 내용을 확인하고 **다음**으로 이동합니다. 다음 단계는 **영상 업로드 및 섹션 구성**입니다.

> **화면 예시 준비 중** · 강좌의 기본 정보와 상세 소개를 입력합니다.

## 2. 작업 중인 내용 저장하기 <a href="#step-2" id="step-2"></a>

아직 수업 구성을 끝내지 않았다면 **임시 저장**을 사용합니다. 입력 오류가 표시되면 안내된 항목을 먼저 보완합니다. 저장 안내를 확인한 뒤 목록이나 상세 화면에서 해당 강좌를 다시 열어 내용이 남아 있는지 확인합니다.

| 동작 | 구분할 점 |
| --- | --- |
| 임시 저장 | 작업 중인 내용을 보관하는 동작입니다. 수강생 공개 완료와 다릅니다 |
| 화면 미리보기 | 관리자에게 보이는 내용 점검용입니다. 판매·수강 권한 확인을 대신하지 않습니다 |
| 최종 완료 | 강좌 생성·수정 화면에서 커리큘럼을 확인한 뒤 발행을 요청합니다 |

## 3. 커리큘럼 구성하고 발행하기 <a href="#step-3" id="step-3"></a>

1. [커리큘럼 구성하기](curriculum.md)에 따라 섹션과 수업을 만듭니다.
2. 필요한 영상을 연결하고 제목·순서·공개 범위를 확인합니다.
3. **화면 미리보기**에서 소개와 커리큘럼을 확인합니다.
4. 강좌 생성·수정 화면의 **최종 완료**를 누릅니다.
5. 강좌 상세의 처리 상태와 결과를 확인합니다. 발행중·실패 상태를 완료로 간주하지 않습니다.

> **화면 예시 준비 중** · 임시 저장과 발행 결과는 별도로 확인합니다.

## 4. 기존 강좌 수정하기 <a href="#step-4" id="step-4"></a>

강좌 목록에서 수정할 강좌를 열어 기본 정보를 바꿉니다. 영상·수업 순서 변경은 커리큘럼 단계에서 진행합니다. 저장 후에는 관리자 미리보기와 실제 수강생 화면을 각각 확인합니다.

**판매 중인 강좌를 수정할 때는 기존 수강생의 학습 흐름을 확인하세요.** 영상이나 수업을 삭제하는 대신 교체·추가가 필요한지 먼저 검토합니다. 강좌를 발행했다고 연결 상품의 가격·판매 상태까지 바뀌는 것은 아닙니다.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 강좌 목록에 정확한 제목과 썸네일이 표시됩니다.
- [ ] 다시 열었을 때 요약·상세 정보·카테고리가 저장되어 있습니다.
- [ ] 섹션과 수업이 의도한 순서로 보입니다.
- [ ] 발행 결과가 확인되며 처리 중·실패가 남아 있지 않습니다.
- [ ] 수강생에게 제공할 때는 상품 연결·판매 상태 또는 수강 권한도 별도로 확인했습니다.

## 자주 막히는 부분 <a href="#troubleshooting" id="troubleshooting"></a>

| 상황 | 확인할 것 |
| --- | --- |
| 다음 단계로 이동하지 못해요 | 제목·요약·카테고리 등 화면의 입력 오류를 확인하고 보완합니다 |
| 미리보기가 비활성화돼요 | 기본 정보를 먼저 저장한 뒤 미리보기 버튼을 확인합니다 |
| 저장했는데 수강생 화면에 안 보여요 | 임시 저장과 발행을 구분하고 상품 연결·판매 상태·수강 권한을 확인합니다 |
| 최종 완료 후 바로 반영되지 않아요 | 강좌 상세의 발행 처리 상태를 확인합니다. 실패 안내가 있다면 결과를 확인한 뒤 대응합니다 |
