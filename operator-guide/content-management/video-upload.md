# 강의 영상 업로드하기

> **검토용 가이드** · 실제 서비스 화면·동작 확인과 이미지 보완이 남아 있습니다. 본문의 실행 보류·주의사항을 먼저 확인하세요.

<figure><img src="../.gitbook/assets/branding/content-management-illustration-v1.png" alt="콘텐츠 관리 대표 이미지"><figcaption></figcaption></figure>

촬영한 영상을 강좌에 업로드하고 해당 수업에 연결합니다. **업로드 완료, 수업 연결, 재생 가능 여부는 각각 확인해야 합니다.**

**작업 순서:** 파일 확인 → 영상 업로드 → 수업 연결 → 변환·재생 확인 → 저장·발행 확인

## 시작 전 준비 <a href="#before-you-start" id="before-you-start"></a>

| 준비할 것 | 확인 기준 |
| --- | --- |
| 강좌와 수업 | 영상을 연결할 강좌·수업을 만들어 두기 |
| 영상 파일 | 원본에서 영상 길이·칠판 글씨·강사 목소리 확인 |
| 파일명 | `01-일차방정식-기본개념.mp4`처럼 수업을 구분하기 쉬운 이름 |
| 네트워크 | 업로드 동안 안정적인 연결 유지, PC 절전·네트워크 변경 피하기 |
| 원본 보관 | 변환본을 만들더라도 원본 파일은 따로 보관 |

### 업로드 파일 기준 <a href="#upload-requirements" id="upload-requirements"></a>

| 구분 | 기준 |
| --- | --- |
| 지원 확장자 | mp4, mov, m4v, webm, mkv |
| 미지원 확장자 | avi, wmv, flv, 3gp |
| 파일당 최대 용량 | 5GB |
| 준비하기 쉬운 권장 형식 | MP4, H.264 영상, AAC 오디오 |

확장자는 파일의 형식이고, H.264·HEVC는 내부 영상의 압축 방식입니다. 지원 확장자라고 해도 모든 코덱 조합의 변환 성공이 보장되는 것은 아닙니다. 아이폰의 mov 파일도 확장자 목록에 포함되지만 실제 변환·재생 결과까지 확인하세요.

**파일 이름의 확장자만 바꾸지 마세요.** 용량이 크거나 변환에 실패한다면 [영상 용량 줄이기](video-optimization.md)를 따라 별도 변환본을 만듭니다. 1080p·30fps는 최적화 시작값이며 업로드의 최소 해상도·최대 길이 기준이 아닙니다.

## 메뉴 위치 <a href="#menu-location" id="menu-location"></a>

강좌 생성·수정 화면의 **영상 업로드 및 섹션 구성**으로 들어갑니다. 한 수업에 연결하려면 수업을 열고 **영상 관리**, 여러 파일을 먼저 올리려면 **강의 영상 일괄 업로드**를 사용합니다.

## 1. 수업에 새 영상 업로드하기 <a href="#step-1" id="step-1"></a>

1. 영상을 넣을 수업을 엽니다.
2. **영상 관리**에서 **새 영상 업로드**를 선택합니다.
3. 해당 수업에 맞는 영상 파일을 선택합니다.
4. 진행 상태와 결과 안내를 확인합니다.
5. 파일명·영상 길이와 수업에 연결된 파일을 확인합니다.

> **화면 예시 준비 중** · 영상 관리에서 새 파일이나 기존 파일을 선택합니다.

새 영상 업로드에는 파일 저장과 수업 연결이 포함될 수 있습니다. 팝업을 닫거나 취소했다고 업로드한 파일·연결이 모두 되돌아갔다고 판단하지 말고 다시 조회해 결과를 확인합니다.

## 2. 이미 업로드한 영상 연결하기 <a href="#step-2" id="step-2"></a>

같은 강좌에 올려 둔 영상을 사용한다면 영상 목록에서 해당 파일을 선택하고 저장합니다. 이름이 같은 파일이 있다면 파일 크기·날짜·길이로 구분하고, 저장 후 수업을 다시 열어 연결을 확인합니다.

> **동작 예시 준비 중** · 저장 후 해당 수업에 영상이 연결됐는지 확인합니다.

**영상 파일 삭제는 연결 변경과 다릅니다.** 현재 화면에서는 파일 삭제가 저장과 무관하게 즉시 반영될 수 있습니다. 확인창에 연결된 수업이 나오면 영향 범위를 확인한 뒤 진행하며, 삭제를 취소 버튼으로 되돌릴 수 있다고 가정하지 않습니다.

## 3. 여러 영상 한꺼번에 업로드하기 <a href="#step-3" id="step-3"></a>

1. **강의 영상 일괄 업로드**를 엽니다.
2. 올릴 파일을 선택합니다.
3. 파일별 진행 상태를 확인하고 실패한 파일을 구분합니다.
4. 업로드된 파일을 넣을 섹션을 선택합니다.
5. 필요한 미연결 영상을 선택하고 **수업 한 번에 생성하기**를 사용합니다.
6. 생성된 수업의 제목·순서·영상 연결을 점검합니다.

파일을 올리기만 한 상태와 수업에 연결한 상태를 구분하세요. **미연결** 목록에 남아 있다면 필요한 수업에 연결하거나 수업 생성 작업을 이어서 진행합니다.

> **화면 예시 준비 중** · 일괄 업로드한 파일을 선택한 섹션의 수업에 연결합니다.

일괄 업로드는 최대 6개를 동시에 전송하고 나머지 파일은 먼저 시작한 전송이 끝날 때까지 대기합니다. 실패가 반복되면 파일 용량을 줄이거나 큰 파일부터 한 개씩 시도하세요. 진행 중에는 업로드 화면을 열어 두세요. 화면을 닫으면 전송이 계속되는지, 취소되는지 확인하기 어려울 수 있습니다.

업로드 대기 시간이 길었다는 이유만으로 주소가 만료됐다고 판단해 다시 올리지 마세요. 파일별 오류 안내를 먼저 확인합니다. 파일 선택 시 용량·영상 길이 확인, 전송 완료 안내, 수업 연결 결과를 나누어 확인하세요.

파일 선택창에 보이더라도 avi·wmv 파일은 지원하지 않습니다. 설명에 webm이 빠져 있더라도 지원 여부는 위의 **업로드 파일 기준**을 확인하세요. 전송이 끝나도 수업 연결은 실패할 수 있으므로, 연결 결과를 먼저 조회하고 같은 연결을 반복 저장하지 않습니다.

## 4. 변환과 재생 확인하기 <a href="#step-4" id="step-4"></a>

<figure><img src="../.gitbook/assets/branding/video-upload-illustration-v1.png" alt="촬영한 영상과 수업 연결을 표현한 개념 일러스트"><figcaption></figcaption></figure>

| 확인 단계 | 확인할 것 |
| --- | --- |
| 파일 업로드 | 전송이 끝나고 업로드 결과가 확인되는지 |
| 수업 연결 | 해당 수업의 파일명·영상 길이가 맞는지 |
| 영상 처리 | 처리 중·실패 안내가 남아 있지 않은지 |
| 관리자 재생 | 시작·중간·끝 구간의 영상과 소리가 정상인지 |
| 수강생 재생 | 발행 후 권한 있는 수강생에게 의도한 영상이 보이는지 |

> **화면 예시 준비 중** · 업로드·연결 후 수강생의 재생 결과를 확인합니다.

업로드 직후 바로 재생되지 않으면 처리 상태를 확인합니다. 처리 중인 파일을 반복 업로드하지 말고, 실패 안내가 있거나 상태가 갱신되지 않으면 오류 내용과 파일 정보를 정리해 운영자에게 문의합니다. 변환이 끝날 때까지 걸리는 시간은 파일과 환경에 따라 다릅니다.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 파일 형식·용량이 기준에 맞고 업로드 결과를 확인했습니다.
- [ ] 정확한 수업에 정확한 영상이 연결되어 있습니다.
- [ ] 관리자에서 시작·중간·끝 구간의 글씨와 소리를 확인했습니다.
- [ ] 저장·발행 결과와 수강 권한 있는 계정의 재생을 확인했습니다.
- [ ] 모바일 화면에서도 읽기·듣기에 문제가 없습니다.

## 자주 막히는 부분 <a href="#troubleshooting" id="troubleshooting"></a>

| 상황 | 확인할 것 |
| --- | --- |
| 파일을 선택할 수 없거나 업로드가 차단돼요 | 확장자·파일당 용량과 화면의 오류 안내를 확인합니다. 저장 공간·권한 안내라면 운영자에게 확인합니다 |
| 5GB를 넘어요 | [용량 줄이기](video-optimization.md)로 변환하거나 수업 단위로 나눕니다 |
| 업로드는 끝났는데 수업에 영상이 없어요 | 미연결 목록과 해당 수업의 영상 선택·저장 결과를 확인합니다 |
| 여러 파일 중 일부가 실패했어요 | 성공한 파일을 다시 올리기 전에 목록을 확인하고, 실패한 파일만 오류별로 다시 시도합니다 |
| 세션·URL 만료 안내가 나와요 | 기존 파일 목록·수업 연결·마지막 오류부터 확인합니다. 결과 확인 전 재업로드하거나 서명 주소를 수정/공유하지 않습니다. 새 업로드가 필요하면 담당자가 실패 대상을 확인한 뒤 진행합니다 |
| mov 파일이 변환되지 않아요 | 확장자 허용과 코덱 변환은 다릅니다. 원본을 보관하고 MP4·H.264 변환본으로 다시 확인합니다 |
| 관리자에서는 되는데 수강생은 안 돼요 | 발행 결과·공개 범위·미리보기·수강 권한을 별도로 확인합니다 |

문의할 때는 강좌·수업 이름, 파일 확장자·용량, 실패 시점과 오류 화면을 함께 정리하세요. 원본 영상이나 학생 정보는 공개 게시판에 올리지 않습니다.
