# 사이트 기본 정보 설정하기

<figure><img src="../.gitbook/assets/branding/page-headers/site-and-communication/site-basic-information-v2.png" alt="사이트 기본 정보 설정하기 대표 이미지"><figcaption></figcaption></figure>

**업무 대상:** 사이트 이름·공유 정보·약관 관리를 맡은 담당자용 안내입니다. 강좌 정보 수정과는 다른 업무입니다. 강사는 사이트 공통 설정 변경이 필요하면 운영자에게 요청하세요.

사이트 이름·로고·파비콘을 설정하고 검색·공유 정보와 약관을 확인합니다. 기본 정보, SEO, 약관은 서로 다른 메뉴에서 관리합니다. 사이트 생성과 페이지·메뉴 편집 절차는 여기서 다루지 않습니다.

**완료 기준:** 설정 화면을 다시 열었을 때 변경 내용이 유지되고, 방문자 화면에서도 의도한 결과를 확인했습니다. 약관을 변경했다면 승인된 내용·버전과 기존 회원 동의에 미치는 영향까지 별도로 확인했습니다.

## 시작 전 준비 <a href="#before-you-start" id="before-you-start"></a>

| 준비할 것 | 예시·확인 기준 |
| --- | --- |
| 변경 권한 | 사이트 소유자 계정 또는 담당자에게 확인한 편집 권한. 운영자라는 역할명만으로 모든 설정을 바꿀 수 있다고 판단하지 않습니다 |
| 사이트 이름 | `예시교육`처럼 표시할 이름. 2~30자의 한글·영문·숫자·공백으로 준비하고 특수문자·연속 공백은 피합니다 |
| 로고·파비콘 | 원본 파일을 보관하고 작은 화면에서도 구분되는 PNG 파일부터 준비합니다. 최종 허용 형식·용량은 해당 화면에서 확인하고 담당자에게도 확인합니다 |
| 검색·공유 문구 | 사이트 제목과 짧은 설명, 공유용 제목·설명. 현재 입력 제한 차이가 있어 제목 40자·설명 120자 이내의 짧은 문구부터 준비합니다 |
| 공유 이미지 | JPG·PNG·WebP 중 2MB 이하의 파일을 준비합니다. 업로드 후 실제 표시 결과를 별도로 확인합니다 |
| 약관 변경안 | 담당자가 승인한 본문·변경 사유·버전 선택안. 초안은 서비스 밖에서 작성·검토합니다 |

SEO 설정은 소유자 여부와 이용 플랜에 따라 저장이 제한될 수 있습니다. 메뉴가 보이거나 입력할 수 있는 것과 저장할 수 있는 것은 다릅니다. 권한을 확인하지 못했다면 현재 설정 조회까지만 진행합니다.

## 메뉴 위치 <a href="#menu-location" id="menu-location"></a>

관리자 **홈페이지 관리**에서 작업에 맞는 메뉴를 엽니다.

| 메뉴 | 관리할 내용 | 구분할 점 |
| --- | --- | --- |
| 홈페이지 정보 설정 | 사이트 이름·주소 확인, 로고·파비콘 | 주소는 읽기 전용입니다. 별도 사이트 소개 입력란은 없습니다 |
| SEO (검색최적화) | Meta·OG·Robots 설정 | 검색·공유 정보와 검색 로봇 허용 여부를 관리합니다 |
| 약관 설정 | 이용약관·개인정보처리방침·환불 정책·마케팅 수신 동의 | 기존 내용·버전 확인과 변경 등록을 구분합니다 |

> **화면 예시 준비 중** · 기본 정보·검색/공유 정보·약관은 각 메뉴에서 확인합니다. 사이트 주소는 읽기 전용입니다.

## 1. 사이트 이름과 주소 확인하기 <a href="#step-1" id="step-1"></a>

1. **홈페이지 정보 설정**을 엽니다.
2. 표시된 주소가 작업할 사이트의 주소인지 확인합니다.
3. **사이트 이름**에 표시할 이름을 입력합니다.
4. 이름의 오탈자와 공백을 확인합니다. 로고·파비콘도 바꿀 예정이라면 다음 단계에서 함께 준비합니다.

**사이트 이름을 바꿔도 사이트 주소가 바뀌지는 않습니다.** 브라우저 탭에 표시할 제목은 SEO의 사이트 제목도 별도로 확인합니다. 홈페이지 본문의 긴 소개 문구는 페이지 편집에서 다룹니다.

## 2. 로고·파비콘 선택하고 저장하기 <a href="#step-2" id="step-2"></a>

로고는 사이트의 브랜드 이미지이고, 파비콘은 브라우저 탭 등에서 사이트를 구분하는 작은 아이콘입니다.

1. 변경할 로고·파비콘 파일을 각각 선택합니다.
2. 자르기 화면이 열리면 글자·상징이 잘리지 않도록 조정합니다.
3. 미리보기에서 여백·잘림·식별 가능 여부를 확인합니다. 파일을 선택한 것만으로 저장 완료로 보지 않습니다.
4. 사이트 이름과 선택한 이미지를 다시 확인한 뒤 **저장**합니다.
5. 저장 결과를 확인하고 같은 메뉴를 다시 열어 이름·로고·파비콘이 각각 유지되는지 확인합니다.

> **파비콘 파일 형식을 먼저 확인하세요.**
> 파비콘의 도움말과 실제 업로드 허용 기준이 다를 수 있으며, 최종 지원 형식은 아직 확인되지 않았습니다. PNG 파일을 우선 준비하되 ICO 등 도움말에 적힌 형식이 모두 업로드된다고 생각하지 마세요. 업로드 오류가 나면 확장자만 바꾸지 말고 담당자에게 지원 형식을 확인합니다.

> **화면 예시 준비 중** · 선택한 로고·파비콘의 잘림과 작은 화면에서의 식별 여부를 확인합니다.

저장 도중 오류가 나면 **모든 변경이 취소됐다고 가정하지 마세요.** 로고·파비콘·사이트 이름이 순서대로 처리되므로 일부 항목만 반영됐을 수 있습니다. 다시 열어 각 항목을 확인한 뒤 남은 변경을 판단합니다.

> **동작 예시 준비 중** · 저장 후 다시 열어 이름·로고·파비콘을 각각 확인합니다.

## 3. 검색·공유 정보 설정하기 <a href="#step-3" id="step-3"></a>

`SEO (검색최적화)`를 엽니다. 다음 세 탭은 하나의 저장 화면입니다.

| 탭 | 입력·확인할 내용 | 작성 예시·주의 |
| --- | --- | --- |
| Meta 설정 | 사이트 제목 (Meta Title), 사이트 설명 (Meta Description), Keyword | 제목 `예시교육`, 설명 `강좌와 교재를 확인하고 학습할 수 있는 예시교육 사이트입니다.`처럼 짧게 작성합니다 |
| OG 설정 | OG 타이틀, OG Description, 이미지 업로드 | 링크를 공유할 때 사용할 제목·설명·이미지입니다. 관리자 미리보기와 외부 공유 결과는 다를 수 있습니다 |
| Robots 설정 | 허용·차단 | 검색 엔진이 사이트 내용을 수집하고 검색 결과에 등록하도록 허용할지 정하는 설정입니다. 회원 전용 접근 설정이나 사이트 운영 중지가 아닙니다 |

1. Meta의 사이트 제목·설명을 확인합니다. 화면에서 입력이 허용돼도 저장 단계에서 길이 오류가 날 수 있어 짧은 문구부터 사용합니다.
2. OG의 제목·설명·이미지를 확인합니다. Meta 제목뿐 아니라 **OG 타이틀도 채워져 있는지** 확인합니다.
3. Robots의 현재 값이 운영 의도와 일치하는지 확인합니다. 변경할 필요가 없다면 기존 값을 유지합니다.
4. 세 탭의 값을 모두 확인하고 **저장**합니다. 어느 탭에서 저장하든 Meta·OG·Robots가 함께 저장됩니다.
5. 다시 열어 세 탭의 저장값을 각각 확인합니다.

**Robots를 차단해도 사이트가 비공개가 되거나 방문자의 접근이 막히는 것은 아닙니다.** 기존 검색 결과가 즉시 사라지는 것도 보장하지 않습니다. 개별 페이지의 공개·발행과 메뉴 노출은 [페이지·메뉴 구성하기](pages-and-menus.md)에서 따로 확인합니다. 메뉴 숨김 역시 페이지 접근 차단을 대신하지 않습니다.

> **화면 예시 준비 중** · 세 탭의 값을 확인한 뒤 저장합니다. 어느 탭에서 저장해도 세 묶음이 함께 저장됩니다.

## 4. 약관 내용·버전 확인하기 <a href="#step-4" id="step-4"></a>

**약관 설정**에서 대상 항목의 내용과 버전을 먼저 확인합니다. 이 단계는 약관 변경안을 시험 저장하는 절차가 아닙니다.

1. 목록에서 확인할 항목과 현재 버전을 찾습니다.
2. 상세를 열고 제목·약관 내용을 확인합니다. 목록 이름이 예상과 다르면 상세 제목으로 대상 항목을 다시 확인합니다.
3. 수정이 필요하면 승인된 변경안과 현재 내용을 비교합니다. **미등록**이 표시되면 담당자에게 초기 등록 가능 여부와 절차를 확인합니다.
4. 기존 약관을 변경할 때는 변경 권한과 버전의 영향을 먼저 확인합니다. 확인되지 않았다면 저장하지 않습니다.

| 버전 선택 | 클킷에서 적용되는 영향 | 변경 전 확인 |
| --- | --- | --- |
| 패치 업데이트 | 기존 회원의 동의 상태를 새 버전에 이어서 유지하는 처리 | 승인된 변경안과 선택한 버전이 일치하는지 확인합니다 |
| 마이너 업데이트 | 기존 회원의 동의 상태를 새 버전에 이어서 유지하는 처리 | 변경 내용과 동의 유지 여부를 담당자와 확인합니다 |
| 메이저 업데이트 | 기존 동의를 그대로 이어서 유지하지 않고 재동의가 필요한 처리 | 회원 영향과 재동의 화면·진행 방법을 먼저 확인합니다 |

> **주의: 약관의 ‘임시 저장’을 초안 보관용으로 사용하지 마세요.**
> **임시 저장도 저장과 마찬가지로 약관 변경을 등록할 수 있습니다.** 활성 약관과 회원 동의에 영향을 줄 수 있으므로 검토 중인 문구는 서비스 밖에서 작성합니다. 버튼 이름만 보고 비공개 보관·예약 적용이라고 판단하지 않습니다.

승인된 기존 약관 변경은 **수정하기**에서 본문·버전을 확인한 뒤 **저장**하고, 목록과 상세를 다시 열어 내용·버전을 대조합니다. 저장 오류가 나면 반복해서 등록하지 말고 최신 약관을 먼저 확인합니다. 버전 선택 설명은 클킷의 처리 방식을 구분하기 위한 것이며 변경안의 적법성이나 재동의 필요성에 대한 법률 판단을 대신하지 않습니다.

> **화면 예시 준비 중** · 약관의 대상·내용·버전과 변경 영향을 확인합니다. 임시 저장을 초안 보관용으로 사용하지 않습니다.

## 5. 방문자 화면에서 결과 확인하기 <a href="#step-5" id="step-5"></a>

관리자 저장값과 방문자가 보는 결과를 나누어 확인합니다.

| 확인 위치 | 확인할 결과 |
| --- | --- |
| PC·모바일 사이트 | 로고가 보이는지, 글자·이미지가 잘리거나 겹치지 않는지 확인합니다 |
| 브라우저 탭 | 설정한 제목·파비콘이 표시되는지 확인합니다. 이전 아이콘이 보이면 새로고침·새 창에서도 비교합니다 |
| 사이트의 약관 연결 위치 | 실제 연결된 항목의 내용과 버전을 확인합니다. 관리자 상세만으로 방문자 반영 완료를 판단하지 않습니다 |
| 외부 링크 공유 | 공유 대상과 공개해도 되는 내용인지 확인한 뒤 제목·설명·이미지를 확인합니다. 관리자 OG 미리보기만으로 외부 반영을 확정하지 않습니다 |

검색 엔진이 내용을 수집해 검색 결과에 표시하는 과정과 외부 서비스가 저장해 둔 공유 정보를 갱신하는 과정은 클킷에 설정을 저장하는 것과 별개입니다. 저장 직후 검색 노출·순위·공유 이미지 갱신을 보장하지 않습니다. 약관을 메이저 버전으로 변경했다면 기존 회원의 실제 재동의 결과도 별도로 확인합니다.

> **화면 예시 준비 중** · 관리자 저장값과 방문자가 보는 결과를 구분해 확인합니다. 외부 공유·검색 결과는 별도 확인 대상입니다.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 다시 연 홈페이지 정보 설정에 사이트 이름·로고·파비콘이 각각 유지됩니다.
- [ ] 사이트 이름을 바꾸면서 주소까지 변경됐다고 안내하지 않았습니다.
- [ ] SEO 세 탭의 저장값과 Meta·OG 제목을 각각 확인했습니다.
- [ ] Robots를 접근 제한이나 운영 중지 기능으로 사용하지 않았습니다.
- [ ] 약관의 대상·내용·버전과 승인 범위를 확인했습니다. 변경했다면 기존 동의 영향도 확인했습니다.
- [ ] PC·모바일의 로고, 브라우저 탭과 실제 약관 연결 결과를 확인했습니다.
- [ ] 외부 공유·검색 결과는 관리자 저장 성공과 구분해 확인 여부를 기록했습니다.

## 자주 막히는 부분 <a href="#troubleshooting" id="troubleshooting"></a>

| 상황 | 확인할 것 |
| --- | --- |
| 메뉴·변경·저장이 안 보여요 | 계정 권한과 사이트 소유자 여부, 이용 플랜을 담당자에게 확인합니다. 다른 계정의 인증정보를 공유받지 않습니다 |
| 사이트 이름을 저장할 수 없어요 | 2~30자·문자 종류·공백을 확인합니다. 소유자 여부와 중복 이름 등 오류 안내도 확인합니다 |
| 이미지 선택·업로드가 실패해요 | 해당 항목의 파일 기준과 오류 안내를 확인합니다. 파비콘은 도움말과 허용 목록 차이가 있어 담당자 확인이 필요합니다 |
| 저장 오류가 났는데 일부만 바뀌었어요 | 다시 열어 이름·로고·파비콘을 따로 확인합니다. 전부 취소됐다고 보고 같은 변경을 반복하지 않습니다 |
| SEO 글자 수 오류가 나요 | Meta 제목 40자·설명 120자 이내의 짧은 문구부터 확인합니다. OG에도 같은 서비스 최대치가 적용된다고 단정하지 않습니다 |
| Robots만 바꿨는데 저장이 안 돼요 | Meta·OG 제목 등 다른 탭의 필수 항목과 오류 안내도 확인합니다. 세 탭이 함께 저장됩니다 |
| 약관이 미등록이거나 목록 이름이 달라요 | 상세 제목과 대상 종류를 확인하고 담당자에게 초기 등록·표시 차이를 문의합니다. 임의로 새 버전을 반복 등록하지 않습니다 |
| 로고·파비콘·공유 이미지가 이전 것으로 보여요 | 관리자 저장값과 새 창의 사이트 결과를 먼저 비교합니다. 외부 서비스에 저장된 이전 공유 정보(캐시)를 즉시 갱신하려고 약관·다른 설정까지 재저장하지 않습니다 |
