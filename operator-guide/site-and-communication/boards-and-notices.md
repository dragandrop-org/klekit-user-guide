# 게시판·공지 운영하기

<figure><img src="../.gitbook/assets/branding/page-headers/site-and-communication/boards-and-notices-v2.png" alt="게시판·공지 운영하기 대표 이미지: 공지 게시판과 확성기"><figcaption></figcaption></figure>

일정·수업 안내는 **공지사항**, 용도별 글과 댓글은 **사용자 정의 게시판**, 메인 화면의 기간 한정 안내는 **공지·프로모션 관리**에서 운영합니다. 이름이 비슷해도 작성 방식·접근 정책·노출 위치는 다릅니다.

**완료 기준:** 의도한 대상에게 최신 내용이 보이고, 첨부·링크·고정 또는 노출 기간이 맞습니다. 관리자 저장 성공만으로 학생 안내를 마치지 않습니다.

> **비공개 공지에 개인정보나 회원 전용 자료를 보관하지 마세요.**
> 비공개 설정만으로 공지 본문·첨부의 접근 보호를 보장할 수 없습니다. 보호 범위를 확인하기 전에는 비공개 공지를 보안용 보관함이나 임시저장 대용으로 사용하지 말고 학생 개인정보·민감한 자료를 등록하지 않습니다.

## 시작 전 준비 <a href="#before-you-start" id="before-you-start"></a>

| 준비할 것 | 확인 기준 |
| --- | --- |
| 사용할 기능 | 전체 안내인지, 정책이 있는 게시판인지, 메인 화면 팝업인지 먼저 정합니다 |
| 제공 범위·권한 | 조회·작성·수정·삭제 권한은 별개입니다. 사용자 정의 게시판·공지/프로모션은 제공되는 환경인지 먼저 확인합니다 |
| 제목·내용 | 예: `10월 수업 일정 안내`. 날짜·대상·변경 사항·연결할 안내를 준비합니다 |
| 첨부·링크 | 배포 가능한 파일·최종 주소를 준비합니다. 개인정보·인증정보·유료 자료의 공개 링크는 넣지 않습니다 |
| 게시판 정책 | 조회 대상과 글 작성·댓글·대댓글·첨부·비밀글 허용을 각각 정합니다 |

## 메뉴와 기능 선택 <a href="#section-2" id="section-2"></a>

| 메뉴 | 사용할 때 | 다른 기능과 구분할 점 |
| --- | --- | --- |
| 게시판 관리 → 공지사항 | 기존 공지 작성·수정·상단 고정 | 사용자 정의 게시판의 조회 대상·댓글 정책 설정을 가져오지 않습니다 |
| 게시판 관리 → 사용자 정의 게시판 | 게시판 생성·정책 설정·글/댓글 관리 | 게시판 생성과 페이지 연결·발행은 별개입니다 |
| 홈페이지 관리 → 공지·프로모션 관리 | 메인 화면에 기간·기기별 안내 표시 | 공지사항의 상단 고정이나 전체 페이지 배너가 아닙니다 |

사용자 정의 게시판·공지/프로모션 메뉴가 없거나 열리지 않으면 제공 여부·환경·권한을 확인합니다. 기존 공지사항이 보인다는 이유로 두 기능도 제공된다고 판단하지 않습니다. 학생 질문의 답변 상태를 처리하는 Q&A는 이 게시판 관리와 구분합니다.

## 1. 기존 공지사항 작성하기 <a href="#step-1" id="step-1"></a>

1. **게시판 관리 → 공지사항**을 엽니다. 제목·내용 검색과 목록의 공개 상태를 확인합니다.
2. 목록 상단의 **글쓰기**를 눌러 작성 화면을 엽니다. 공지가 없는 첫 화면의 **공지 작성**도 같은 작성 화면으로 이동합니다.
3. **공지사항 제목**과 **본문**을 입력합니다. 제목은 현재 입력 화면에 맞춰 80자 이내의 짧은 문구로 준비합니다.
4. 필요하면 **파일 첨부**로 파일을 올립니다. 업로드가 끝나면 파일명·개수와 실제 첨부 목록을 확인합니다.
5. **공개 여부**의 **비공개** 스위치를 확인합니다. 스위치를 켜면 비공개, 끄면 공개 설정입니다. 비공개의 접근 보호는 상단 경고를 따릅니다.
6. **작성**을 누릅니다. 업로드 중에는 작성을 마치지 않습니다. 성공 후 목록에서 같은 제목·상태를 확인하고 상세를 다시 엽니다.

공지사항에는 별도 **임시 저장**·승인 대기·예약 발행 절차가 없습니다. 공개로 작성하면 별도 웹빌더 발행 없이 공개 상태로 등록되므로, 작성 전 내용을 검토합니다. 저장하지 않고 **취소**하거나 화면을 나간 내용을 다시 불러올 수 있다고 보장하지 않습니다.

첨부 영역의 `PDF·이미지 / 최대 5MB` 안내와 실제 선택·업로드할 수 있는 파일 기준에 차이가 있어 최종 허용 기준은 아직 확인이 필요합니다. 화면 도움말을 전체 서비스의 확정 허용 목록으로 사용하지 않습니다. 업로드 오류가 나면 해당 파일이 목록에 추가됐는지 먼저 확인하고, 실패한 파일까지 저장됐다고 가정하지 않습니다.

> **화면 예시 준비 중** · 공지사항에서 글을 찾고 공개 상태와 고정 여부를 확인합니다. 목록 제외만으로 상세 접근 보호를 판단하지 않습니다.

> **화면 예시 준비 중** · 내용을 검토하고 업로드가 끝난 첨부를 확인한 뒤 작성합니다. 비공개 설정을 안전한 임시저장으로 사용하지 않습니다.

## 2. 공지 수정·상단 고정·정리하기 <a href="#step-2" id="step-2"></a>

| 작업 | 순서·확인할 결과 |
| --- | --- |
| 내용 수정 | 상세의 **수정** → 제목·본문·첨부 확인 → **수정** → 같은 상세 재조회. 공개 중인 글의 변경을 별도 발행 대기로 생각하지 않습니다 |
| 상단 고정 | 목록의 해당 글 관리 메뉴에서 **상단 고정** → 고정 아이콘·정렬·방문자 목록 확인. 비공개 공지는 고정할 수 없습니다 |
| 고정 해제 | **고정 해제** → 목록과 방문자 순서 재확인. 해제는 글 삭제가 아닙니다 |
| 공개 상태 변경 | **공개로 전환 / 비공개로 전환** → 상태 재조회. 비공개로 바꾸면 기존 상단 고정도 해제됩니다. 다시 공개해도 고정이 자동 복원된다고 생각하지 않습니다 |
| 삭제 | 삭제 확인 창의 제목·대상을 확인한 뒤 진행합니다. 복구 화면이나 자동 복구를 보장하지 않으므로 먼저 내용을 별도로 보관할지 판단합니다 |

공개 공지를 PC·모바일 방문자 목록에서 찾아 제목·본문·고정 순서를 확인합니다. 첨부는 관리자 상세의 **미리보기 / 다운로드**와 방문자의 실제 열람 결과를 구분합니다. 파일 업로드·글 저장 성공만으로 첨부 열람 완료를 판단하지 않습니다.

비공개 전환 후 목록에서 사라진 것만으로 직접 주소 접근까지 차단됐다고 안내하지 않습니다. 접근 보호 여부가 아직 확인되지 않았다면 민감한 내용을 올리지 말고 담당자에게 확인합니다. 운영 비공개 글을 시험 삼아 열거나 공유하지 않습니다.

> **화면 예시 준비 중** · 수정한 내용과 상단 고정 결과를 방문자 화면에서 확인합니다. 파일 연결과 실제 열람도 구분합니다.

> **동작 예시 준비 중** · 수정 후 같은 공지를 다시 열어 확인하고 고정/해제 결과를 방문자 목록에서 확인합니다.

## 3. 사용자 정의 게시판 만들고 정책 정하기 <a href="#step-3" id="step-3"></a>

이 절은 **사용자 정의 게시판이 제공되는 환경에서만** 진행합니다. 기존 공지사항·Q&A 설정을 변경하는 절차가 아닙니다.

1. **사용자 정의 게시판 → 게시판 만들기**로 **새 게시판 만들기** 화면을 엽니다.
2. **게시판 이름**과 필요한 **설명**을 입력합니다. 같은 사이트의 기존 게시판과 이름이 중복되지 않게 합니다.
3. **조회 대상 / 게시글 작성 대상 / 댓글**을 각각 선택합니다.
4. 필요한 경우에만 **1단계 대댓글 허용 / 첨부파일 / 비밀글**을 켭니다.
5. **게시판 만들기**를 누른 뒤 상세에서 저장된 정책과 연결 페이지를 확인합니다.
6. 정책을 바꿀 때는 **게시판 설정 → 설정 수정 → 변경사항 저장** 후 다시 확인합니다.

| 설정 | 선택·영향 |
| --- | --- |
| 조회 대상 | **누구나 / 로그인 회원 / 수강 회원**. 수강 회원은 해당 사이트의 유효한 수강 권한 기준이며 특정 강좌별 게시판 지정과 같지 않습니다 |
| 게시글 작성 대상 | **운영자만 / 접근 가능한 회원**. 누구나 조회할 수 있어도 비회원 글 작성까지 허용하는 것은 아닙니다 |
| 댓글 | **사용 안 함 / 접근 가능한 회원**. 댓글을 끄면 운영자도 새 댓글을 작성할 수 없습니다 |
| 1단계 대댓글 허용 | 댓글이 켜져 있을 때 별도로 선택합니다. 댓글을 끄면 함께 꺼지며 대댓글에 다시 답글을 다는 구조는 아닙니다 |
| 첨부파일 | 신규 첨부 허용 여부입니다. 꺼도 기존 파일을 일괄 삭제하는 설정이 아닙니다 |
| 비밀글 | 신규 비밀글 작성 허용 여부입니다. 꺼도 기존 비밀글을 일반 공개 글로 바꾸는 설정이 아닙니다 |

새 게시판의 초기값은 **누구나 조회·운영자만 작성·댓글/대댓글/첨부/비밀글 끔**입니다. 회원 전용으로 운영하려면 조회 대상을 저장 전에 바꿉니다. 게시판 정책과 실제 담당자의 관리 권한도 별도로 확인합니다.

> **화면 예시 준비 중** · 조회 대상과 글 작성·댓글 정책을 각각 저장합니다. 누구나 조회해도 비회원 글 작성까지 허용되는 것은 아닙니다.

## 4. 게시글·댓글 관리하기 <a href="#step-4" id="step-4"></a>

1. 게시판 상세의 **게시글** 탭에서 제목·작성자, **전체 / 게시됨 / 숨김**, **공개글 / 비밀글**을 구분해 찾습니다.
2. **게시글 작성**에서 제목·본문을 입력하고 허용된 경우에만 첨부·비밀글을 설정합니다.
3. **게시하기**를 누른 뒤 같은 게시글 상세에서 내용·상태·파일을 다시 확인합니다. 임시저장·승인 단계 없이 게시 상태로 등록됩니다.
4. 상세 관리 메뉴의 **수정 / 상단 고정 / 고정 해제 / 숨김 처리 / 다시 게시 / 게시글 삭제**는 필요한 작업만 선택합니다. 제공되는 행동은 권한에 따라 달라집니다.

**게시됨·숨김은 글의 노출 상태를, 공개글·비밀글은 열람 대상을 구분합니다.** 숨김은 일반 방문자 노출을 중단하는 관리 상태이고, 비밀글은 본문·댓글·첨부 열람 대상을 제한하는 방식입니다. 제목·작성자 같은 목록 정보까지 모두 감추는 기능으로 안내하지 않습니다. 작성자·다른 회원·비회원·관리 권한자가 실제로 열람할 수 있는 범위는 각각 확인합니다.

댓글이 허용되고 글이 게시 중이면 상세의 입력란에서 **댓글 등록**합니다. 대댓글이 허용되면 최상위 댓글의 **답글 → 답글 등록**을 사용합니다. 숨김 글이나 댓글 사용 안 함에서는 새 댓글을 작성하는 절차로 안내하지 않습니다. 댓글 기능을 꺼도 관리 화면에는 기존 댓글이 남습니다. 댓글을 삭제하려면 삭제 권한과 삭제 확인 절차를 별도로 확인합니다.

첨부·비밀글 기능을 끈 뒤에도 기존 첨부를 임의로 제거하거나 비밀글을 공개로 바꾸지 않습니다. 변경 전후 목록·파일·비밀글 상태를 다시 확인합니다. 첨부 개수·형식·용량은 공지사항이나 영상 업로드 기준을 그대로 적용하지 않습니다.

> **화면 예시 준비 중** · 게시됨/숨김과 공개글/비밀글은 다릅니다. 댓글과 답글은 게시판 정책·글 상태에 맞게 사용합니다.

## 5. 게시판 연결 페이지와 방문자 결과 확인하기 <a href="#step-5" id="step-5"></a>

게시판을 만들거나 글을 게시해도 새 페이지·메뉴가 자동으로 생기지 않습니다. **연결 페이지** 탭은 연결 현황을 확인하는 곳이며, 게시판을 직접 연결·해제하는 편집 화면이 아닙니다.

| 표시·행동 | 확인할 것 |
| --- | --- |
| 연결·미연결 | 연결 배지는 작업본 연결도 포함할 수 있습니다. 연결만으로 방문자 공개 완료를 판단하지 않습니다 |
| 게시 중 / 비공개 / 임시저장 | 연결 페이지의 상태입니다. 게시글의 게시됨/숨김과 구분합니다 |
| 수강생 사이트에서 보기 | 공개된 대표 연결 페이지가 있을 때 사용하는 이동입니다. 버튼 활성만으로 모든 페이지·역할의 접근 성공을 판단하지 않습니다 |
| 웹빌더 열기 | 최종 이동 경로·편집 대상 확인이 필요합니다. 다른 페이지를 열거나 메인을 저장하는 위험을 먼저 확인합니다 |

> **커스텀 페이지의 게시판 연결·편집은 보류합니다.**
> [페이지·메뉴 구성하기](pages-and-menus.md)의 안내처럼 선택한 페이지가 아닌 메인 페이지를 바꿀 위험이 있습니다. 연결 페이지 탭에서 올바른 대상으로 이동하는지도 아직 확인되지 않았으므로, 커스텀 빌더로 들어가 게시판을 연결·저장·발행하지 않습니다. 기존 연결 현황만 읽고 필요한 변경은 담당자에게 확인하세요.

담당자가 안전한 연결 방법을 확인한 뒤에도 페이지의 발행본·공개, 게시판 정책, 글 상태는 각각 확인해야 합니다. 페이지 공개와 게시판의 회원 전용 설정은 다릅니다. PC·모바일의 표시와 접근 보호가 확인되지 않았다면 회원 전용·비공개 보호가 완료됐다고 안내하지 않습니다.

게시판 삭제는 페이지 자체를 삭제하는 작업과 다릅니다. 삭제 확인 창의 연결 페이지·글/댓글 영향과 보관 안내를 확인합니다. 보관 기간이 표시된다고 운영자가 화면에서 복구할 수 있는 것은 아닙니다. 필요한 글·댓글이 있는지 확인하지 않은 채 삭제하지 않습니다.

> **화면 예시 준비 중** · 연결 현황과 페이지 상태를 따로 확인합니다. 연결 배지만으로 방문자 공개 완료를 판단하지 않습니다.

## 6. 공지·프로모션 설정하기 <a href="#step-6" id="step-6"></a>

이 절은 **공지·프로모션이 제공되는 환경에서만** 진행합니다. 현재 안내 대상은 수강생 사이트 **메인 화면**입니다. 전체 페이지·특정 강좌·특정 회원에게만 노출하는 타기팅 기능으로 안내하지 않습니다.

1. **홈페이지 관리 → 공지·프로모션 관리 → 공지·프로모션 등록**을 엽니다.
2. **기본 정보**에서 제목·**노출 디바이스**와 **표시 방식**을 정합니다.
3. **다음 → 콘텐츠**에서 **텍스트만 / 이미지 포함**을 선택하고 본문을 작성합니다. 이미지를 쓰더라도 대체 안내 본문을 준비합니다.
4. **다음 → 노출 조건**에서 KST 공개 시작·종료 시각, 노출 시점·닫기 방식·필요한 클릭 이동을 설정합니다.
5. 아직 방문자에게 표시하지 않을 내용은 **게시중지로 저장**합니다. 노출을 승인한 내용만 **게시**합니다. **다음**을 눌러 단계를 이동한 것만으로 설정이 저장되지는 않습니다.
6. 저장 후 상세에서 제목·본문·기간·기기·상태·버전을 다시 확인합니다. 충돌 오류가 나면 최신 설정을 다시 읽고 변경 내용을 대조합니다.

| 설정 | 준비·확인 기준 |
| --- | --- |
| 제목·본문 | 제목 30자·본문은 짧은 안내로 준비합니다. 공지사항의 긴 본문 입력과 같은 편집 기준이 아닙니다 |
| 노출 디바이스 | **PC + 모바일 / PC / 모바일**. 회원 유형 선택이 아닙니다 |
| 화면 가장자리에 표시 | PC에서는 화면 오른쪽의 팝업으로, 모바일에서는 화면 아래에서 올라오는 창으로 표시합니다. |
| 화면 중앙에 표시 | PC와 모바일 모두 화면 중앙에 창으로 표시합니다. |
| 이미지 포함 | JPG/PNG, 5MB 이하·16:9·최소 960×540px 기준으로 준비합니다. 업로드/크롭 후 실제 결과를 다시 확인합니다 |
| 공개 기간 | 한국 시간(KST)으로 시작 시각부터 종료 시각 직전까지입니다. 종료 시각은 포함하지 않으며, 시작보다 늦은 종료 시각이 필요합니다 |
| 노출 시점 | 페이지 진입 후 즉시 또는 설정한 지연 시간. 공개 시작일 예약과 다릅니다 |
| 닫기 방식 | 현재 브라우저 세션 동안 닫기 또는 N일간 보지 않기. 다른 기기까지 동기화되는 회원별 설정으로 안내하지 않습니다 |
| 클릭 이동 | 링크 URL과 현재/새 탭을 확인합니다. 자세히 보기를 눌러 실제 도착 페이지를 확인합니다 |

> **화면 예시 준비 중** · 기간·기기·표시 방식을 확인하고 게시중지로 저장하거나 게시합니다. 다음 버튼은 저장 완료가 아닙니다.

## 7. 프로모션 상태와 실제 노출 확인하기 <a href="#step-7" id="step-7"></a>

| 상태 | 뜻·다음 확인 |
| --- | --- |
| 게시중지 | 저장됐지만 공개 조회 대상이 아닙니다. 다시 게시하려면 기간·내용을 확인합니다 |
| 예약 | 게시 상태이며 시작 전입니다. 저장 직후 메인에 안 보여도 오류로 단정하지 않습니다 |
| 노출 중 | 게시·현재 기간 조건을 충족합니다. 실제 기기·메인 경로·닫기 이력·다른 메시지와의 표시를 확인합니다 |
| 종료 | 종료 시각을 지났습니다. 기간을 수정한 뒤 게시 여부를 확인하며 과거 항목을 무조건 재게시하지 않습니다 |

PC·모바일 **메인 화면**에서 이미지·본문·닫기·자세히 보기와 실제 연결 주소를 확인합니다. 여러 메시지의 기간이 겹쳐도 저장될 수 있지만 모두 동시에 같은 방식으로 표시된다는 뜻은 아닙니다. 중앙 모달·하단 바텀시트·레이어 팝업이 어떤 순서로 나타나는지, 서로 겹치거나 가리지 않는지 실제 화면에서 확인합니다.

한 번 닫은 항목은 같은 브라우저의 세션·기간 기록 때문에 다시 안 보일 수 있습니다. 새로고침만으로 기록이 없어지거나, 내용을 수정하면 모든 방문자에게 다시 뜬다고 보장하지 않습니다. 확인 중인 브라우저·기기에서 이미 닫은 항목인지 확인합니다.

노출을 중단하려면 **게시중지** 후 상태와 방문자 결과를 다시 확인합니다. 이미 열린 화면이 즉시 모두 닫힌다고 보장하지 않습니다. **복제**는 게시중지 상태의 새 항목으로 시작하므로 기간·링크를 재확인합니다. 삭제가 제한된 노출 중·예약 항목은 게시 상태부터 확인하고, 삭제를 노출 중지의 첫 수단으로 쓰지 않습니다.

성과 요약의 **노출 수 / CTA 클릭 수 / 클릭률**은 노출·클릭 기록을 모은 수치입니다. **CTA 클릭 수**는 **자세히 보기** 같은 이동 버튼을 누른 횟수입니다. 실제 학생 수·읽음 완료·구매 건수와 같지 않습니다. 성과를 비교할 때는 집계 시점을 구분합니다. 중복 기록이나 브라우저의 집계 정보 전송 실패가 수치에 영향을 주었는지는 담당자에게 확인을 요청합니다.

> **화면 예시 준비 중** · 메인 화면의 실제 표시·링크·닫기를 확인합니다. 노출 중 상태와 방문자 화면, 게시중지 후 반영은 각각 확인합니다.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 기존 공지사항·사용자 정의 게시판·공지/프로모션의 메뉴와 목적을 구분했습니다.
- [ ] 공개 공지의 내용·상태·첨부를 다시 확인했고 비공개를 접근 보호·임시저장으로 사용하지 않았습니다.
- [ ] 공지의 고정/해제와 비공개 전환 시 고정 해제를 구분했습니다.
- [ ] 게시판 조회·글 작성·댓글/대댓글·첨부·비밀글 정책과 실제 담당자 권한을 확인했습니다.
- [ ] 게시글의 게시됨/숨김·공개글/비밀글, 기존 글/댓글·파일 보존을 구분했습니다.
- [ ] 커스텀 빌더의 편집 대상이 안전하게 구분되는지 확인하기 전에는 편집하지 않았고, 페이지 연결·발행·공개와 방문자 접근을 구분했습니다.
- [ ] 프로모션의 저장과 게시를 구분하고 예약·노출 중·종료 상태를 확인했습니다. 메인 화면의 경로·기기·닫기 이력과 링크의 실제 이동 결과도 확인했습니다.
- [ ] PC·모바일과 필요한 역할별 결과를 확인했고 저장 알림·성과 집계를 학생 열람 완료로 사용하지 않았습니다.

## 자주 막히는 부분 <a href="#troubleshooting" id="troubleshooting"></a>

| 상황 | 확인할 것 |
| --- | --- |
| 비공개 공지가 목록에서 사라졌어요 | 목록 제외와 상세 접근 보호는 다릅니다. 개인정보·전용 자료 보관을 중단하고 보호 동작을 담당자에게 확인합니다 |
| 비공개 공지를 고정할 수 없어요 | 비공개 고정은 제한됩니다. 공개 전환은 내용을 검토한 뒤 결정하고 필요하면 다시 고정합니다 |
| 첨부가 없거나 열리지 않아요 | 업로드 완료·저장된 첨부 목록과 실제 방문자 권한/열람을 각각 확인합니다. 도움말의 형식·용량만으로 성공을 보장하지 않습니다 |
| 게시판/프로모션 메뉴가 없어요 | 해당 사이트의 기능 제공 여부와 계정 권한을 담당자에게 확인합니다. 공지 메뉴와 같은 제공 조건이라고 판단하지 않습니다 |
| 게시판을 만들었는데 학생에게 안 보여요 | 페이지 자동 생성은 없습니다. 연결 현황·발행본·공개·게시판 정책·글 상태를 확인하고 빌더 제약이 해결되기 전 편집은 중단합니다 |
| 연결 배지는 있는데 보기 버튼이 꺼져요 | 작업본만 연결됐거나 대표 공개 페이지가 없을 수 있습니다. 연결 페이지 탭의 상태를 확인합니다 |
| 댓글 입력이나 답글이 없어요 | 댓글 정책·게시글 상태, 대댓글 허용·최상위 댓글 여부와 권한을 확인합니다. 운영자도 댓글 끔을 우회하지 않습니다 |
| 비밀글/첨부를 껐는데 기존 글이 남아요 | 신규 허용을 끄는 설정입니다. 기존 비밀글의 보호·첨부가 사라진 것으로 판단하지 않습니다 |
| 노출 중인데 팝업이 안 보여요 | 메인 경로·대상 기기·공개 조건·닫기 이력·지연 시간·다른 메시지 표시를 확인합니다 |
| 저장 충돌·일부 결과가 불명확해요 | 같은 항목을 다시 조회해 최신 설정·버전과 결과를 확인합니다. 중복 생성·재게시를 반복하지 않습니다 |
