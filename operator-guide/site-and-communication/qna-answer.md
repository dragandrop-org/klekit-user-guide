# Q&A 질문에 답변하기

> **검토용 가이드** · 실제 서비스 화면·동작 확인과 이미지 보완이 남아 있습니다. 본문의 실행 보류·주의사항을 먼저 확인하세요.

**게시판 관리 → Q&A**에서 수강생이 강좌·수업에 남긴 질문을 찾고 답글을 등록합니다. 질답 담당 강사·조교가 사용하는 기능 안내이며, 일반 고객 상담이나 주문 문의 처리 절차가 아닙니다.

**완료 기준:** 같은 질문을 다시 열었을 때 작성한 답글과 선택한 답변 상태가 맞고, 질문한 수강생도 답글을 확인할 수 있습니다. 등록 알림만으로 학생 열람·알림 수신까지 완료됐다고 판단하지 않습니다.

> **조회·답글 등록·상태 변경은 별도 권한입니다.**
> 조교라는 역할명이나 입력란 노출만으로 등록 성공을 보장하지 않습니다. 현재 화면과 서버의 답변 권한 기준에 차이가 있어 실제 담당 계정의 권한 조합을 먼저 확인해야 합니다. 권한 오류가 나면 운영자에게 확인하고 다른 사람의 계정을 빌리거나 질문을 공개로 바꿔 우회하지 않습니다.

## 시작 전 준비

| 준비할 것 | 확인 기준 |
| --- | --- |
| 담당 계정 | 해당 사이트의 Q&A 조회·답글 등록·필요한 상태 변경이 가능한 계정인지 확인합니다 |
| 질문 범위 | 담당 강좌·수업과 기존 질문/답글을 확인합니다. 강좌가 같아도 다른 수업 질문에 답하지 않도록 합니다 |
| 현재 상태 | 답변 대기·답변 중·답변 완료를 구분하고 기존 답변 담당 표시가 있으면 확인합니다 |
| 답글·이미지 | 답변할 내용과 필요한 풀이 이미지를 준비합니다. 학생 개인정보·배포할 수 없는 자료는 포함하지 않습니다 |
| 검수 환경 | 승인된 테스트 사이트·조교/수강생 계정·샘플 질문을 사용합니다. 촬영용으로 운영 질문·답글·상태를 바꾸지 않습니다 |

## 메뉴와 답변 상태

기본 진입은 **게시판 관리 → Q&A**입니다. 목록의 답변 상태는 공개/비공개나 학생의 읽음 여부가 아닙니다.

| 표시 | 뜻·사용 기준 |
| --- | --- |
| 전체 | 현재 강좌·검색 조건에 해당하는 세 답변 상태의 질문을 함께 봅니다 |
| 답변 대기 | 아직 처리 전인 질문을 찾습니다. 상태만으로 답글이 전혀 없다고 단정하지 않습니다 |
| 답변 중 | 추가 설명·확인이 필요한 질문을 이어서 처리합니다 |
| 답변 완료 | 답변 처리를 마친 상태입니다. 관리자 화면에서 새 답글 입력이 잠깁니다. 학생의 읽음·이해 완료를 뜻하지 않습니다 |
| 강좌 공통 질문 | 특정 수업을 지정하지 않은 질문입니다. 오류나 누락 수업으로 단정하지 않습니다 |
| 비공개 | 비밀 질문 표시입니다. 답변 상태와 별개이며 실제 담당자의 본문·이미지 접근을 확인합니다 |

## 1. 답변할 질문 찾기

1. **Q&A** 목록에서 **답변 대기** 또는 이어서 처리할 **답변 중**을 선택합니다.
2. 특정 강좌만 보려면 **필터**에서 강좌를 선택하고 **적용하기**를 누릅니다. 선택만 하고 팝업을 닫은 것을 적용 완료로 생각하지 않습니다.
3. 제목·수강생명·강좌명·강의명으로 검색어를 입력하고 **검색**을 누릅니다. 필요하면 **정렬 → 최신순 / 오래된순 / 조회수순 → 적용하기**로 순서를 바꿉니다.
4. 제목과 수강생·강좌·강의명·상태를 대조한 뒤 질문을 엽니다. 목록 건수는 현재 강좌·검색 범위의 값이며 담당자 개인의 미처리 건수로 해석하지 않습니다.

질문이 보이지 않으면 선택한 상태·강좌·검색 조건과 페이지를 확인합니다. 현재 목록에는 기간·담당자별 필터를 사용하는 절차가 없으므로 보이지 않는 필터를 찾도록 안내하지 않습니다.

> **화면 예시 준비 중** · 답변 상태와 강좌·검색 조건을 확인하고 답변할 질문을 엽니다.

## 2. 질문 내용과 기존 답글 확인하기

1. 상세의 제목·작성자·강좌·수업을 확인합니다. **강좌 공통 질문**이면 질문 본문에서 어떤 내용을 묻는지 먼저 확인합니다.
2. 질문 본문과 기존 **댓글** 영역을 읽습니다. 이 영역에서 학생의 추가 내용과 담당자의 답글을 함께 확인합니다.
3. 현재 답변 상태와 **답변 담당** 표시가 있으면 확인합니다. 이 표시는 직접 담당자를 고르거나 다른 조교에게 재배정하는 버튼이 아닙니다.
4. 비공개 질문이나 이미지가 열리지 않으면 권한·업로드 상태를 확인합니다. 확인하지 못한 내용을 추측해서 답하거나 외부 공개 링크로 옮기지 않습니다.

다른 담당자의 답글이 이미 있으면 같은 내용을 중복 등록하기 전에 최신 상세를 확인합니다. 화면을 열어 둔 사이 다른 사람이 처리할 수 있으므로 오래 열린 화면의 상태만 보고 완료 처리하지 않습니다.

> **화면 예시 준비 중** · 질문의 수업과 기존 댓글을 먼저 확인합니다. 강좌 공통 질문과 담당 표시를 구분합니다.

## 3. 답글 작성하고 이미지 확인하기

1. 상세 아래 **답글 작성** 입력란에 답변을 입력합니다. 질문의 어느 부분에 답하는지 알 수 있게 작성하고 기존 답글과 중복되는지 확인합니다.
2. 풀이 이미지가 필요하면 편집기의 이미지 삽입 기능을 사용합니다. 업로드가 끝나 실제 이미지가 본문에 나타나는지 확인합니다.
3. 작은 글씨·수식·사진 회전·잘림과 줄바꿈을 확인합니다. 이미지만 넣을 때도 질문과 연결되는 짧은 설명을 함께 적으면 내용을 확인하기 쉽습니다.
4. 내용이 준비되면 **답글 등록**을 누릅니다. 이 단계에서는 바로 등록되는 것이 아니라 상태 선택 창이 열립니다.

이미지 삽입과 PDF·영상 등 일반 파일 첨부는 다릅니다. Q&A의 최종 허용 형식·용량·개수와 학생 열람은 확인 대기이므로 영상 업로드의 5GB 기준이나 공지 첨부 도움말을 가져오지 않습니다. 이미지 업로드 성공도 답글 저장 성공과는 별개입니다.

별도 임시저장·자동저장 완료 표시를 전제로 안내하지 않습니다. 등록 전 화면을 벗어나거나 새로고침하면 입력 내용을 다시 불러올 수 있다고 보장하지 않으므로, 긴 답변은 개인정보 없는 작업본을 별도로 준비합니다.

> **화면 예시 준비 중** · 답글 내용과 풀이 이미지가 보이는지 확인한 뒤 답글 등록을 누릅니다.

## 4. 등록 후 상태 선택하고 결과 확인하기

1. **답글 등록 후 상태** 창에서 **답변 중 / 답변 완료** 중 하나를 선택합니다. 창을 열면 기본 선택은 **답변 중**입니다.
2. 추가 확인이나 학생의 설명이 더 필요하면 **답변 중**, 답변 처리를 마칠 때는 **답변 완료**를 선택합니다. 등록 후 **답변 대기**는 이 창의 선택 항목이 아닙니다.
3. **등록**을 누르고 처리가 끝날 때까지 기다립니다. **취소**로 창을 닫은 것은 답글 등록 완료가 아닙니다.
4. 등록 후 같은 질문을 다시 열어 답글 내용·이미지·작성자와 상태를 확인합니다. 목록으로 돌아가 바뀐 상태의 탭에서도 같은 질문을 찾습니다.
5. 승인된 테스트 수강생 계정에서 같은 질문의 답글·이미지를 확인합니다. 관리자 상세 조회 성공과 수강생 열람 성공을 구분합니다.

실패하거나 결과가 불명확하면 입력 내용을 보존하고 최신 상세부터 확인합니다. 이미 답글이 등록됐는지 확인하지 않고 **등록**을 반복해 중복 답글을 만들지 않습니다. 답글은 보이는데 선택한 상태가 다르면 권한·최신 상태를 운영자에게 확인합니다.

**답변 완료는 학생에게 알림이 도착했거나 학생이 읽었다는 뜻이 아닙니다.** 이메일·앱 알림·문자 등의 자동 발송이나 읽음 확인은 이 절차의 완료 결과로 보장하지 않습니다.

> **화면 예시 준비 중** · 등록 후 상태를 선택하고 등록을 눌러 답글 작성을 마칩니다.

> **화면 예시 준비 중** · 저장된 답글과 상태를 다시 확인합니다. 수강생 열람과 읽음·알림 수신은 별개입니다.

> **동작 예시 준비 중** · 답글과 등록 후 상태를 정한 뒤 같은 질문을 다시 열어 결과를 확인합니다.

## 5. 상태만 변경하거나 추가 답글 달기

상세의 **답변 상태 변경** 선택란은 상태 변경 권한이 있는 계정에 표시됩니다. 답글 등록 창에서 상태를 고르는 것과 별도 기능입니다.

| 필요한 작업 | 순서·주의할 점 |
| --- | --- |
| 기존 답변을 확인하고 완료 처리 | 내용·이미지 확인 → 상세 상태에서 **답변 완료** 선택 → **답변 완료로 변경할까요?** 창 확인 → **답변 완료로 변경** → 재조회 |
| 완료된 질문에 새 답글 추가 | 권한 있는 담당자가 상세 상태를 **답변 중**으로 변경 → 상태 재조회 → 새 답글 작성 → 등록 후 상태 선택·등록 → 재조회 |
| 대기로 되돌리기 | 필요한 경우에만 **답변 대기**로 변경합니다. 답글 삭제가 아니며 담당자 정보에도 영향이 있으므로 단순 재배정 수단으로 쓰지 않습니다 |

상태만 바꿔도 답글이 자동 생성·수정되는 것은 아닙니다. 반대로 완료 상태에서 새 답글을 쓰기 위해 기존 답글을 지울 필요도 없습니다. 상태 선택란이 없으면 권한 있는 운영자에게 요청하고 다른 화면에서 우회하지 않습니다.

완료된 질문의 추가 답글 입력 제한은 현재 관리자 화면 기준입니다. 수강생의 추가 질문·댓글이 항상 같은 방식으로 잠기거나 자동으로 다시 답변 중이 된다고 보장하지 않습니다.

## 6. 본인 답글 수정하거나 삭제하기

1. 본인이 작성한 답글의 **더보기 → 수정**을 엽니다. 다른 작성자의 답글 수정 메뉴가 없으면 정상적인 화면 제한일 수 있습니다.
2. 내용·이미지를 고치고 **저장**합니다. **취소**는 수정 내용을 저장하지 않습니다.
3. 같은 질문을 다시 열어 수정한 답글과 현재 답변 상태를 확인합니다. 답글 수정으로 상태까지 원하는 값으로 바뀌었다고 생각하지 않습니다.

삭제가 꼭 필요하면 본인 답글의 **더보기 → 삭제**에서 대상을 확인하고 최종 **삭제**합니다. 화면은 복구 불가로 안내하므로 내용을 확인한 뒤 결정합니다. 삭제를 오류 재시도나 완료 상태 해제의 수단으로 쓰지 않으며, 삭제 후 남은 답글·상태를 다시 확인합니다.

본인 답글 메뉴가 보여도 비밀 질문 접근·서버 권한과 처리 결과는 별도입니다. 다른 담당자 답글의 수정·삭제를 이 화면의 일반 절차로 안내하지 않습니다.

> **화면 예시 준비 중** · 본인이 작성한 답글을 수정하고 저장합니다. 수정한 내용과 현재 답변 상태를 각각 확인합니다.

## 완료 후 확인

- [ ] 담당 계정으로 질문 조회·답글 등록·필요한 상태 변경이 가능한지 확인했습니다.
- [ ] 질문의 강좌·수업·공통 질문 여부와 기존 댓글·담당 표시를 확인했습니다.
- [ ] 답글 내용·이미지의 업로드/표시를 확인했고 일반 파일 지원·자동저장을 가정하지 않았습니다.
- [ ] 답글 등록 후 상태 창에서 의도한 상태를 선택하고 최종 등록했습니다.
- [ ] 같은 상세·목록을 다시 열어 답글·작성자·상태와 중복 여부를 확인했습니다.
- [ ] 추가 답글·본인 수정/삭제 결과와 상태를 각각 확인했고 다른 작성자의 답글을 임의 변경하지 않았습니다.
- [ ] 테스트 수강생의 답글·이미지 열람을 확인했고 완료 상태를 읽음·알림 수신으로 사용하지 않았습니다.

| 조교인데 Q&A나 입력란이 안 보여요 | 사이트·로그인 계정과 조회/답글 권한을 확인합니다. 역할 이름만으로 기능을 보장하지 않습니다 |
| 답변 대기에 질문이 안 보여요 | 전체·답변 중/완료와 강좌·검색·페이지를 확인합니다. 다른 담당자가 상태를 바꿨는지도 최신 상세로 확인합니다 |
| 답글 등록을 눌렀는데 안 올라왔어요 | 상태 선택 창의 최종 등록 여부와 최신 상세를 확인합니다. 팝업 취소·업로드 완료는 답글 등록 완료가 아닙니다 |
| 답변 완료라 입력할 수 없어요 | 추가 답글이 필요하면 권한 있는 담당자가 먼저 답변 중으로 변경하고 결과를 확인합니다 |
| 답글은 보이는데 상태가 달라요 | 최신 상세·권한 조합과 다른 담당자의 변경을 확인합니다. 중복 답글을 올려 상태를 맞추지 않습니다 |
| 비공개 질문이나 이미지가 안 열려요 | 실제 계정의 접근 권한·업로드/표시를 확인합니다. 질문을 공개하거나 외부에 올려 우회하지 않습니다 |
| 수정 메뉴가 없거나 저장이 실패해요 | 본인이 쓴 답글인지, 로그인 정보·접근 권한이 유효한지 확인합니다. 실패하면 최신 답글을 읽고 수정안을 대조합니다 |
| 완료했는데 학생이 못 봤다고 해요 | 해당 학생 계정에서 같은 질문·답글·이미지를 확인합니다. 완료 상태만으로 열람·알림 수신을 판단하지 않습니다 |
