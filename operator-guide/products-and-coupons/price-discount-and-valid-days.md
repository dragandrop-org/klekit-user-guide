# 가격·할인·수강 기간 설정

<figure><img src="../.gitbook/assets/branding/page-headers/products-and-coupons/price-discount-and-valid-days-v2.png" alt="가격·할인·수강 기간 설정하기 대표 이미지"><figcaption></figcaption></figure>

**업무 대상:** 상품 판매·쿠폰 운영을 맡은 담당자용 안내입니다. 강의 콘텐츠만 관리한다면 판매 조건 변경은 학원 운영자에게 요청하세요. 실제 작업 가능 범위는 본인 계정의 권한을 확인하세요.

상품에 포함된 콘텐츠의 금액과 할인, 강좌를 이용할 기간을 설정합니다. **콘텐츠 정가, 상품 할인 전 금액, 할인 후 가격, 주문 결제 금액은 서로 다릅니다.**

**작업 순서:** 구성 금액 확인 → 무료/유료 선택 → 할인 설정 → 강좌 포함 시 기간 설정 → 저장·재조회 → 구매 금액·이용 기간 확인

## 시작 전 준비 <a href="#before-you-start" id="before-you-start"></a>

| 준비할 것 | 확인 기준 |
| --- | --- |
| 상품과 구성 | [상품 생성·콘텐츠 연결](create-products-and-connect-content.md)을 먼저 확인 |
| 금액 | 콘텐츠별로 상품에서 사용할 할인 전 구성 금액 |
| 할인 | 할인없음·금액 할인·비율 할인 중 선택 |
| 수강 기간 | 강좌 포함 여부와 제공할 일수. 자료·교재 기간으로 일괄 해석하지 않기 |
| 판매 준비 | 유료 등록 가능 플랜과 실제 판매자·콘텐츠·재고 조건 |

## 메뉴 위치 <a href="#menu-location" id="menu-location"></a>

상품 생성의 **정보 입력**, 또는 상품 상세의 **상품 설정**으로 들어갑니다. **콘텐츠 선택**에서 구성 금액을 설정하고 **수강료 설정**에서 무료/유료·할인을 설정합니다. 현재 화면은 교재·자료 상품에도 `수강료 설정`이라는 제목을 사용합니다.

## 1. 구성 금액과 합계 확인하기 <a href="#step-1" id="step-1"></a>

| 금액 | 의미 |
| --- | --- |
| 콘텐츠 정가 | 새 상품을 구성할 때 불러오는 참고값. 기존 상품 가격 자동 변경 없음 |
| 구성 금액 | 해당 상품에서 콘텐츠별로 사용할 할인 전 기준 금액 |
| 수강료 합계 | 구성 금액에 제공 수량을 적용해 합산한 상품의 할인 전 금액 |
| 할인 후 가격 | 상품 할인을 적용한 가격. 주문별 쿠폰·배송비 등과 구분 |

**콘텐츠 선택**의 각 항목 옆 금액을 입력합니다. 새 상품 관리 화면에서는 합계가 자동 계산되므로 **수강료 합계 칸을 직접 수정하는 방식이 아닙니다.** 단일 상품도 선택한 콘텐츠 옆 구성 금액을 수정합니다.

예를 들어 강좌 80,000원과 교재 20,000원을 각각 수량 1로 구성하면 할인 전 합계는 100,000원입니다. 각 구성 금액은 0원 이상 정수로 입력하고, 합계를 다시 확인합니다.

> **화면 예시 준비 중** · 구성 금액을 입력하면 할인 전 합계가 계산됩니다.

## 2. 무료·유료와 할인 설정하기 <a href="#step-2" id="step-2"></a>

**수강료 설정**에서 무료 또는 유료를 선택합니다. 유료 상품은 할인 전 합계가 0원보다 커야 합니다. 무료 상품은 구성 금액도 모두 0원으로 맞춥니다. **무료 선택만으로 기존 구성 금액이 자동 초기화된다고 가정하지 않습니다.**

| 할인 유형 | 설정할 값 | 예시: 할인 전 100,000원 |
| --- | --- | --- |
| 할인없음 | 별도 할인 없음 | 100,000원 |
| 금액 할인 | 할인할 원 단위 금액. 할인 전 금액을 초과하지 않기 | 10,000원 할인 → 90,000원 |
| 비율 할인 | 0~100% | 10% 할인 → 90,000원 |

위 예시는 상품 할인만 적용한 금액입니다. 실제 주문의 쿠폰·배송비·구성 변경 결과를 포함한 계산 예시가 아닙니다. 입력 화면의 가격 표시와 저장 후 조회한 금액을 함께 확인합니다.

**무료 체험 중에는 유료 상품 등록이 제한됩니다.** 제한 안내가 나오면 플랜 상태를 확인합니다. 할인으로 결제 금액을 0원으로 만든 상품도 할인 전 금액이 있는 유료 상품이므로 무료 등록으로 간주하지 않습니다.

> **화면 예시 준비 중** · 상품 할인과 실제 주문의 쿠폰·배송비는 구분합니다.

## 3. 강좌 포함 여부에 따라 수강 기간 설정하기 <a href="#step-3" id="step-3"></a>

| 상품 구성 | 기간 설정 |
| --- | --- |
| 강좌 단독 또는 강좌 포함 패키지 | 수강 기간을 확인. 유료 강좌가 포함되면 1~365일 필수 |
| 교재·디지털 자료만 포함 | 수강 기간을 입력하지 않음. 기간 입력이 없거나 값이 0으로 보이더라도 무제한 강좌를 제공한다는 뜻은 아님 |
| 강좌 여러 개 포함 | 상품의 공통 수강 일수. 구성품별로 다른 기간을 입력하는 방식이 아님 |

**수강 기간**에서 **직접입력**으로 일수를 입력하거나 **캘린더 지정**을 선택합니다.

달력 선택 시 표시되는 **총 N일**을 확인하세요. 현재 화면은 선택한 날짜와 오늘의 차이를 일수로 바꾸어 저장합니다. **달력의 날짜를 모든 구매자의 고정 종료일로 설정하는 기능으로 해석하지 않습니다.** 상품에 저장된 일수와 실제 구매자의 이용 시작·종료일은 따로 확인합니다.

무료 강좌와 유료 강좌는 기간 입력 조건이 다릅니다. 기간을 비워 두었다는 이유로 무제한 수강 상품으로 안내하지 마세요. 제공할 기간을 정해 일수로 입력하고 실제 수강권 지급 결과를 확인합니다.

> **화면 예시 준비 중** · 달력 선택 후 저장할 수강 일수를 확인합니다.

## 4. 저장하고 구매 결과 확인하기 <a href="#step-4" id="step-4"></a>

생성은 **최종 완료**, 수정은 **수정 완료**를 누릅니다. 상품 상세와 상품 설정을 다시 열어 구성 금액·할인·수강 일수를 확인합니다. 판매를 시작할 상품은 [판매 상태 관리](stock-and-sales-status.md)도 확인합니다.

구매 후에는 같은 주문의 상품 가격, 쿠폰 적용, 교재 배송비, 최종 결제 금액을 각각 구분합니다. 강좌는 지급된 수강권의 시작·종료일도 확인합니다. 관리자 설정이 맞아도 결제와 수강권 지급 결과는 별개입니다. 판매 전 구매 흐름 확인이 필요하다면 운영 책임자에게 요청하고, 확인용 주문을 임의로 만들지 않습니다.

상품의 가격·기간을 바꿔도 기존 주문 금액이 자동으로 다시 계산되거나 이미 지급된 수강권이 연장됐다고 판단하지 마세요. 기존 구매자의 기간을 바꾸려면 필요한 권한과 별도의 처리 절차를 확인합니다.

> **화면 예시 준비 중** · 저장된 상품 조건과 구매자의 실제 권한 결과는 별도로 확인합니다.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 콘텐츠별 구성 금액에 제공 수량을 적용해 합산한 결과가 상품 할인 전 합계와 일치합니다.
- [ ] 무료 설정은 구성 금액도 0원이며 유료 등록 제한을 확인했습니다.
- [ ] 할인 값과 저장 후 가격을 확인했습니다.
- [ ] 강좌 포함 여부에 맞게 기간을 설정하고 일수와 달력 날짜를 구분했습니다.
- [ ] 실제 구매 금액·수강권 결과와 기존 구매자의 변경 범위를 별도로 확인했습니다.

## 자주 막히는 부분 <a href="#troubleshooting" id="troubleshooting"></a>

| 상황 | 확인할 것 |
| --- | --- |
| 합계 금액 칸이 수정되지 않아요 | 합계는 자동 계산입니다. 콘텐츠별 구성 금액을 수정합니다 |
| 무료인데 최종 완료가 안 돼요 | 구성 금액이 남아 있는지 확인하고 모두 0원으로 맞춥니다 |
| 유료 선택이 제한돼요 | 무료 체험·플랜 조회 상태와 안내를 확인합니다 |
| 할인 값 오류가 나요 | 금액 할인은 할인 전 금액 이하, 비율 할인은 0~100%인지 확인합니다 |
| 수강 기간이 안 보여요 | 상품에 강좌가 있는지 확인합니다. 교재·자료만 구성하면 수강 기간을 입력하지 않습니다 |
| 달력 날짜와 학생 종료일이 달라요 | 달력은 일수 입력 방식입니다. 저장 일수와 지급된 수강권의 시작·종료일을 확인합니다 |
| 금액·기간을 바꿨는데 기존 구매 결과는 그대로예요 | 신규 상품 조건 변경과 기존 주문·수강권 변경은 별도입니다 |
| 가격 표시가 누락되거나 구매 금액과 달라요 | 저장된 구성 금액·할인, 주문 쿠폰·배송비를 나누어 확인합니다. 화면 표시만으로 임의 금액을 확정하지 않습니다 |
