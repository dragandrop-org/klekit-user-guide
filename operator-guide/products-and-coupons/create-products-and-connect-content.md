# 상품 만들고 콘텐츠 연결하기

> **검토용 가이드** · 실제 서비스 화면·동작 확인과 이미지 보완이 남아 있습니다. 본문의 실행 보류·주의사항을 먼저 확인하세요.

<figure><img src="../.gitbook/assets/branding/page-headers/products-and-coupons/create-products-and-connect-content-v2.png" alt="상품 만들고 콘텐츠 연결하기 대표 이미지"><figcaption></figcaption></figure>

**업무 대상:** 상품 판매·쿠폰 운영을 맡은 담당자용 안내입니다. 강의 콘텐츠만 관리한다면 판매 조건 변경은 학원 운영자에게 요청하세요. 실제 작업 가능 범위는 본인 계정의 권한을 확인하세요.

등록한 강좌·교재·디지털 자료를 학생이 구매할 **판매 상품**으로 구성합니다. 콘텐츠는 수업·교재 정보·자료 파일을 관리하고, 상품은 포함할 콘텐츠와 판매 조건을 관리합니다.

**작업 순서:** 콘텐츠 준비 → 상품 유형 선택 → 콘텐츠 연결 → 상품 정보·판매 조건 입력 → 최종 완료 → 미판매 보관 또는 판매 시작

## 시작 전 준비 <a href="#before-you-start" id="before-you-start"></a>

| 준비할 것 | 확인 기준 |
| --- | --- |
| 상품 생성·수정 권한 | 사용할 사이트와 담당 계정의 권한 |
| 연결할 콘텐츠 | [강좌](../content-management/course-create-and-edit.md), [교재](../content-management/textbook-create-and-edit.md), [디지털 자료](../content-management/digital-resource-and-files.md)를 먼저 등록 |
| 상품 구성 | 단일 콘텐츠인지, 여러 콘텐츠를 묶을지 결정 |
| 상품 정보 | 학생에게 표시할 제목·이미지·소개 |
| 판매 조건 | 구성 금액·할인·수강 기간·과세 설정, 교재 재고와 판매 준비 조건 |

같은 콘텐츠를 여러 상품에서 사용할 수 있습니다. 새 상품을 만들려고 원본 교재·자료를 다시 등록할 필요는 없습니다. 같은 교재를 사용하는 상품들은 그 교재의 재고를 공유합니다.

## 메뉴 위치 <a href="#menu-location" id="menu-location"></a>

관리자의 **상품 목록 → 상품 생성**에서 **상품 종류 선택**으로 들어갑니다. 유형을 선택하고 **다음 단계**를 누릅니다. 기존 상품 수정은 상품 상세의 **상품 설정**에서 진행합니다.

> **화면 예시 준비 중** · 판매할 구성에 맞춰 강좌·교재·디지털 자료·패키지를 선택합니다.

## 1. 상품 유형 선택하기 <a href="#step-1" id="step-1"></a>

| 판매할 구성 | 선택할 유형 | 예시 |
| --- | --- | --- |
| 강좌 하나 | 강좌 | 수학 개념 강좌 |
| 교재 콘텐츠 하나 | 교재 | 수학 개념 교재 |
| 디지털 자료 하나 | 디지털 자료 | 기출문제 PDF |
| 여러 콘텐츠를 함께 제공 | 패키지 | 여러 강좌, 서로 다른 교재·자료, 강좌+교재+자료 |

여러 강좌뿐 아니라 교재끼리·자료끼리 묶거나 종류를 섞을 때도 **패키지**를 선택합니다. 생성 화면에서 별도 `혼합` 유형을 찾아 선택하는 방식이 아닙니다.

상품 유형과 포함할 콘텐츠 종류를 맞춥니다. 기존 단일 상품을 수정하면서 다른 종류의 상품으로 바꾸는 것은 별도 확인이 필요합니다. 유형을 바꿀 판매 기획이라면 기존 상품과 구매자 영향부터 확인하세요.

## 2. 콘텐츠 선택하고 구성 확인하기 <a href="#step-2" id="step-2"></a>

1. **콘텐츠 선택 → 선택하기**를 누릅니다.
2. 해당 콘텐츠 종류와 이름으로 찾습니다.
3. 단일 상품은 콘텐츠 하나, 패키지는 포함할 콘텐츠들을 선택합니다.
4. 선택된 목록을 확인하고 선택 창의 **등록**을 누릅니다.
5. 상품 입력 화면에서 제목·종류·구성 금액을 다시 확인합니다.

여기서 **등록**은 선택 결과를 상품 입력 화면으로 가져오는 동작입니다. 아직 상품 생성이 끝난 것은 아닙니다.

| 변경할 것 | 화면에서 할 일 |
| --- | --- |
| 단일 상품의 콘텐츠 변경 | **콘텐츠 변경**에서 다른 콘텐츠 선택 |
| 단일 선택 취소 | 선택 해제 아이콘으로 연결 후보 제거 |
| 패키지 구성 추가·변경 | **선택하기**에서 전체 선택 목록 확인 후 등록 |
| 패키지 구성 제거 | 해당 항목의 제거 아이콘을 누르고 남은 목록 확인 |

새로 선택한 콘텐츠는 각각 수량 1로 구성됩니다. **현재 확인한 화면에는 수량 변경 입력이 없습니다.** 같은 교재를 여러 권 제공해야 한다면 담당자에게 가능한 처리 방법을 먼저 확인하세요. 같은 콘텐츠를 중복 선택해 수량을 늘리는 것으로 대신하지 않습니다.

> **동작 예시 준비 중** · 콘텐츠를 선택한 뒤 상품 입력 화면에서 포함 항목을 다시 확인합니다.

## 3. 상품 정보와 판매 조건 입력하기 <a href="#step-3" id="step-3"></a>

**기본 정보**의 **제목 입력**에 상품명을 입력하고 이미지·소개를 설정합니다. 콘텐츠 제목을 가져왔더라도 실제 판매 구성에 맞는지 확인하세요. 패키지라면 포함 강좌·교재·자료가 소개에 드러나도록 작성합니다.

| 설정할 항목 | 이어서 확인할 가이드 |
| --- | --- |
| 구성 금액·무료/유료·할인·수강 기간 | [가격·할인·수강 기간 설정하기](price-discount-and-valid-days.md) |
| 구성품별 과세·면세와 판매자 책임 확인 | [과세·면세 정보 설정하기](tax-settings.md) |
| 재고·품절·판매 시작·중지 | [재고·판매 상태 관리하기](stock-and-sales-status.md) |

교재·디지털 자료의 정가는 새 상품의 금액을 입력할 때 참고하는 값입니다. 상품에서 변경한 금액이 원본 콘텐츠의 정가를 다시 바꾸는 것은 아닙니다. 콘텐츠가 게시 완료여도 상품 생성·판매 조건 설정은 별도로 진행합니다.

> **화면 예시 준비 중** · 상품 정보와 실제 포함 콘텐츠를 함께 확인합니다.

## 4. 생성 완료와 판매 시작 구분하기 <a href="#step-4" id="step-4"></a>

**최종 완료**를 누른 뒤 오류 안내와 상품 생성 결과를 확인합니다. 상품이 만들어져도 판매가 바로 시작되는 것은 아닙니다. 생성 후 다음 화면에서 미판매 보관 또는 판매 시작을 선택합니다.

| 선택 | 의미 |
| --- | --- |
| 최종 완료 | 상품 생성. 바로 신규 판매를 시작하는 버튼은 아님 |
| 비공개로 저장 | 생성된 상품을 판매 중지 상태로 두고 목록으로 이동. 콘텐츠의 임시 저장과 구분 |
| 판매 시작 | 콘텐츠·재고·판매자 등 판매 조건을 충족해야 판매 상태를 바꿀 수 있음. 선택 후 실제 상태 확인 |

현재 확인한 생성 화면의 **임시저장** 버튼은 비활성 상태입니다. 입력 중인 내용을 이 버튼으로 저장할 수 있다고 생각하지 마세요. **비공개로 저장**은 작성 중 저장이 아니라, 최종 완료 뒤 이미 생성된 상품을 미판매 상태로 보관하는 선택입니다.

판매 시작 후 상품 목록·상세를 다시 열어 상태와 판매 준비 안내를 확인합니다. 사이트에 상품이 표시되고 구매 가능한지는 별도로 확인합니다. 관리자 생성 성공만으로 수강·배송·자료 다운로드까지 완료된 것은 아닙니다.

> **화면 예시 준비 중** · 상품 생성과 신규 판매 시작은 별도로 확인합니다.

## 5. 기존 상품 수정하기 <a href="#step-5" id="step-5"></a>

상품 상세의 **상품 설정**에서 제목·소개·구성과 판매 조건을 수정하고 **수정 완료**를 누릅니다. 저장 후 같은 상품을 다시 열어 변경 내용이 반영됐는지 확인합니다. 판매 중인 상품은 수정 뒤에도 판매 준비 조건을 충족해야 합니다.

상품 구성을 바꿔도 기존 구매자에게 새 콘텐츠가 자동으로 추가 지급됐다고 판단하지 마세요. 기존 주문의 이용 권한과 앞으로 구매할 상품의 구성을 나누어 확인합니다. 자료 파일을 교체한다면 [자료 파일 관리](../content-management/digital-resource-and-files.md)의 버전별 권한 기준도 함께 확인하세요.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 상품 유형과 포함할 콘텐츠가 의도한 구성입니다.
- [ ] 제목·소개·이미지와 구성 금액이 저장됐습니다.
- [ ] 할인·기간·과세·재고를 해당 가이드로 확인했습니다.
- [ ] 상품 생성, 미판매 보관, 판매 시작을 구분했습니다.
- [ ] 판매할 상품은 상태·판매 준비 안내와 실제 구매 결과를 별도로 확인했습니다.

## 자주 막히는 부분 <a href="#troubleshooting" id="troubleshooting"></a>

| 상황 | 확인할 것 |
| --- | --- |
| 교재·자료 유형이 안 보여요 | 사이트에서 해당 상품 유형을 사용할 수 있는지와 계정 권한을 담당자에게 확인합니다 |
| 선택할 콘텐츠가 없어요 | 같은 사이트에 등록됐는지, 종류·검색어·계정 권한·콘텐츠 상태를 확인합니다 |
| 선택 창에서 등록했는데 상품이 없어요 | 선택 등록과 상품 최종 완료는 별도입니다. 입력 화면과 상품 목록을 확인합니다 |
| 교재 수량을 여러 권으로 바꾸고 싶어요 | 현재 화면의 수량 변경 입력은 확인되지 않았습니다. 중복 선택 대신 담당자에게 지원 범위를 확인합니다 |
| 임시저장이 안 눌려요 | 현재 생성 화면의 임시저장은 비활성입니다. 최종 완료 뒤 미판매 보관과 혼동하지 않습니다 |
| 최종 완료했는데 판매 중지가 보여요 | 상품 생성과 판매 시작은 별도입니다. 판매 준비 조건을 확인한 뒤 의도한 상태를 적용합니다 |
| 저장 실패 또는 결과가 불확실해요 | 목록·상세에서 생성·수정 반영 여부를 먼저 확인합니다. 바로 같은 상품을 중복 생성하지 않습니다 |
| 다른 담당자 수정 후 저장이 거절돼요 | 최신 상품을 다시 열고 변경된 구성·금액·상태를 비교한 뒤 수정합니다 |
