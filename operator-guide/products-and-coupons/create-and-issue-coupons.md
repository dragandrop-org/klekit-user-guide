# 쿠폰 만들고 발급하기

> **검토용 가이드** · 실제 서비스 화면·동작 확인과 이미지 보완이 남아 있습니다. 본문의 실행 보류·주의사항을 먼저 확인하세요.

<figure><img src="../.gitbook/assets/branding/page-headers/products-and-coupons/create-and-issue-coupons-v2.png" alt="쿠폰 만들고 발급하기 대표 이미지"><figcaption></figcaption></figure>

**업무 대상:** 상품 판매·쿠폰 운영을 맡은 담당자용 안내입니다. 강의 콘텐츠만 관리한다면 판매 조건 변경은 학원 운영자에게 요청하세요. 실제 작업 가능 범위는 본인 계정의 권한을 확인하세요.

할인 조건과 발급 방식을 정하고, 수강생이 받은 쿠폰의 상태를 확인합니다. **쿠폰 생성, 회원에게 발급, 주문에서 사용은 서로 다른 단계입니다.**

**작업 순서:** 발급 방식 선택 → 조건 입력 → 생성·발급 결과 확인 → 내역 확인 → 필요 시 중지·추가 발급

## 시작 전 준비 <a href="#before-you-start" id="before-you-start"></a>

| 준비할 것 | 확인 기준 |
| --- | --- |
| 할인 목적 | 신규 가입·첫 구매·상담 감사처럼 쿠폰의 용도 |
| 할인 조건 | 정액·정률, 할인 금액·비율, 최소 상품 금액, 필요 시 최대 할인 금액 |
| 사용 기간 | 발급일 기준 사용 일수 또는 고정 만료일 |
| 발급 방식과 대상 | 수동 발급·코드 발급·다운로드·자동 발급 중 선택하고 해당 사이트의 대상 회원 확인 |
| 작업 권한 | 조회·생성·수정·발급·삭제·CSV 내보내기에 필요한 권한 |

## 메뉴 위치 <a href="#menu-location" id="menu-location"></a>

관리자 **쿠폰 관리**에서 **쿠폰 생성**을 누릅니다. 생성 후에는 목록에서 해당 쿠폰을 열어 **발급 내역**, **운영 설정**, **추가 발급**을 확인합니다. 작업에 따라 필요한 권한이 달라 버튼이 보이지 않을 수 있습니다.

## 1. 발급 방식 선택하기 <a href="#step-1" id="step-1"></a>

<figure><img src="../.gitbook/assets/branding/coupon-discount-illustration-v1.png" alt="쿠폰 티켓과 할인 태그"><figcaption></figcaption></figure>

**발급 방식 선택**에서 목적에 맞는 방식을 선택하고 **다음 단계**로 이동합니다.

| 방식 | 쿠폰을 받는 방법 | 운영자가 준비할 것 |
| --- | --- | --- |
| 수동 발급 | 운영자가 선택한 수강생에게 발급 | 대상 회원 확인·선택 |
| 코드 발급 | 수강생이 코드를 등록해 받음 | 쿠폰 코드·중복 확인·안내할 대상 |
| 다운로드 | 수강생이 쿠폰함에서 직접 받음 | 필요한 발급 한도·사용 조건 |
| 자동 발급 | 설정한 이벤트 발생 시 발급 | 회원가입·첫 결제·첫 수강평 중 조건 선택 |

발급 방식은 만든 뒤 수정 화면에서 바꿀 수 없습니다. 다른 방식이 필요하면 기존 쿠폰의 발급·사용 내역을 확인한 뒤 새 쿠폰을 준비합니다.

> **화면 예시 준비 중** · 수강생이 쿠폰을 받는 방식에 맞춰 발급 방식을 선택합니다.

## 2. 기본 정보·할인·사용 기간 입력하기 <a href="#step-2" id="step-2"></a>

| 항목 | 입력 예시·확인할 점 |
| --- | --- |
| 쿠폰명·쿠폰 설명 | `첫 구매 감사`처럼 용도를 구분하고 수강생에게 표시될 내용 확인 |
| 할인 방식 | 정액은 할인 금액, 정률은 할인율 입력 |
| 최대 할인 금액 | 정률일 때 필요에 따라 상한 입력. 비워 두면 별도 할인 상한을 두지 않는 설정 |
| 최소 상품 금액(원) | 쿠폰을 사용하기 위한 최소 금액 조건 |
| 발급일 기준 | 발급 후 사용 일수 입력 |
| 고정 만료일 | 모든 발급 대상에 적용할 만료일 선택 |

할인 금액과 사용 기간은 예시 값을 그대로 쓰기보다 운영 목적에 맞춰 정합니다. 수강생에게 안내한 조건과 저장된 조건이 같은지 확인하세요.

> **화면 예시 준비 중** · 할인 조건과 수강생이 사용할 기간을 설정합니다.

### 수동 발급 <a href="#manual-issue" id="manual-issue"></a>

**발급 대상**의 **수강생 추가**를 눌러 대상 회원을 선택합니다. 이름이 같은 회원은 계정 정보를 대조합니다. **현재 페이지 전체 선택**을 전체 사이트 회원 선택으로 해석하지 않습니다.

대상을 선택하고 쿠폰을 생성한 뒤에는 쿠폰이 만들어졌는지와 선택한 회원에게 발급됐는지를 각각 확인합니다. 대상을 넣지 않고 생성한 경우에는 발급이 끝났다고 판단하지 말고 상세의 발급 내역과 **추가 발급**을 확인합니다.

### 코드 발급 <a href="#code-issue" id="code-issue"></a>

**쿠폰 코드**를 입력하고 **중복 확인**을 완료합니다. 코드는 6~20자의 허용된 문자로 입력하며 공백을 넣지 않습니다. 중복 확인 뒤 코드를 바꿨다면 다시 확인합니다. 코드가 생성되었다고 수강생에게 자동으로 발급된 것은 아닙니다.

### 다운로드·자동 발급 <a href="#automatic-issue" id="automatic-issue"></a>

필요하면 `총 발급 한도(선택)`를 입력합니다. 비워 두는 것은 무제한 설정이므로 운영 의도를 확인합니다. 자동 발급에서는 **자동 발급 방식 유형**을 선택합니다.

| 자동 조건 | 확인할 결과 |
| --- | --- |
| 회원가입 | 해당 사이트 가입 이벤트 후 쿠폰 발급 내역 확인 |
| 첫 결제 | 첫 구매 결제 완료 이후 발급 내역 확인. 결제 전에 받는 쿠폰이 아니므로 첫 주문의 선할인과 구분 |
| 첫 수강평 | 첫 수강평 등록 이후 발급 내역 확인 |

**기존 회원·과거 주문에 소급 발급된다고 가정하지 않습니다.** 자동 쿠폰을 생성하는 작업과 회원의 이벤트 발생·발급 결과를 구분하세요.

## 3. 생성하고 발급 결과 확인하기 <a href="#step-3" id="step-3"></a>

1. 발급 방식·할인·사용 기간·대상을 확인합니다.
2. **최종 완료**를 누릅니다.
3. 생성 결과의 **발급 성공·발급 실패** 인원을 확인합니다.
4. 목록에서 쿠폰을 열어 저장된 조건과 발급 내역을 다시 확인합니다.
5. 대상 수강생의 쿠폰함에서 수령 결과를 확인합니다.

수동 발급 대상 중 일부가 실패해도 성공한 발급이 함께 취소되는 것은 아닙니다. 결과가 불명확할 때 새 쿠폰을 반복 생성하거나 성공 대상을 다시 발급하지 말고 기존 쿠폰·대상 내역을 먼저 조회합니다.

> **동작 예시 준비 중** · 쿠폰 생성과 대상별 발급 결과를 구분해 확인합니다.

## 4. 수동 쿠폰 추가 발급하기 <a href="#step-4" id="step-4"></a>

활성 상태의 수동 쿠폰 상세에서 **상세 메뉴 → 추가 발급**으로 들어갑니다. 추가할 수강생을 선택하고 **선택 완료**를 누른 뒤 대상 정보를 다시 확인해 **발급**합니다.

**발급 결과**에서 성공·실패 대상과 사유를 확인합니다. 이미 받은 회원인지, 다른 사이트 회원인지, 쿠폰이 중지·만료됐는지 먼저 확인하세요. 추가 발급은 사용한 쿠폰을 복구하거나 같은 회원에게 무조건 한 장 더 지급하는 기능이 아닙니다.

> **화면 예시 준비 중** · 추가 발급 대상과 성공·실패 결과를 확인합니다.

## 5. 발급 내역과 사용 상태 확인하기 <a href="#step-5" id="step-5"></a>

쿠폰 상세의 **발급 내역**에서 회원명·이메일을 검색하고 상태를 필터링합니다. 발급일·만료일·사용일을 함께 확인합니다.

| 상태 | 의미·확인할 점 |
| --- | --- |
| 사용 가능 | 아직 사용하지 않은 쿠폰. 주문 조건을 만족하는지는 결제 화면에서 별도 확인 |
| 사용 완료 | 쿠폰 사용 이력 확인. 발급 횟수와 구분 |
| 만료 | 유효기간과 만료일 확인 |
| 취소 | 해당 발급 건의 취소 상태. 주문 전체의 취소·환불 완료와 동일하게 해석하지 않기 |

### CSV 다운로드 <a href="#csv-export" id="csv-export"></a>

필요한 검색·상태 필터를 적용한 뒤 **발급 내역 정렬 메뉴 → CSV 다운로드**를 사용합니다. 화면에 보이는 페이지나 선택한 회원만 파일에 담긴다고 생각하지 마세요. 다운로드된 파일의 대상·건수·기간이 필요한 범위와 맞는지 확인합니다.

CSV에는 수강생 이름·이메일 등 개인정보가 포함됩니다. 승인된 업무 용도로만 보관·공유하고 공개 문서에 실제 파일을 첨부하지 않습니다.

> **화면 예시 준비 중** · 발급 내역에서 사용 상태를 확인하고 필요한 범위를 내보냅니다.

## 6. 수정·발급 중지·삭제 구분하기 <a href="#step-6" id="step-6"></a>

| 작업 | 기준·영향 |
| --- | --- |
| 쿠폰 수정 | 발급 이력이 없는 쿠폰에서 확인. 발급 이력이 생긴 쿠폰과 만료 쿠폰은 화면에서 수정 제한 |
| 발급 중지 | 신규 발급을 멈춤. 이미 받은 쿠폰의 사용을 일괄 차단하는 기능이 아님 |
| 발급 활성·재개 | 다시 발급 가능한 상태인지 확인. 만료를 연장하거나 자동 해제하는 작업이 아님 |
| 쿠폰 삭제 | 관리자 운영 대상에서 제외. 기존 발급·사용 이력과 주문 할인 이력을 지우는 작업이 아님 |

쿠폰 상세의 **상세 메뉴 → 운영 설정**에서 필요한 작업을 선택합니다. 신규 발급만 잠시 멈추려면 삭제보다 발급 중지의 목적과 영향을 먼저 확인합니다.

**사용 가능한 발급 건이 남아 있으면 삭제가 제한됩니다.** 삭제 권한이나 버튼이 있어도 완료를 보장하지 않습니다. 확인창을 읽고 결과를 확인하며, 삭제 후 복구를 가정하지 않습니다.

> **화면 예시 준비 중** · 신규 발급 중지와 수정·삭제 제한을 구분합니다.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 의도한 발급 방식·할인 조건·사용 기간이 저장되어 있습니다.
- [ ] 쿠폰 생성과 실제 발급 결과를 구분해 확인했습니다.
- [ ] 수동·추가 발급의 성공·실패 대상과 사유를 확인했습니다.
- [ ] 대상 수강생의 쿠폰함과 주문 적용 조건을 별도로 확인했습니다.
- [ ] 중지·수정·삭제 제한과 기존 수령 쿠폰에 미치는 영향을 확인했습니다.
- [ ] CSV 작업을 했다면 권한·필터·파일 범위·개인정보 취급을 확인했습니다.

## 자주 막히는 부분 <a href="#troubleshooting" id="troubleshooting"></a>

| 상황 | 확인할 것 |
| --- | --- |
| 생성·수정·추가 발급·CSV 버튼이 없어요 | 해당 작업 권한과 쿠폰 방식·상태·발급 이력을 확인합니다 |
| 코드 발급을 완료할 수 없어요 | 코드 형식과 중복 확인 여부를 점검합니다. 코드를 바꾸면 다시 중복 확인합니다 |
| 생성 성공인데 받은 회원이 없어요 | 발급 방식·선택 대상·발급 내역을 확인합니다. 코드·다운로드·자동은 수령 동작이나 이벤트가 별도로 필요합니다 |
| 일부 회원만 발급에 실패했어요 | 실패 사유와 기존 발급 건을 확인합니다. 성공한 회원에게 다시 발급하지 말고 실패한 대상만 확인합니다 |
| 자동 쿠폰이 안 들어와요 | 설정 조건·활성 상태·한도·만료·기존 발급 여부를 확인합니다. 회원가입·첫 결제·첫 수강평 중 설정한 조건이 실제로 발생했는지도 확인합니다 |
| 중지했는데 수강생이 쿠폰을 썼어요 | 발급 중지는 신규 발급 중지입니다. 이미 받은 쿠폰은 유효기간·주문 조건에 따라 사용할 수 있습니다 |
| 쿠폰 수정·삭제가 차단돼요 | 발급 이력과 사용 가능한 발급 건, 쿠폰 상태를 확인합니다. 내역을 없애려고 반복 삭제하지 않습니다 |
| 쿠폰은 있는데 주문에 적용되지 않아요 | 소유 계정·기간·사용 상태·최소 금액과 결제 화면의 적용 불가 사유를 확인합니다. 사용 가능 표시만으로 모든 주문 적용을 보장하지 않습니다 |
