# 재고·판매 상태 관리하기

<figure><img src="../.gitbook/assets/branding/page-headers/products-and-coupons/stock-and-sales-status-v2.png" alt="재고·판매 상태 관리하기 대표 이미지"><figcaption></figcaption></figure>

**업무 대상:** 상품 판매·쿠폰 운영을 맡은 담당자용 안내입니다. 강의 콘텐츠만 관리한다면 판매 조건 변경은 학원 운영자에게 요청하세요. 실제 작업 가능 범위는 본인 계정의 권한을 확인하세요.

교재 수량을 확인·조정하고 상품의 신규 판매를 시작하거나 중지합니다. **콘텐츠 상태, 상품 판매 상태, 실제 판매 가능 여부는 별개의 확인 항목**입니다.

**작업 순서:** 상품 상태·판매 준비 안내 확인 → 필요한 교재 재고 조정 → 수량·이력 재조회 → 판매 상태 적용 → 구매 가능 여부 확인

## 시작 전 준비 <a href="#before-you-start" id="before-you-start"></a>

| 준비할 것 | 확인 기준 |
| --- | --- |
| 권한 | 상품 상태 변경·교재 재고 관리·삭제는 서로 다른 작업. 담당 권한 확인 |
| 연결 교재 | 상품 이름뿐 아니라 포함된 교재 콘텐츠와 다른 연결 상품 확인 |
| 실제 수량·예약 | 실제 보유 수량과 진행 중 주문·예약 확인 |
| 조정 사유 | 입고·출고 차감·재고 실사 보정 중 어떤 작업인지 기록 |
| 기존 구매자 영향 | 판매 중지·콘텐츠 중지·삭제·권한 회수·주문 취소를 구분 |

교재 재고는 **콘텐츠 단위로 공유**합니다. 같은 교재를 두 상품에서 판매해도 상품마다 재고가 따로 생기는 것은 아닙니다. 최초 재고 등록은 [교재 등록·수정](../content-management/textbook-create-and-edit.md)을 확인합니다.

## 메뉴 위치 <a href="#menu-location" id="menu-location"></a>

- 상품: **상품 목록 → 상품 상세 → 운영 설정**에서 판매 상태 변경.
- 교재: **콘텐츠 목록 → 교재 상세 → 재고 이력 → 재고 조정**에서 수량 조정.

## 1. 상태와 판매 준비 조건 확인하기 <a href="#step-1" id="step-1"></a>

| 표시·조건 | 의미 |
| --- | --- |
| 콘텐츠 게시 완료 | 강좌·교재·자료의 콘텐츠 상태. 상품 판매 시작과 다름 |
| 상품 판매 중 | 신규 판매를 위한 상품 상태. 다른 조건도 충족해야 구매 가능 |
| 상품 판매 중지 | 신규 판매를 멈춘 상품 상태. 주문 취소·기존 권한 회수와 다름 |
| 품절·재고 부족 | 포함 교재의 가용 수량이 제공 수량보다 부족한 상태. 별도 판매 상태 선택값이 아님 |
| 판매 준비 안내 | 포함 콘텐츠·파일·대표 이미지·재고·유료 강좌 기간·판매자 등 부족한 조건 |

상품 목록·상세에서 판매 상태와 판매 준비 안내를 함께 확인합니다. 포함된 교재 하나라도 필요한 수량을 충족하지 못하면 교재 포함 패키지 전체의 구매가 제한될 수 있습니다.

> **화면 예시 준비 중** · 판매 중 상태여도 다른 조건 때문에 구매가 제한될 수 있습니다.

### 판매할 수 있는 수량 이해하기 <a href="#section-4" id="section-4"></a>

판매 가능 수량은 보유 수량만으로 판단하지 않습니다. 재고를 관리하는 교재는 **보유 수량 − 예약 수량**을 기준으로 해당 상품의 제공 수량을 충족해야 합니다. 예를 들어 보유 10권·예약 3권이면 추가 판매에 사용할 수 있는 수량은 7권입니다.

현재 교재 상세의 `재고` 표시만으로 예약·가용 수량까지 모두 확인한 것으로 판단하지 마세요. 표시되지 않는 예약 수량이나 진행 중 주문은 운영 담당자가 확인합니다. 재고가 조회되더라도 주문의 예약 수량과 결제 후 차감 결과까지 확인된 것은 아닙니다.

## 2. 교재 재고 조정하기 <a href="#step-2" id="step-2"></a>

1. 해당 교재 상세의 **재고 이력**을 엽니다.
2. 현재 수량·처리 이력과 진행 중 주문을 확인하고 **재고 조정**을 누릅니다.
3. **이력**에서 **입고**, **출고 차감**, **재고 실사 보정** 중 작업을 선택합니다.
4. **변동 수량**에 증감분을 입력합니다.
5. 필요한 경우 `상세 사유 (선택)`에 확인 근거를 입력합니다.
6. **조정하기**를 누르고 재고·처리 후 수량·이력을 다시 조회합니다.

| 실제 작업 | 변동 수량 예시 |
| --- | --- |
| 10권 추가 입고 | `10` |
| 3권 수동 차감 | `-3` |
| 장부 20권, 실사 18권으로 보정 | `-2` |

**변동 수량은 최종 총량이 아닙니다.** 0 또는 소수는 입력하지 않습니다. 재고 실사 보정으로 수량을 줄일 때도 예약된 수량을 남겨 두어야 하므로 조정이 거절될 수 있습니다. 차감 오류가 나면 예약 수량과 최신 재고 수량을 확인합니다.

주문 처리에서 이미 재고가 반영됐다면 같은 출고를 다시 수동 차감하지 않습니다. 재고 오류를 해결하려고 임의 입고·차감을 반복하지 마세요. 성공 여부가 불확실하면 이력을 먼저 확인한 뒤 필요한 조정만 진행합니다.

> **화면 예시 준비 중** · 최종 총량이 아니라 입고·차감할 증감분을 입력합니다.

> **동작 예시 준비 중** · 재고 조정 후 수량·이력과 연결 상품의 판매 조건을 다시 확인합니다.

## 3. 판매 시작·중지 적용하기 <a href="#step-3" id="step-3"></a>

상품 상세의 **운영 설정**에서 **판매 상태 변경**을 엽니다.

| 작업 | 진행 방법 |
| --- | --- |
| 판매 중지 | **판매 중지 → 변경 적용** → 상태 재조회·신규 구매 제한 확인 |
| 판매 시작·재개 | 필요한 조건 해결 → **판매 중 → 변경 적용** → 상태·판매 준비 안내·구매 결과 확인 |

상품 생성 직후에는 완료 화면의 **판매 시작**으로도 시작할 수 있습니다. 판매 시작이 거절되면 대표 이미지·연결 콘텐츠·자료 파일·재고·유료 강좌 기간·판매자 안내 중 해당 원인을 해결합니다. 창이 닫힌 것만으로 변경 성공이라고 판단하지 않습니다.

> **화면 예시 준비 중** · 신규 판매 상태 변경과 기존 구매자 권한 처리는 구분합니다.

## 4. 재입고·콘텐츠 복구 후 다시 확인하기 <a href="#step-4" id="step-4"></a>

품절은 교재의 판매 가능 수량이 부족한 상태이며, 별도로 고르는 상품 유형이나 판매 상태가 아닙니다. 재입고 후에는 상품이 판매 중인지, 다른 판매 조건도 충족하는지, 실제 구매할 수 있는지를 확인합니다. 상품 자체가 판매 중지라면 재고만 늘려도 판매가 재개됐다고 판단하지 않습니다.

콘텐츠 중지·파일 누락 등 다른 문제가 해결됐을 때도 상품 상태와 판매 준비 조건을 다시 확인합니다. **콘텐츠를 복구했으니 자동으로 재판매됐다고 가정하지 않습니다.** 필요한 경우 담당자가 판매 상태를 다시 적용하고, 수강생 화면에서 구매 가능한지 확인합니다.

## 5. 판매 중지와 삭제·권한 회수 구분하기 <a href="#step-5" id="step-5"></a>

신규 판매만 멈추려면 **판매 중지**를 사용합니다. 판매 중지는 이미 생성된 주문의 취소·환불·배송 처리나 기존 수강권·자료 이용 권한 회수 버튼이 아닙니다. 기존 구매자의 접근은 해당 권한·기간·콘텐츠 상태와 함께 확인합니다.

**삭제는 판매 중지와 다른 작업입니다.** 단순 판매 종료를 위해 삭제하지 않습니다. 운영 담당자는 삭제가 구매자, 진행 중인 주문, 연결된 콘텐츠와 상품 진열에 어떤 영향을 미치는지 확인합니다. 실제 삭제 제한도 확인한 뒤 승인된 범위에서 처리합니다. 화면 안내만으로 삭제가 안전하거나 기존 주문·권리가 모두 보존된다고 확정하지 마세요.

## 완료 후 확인 <a href="#completion-checklist" id="completion-checklist"></a>

- [ ] 같은 교재를 사용하는 상품의 공유 재고를 확인했습니다.
- [ ] 재고 조정은 증감분으로 입력했고 수량·이력을 재조회했습니다.
- [ ] 주문에서 이미 반영된 출고·취소를 중복 조정하지 않았습니다.
- [ ] 상품 상태와 판매 준비 조건을 함께 확인했습니다.
- [ ] 판매 중지·품절·삭제·주문 취소·권한 회수를 구분했습니다.
- [ ] 기존 구매자 접근과 신규 구매 가능 여부를 따로 확인했습니다.

## 자주 막히는 부분 <a href="#troubleshooting" id="troubleshooting"></a>

| 상황 | 확인할 것 |
| --- | --- |
| 재고가 있는데 구매가 안 돼요 | 예약·가용 수량, 포함 교재 수량과 상품·콘텐츠·판매자 조건을 확인합니다 |
| 다른 상품의 재고도 바뀌었어요 | 같은 교재 콘텐츠를 연결한 상품은 재고를 공유합니다 |
| 재고 조정 버튼이 안 눌려요 | 해당 교재의 재고 정보가 조회됐는지, 담당 권한·화면 오류를 확인합니다 |
| 재고 감소가 거절돼요 | 최신 수량·예약 수량과 변동 수량을 확인합니다. 예약을 피하려 임의로 입고하지 않습니다 |
| 조정 결과를 모르겠어요 | 수량과 이력을 먼저 재조회합니다. 같은 변동을 바로 반복하지 않습니다 |
| 재입고했는데 판매 중지예요 | 재고와 상품 판매 상태는 별도입니다. 판매 조건을 확인하고 담당자가 재개합니다 |
| 판매 상태 창은 닫혔는데 변경되지 않았어요 | 결과 안내를 확인하고 상품 상세를 다시 엽니다. 판매 준비 조건이 맞는지, 다른 담당자의 변경으로 저장이 거절됐는지 확인합니다 |
| 판매 중지하면 기존 학생도 못 쓰나요? | 신규 판매 중지와 기존 권한 회수는 다릅니다. 기존 권한·기간·콘텐츠 상태를 함께 확인합니다 |
| 판매 종료하려고 삭제해도 되나요? | 신규 판매 중지는 판매 중지를 사용합니다. 삭제 영향·실제 제한은 담당자가 별도로 확인합니다 |
