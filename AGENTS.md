# Repository Instructions

## Commit Convention

Use this commit message format for this GitBook repository:

```text
[GITBOOK-x.y.z] Commit summary
```

Use Korean for the summary.

Examples:

```text
[GITBOOK-1.0.0] 영상 업로드 파일 기준 추가
[GITBOOK-1.0.1] 영상 업로드 용량 안내 수정
[GITBOOK-1.1.0] 정산 정보 설정 가이드 추가
[GITBOOK-2.0.0] 사용자 가이드 목차 개편
```

## Version Rules

Use semantic versioning from `1.0.0`.

| Version | When to increase |
| --- | --- |
| Major | Large structure changes, table of contents reorganization, deleting or replacing existing guide sections |
| Minor | New guide pages, new major sections, new feature documentation |
| Patch | Typos, wording fixes, small clarifications, screenshots, small policy or limit updates |

## Current Starting Point

Start this convention at:

```text
[GITBOOK-1.0.0]
```
