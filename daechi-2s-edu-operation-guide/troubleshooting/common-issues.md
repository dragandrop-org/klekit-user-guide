# 자주 발생하는 문제 해결 가이드

> 재원생 사이트 운영 중 자주 발생하는 문제와 1차 확인 방법입니다.

> 이미지 위치: 문제 대응 메인 이미지  
> 추천 이미지: 오류 화면 예시 또는 문의 정리 표 캡처

## 먼저 확인할 3가지

| 순서 | 확인 | 이유 |
| --- | --- | --- |
| 1 | 학생 계정 | 다른 계정으로 로그인했을 수 있습니다. |
| 2 | 수강 권한 | 권한이 없으면 영상이 보이지 않습니다. |
| 3 | 영상 공개 상태 | 업로드되어도 비공개면 학생에게 보이지 않습니다. |

## 영상이 안 보일 때

| 확인할 것 | 설명 |
| --- | --- |
| 학생 계정 | 학생이 올바른 계정으로 로그인했는지 확인합니다. |
| 수강 권한 | 해당 강좌 수강권이 있는지 확인합니다. |
| 공개 상태 | 강의가 학생에게 공개되어 있는지 확인합니다. |
| 영상 연결 | 강의에 영상이 연결되어 있는지 확인합니다. |

> 이미지 위치: 영상이 안 보이는 학생 화면  
> 추천 이미지: 강좌 목록에 영상이 안 보이는 화면 캡처

## 영상 재생이 안 될 때

1. 새로고침 후 다시 재생합니다.
2. 다른 브라우저에서 확인합니다.
3. 모바일과 PC 중 다른 기기에서 확인합니다.
4. 같은 강좌의 다른 영상도 재생되는지 확인합니다.
5. 계속 안 되면 운영자에게 전달합니다.

> GIF 위치: 영상 재생 확인  
> 추천 GIF: 새로고침 → 영상 클릭 → 재생 실패 화면 확인

## 로그인이 안 될 때

| 상황 | 확인할 것 |
| --- | --- |
| 아이디를 모릅니다. | 학생 이름과 연락처로 계정을 확인합니다. |
| 비밀번호를 모릅니다. | 비밀번호 재설정이 필요한지 확인합니다. |
| 로그인 후 강좌가 없습니다. | 수강권이 부여되어 있는지 확인합니다. |

> 이미지 위치: 로그인 실패 화면  
> 추천 이미지: 로그인 실패 메시지 또는 계정 확인 화면 캡처

## 업로드가 실패했을 때

- 브라우저 창을 닫았는지 확인합니다.
- 영상 파일 형식이 `mp4`, `mov`, `m4v`, `webm`, `mkv` 중 하나인지 확인합니다.
- `avi`, `wmv`, `flv`, `3gp` 파일은 업로드할 수 없습니다.
- 파일 크기가 5GB 이하인지 확인합니다.
- 인터넷 연결 상태를 확인합니다.
- 여러 영상을 한꺼번에 등록한 뒤 오래 기다렸다가 업로드하면 업로드 URL이 만료될 수 있습니다. 이 경우 다시 업로드를 시작해 주세요.
- 같은 파일을 다시 업로드합니다.
- 반복 실패하면 운영자에게 파일명과 화면 캡처를 전달합니다.

## 업로드 파일 기준

| 항목 | 기준 |
| --- | --- |
| 지원 확장자 | `mp4`, `mov`, `m4v`, `webm`, `mkv` |
| 미지원 확장자 | `avi`, `wmv`, `flv`, `3gp` |
| 최대 용량 | 파일당 5GB |
| 휴대폰 촬영 | 안드로이드 `mp4`, 아이폰 `mov` 업로드 가능 |
| 권장 방식 | 큰 파일은 안정적인 인터넷 환경에서 하나씩 업로드 |

> 운영 참고: 현재 업로드 URL 유효 시간은 10분입니다. 여러 영상을 순차 업로드할 때 나중 영상은 URL 만료로 실패할 수 있습니다.

> 이미지 위치: 업로드 실패 화면  
> 추천 이미지: 업로드 진행률 멈춤, 실패 메시지, 파일 선택 화면 캡처

## 운영자에게 전달할 정보

```text
발생 일시:
사용자 이름:
역할: 강사 / 학생 / 질답조교 / 운영자
강좌명:
강의 제목:
문제 상황:
확인한 내용:
화면 캡처:
```
