# Q&A 기능 사용 가이드

> 질답조교가 클킷 Q&A 기능으로 학생 질문을 확인하고 답변할 때 보는 사용 가이드입니다.  
> 목표는 Q&A 메뉴 진입, 질문 확인, 답변 작성, 답변 완료 확인까지 같은 방식으로 처리하는 것입니다.

> 이미지 위치: Q&A 질문 목록 화면  
> 추천 이미지: Q&A 메뉴에서 질문 목록, 미답변/답변완료 상태가 보이는 화면 캡처

## 이 문서에서 다루는 것

| 기능 | 확인할 내용 |
| --- | --- |
| Q&A 메뉴 이동 | 질문 목록 화면으로 들어갑니다. |
| 질문 목록 확인 | 미답변 질문과 답변 완료 질문을 구분합니다. |
| 질문 상세 확인 | 학생 질문 내용과 첨부 이미지를 확인합니다. |
| 답변 작성 | 답변 입력 영역에 내용을 작성합니다. |
| 답변 등록 | 답변을 저장하고 상태를 확인합니다. |

## Q&A 답변 기본 흐름

```text
Q&A 메뉴 접속
→ 질문 목록 확인
→ 미답변 질문 선택
→ 질문 내용과 첨부 이미지 확인
→ 답변 작성
→ 답변 등록
→ 답변 완료 상태 확인
```

> GIF 위치: Q&A 답변 전체 흐름  
> 추천 GIF: Q&A 메뉴 접속 → 미답변 질문 선택 → 답변 작성 → 답변 등록

## 1. Q&A 메뉴로 들어가기

1. 클킷 관리자 페이지에 로그인합니다.
2. 왼쪽 메뉴에서 `Q&A` 또는 질문 관리 메뉴를 선택합니다.
3. 질문 목록 화면이 열리는지 확인합니다.

> GIF 위치: Q&A 메뉴 진입  
> 추천 GIF: 관리자 로그인 → 왼쪽 메뉴에서 Q&A 클릭 → 질문 목록 확인

## 2. 질문 목록 확인하기

질문 목록에서 먼저 미답변 질문을 확인합니다.

> 이미지 위치: 질문 목록 필터  
> 추천 이미지: 미답변/답변완료 필터 또는 상태 표시가 보이는 화면 캡처

확인할 것:

| 확인 항목 | 기준 |
| --- | --- |
| 상태 | 미답변 질문을 우선 확인합니다. |
| 학생명 | 질문한 학생을 확인합니다. |
| 강좌명 | 담당 강좌 질문이 맞는지 확인합니다. |
| 등록일 | 오래된 질문부터 확인합니다. |
| 제목 또는 내용 | 어떤 질문인지 대략 확인합니다. |

> 이미지 위치: 질문 상세 화면  
> 추천 이미지: 학생 질문 내용, 첨부 이미지, 답변 입력 영역이 함께 보이는 화면 캡처

## 3. 질문 상세 확인하기

1. 답변할 질문을 선택합니다.
2. 질문 본문을 읽습니다.
3. 첨부 이미지가 있다면 문제 사진과 학생 풀이를 확인합니다.
4. 담당 강좌 질문이 맞는지 다시 확인합니다.

> GIF 위치: 질문 상세 확인  
> 추천 GIF: 질문 목록에서 질문 클릭 → 상세 내용과 첨부 이미지 확인

## 4. 답변 작성하기

답변 입력 영역에 학생에게 보여질 답변을 작성합니다.

답변 작성 기준:

| 기준 | 작성 방법 |
| --- | --- |
| 먼저 결론 | 학생이 무엇을 고치면 되는지 먼저 알려줍니다. |
| 풀이 과정 | 계산이나 논리 흐름을 단계별로 적습니다. |
| 학생 풀이 반영 | 학생이 틀린 지점을 기준으로 설명합니다. |
| 너무 긴 답변 지양 | 한 번에 읽을 수 있게 핵심 위주로 답합니다. |
| 추가 질문 유도 | 이해가 안 되면 다시 질문하라고 안내합니다. |

> 이미지 위치: 답변 입력 화면  
> 추천 이미지: 답변 입력창, 저장/등록 버튼이 보이는 화면 캡처

## 답변 예시

```text
이 문제는 등차수열의 일반항을 먼저 세우는 게 핵심입니다.

1. 첫째항과 공차를 먼저 찾습니다.
2. 일반항 an = a1 + (n-1)d 에 대입합니다.
3. 문제에서 묻는 n 값을 넣어 계산합니다.

학생 풀이에서는 공차를 반대로 잡은 부분이 틀렸습니다.
공차를 다시 확인해서 같은 방식으로 풀어보세요.
```

## 5. 답변 등록하기

1. 답변 내용을 다시 확인합니다.
2. `등록`, `저장`, 또는 `답변 완료` 버튼을 누릅니다.
3. 질문 상태가 답변 완료로 바뀌었는지 확인합니다.
4. 학생 화면에서 답변이 보이는지 확인할 수 있으면 함께 확인합니다.

> GIF 위치: 답변 등록  
> 추천 GIF: 답변 작성 → 등록 버튼 클릭 → 답변 완료 상태 확인

## 6. 추가 정보가 필요할 때

학생 질문만으로 답변하기 어려우면 바로 답을 추측하지 말고 추가 정보를 요청합니다.

```text
문제 전체 사진이 필요합니다.
교재 페이지와 학생이 푼 풀이 과정을 같이 올려 주세요.
확인 후 이어서 답변드리겠습니다.
```

## 7. 강사에게 전달해야 하는 경우

| 상황 | 전달 이유 |
| --- | --- |
| 수업에서만 다룬 특수한 풀이입니다. | 강사 의도 확인이 필요합니다. |
| 문제 오류가 의심됩니다. | 정답 또는 문제 조건 확인이 필요합니다. |
| 학생 질문이 개별 상담에 가깝습니다. | 학습 방향 판단이 필요합니다. |
| 답변 후에도 같은 질문이 반복됩니다. | 강사 보충 설명이 필요할 수 있습니다. |

## 8. 강사에게 전달할 때

아래 형식으로 정리해 전달합니다.

```text
학생명:
강좌명:
질문 내용:
첨부 이미지:
질답조교가 확인한 내용:
강사 확인이 필요한 부분:
```

> 이미지 위치: 강사 전달 예시  
> 추천 이미지: 위 템플릿을 채운 Notion 또는 메시지 예시 캡처

## 답변 전 체크리스트

- 담당 강좌 질문이 맞습니다.
- 질문 내용과 첨부 이미지를 확인했습니다.
- 학생이 틀린 지점을 기준으로 답변했습니다.
- 답변이 너무 길지 않습니다.
- 답변 등록 버튼을 눌렀습니다.
- 답변 완료 상태로 바뀌었습니다.
- 강사 확인이 필요한 질문은 따로 전달했습니다.
