# 공지사항 관리 가이드

> 운영자가 재원생 사이트에 공지사항을 등록하고 관리할 때 보는 가이드입니다.

> 이미지 위치: 공지사항 목록 화면  
> 추천 이미지: 관리자 공지사항 메뉴 또는 공지 목록 화면 캡처

## 공지 작성 기준

| 항목 | 기준 |
| --- | --- |
| 제목 | 학생이 내용을 바로 알 수 있게 작성합니다. |
| 대상 | 전체, 반별, 강좌별 대상을 명확히 합니다. |
| 날짜 | 적용 날짜나 마감일을 포함합니다. |
| 내용 | 학생이 해야 할 행동을 구체적으로 적습니다. |

## 제목 예시

```text
[수학 김재하] 07/15 보강 안내
[전체] 8월 모의고사 일정 안내
[영어 실전A] 과제 제출 안내
```

## 공지 등록 흐름

```text
공지 대상 선택
→ 제목 작성
→ 내용 작성
→ 첨부파일 또는 링크 확인
→ 저장
→ 학생 화면 확인
```

> GIF 위치: 공지 등록  
> 추천 GIF: 공지 작성 → 저장 → 학생 화면에서 공지 확인

## 등록 전 체크리스트

- 공지 대상이 맞습니다.
- 날짜와 시간이 맞습니다.
- 학생이 해야 할 행동이 명확합니다.
- 오탈자가 없습니다.
- 첨부파일이나 링크가 정상 작동합니다.

## 화면 캡처가 필요한 위치

| 위치 | 필요한 이미지 |
| --- | --- |
| 공지 목록 | 등록된 공지가 보이는 화면 |
| 공지 작성 | 제목, 대상, 내용 입력 화면 |
| 첨부파일 | 파일 또는 링크 첨부 화면 |
| 학생 화면 | 학생에게 공지가 보이는 화면 |

## 추가 작성 필요

- 반별 공지 등록 기준
- 공지 수정/삭제 기준
- 긴급 공지 운영 방식
