# 강좌·계정·수강권 관리 가이드

> 운영자가 강좌, 강사 계정, 학생 계정, 수강 권한을 관리할 때 보는 가이드입니다.

> 이미지 위치: 관리자 메인 또는 강좌 관리 화면  
> 추천 이미지: 강좌 목록과 학생/계정 메뉴가 보이는 화면 캡처

## 언제 보나요

| 상황 | 확인할 내용 |
| --- | --- |
| 새 강좌를 열어야 합니다. | 강좌 생성과 기본 정보 확인 |
| 새 강사 계정이 필요합니다. | 강사 계정 생성과 권한 확인 |
| 학생이 영상을 볼 수 없습니다. | 학생 계정과 수강권 확인 |
| 반이 변경되었습니다. | 강좌 또는 수강 권한 변경 |

## 기본 흐름

```text
강좌 생성 또는 확인
→ 강사 계정 연결
→ 학생 계정 확인
→ 수강 권한 부여
→ 학생 화면 확인
```

> GIF 위치: 수강 권한 부여 흐름  
> 추천 GIF: 학생 검색 → 강좌 선택 → 수강권 부여 → 학생 화면 확인

## 운영 체크리스트

- 강좌명이 학원 내부 명칭과 일치합니다.
- 담당 강사가 올바르게 연결되어 있습니다.
- 학생 계정이 중복 생성되지 않았습니다.
- 학생에게 필요한 강좌 수강권이 부여되어 있습니다.
- 학생 화면에서 강좌와 영상이 보입니다.

## 화면 캡처가 필요한 위치

| 위치 | 필요한 이미지 |
| --- | --- |
| 강좌 생성 | 강좌 기본 정보 입력 화면 |
| 강사 계정 | 강사 계정 생성 또는 권한 설정 화면 |
| 학생 계정 | 학생 검색/생성 화면 |
| 수강권 | 학생에게 강좌 권한을 부여하는 화면 |
| 학생 화면 | 권한 부여 후 강좌가 보이는 화면 |

## 추가 작성 필요

- 학생 계정 생성 기준
- 수강권 부여 기준
- 반 변경 시 처리 방식
