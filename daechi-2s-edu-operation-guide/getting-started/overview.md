# 운영 개요

> 재원생이 복습 영상과 공지사항을 편하게 확인할 수 있도록 운영하는 내부 학습 사이트입니다.

## 페이지 목적

| 이 페이지에서 정하는 것 | 설명 |
| --- | --- |
| 왜 운영하나요 | 복습 영상과 공지 전달을 한곳으로 모읍니다. |
| 누가 관리하나요 | 강사, 운영자, 질답조교의 역할을 나눕니다. |
| 무엇을 확인하나요 | 영상 공개, 재생, 권한, 공지 전달, Q&A 답변 상태를 확인합니다. |

> 이미지 위치: 재원생 사이트 학생 화면  
> 추천 이미지: 학생이 복습 영상 목록을 보는 화면 캡처

## 운영 목적

| 목적 | 설명 |
| --- | --- |
| 복습 영상 제공 | 수업 후 학생이 다시 볼 수 있는 영상을 제공합니다. |
| 공지 전달 | 반별·강좌별 공지사항을 한곳에서 확인할 수 있게 합니다. |
| 운영 효율화 | 강사, 운영자, 질답조교가 역할에 맞게 사이트를 관리합니다. |

## 기본 운영 흐름

```text
강사 수업 촬영
→ 복습 영상 업로드
→ 운영자 확인
→ 학생에게 공개
→ 학생 Q&A 질문 등록
→ 질답조교 Q&A 답변 작성
→ 필요 시 강사 또는 운영자에게 전달
```

> GIF 위치: 전체 운영 흐름  
> 추천 GIF: 강사가 영상 업로드 후 학생 화면에서 영상이 보이는지 확인하는 짧은 흐름

## 운영 기준

- 강좌명과 강의 제목은 학생이 알아보기 쉽게 작성합니다.
- 복습 영상은 업로드 후 학생 화면에서 재생 여부를 확인합니다.
- 공지사항은 대상 학생이 헷갈리지 않도록 반명, 날짜, 내용을 명확히 적습니다.
- 문제가 생기면 화면 캡처와 함께 운영자에게 전달합니다.

## 먼저 만들면 좋은 페이지

| 우선순위 | 페이지 | 이유 |
| --- | --- | --- |
| 1 | 복습 영상 업로드 가이드 | 강사들이 가장 자주 쓰는 문서입니다. |
| 2 | Q&A 기능 사용 가이드 | 질답조교가 Q&A 기능을 빠르게 사용할 수 있습니다. |
| 3 | 자주 발생하는 문제 해결 가이드 | 반복 질문과 운영 이슈를 줄일 수 있습니다. |
