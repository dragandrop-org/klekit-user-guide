# 역할별 업무 범위

> 누가 무엇을 담당하는지 정리한 역할표입니다.  
> 문제가 생기면 먼저 본인 역할 안에서 확인하고, 해결이 어렵다면 다음 담당자에게 넘깁니다.

> 이미지 위치: 역할별 운영 구조  
> 추천 이미지: 강사, 운영자, 질답조교 역할을 한 화면에 보여주는 간단한 도식 또는 Notion 표 캡처

## 역할 요약

| 역할 | 주요 업무 |
| --- | --- |
| 강사 | 복습 영상 업로드, 강의 제목 확인, 업로드 후 재생 확인 |
| 운영자 | 강좌·계정·수강권 관리, 공지사항 관리, 최종 문제 대응 |
| 질답조교 | Q&A 질문 확인, 답변 작성, 어려운 질문 전달 |

## 업무 전달 기준

| 상황 | 1차 담당 | 최종 담당 |
| --- | --- | --- |
| 영상 업로드 실패 | 강사 | 운영자 |
| 학생이 Q&A에 질문 등록 | 질답조교 | 강사 |
| 답변하기 어려운 질문 | 질답조교 | 강사 |
| 학생이 영상 안 보인다고 문의 | 운영자 | 운영자 |
| 수강권이 없는 것 같음 | 운영자 | 운영자 |
| 공지 내용 수정 필요 | 운영자 | 운영자 |
| 강좌명이 잘못됨 | 운영자 | 운영자 |

## 강사

- 담당 강좌에 복습 영상을 업로드합니다.
- 강의 제목을 날짜와 수업 내용 기준으로 작성합니다.
- 업로드 후 영상이 정상 재생되는지 확인합니다.
- 문제가 있으면 운영자에게 전달합니다.

## 운영자

- 강좌와 계정을 생성하고 관리합니다.
- 학생별 수강 권한을 확인합니다.
- 공지사항을 등록하고 수정합니다.
- 강사 또는 질답조교가 해결하기 어려운 운영 문제를 처리합니다.

## 질답조교

- Q&A 메뉴에서 학생 질문을 확인합니다.
- 답변 입력 영역에 풀이, 개념 설명, 힌트 등 필요한 답변을 작성합니다.
- 질문 내용이 불명확하면 Q&A 답변으로 추가 정보를 요청합니다.
- 답변하기 어려운 질문은 강사에게 전달합니다.
- 사이트 기능 문제나 권한 문제는 운영자에게 전달합니다.

## 담당자에게 전달할 때 기본 형식

```text
요청자:
역할:
강좌명:
질문 또는 문제 상황:
확인한 내용:
필요한 조치:
화면 캡처:
```
