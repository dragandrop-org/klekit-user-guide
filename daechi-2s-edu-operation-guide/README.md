# 대치투에스에듀 재원생 사이트 운영 가이드

> 클킷으로 재원생 사이트를 운영할 때 쓰는 내부 매뉴얼입니다.  
> 강사, 운영자, 질답조교가 각자 해야 할 일을 빠르게 확인할 수 있도록 역할별로 나눴습니다.

## 한눈에 보기

| 구분 | 누가 보나요 | 핵심 목적 |
| --- | --- | --- |
| 시작하기 | 전체 | 사이트 운영 방식과 역할을 맞춥니다. |
| 강사용 가이드 | 강사 | 수업 복습 영상을 올리고 확인합니다. |
| 운영자 가이드 | 실장님, 운영 담당자 | 강좌, 계정, 수강권, 공지사항을 관리합니다. |
| 질답조교 가이드 | 질답조교 | Q&A 기능으로 학생 질문을 확인하고 답변합니다. |
| 문제 대응 | 전체 | 자주 생기는 문제를 빠르게 확인합니다. |

> 이미지 위치: Notion 페이지 상단 커버  
> 추천 이미지: 학원 로고, 재원생 사이트 메인 화면, 또는 클킷 관리자 메인 화면 캡처

## 운영 흐름

```text
수업 촬영
→ 강사 복습 영상 업로드
→ 운영자 공개 상태 확인
→ 학생 시청
→ 학생 Q&A 질문 등록
→ 질답조교 Q&A 답변 작성
→ 필요 시 강사 또는 운영자에게 전달
```

## Notion 권장 페이지 구조

```text
대치투에스에듀 재원생 사이트 운영 가이드
├─ 시작하기
│  ├─ 운영 개요
│  └─ 역할별 업무 범위
├─ 강사용 가이드
│  └─ 복습 영상 업로드 가이드
├─ 운영자 가이드
│  ├─ 강좌·계정·수강권 관리 가이드
│  └─ 공지사항 관리 가이드
├─ 질답조교 가이드
│  └─ Q&A 기능 사용 가이드
└─ 문제 대응
   └─ 자주 발생하는 문제 해결 가이드
```
