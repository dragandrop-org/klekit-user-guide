# 복습 영상 업로드 가이드

> 선생님이 수업 복습 영상을 직접 올릴 때 보는 원페이지 가이드입니다.  
> 아래 순서대로 진행하면 업로드부터 학생 화면 확인까지 끝낼 수 있습니다.

> 중요: 업로드 중에는 브라우저 창을 닫지 마세요. 영상 용량이 크면 업로드에 시간이 걸릴 수 있습니다.

> 이미지 위치: 페이지 상단 대표 이미지  
> 추천 이미지: 클킷 관리자에서 강좌 목록이 보이는 화면 캡처

## 오늘 해야 할 일

| 순서 | 작업 | 완료 기준 |
| --- | --- | --- |
| 1 | 담당 강좌 선택 | 내가 올릴 강좌가 맞습니다. |
| 2 | 새 강의 생성 | 오늘 수업용 강의가 만들어졌습니다. |
| 3 | 영상 업로드 | 업로드가 완료되었습니다. |
| 4 | 강의 제목 수정 | 날짜와 수업 내용이 들어갔습니다. |
| 5 | 저장 및 확인 | 학생 화면에서 영상이 재생됩니다. |

## 시작하기 전에 준비해 주세요

| 준비물 | 예시 |
| --- | --- |
| 클킷 관리자 계정 | 학원에서 안내받은 아이디와 비밀번호 |
| 업로드할 영상 파일 | mp4 파일 권장 |
| 올릴 강좌명 | 수학 김재하 - 실통수 라이트 (수1&수2) |
| 수업 날짜 | 07/11 |
| 강의 제목 | 07/11 수열 기본 개념 |

## 영상 파일 준비 기준

업로드 전에 영상 파일이 아래 기준에 맞는지 확인해 주세요.

| 항목 | 권장 기준 |
| --- | --- |
| 권장 파일 형식 | `mp4` |
| 업로드 가능 파일 형식 | `mp4`, `mov`, `m4v`, `webm`, `mkv` |
| 업로드 불가 파일 형식 | `avi`, `wmv`, `flv`, `3gp` |
| 코덱 | H.264 권장 |
| 해상도 | 1080p, 1920x1080 권장 |
| 화면 비율 | 16:9 권장 |
| 오디오 | 소리가 정상적으로 들어간 영상 |
| 파일 크기 | 파일당 최대 5GB |
| 파일명 | `강사명_수업명_날짜.mp4` 형식 권장 |

> 중요: 휴대폰 기본 촬영 영상은 대부분 그대로 업로드할 수 있습니다. 안드로이드는 보통 `mp4`, 아이폰은 보통 `mov` 형식입니다.

> 주의: 5GB에 가까운 영상은 업로드 시간이 오래 걸리고 네트워크 상태에 따라 실패할 수 있습니다. 가능하면 안정적인 인터넷 환경에서 업로드해 주세요.

## 업로드 전 파일 체크리스트

- 영상 파일이 PC에서 정상 재생됩니다.
- 소리가 작거나 끊기지 않습니다.
- 화면이 가로 방향으로 정상 표시됩니다.
- 파일명이 수업 날짜와 강좌를 알아보기 쉽게 되어 있습니다.
- 파일 크기가 5GB 이하입니다.
- `avi`, `wmv`, `flv`, `3gp` 파일이 아닙니다.

## 전체 순서

```text
강좌 선택
→ 강좌 설정
→ 다음 클릭
→ 강의 생성
→ 영상 업로드 및 연결
→ 강의 제목 수정
→ 저장
→ 학생 화면 확인
```

> GIF 위치: 전체 업로드 흐름 요약  
> 추천 GIF: 강좌 선택부터 저장까지 20~30초 빠른 화면 녹화

## 영상 파일 이름 추천

영상 파일 이름은 나중에 다시 찾기 쉽도록 아래처럼 저장해 주세요.

```text
강사명_수업명_날짜.mp4
```

예시:

```text
김재하_실통수라이트_0711.mp4
유재석_수능영어실전A_0712.mp4
김정영_수능국어기본반_0713.mp4
```

## 강의 제목 규칙

강의 제목은 학생이 바로 알아볼 수 있게 `날짜 + 수업 내용`으로 적어 주세요.

| 좋은 예 | 아쉬운 예 |
| --- | --- |
| 07/11 수열 기본 개념 | 1강 |
| 07/13 수열 문제풀이 | 영상1 |
| 07/15 모의고사 해설 | 복습 |

## 1. 관리자 페이지에 로그인하기

1. 클킷 관리자 페이지에 접속합니다.
2. 학원에서 안내받은 아이디와 비밀번호를 입력합니다.
3. 로그인 버튼을 누릅니다.

> GIF 위치: 로그인  
> 추천 GIF: 관리자 페이지 접속 → 아이디 입력 → 로그인 클릭

## 2. 강좌 선택하기

1. 왼쪽 메뉴에서 `강좌 관리`를 누릅니다.
2. 강좌 목록에서 내가 올릴 수업을 찾습니다.
3. 강좌명을 확인하고 선택합니다.

> GIF 위치: 강좌 선택  
> 추천 GIF: 왼쪽 메뉴 `강좌 관리` 클릭 → 담당 강좌 검색/선택

확인할 것:

| 항목 | 기준 |
| --- | --- |
| 과목 | 담당 과목이 맞습니다. |
| 강사명 | 본인 이름 또는 담당 강사명이 맞습니다. |
| 반명 | 업로드할 반이 맞습니다. |

> 주의: 다른 선생님의 강좌에 영상을 올리지 않도록 강좌명을 꼭 확인해 주세요.

## 3. 강좌 설정으로 들어가기

1. 선택한 강좌의 관리 화면으로 들어갑니다.
2. `강좌 설정` 화면으로 이동합니다.
3. 강좌 정보가 맞는지 확인합니다.
4. 화면 하단 또는 우측의 `다음` 버튼을 누릅니다.

> GIF 위치: 강좌 설정 확인  
> 추천 GIF: 강좌 설정 화면 확인 → `다음` 버튼 클릭

## 4. 강의 생성하기

1. 다음 화면에서 `강의 생성` 버튼을 누릅니다.
2. 새 강의가 생성되었는지 확인합니다.
3. 아직 제목이 임시로 되어 있어도 괜찮습니다.

> GIF 위치: 강의 생성  
> 추천 GIF: `강의 생성` 버튼 클릭 → 새 강의가 목록에 추가되는 화면

## 5. 영상 업로드 및 연결하기

1. 생성한 강의를 선택합니다.
2. 영상 업로드 영역에서 업로드할 영상 파일을 선택합니다.
3. 업로드가 끝날 때까지 기다립니다.
4. 업로드가 완료되면 해당 영상을 강의에 연결합니다.
5. 강의에 영상이 연결되었는지 확인합니다.

> GIF 위치: 영상 업로드 및 연결  
> 추천 GIF: 영상 파일 선택 → 업로드 진행 → 강의에 영상 연결

업로드 중 확인:

| 항목 | 확인 기준 |
| --- | --- |
| 파일명 | 오늘 올릴 영상 파일이 맞습니다. |
| 업로드 상태 | 완료 상태가 표시됩니다. |
| 영상 연결 | 생성한 강의에 영상이 연결되어 있습니다. |

> 주의: 업로드 중에는 새로고침하거나 창을 닫지 마세요. 업로드가 실패할 수 있습니다.

## 6. 강의 제목 수정하기

1. 영상이 연결된 강의의 제목을 수정합니다.
2. 제목은 `날짜 + 수업 내용`으로 적습니다.
3. 필요하면 강의 설명을 짧게 입력합니다.

> GIF 위치: 강의 제목 수정  
> 추천 GIF: 임시 제목 선택 → `07/11 수열 기본 개념`처럼 제목 수정

제목 예시:

| 좋은 제목 | 피해야 할 제목 |
| --- | --- |
| 07/11 수열 기본 개념 | 1강 |
| 07/13 수열 문제풀이 | 영상1 |
| 07/15 모의고사 해설 | 복습 |

## 7. 저장하기

1. 영상이 강의에 연결되었는지 확인합니다.
2. 강의 제목이 맞는지 확인합니다.
3. `저장` 버튼을 누릅니다.
4. 저장 완료 메시지가 보이면 다음 단계로 이동합니다.

> GIF 위치: 저장  
> 추천 GIF: 영상 연결 상태 확인 → 저장 클릭 → 저장 완료 메시지 확인

## 8. 공개 상태 확인하기

1. 강의가 학생에게 보여야 하는 상태인지 확인합니다.
2. 비공개로 되어 있다면 공개 상태로 변경합니다.

> 이미지 위치: 공개 상태 확인  
> 추천 이미지: 공개/비공개 상태가 보이는 화면 캡처

| 항목 | 확인 기준 |
| --- | --- |
| 강좌명 | 내 수업이 맞습니다. |
| 강의 제목 | 날짜와 수업 내용이 맞습니다. |
| 영상 | 업로드와 연결이 끝났습니다. |
| 공개 상태 | 학생이 볼 수 있는 상태입니다. |

## 9. 학생 화면에서 확인하기

1. 가능하면 학생 화면 또는 미리보기 화면으로 이동합니다.
2. 방금 올린 강의가 보이는지 확인합니다.
3. 영상을 눌러 재생되는지 확인합니다.
4. 소리와 화면이 정상인지 확인합니다.

> GIF 위치: 학생 화면 확인  
> 추천 GIF: 학생 화면 또는 미리보기 화면 → 방금 올린 영상 클릭 → 재생 확인

## 문제가 생겼을 때

문제가 생기면 아래 정보를 운영 담당자에게 보내 주세요.

| 필요한 정보 | 예시 |
| --- | --- |
| 강사명 | 김재하 |
| 강좌명 | 수학 김재하 - 실통수 라이트 (수1&수2) |
| 강의 제목 | 07/11 수열 기본 개념 |
| 문제 상황 | 업로드가 80%에서 멈췄습니다. |
| 화면 캡처 | 오류 화면 캡처 |

## 자주 하는 실수

| 실수 | 해결 방법 |
| --- | --- |
| 다른 강좌에 영상을 올렸습니다. | 운영 담당자에게 잘못 올린 강좌명과 강의명을 알려 주세요. |
| 영상 업로드 중 창을 닫았습니다. | 다시 강의 화면에 들어가 업로드 상태를 확인하고, 실패했다면 다시 업로드해 주세요. |
| 영상은 올렸지만 강의에 연결하지 않았습니다. | 생성한 강의에 업로드한 영상을 연결해 주세요. |
| 제목을 수정하지 않았습니다. | 영상 연결 후 강의 제목을 날짜와 수업 내용으로 수정해 주세요. |
| 저장 버튼을 누르지 않았습니다. | 업로드 후 반드시 저장 버튼을 눌러 주세요. |
| 학생에게 영상이 안 보입니다. | 영상 연결 여부와 공개 상태를 확인해 주세요. |
| 영상은 보이는데 재생이 안 됩니다. | 다른 브라우저에서 확인한 뒤, 계속 안 되면 운영 담당자에게 알려 주세요. |

## 마지막 체크리스트

- 강좌명이 맞습니다.
- 강의 제목에 날짜가 들어갔습니다.
- 영상 업로드가 완료되었습니다.
- 영상이 강의에 연결되었습니다.
- 저장 버튼을 눌렀습니다.
- 학생 화면에서 영상이 재생됩니다.
